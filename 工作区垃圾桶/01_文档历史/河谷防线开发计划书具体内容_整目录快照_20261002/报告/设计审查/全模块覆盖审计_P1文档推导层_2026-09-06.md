### 1.2 P-1 阶段特殊发现（矩阵正式立项前置情报）

1. **RanchSystem 双缺**（#14/#15）：买幼崽/宰杀 API 已 kingdomId 参数化（HH.30 预留），但**玩家 UI 与 AI 行动两端都无入口**——「玩家能做的 AI 都要做」在此处前置翻转为「玩家自己也不能做」。修复归属需裁决（补玩家 UI+AI 行动 or 双端缓）。
2. **PatrolTaskSystem 玩家入口未接线**（#11）：API 存在（StartPatrol 三重载）+交互入口 2_13 预留未落——与 2_22 P0「AI 驻防巡逻驱动」同域，建议合并裁决（AI 驱动为主、玩家入口是否补为次）。
3. **D545 对称典范清单（已 kingdomId 参数化的玩家 API）**：BuildController.TryBuild / TrainingSystem.TryTrain / RanchSystem.BuyCub+Slaughter / TradeSystem（国库域）——AI 通道预埋完成度好，缺口集中在**行动池消费端**（AI 没有对应行动定义）而非 API 供给端。
4. **AI 行动池现状**（UtilityActionConfig.cs HH.86 施工后实读）：21 行动=15 原有（①~⑥+⑦~⑮按序）+6 新增（建井/铁匠/战争学院/战营/熔炉/射箭场）；建造类 11 条带 buildingId+成本镜像；buildTargetCap 连轴守卫（DZ-041）已入。
5. **FormulationPanel 疑云**（注册底表 E12 同族）：底表 UI 全家列 Systems/UI/FormulationPanel——实盘 283 文件无此文件；TradePanel/FormationPanel 均在。待 P-2 定性（文档笔误 or 未实施规划件）。
