## 一、定位

**中心任务调度**（ScheduleCenter，类名 `ScheduleCenterStub` 兼容旧引用）是王国所有"工人干活"类任务的统一派发口。职责是**检测触发 → 找空闲工人 → 注入任务刺激**，由工人 AI 大脑驱动执行。

它只负责"派发"，不负责"决定做什么"（决策在 AI 大脑）也不负责"怎么执行"（执行在工人行为）。

## 二、职责范围

| 任务方向 | 触发源 | 现状 |
|---------|--------|------|
| 搬运 | 产能建筑存储达标（StorageComponent） | ✅ 已实现 |
| 操作战争机器 | 机器缺工人 + 附近有敌 | ✅ 已实现 |
| 建造 / 升级 / 重建 / 修复 | 建筑放置 / 废墟（3.5.3 §七） | ❌ 待扩展 |
| 生产（采集/种植/加工/挑水/养殖） | 建筑需工人（3.5.3 §八） | ❌ 待扩展 |

## 三、派发机制

### 3.1 流程
```
每秒 tick：
  1. 遍历触发源（建筑/机器）
  2. 跳过已有任务中的（_transporting 标记，防重复）
  3. 找空闲工人（IsIdleForTask：无战斗/无进行中任务）
  4. 派发：npc.AddTaskStimulus(new TaskStimulus(优先级, 位置, 强度, expiry, issuer))
  5. 任务完成（建筑清空/机器满编）→ 释放标记
```

### 3.2 关键规则
- **防重复**：`_transporting` 标记（建筑 → 状态），任务完成后释放。
- **任务生命周期**：刺激带 `expiry`——工人被打断没去 → 刺激过期自然消失 → 下 tick 重派。
- **昼夜节律**：夜间停发 B/C 户外任务（防"白派活、威胁层就撤退"冲突）。
- **空闲判定**：`IsIdleForTask` = 当前焦点无效 / 是 Wander/Follow（无进行中工作任务）。
