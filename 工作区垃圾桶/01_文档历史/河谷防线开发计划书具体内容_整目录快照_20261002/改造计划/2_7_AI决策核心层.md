## 一、老系统与新系统的衔接

### 1.1 现状（1D 决策核）

老 `AI.Core`（L1 焦点/L2 姿态/L3 指令）：
- 三层管线 + 记忆组件群 + 反馈控制环
- **距离类输入用轴距离**（1D 直线=真距离）：
  - `NearestEnemyDist`、`baseRetreatCells`、`FormationChaseRangeCells`、任务按距离排序
- `Vector2X` 解耦层已是最大迁移资产

### 1.2 核心变化

```
1D：距离类输入 = 轴距离（直线=真距离）
2D：距离类输入 = 格单位分量归一化欧氏（doc 1 §1.6）+ 成本场（AI 看见威胁绕路）
```

**三层管线保留**（L1/L2/L3 + 记忆组件），只改：
1. 距离类输入 → 格单位距离
2. 接入成本场（大脑成本偏好 → 2_6 成本场）
3. 撤退/槽位 2D 化

## 五、要开发的新系统（详细设计）

### 5.1 距离 2D 化

```
NearestEnemyDist = GridMath.DistCells(self, enemy)     // 格单位，§1.6
baseRetreatCells / FormationChaseRangeCells = 格单位阈值（SO）
任务距离排序 = GridMath.DistCells
方向类输入 = 格空间归一化向量（来袭方位扇区，8 向量化）
```

### 5.2 成本场决策接入（AI 看见）

```csharp
/// <summary>L3 输出的行为指令（核心层→工具层契约）。</summary>
public struct BehaviorCommand
{
    public GridCoord goal;              // 目标微格
    public CostBias bias;               // 成本偏好
    public byte priority;
}

public struct CostBias
{
    public float threatWeight;          // 威胁带惩罚（占位 2.0）
    public float safetyWeight;          // 安全区吸引（占位 0.5）
    public float formationWeight;       // 编队位吸引（占位 0.8）
}
```

```
大脑输出 BehaviorCommand = {目标, 成本偏好}
→ 2_6 CostFieldBuilder 合成微格成本（P1）
→ 寻路在成本场上绕开威胁
成本权重先 SO 手配，2_9 入训后由训练产出替换
```

> 合成公式见 2_6 §5.3（D250，2026-08-14 终审修订）：costField=clamp(1+2.0×threat-0.5×safety-0.8×formation, 0.1, 10)；寻路代价=terrainCost×costField。

### 5.3 撤退逃逸点算法（2026-08-13 审计定细）

> ⚠️ 实况对照（2026-08-29 裁决修订 D414）：现役实现 = `Systems/AI/EscapePointSampler.cs`，非下方 24 候选点纯采样——代码在等分采样基础上引入「最近威胁方向 + 多敌分布」做**期望方向加权**（敌方向反向叠加/近敌权重大 → 扇区加权优先期望方向 + 避敌惩罚 + distBias），保住"往敌稀疏/开口侧逃"的语义差异。下方算法为设计底稿，与代码的差异=期望方向加权 + sim 新输入（见文件头 sim 差距注，训练回灌 champion 会错位，已登记附加条件②）。

```
输入：单位位置 P、最近威胁方向 D（格空间归一化）、撤退距离 R_cells（RetreatFormulas）
1. 扇区：以 -D 为中心 ±60° 的撤退扇区
2. 采样：扇区内按半径 R×{0.6, 0.8, 1.0} 三圈 × 每圈 8 方向 = 24 候选点（固定顺序，确定性）
3. 过滤：候选点必须 IsWalkable 且 IsReachable(P→候选)（2_6 P1；P1 前退化为 IsWalkable）
   硬约束：剔除 dist(P,候选) > R×1.2 的候选点（防跨图撤退，D264，2026-08-14 终审修订）
4. 评分：score = costField(候选) + 0.5×|dist(P,候选) - R|（贴近理想撤退距离；距离项权重由 0.2 上调至 0.5，D264，2026-08-14 终审修订）
5. 取 score 最小的候选为 EscapePoint；全部失败 → 原地固守（L2 转防御姿态）
```

### 5.4 编队槽位（2D）

```
槽位 = 2D 形状（线/圆/楔形）带朝向（朝向敌人/前进方向，2_8 D2）
生成：以锚点+朝向做形状公式展开槽位坐标（格单位）
校验：槽位必须可走（微格 IsSubWalkable）；不可走 → 沿朝向反方向回缩 1 格重试（≤3 次）
FormationBrain 意图自决/军令强度保留
```
