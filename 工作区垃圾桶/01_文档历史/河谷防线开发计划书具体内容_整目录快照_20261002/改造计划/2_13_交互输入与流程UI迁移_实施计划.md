### 步骤 3：SelectionController 新增（上帝视角核心）

**文件**：新增 `Systems/Interaction/SelectionController.cs`

**设计 §5.2**：
```csharp
public class SelectionController : Singleton<SelectionController>
{
    public List<UnitController> Selected { get; }   // 框选/点选集合（己方）
    public Building SelectedBuilding { get; }        // 点选建筑（独立于单位选择）
    public void BeginDrag(Vector2 screenPos);        // 左键按下（候选框选）
    public void EndDrag(Vector2 screenPos);          // 左键抬起 → 判定点击/框选
    public void IssueRightClick(Vector2 worldPos);   // 右键指令（归 2_8）
    public void DeployGuard(GridCoord target);       // 守卫部署（D116）
    public void PrioritizeHarvest(GridCoord resource);// 微操（D115）
}
```

**实现逻辑**：
- 订阅 `LeftClickPressedEvent` / `RightClickPressedEvent`（InputManager 发布）
- 框选阈值：`SelectionConfig.dragThresholdPx`（SO，默认 5px）
  - 拖拽距离 ≤ 阈值 → 点选（射线找最近可交互物）
  - 拖拽距离 > 阈值 → 框选（屏幕矩形 → 世界矩形 → `GridSystem.GetUnitsInRect` → 过滤 **kingdomId==0**（己方=玩家王国 0，2_16实施 步骤7 补丁2 现行；2026-08-29 裁决修订 D414，取代"faction=己方"））
- 框选矩形：`new Rect(dragStart, dragEnd - dragStart)` 屏幕像素
- 点选：优先 `IInteractable`（建筑/资源点），回落 `IClickInteractable`（NPC）
- 右键指令：
  - 有选中集 → 发布 `UnitCommandEvent(BattleCommand.MoveTo, worldPos)` 等（2_8 消费）
  - **右键点己方单位 = 跟进（Follow：跟随目标单位移动，D2，2026-08-14 终审修订，D2XX）**
  - 空选 → 清除选择
- 微操（D115）：选中工人 + 右键资源点 → `PrioritizeHarvest(GridCoord)`
- 守卫部署（D116）：选中士兵 + 右键高价值点 → `DeployGuard(GridCoord)`

**框中可视化**：`OnGUI` 或 `Debug.DrawLine` 临时画框选矩形（阶段 0 占位，正式渲染归 2_10）

**验收**：
