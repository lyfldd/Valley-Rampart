### 1.1 核心接口：IAIDebugInfoExtended

public interface IAIDebugInfo

### 1.2 数据结构

```csharp
// 焦点/谱系切换记录
public struct AISwitchRecord
{
    public readonly float Timestamp;           // 发生时间（Time.time）
    public readonly Focus OldFocus;            // 切换前焦点
    public readonly Focus NewFocus;            // 切换后焦点
    public readonly BehaviorSpectrum OldSpectrum;  // 切换前谱系
    public readonly BehaviorSpectrum NewSpectrum;  // 切换后谱系
    public readonly string Description;        // "焦点切换: 威胁->任务" 等
}

// 刺激源调试信息
public struct StimulusDebugInfo
{
    public readonly AttentionLayer Layer;      // 层（Threat/Hate/Task/Perception/Curiosity）
    public readonly float Intensity;           // 强度 0-100
    public readonly Vector2 Position;          // 焦点位置
    public readonly bool IsFocus;              // 是否为当前焦点
}

// 快照（UI 每帧调 GetSnapshot() 获取全部数据）
public struct AIDebugSnapshot
{
    public bool HasSelection;                  // 是否有选中 NPC
    public string NPCName;                     // NPC 名称
    public Vector2 NPCPosition;                // NPC 位置
    public float HPRatio;                      // 血量 0-1
    public Focus CurrentFocus;                 // 当前焦点
    public BehaviorSpectrum CurrentSpectrum;   // 当前谱系
    public ThreatLevel CurrentThreatLevel;     // 威胁等级
    public int NearbyEnemyCount;               // 附近敌人数
    public int NearbyAllyCount;                // 附近友军数
    public bool HasProtection;                 // 有保护
    public bool InSafetyConfirmation;           // 安全确认中
    public bool IsInHitCooldown;               // 受击冷却中
    public List<StimulusDebugInfo> TopStimuli;      // 刺激源排行前5
    public List<AISwitchRecord> RecentSwitches;    // 切换历史前5
}
```

## 二、控制器接口：AIDebugController

UI **只与此控制器交互**，不直接访问 NPCBrain。

### 2.1 获取控制器

```csharp
AIDebugController.Instance  // 自动创建单例
```

### 2.2 公开 API

| 方法/属性 | 说明 | UI 调用时机 |
|-----------|------|------------|
| `bool IsDebugMode { get; }` | 调试模式是否开启 | 每帧判断是否显示面板 |
| `IAIDebugInfo SelectedBrain { get; }` | 当前选中的 NPC | 判断有无选中 |
| `GameObject SelectedGameObject { get; }` | 选中的 GameObject | 高亮/标注 |
| `void ToggleDebugMode()` | 切换调试模式 | F1 键按下时 |
| `void ClearSelection()` | 清除选择 | ESC / 切换模式时 |
| `bool TrySelectAtWorldPosition(Vector2 worldPos, float maxDistance=1.5f)` | 在世界位置选择最近的 NPC | 鼠标点击时 |
| `void SelectNPC(IAIDebugInfo brain, GameObject go)` | 直接选择（UI 自行 raycast 时） | 备选方案 |
| `AIDebugSnapshot GetSnapshot()` | 获取当前选中 NPC 的全部数据 | **每帧调用渲染面板** |

### 2.3 典型调用流程

```csharp
// 1. F1 切换调试模式
if (Input.GetKeyDown(KeyCode.F1))
    AIDebugController.Instance.ToggleDebugMode();

// 2. 调试模式下，点击选择 NPC
if (AIDebugController.Instance.IsDebugMode && Input.GetMouseButtonDown(0))
{
    Vector2 worldPos = Camera.main.ScreenToWorldPoint(Input.mousePosition);
    AIDebugController.Instance.TrySelectAtWorldPosition(worldPos);
}

// 3. 每帧获取数据渲染面板
if (AIDebugController.Instance.IsDebugMode)
{
    AIDebugSnapshot snapshot = AIDebugController.Instance.GetSnapshot();
    if (snapshot.HasSelection)
        RenderPanel(snapshot);  // UI 自行实现
}
```

## 五、技术实现要求

### 5.1 UI Toolkit

- **UXML** 定义布局结构
- **USS** 定义样式（颜色、字体、间距）
- **C# (UIManager)** 处理交互逻辑（F1、点击、每帧刷新）
- 符合项目 UI 全面迁移惯例

### 5.2 面板样式要求

- 半透明背景（不遮挡游戏画面）：`background-color: rgba(0,0,0,0.75)`
- 可拖动（DraggableManipulator 或自行实现）
- 可折叠（点击标题栏折叠/展开）
- 固定在左上角（position: absolute; left: 0; top: 0）
- 字体等宽（MonoSpace / JetBrains Mono）

### 5.3 NPC 高亮（可选）

选中 NPC 后，可在其头顶画一个标记：
- 方案 A：SceneView + GameView 都画 Gizmos（简单）
- 方案 B：在 NPC 位置实例化一个 Sprite/Line（GameView 可见）
- 首版可用方案 A，后续再优化

### 5.4 性能

- `GetSnapshot()` 每帧调用，内部已用缓冲池避免 GC
- 调试面板只在 `IsDebugMode == true` 时渲染
- 未选中 NPC 时面板隐藏或显示"请选择 NPC"

## 七、完整代码调用链示例

```csharp
// AIDebugUIManager.cs（UI 实现）
using UnityEngine;
using UnityEngine.UIElements;

public class AIDebugUIManager : MonoBehaviour
{
    [SerializeField] private UIDocument _document;
    private VisualElement _root;
    private Label _npcNameLabel;
    // ... 其他 UI 元素引用

    private void Start()
    {
        _root = _document.rootVisualElement;
        _npcNameLabel = _root.Q<Label>("npc-name");
        // ... 初始化 UI 元素
        _root.visible = false;
    }

    private void Update()
    {
        // F1 切换
        if (Input.GetKeyDown(KeyCode.F1))
            AIDebugController.Instance.ToggleDebugMode();

        bool show = AIDebugController.Instance.IsDebugMode;
        _root.visible = show;
        if (!show) return;

        // 点击选择 NPC
        if (Input.GetMouseButtonDown(0))
        {
            Vector2 worldPos = Camera.main.ScreenToWorldPoint(Input.mousePosition);
            AIDebugController.Instance.TrySelectAtWorldPosition(worldPos);
        }

        // ESC 清除
        if (Input.GetKeyDown(KeyCode.Escape))
            AIDebugController.Instance.ClearSelection();

        // 每帧刷新面板
        var snapshot = AIDebugController.Instance.GetSnapshot();
        if (snapshot.HasSelection)
            RenderSnapshot(snapshot);
    }

    private void RenderSnapshot(AIDebugSnapshot s)
    {
        _npcNameLabel.text = s.NPCName;
        // ... 渲染所有字段
    }
}
```

> 2026-08-01 扩展。F1 调试面板新增 Tab 切换和放置士兵功能。

### 10.1 功能描述

- **Tab 切换**：开发者面板顶部新增一排按钮，第一个 Tab 为"AI 可视化"（原面板），第二个 Tab 为"放置士兵"
- **放置士兵**：点击"放置士兵" Tab 后，显示 6 种单位类型按钮（己方将军/士兵/弓手/工人 + 敌方士兵/弓手）
- **放置交互**：点击单位类型按钮后，隐藏 F1 面板，左键连续放置，右键/ESC 退出放置模式
- **UI 栈集成**：放置模式压入 UI 栈（AIDebugSpawnEntry），ESC 由 UIManager.HandleEscape() 统一处理

### 10.5 UI 栈结构（三层）

```
调试模式层（AIDebugModeEntry）
  └─ 交互态层（AIDebugInteractionEntry）
       └─ 放置模式层（AIDebugSpawnEntry）← 新增
```

- **F1** → 压入/弹出调试模式层
- **点击 NPC / 选择 NPC** → 压入/弹出交互态层
- **进入放置模式** → 压入放置模式层
- **ESC / 右键** → 从栈顶往下 Pop（先出放置模式 → 再出交互态 → 再出调试模式）

### 10.6 交互流程

1. **F1** → 开启调试模式，显示开发者面板（默认"AI 可视化" Tab）
2. **点击"放置士兵" Tab** → 切换到放置内容区，显示 6 种单位按钮
3. **点击单位按钮** → 隐藏 F1 面板，压入 AIDebugSpawnEntry，进入放置模式
4. **左键点击场景** → 在鼠标位置生成单位（可连续放置）
5. **右键 / ESC** → 退出放置模式，弹出 AIDebugSpawnEntry，恢复 F1 面板
6. **再次 F1** → 关闭调试模式，清理所有栈条目

### 10.7 验证方式

- 场景：GameScene
- 步骤：
  1. 按 F1 开启调试模式
  2. 点击"放置士兵" Tab
  3. 点击"己方士兵"按钮
  4. 左键点击场景多处，验证连续生成
  5. 按 ESC 或右键，验证退出放置模式
  6. 按 F1 关闭调试模式，验证栈清理
