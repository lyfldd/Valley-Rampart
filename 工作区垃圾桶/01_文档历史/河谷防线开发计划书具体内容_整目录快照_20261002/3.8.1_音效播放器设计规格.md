## 〇、一句话定位

**分层的喇叭，不是混音台**：给定"谁在做什么"，按注意力权重决定**听什么、什么时候响、同时响几个**。不含混响/空间化编辑/DSP 创作/上下半身分层——那些是 DAW 与骨骼音频的活，帧精灵 + 2D/3D 点音源用不到，全部明确不做（§八）。

## 一、关键裁决记录（用户 2026-09-13 逐点裁定）

### 1.1 取态范式：**直调**，不走 EventBus

原 3.8 定「表现层只读订阅 EventBus 可听事件白名单」。**改判**：

| 判据 | 说明 |
|---|---|
| 现库事件面不足 | 全库 ~60 个 `EventBus.Publish` 点，逐条核对后 **18 条音效里 11 条无触发源**（采集劳作/施工中/搬运/远程发射/野怪/灭国/UI 点击 全无事件） |
| 同域已有对称先例 | `SpriteAnimatorSystem` 由状态源**直调** `SetState(unit, AnimState)`；音效走总线＝**同一个状态两套取法**（2_24 §二红线） |
| 结论 | 对齐美术侧：`NPCBrain` / `TaskScheduler` / `DamageSystem` / `ProjectileManager` **直调**音效入口。**零新增 EventBus 事件，「触发源缺口」直接消失** |

> 推论：3.8 §1.2 的 `AudioEventRouter`（职责＝订阅 EventBus 并过滤）**在直调范式下不存在**，其"过滤可见性/距离 → 产出请求"职责并入 `AudioDirector`。组件由 4 个收拢为 **3 个**（§2.2）。

### 1.2 锚点：劳作音挂**工人**，不挂建筑

用户原话：「我要的是**工人在农田劳作**的那个音效，不是**农田**的音效」。

- A1/A2/A3/A3b 四条的宿主 = **NPC 工人**（3D 跟随、工人 Working 才响、人走音走）
- 直接收益：触发源从"树林/矿洞/采石场/农场各发一个事件"压成 **`TaskScheduler` 在 `Working` 起止发一次直调、带工种字段**，四条一起解决
- 配套佐证：美术侧 `AnimState.Attack` 是**工人 Working 的共用挥舞动画**（`SpriteAnimator 规格 §五`），即**视觉不分工种** → **声音是唯一工种区分手段**

### 1.3 焦点模型：**三因子**（视口 ＋ 镜头中心距离 ＋ 玩家注意力锚点）

- **视口矩形**：决定「能不能播」（硬闸门，沿用 3.8 视线三区）
- **镜头中心距离**：决定「多重要」（软权重，进 priority）
- **玩家注意力锚点**：鼠标投影到地图的那个世界点，额外加权 —— 玩家正看的地方更响

> 白赚收益：**注意力锚点与 zoom-to-cursor 的缩放锚点是同一个点**。实现一次，音效加权与相机缩放共用同一份输入。

### 1.4 排序：**重要度分层**，不破"不分阵营"红线

3.8 原定「纯 priority，严格不分阵营」→ **改判**为**按行为类型分层**：

```
战斗/威胁  >  建造  >  采集
```

- 这是**按行为类型**分层，**不是按阵营过滤** → 红线（对全阵营一视同仁）**仍然成立**，无需开口子
- 动机：同屏 AI 单位远多于玩家，若纯拼 priority，AI 的伐木音会把 12 条预算吃满、玩家自己的工坊反而不响

### 1.5 倍速：**pitch 微升（SO 可调）＋ loop 改按次触发**

**实盘倍速为 4 档**（`0.5x / 1x / 2x / 3x`），非 3.8 所写的"0.5x~15x"：

```
SettingsPanel.uxml:25-28 / TopLeftHUD.uxml:37-40  →  0.5x / 1x / 2x / 3x
TimeManager.cs:82   kGameSpeeds = { 0.5f, 1f, 2f, 3f }        ← 活的
TimeManager.cs:339  SetGameSpeed()  ← 被 SettingsPanel.cs:90 / TopLeftHUD.cs:152 调用
TimeManager.cs:306  SetTimeScale()  ← 全库零调用（死代码）
```

- **BGM 不加速**（氛围层，加速变调且破坏情绪）
- **音效**：`pitch = 1 + k × max(0, timeScale − 1)`，`k` 与封顶值**走 SO**（`so-data-driven` 铁律，禁硬编码）
  - **只上行**：`0.5x` 档**不降 pitch**（降八度会低沉怪异）
  - 出厂建议 `k=0.05`、封顶 `1.12` → `0.5x→1.00  1x→1.00  2x→1.05  3x→1.10`
- **哪些变速**（判据：该音效的「语义时长」是否挂钩游戏世界时间）：

| 变速 ✅ | 不变 ❌ |
|---|---|
| A1/A2/A3 劳作、A3b 农作、A5 施工 | A5b 完工升级、A6 拆除倒塌、A11 立国/灭国 |
| A8 近战命中、A9 远程命中、A10 野怪 | B1~B4 环境、C BGM、D UI 点击 |

- **loop 改按次 one-shot**：伐木/施工由"长 loop"改为"敲一下响一声"的密集 one-shot
  - 收益①：密度自动跟倍速，不变调，节拍天然咬合
  - 收益②：**同时解决防齐声**（长 loop 无法随机化相位，一旦错开就永久错开）

### 1.6 时间基

- **BGM / 环境 / UI**：`unscaled`（不受倍速）
- **世界音效**：随倍速的只是 **pitch 微升**（§1.5），**播放速率本身不变调**
- 与美术侧 `Time.deltaTime`（scaled）的分工：动画随倍速加速，音效靠"按次触发密度 + pitch 微升"咬合，**不使用 scaled**（避免高倍速下整体变调失真）

### 1.7 可见性判据：**抽公共只读服务**

现全库**只有一处**实现（`OverheadSpeechManager.IsInView` = `WorldToViewportPoint` + `[-0.1, 1.1]` 边缘带）。3.8 §1.4 计划**再写一套**（视口＋边缘带＋zoom 三档）→ 两套判据必然漂移。

**裁决**：抽成**公共只读服务**（世界坐标 → 是否可见 ＋ 边缘带档），字 / 音效 / 将来的染色视口分级**共用一个真源**，边缘带宽度与 zoom 档只有**一个配置点**。

### 1.8 LOD：**双轴分治**

| 轴 | 权威 | 理由 |
|---|---|---|
| **能不能听到** | **视口（玩家视角）** | 相机拉远时，哪怕区块 AI 热度爆表，玩家也看不见 → 不该全播 |
| **播放精度/更新频率** | **`LodLevel`（复用既有，与美术同源）** | 性能问题，不另建 LOD 系统 |

> 反面案例（硬合一必翻车）：相机拉到最近、玩家正盯着伐木场看，但该区块 AI 热度低 → `LodLevel=远` → **盯着看却没声音**。

### 1.9 裁剪范围（用户裁定）

| 条目 | 裁定 |
|---|---|
| A7 搬运·装卸 | **不做** |
| A8 战斗 | **只要「近战命中」1 条**（挥击起手砍、格挡砍） |
| A9 战斗 | **只要「远程命中」1 条**（发射音砍） |
| 命中音材质分层 | **不做**（不分金属/血肉/木石） |
| A11 立国/灭国 | **两条都做**（灭国需新产素材 ＋ 新增灭亡管线直调点） |
| D UI 点击 | **做**，**新产专用**（不拿战斗/环境素材凑） |
| B4 天气 | **备资产、不等系统**（源库 Rain/Storm 现成，先备素材与 `AudioEventMap` 条目） |

> ⚠️ **「格挡」为凭空条目**：全库只有 `Occupation.ShieldGuard`（盾卫**兵种**），**无任何格挡/招架判定** → 3.8 的 A8「格挡」与 A9「野怪撕咬」同性质：素材与机制皆无，砍除。

## 二、架构

### 2.1 数据流

```
NPCBrain / TaskScheduler / DamageSystem / ProjectileManager（状态源·唯一）
    │ PlayWorld(AudioKey, worldPos, host, ownerId) / StopWorld(handle) / PlayUI(key) / PlayBgm(slot)
    ▼
AudioDirector（单例·GameScene 音频根·直调入口）
    ├─ 可见性门限（公共只读服务）→ 距离/最大可听半径 → priority 计算
    ├─ 产出 AudioRequest（类目/坐标/重要度/变体池/宿主句柄）
    ▼
VoiceManager（播放器核心 · 与 SpriteAnimatorSystem 同构）
    ├─ VoiceRecord[] 平铺结构体数组（handle/host/key/startAt/expireAt/priority/source）
    ├─ AudioSource 池（PlayOneShot 复用）＋ 类目→变体池注册表（共享引用）
    └─ 遍历：过期回收 / 窗口合并 / 分层抢占 / 脏写（仅在换声时操作 source）
    ▼
AudioSource（2D/3D 点音源）
CameraRig.zoom ──► ZoomAudioMixer（三档 crossfade ＋ Ducking）──► AudioMixer 各音轨增益
SettingsPanel ──► AudioConfig 四轨音量
```

### 2.2 职责分工（3 组件）

| 组件 | 职责 | 不做 |
|---|---|---|
| `AudioDirector` | 总控：直调入口、可见性门限、priority 计算、分层预算、生命周期编排（含 `ResetState`） | 不管播放句柄、不碰 Mixer 增益 |
| `VoiceManager` | 播放器本体：池 / 按次触发 / 窗口合并 / 变体随机 / pitch 曲线 / 宿主销毁清理 / 回调 | 不做决策、不反向驱动逻辑（红线） |
| `ZoomAudioMixer` | zoom → 各音轨增益插值、三档 crossfade、Ducking | 不决定"听什么"（只决定"多响"） |

> **组件数 4 → 3**：原 `AudioEventRouter` 的"订阅 EventBus"职责在直调范式下不存在，其余职责并入 `AudioDirector`。

## 三、数据结构（建议草案）

> 执行端可按实现微调字段组织，**但不得违反 §六纪律与 §四功能口径**。

```csharp
public enum AudioLayer { BGM, Ambient, WorldSFX, UI }        // 分层预算域
public enum AudioCategory { Harvest, Construction, Combat, Threat, Kingdom, Ambient, BGM, UI }
public enum SpatialMode { TwoD, ThreeD }
public enum PlayKind { Once, Burst }                          // 一次性 / 按次密集（原 loop）

// 播放器平铺数组元素（SOA/AOS 皆可，取连续内存）
struct VoiceRecord {
    int handleId;  Transform host;  AudioKey key;
    AudioLayer layer;  AudioCategory category;
    float startAt;  float expireAt;      // unscaled 时间
    float priority;  int ownerId;
    int sourceIndex;                     // 池槽位
    bool active;
}

// 直调请求（进队后由 AudioDirector 排序/抢占）
struct AudioRequest {
    AudioKey key;  Vector2 worldPos;  Transform host;
    float importance;                    // 0..1，来自 AudioEventMap
    int ownerId;                         // 归属王国（**只用于统计/调试，禁用于过滤**）
    float timeScaleAtCall;               // 调用时倍速，用于 pitch 曲线
}
```

**表面 API**：

- `PlayWorld(AudioKey key, Vector2 worldPos, Transform host, int ownerId)` → 返回 `handleId`（`-1` = 被丢弃）
- `StopWorld(int handleId)` / `StopAllOfHost(Transform host)`
- `PlayUI(AudioKey key)` / `PlayBgm(BgmSlot slot)` / `StopBgm()`
- `ResetState()` —— 清池 / 清队列 / 清 active / 还原 Mixer
- 预留 `OnVoiceEnd(handleId)` 结束回调（**只预留不接逻辑**，表现禁驱动逻辑）

**SO 配置**（`AudioConfig`，遵 so-data-driven）：

| 字段 | 出厂建议 | 说明 |
|---|---|---|
| `maxWorldVoices` | 12 | 世界 SFX 并发上限 |
| `poolCapacity` | **24** | = 世界 12 + 环境 4 + UI 4 + BGM 1 + 抢占余量 3（用户裁定之值） |
| `ambientVoices` | 4 | 环境层预算 |
| `uiVoices` | 4 | UI 层预算（独立池，不占世界预算） |
| `sameTypeWindowMs` | 120 | 同类窗口合并 |
| `pitchJitterPercent` | ±10~15 | **防齐声**（3.8 原 ±5 不足，见 §1.5 收益②） |
| `volumeJitterDb` | ±3 | 同上 |
| `speedPitchK` | 0.05 | 倍速 pitch 系数（§1.5） |
| `speedPitchCap` | 1.12 | pitch 封顶 |
| `crossfadeSec` | 0.8 | zoom 档 crossfade |
| `duckDb` / `duckAttackMs` / `duckReleaseMs` | −8 / —/ — | 高重要度事件压低 BGM/环境 |
| `zoomBandThresholds` | 三档 | 缩放档阈值 |
| `edgeBandPercent` | 10~20 | 可见性边缘带（**由公共只读服务持有**，§1.7） |
| `priorityWeights{w₁..w₄}` | — | 重要度 / 接近度 / 距离 / 最近播放惩罚 |
| `maxAudibleRadiusDefault` | — | 默认最大可听半径 |

## 四、功能规格（F-01~F-18）

| # | 功能 | 口径 | 依据 |
|---|---|---|---|
| F-01 | **直调入口** | 状态源直调 `PlayWorld/PlayUI/PlayBgm`；**不订阅 EventBus**；未在 `AudioEventMap` 白名单的 key = 不发声 | §1.1 |
| F-02 | **三因子 priority** | `priority = w₁·重要度 + w₂·接近度 + w₃·(−距离) − w₄·最近播放惩罚 + w₅·注意力锚点加成` | §1.3 |
| F-03 | **注意力锚点** | 鼠标投影世界点；与 zoom-to-cursor 共用同一份输入（`CameraRig` 提供只读访问器） | §1.3 |
| F-04 | **并发预算 ＋ 分层抢占** | 命中上限：新 `priority` > 当前最低 → **抢占**（被抢者 **0.1s fade-out** 防爆音）；否则**丢弃**（**不排队** —— 声音延迟 200ms 即音画不同步，与头顶冒泡的"排队"策略**本质不同**，禁照抄） | §1.4 |
| F-05 | **重要度分层** | 战斗/威胁 > 建造 > 采集；**分层是行为类型，非阵营**（红线不动） | §1.4 |
| F-06 | **同类窗口合并** | 同 key 在 `sameTypeWindowMs(120ms)` 内合并为单次代表音，音量按计数对数微增 | 3.8 §1.5③ |
| F-07 | **防齐声（随机化）** | 每次触发独立随机 `pitch ±10~15%` ＋ `音量 ±3dB`；配合 §F-08 逐次随机（长 loop 无法随机化相位，故不采用） | §1.5 |
| F-08 | **按次密集触发（Burst）** | 劳作/施工由长 loop 改为密集 one-shot；**密度自动跟倍速**，不改播放速率 | §1.5 |
| F-09 | **倍速 pitch 曲线** | `pitch = 1 + k×max(0, timeScale−1)`，**只上行**，封顶 `1.12`；`k`/封顶走 SO；**仅"受时间影响"的条目**（清单见 §1.5 表） | §1.5 |
| F-10 | **PlayOneShot 复用** | 同类 one-shot 共用一个 `AudioSource`（`PlayOneShot`），禁每声一个 source | 2_2 池化红线 |
| F-11 | **可见性门限** | 视口内 full / 边缘带弱化 / 带外不播；**判据来自公共只读服务**（与头顶冒泡同源） | §1.7 |
| F-12 | **距离 × 半径** | 3D 距离衰减 ＋ 每类 `maxAudibleRadius`（超出不播＝省预算） | 3.8 §1.5⑤ |
| F-13 | **暂停 / 失焦** | 暂停：留 BGM、静 Ambient+SFX；**恢复＝续播（保留进度）**，不从头重播；失焦：整体静音 | §1.9 裁定 |
| F-14 | **loop 收尾** | 宿主销毁 / 建筑拆除 / 工人死亡 → **即停 ＋ 0.1s 淡出** ＋ 归还池（对齐美术侧 `OnDestroy 必注销`，防池泄漏） | §1.9 裁定 |
| F-15 | **缺素材回退** | 静默跳过 ＋ **一次性告警**（负查询缓存，禁逐帧刷日志）；不崩，不阻断游戏 | 3.8 §六 |
| F-16 | **Ducking** | `重要度≥高` 事件（战斗/立国）触发 → BGM/Ambient 自动 −6~−10dB，播完恢复；**与 BGM 切换叠加时须合并为单条曲线**（防两套淡入淡出打架） | 3.8 §1.5④ |
| F-17 | **BGM 编排** | C1 菜单 / C2 和平 / C3 警戒 / C4 战后过渡；**C3→C2 经 C4 落点**；随机池不重复；常驻不加速（3.8 §2.3.1） | 3.8 §2.3 |
| F-18 | **调试面板** | 实时 active voices / 12 条预算占用 / 最近触发列表 / 抢占计数 / 被丢弃计数（**抢占是黑盒，无观测无法调参**） | §1.9 裁定 |
| F-19 | **池复位** | `ResetState()` 清池 / 清队列 / 清 active / 还原 Mixer 增益（守 `WorldLifecycle` / L-22 纪律，多次建局零残留） | 3.8 §4.2 |

| 音效条目 | 状态源（直调方） | 调用时机 | 备注 |

## 六、实现纪律（硬）

1. **零世界写入**：音频开关两态下同 seed 世界状态**逐字节一致**（表现层铁律）。
2. **直调单向**：音效只消费状态，**禁反向驱动逻辑**（表现禁驱动逻辑红线）。
3. **不排队**：超预算即丢弃（区别于头顶冒泡的排队策略）；实时音频宁可缺、不可迟。
4. **零 GC**：遍历路径零分配（无 LINQ／无闭包／无字符串拼接）；变体池注册表一次构建。
5. **枚举键**：`AudioKey` 用 int 枚举，**禁每帧字符串比较**。
6. **禁每声 new**：`AudioSource` 一律池化 ＋ `PlayOneShot` 复用。
7. **池成对**：借出↔归还、`Subscribe↔Unsubscribe`（若未来有）、Mixer 改值↔`ResetState` 还原，**全部成对**。
8. **不引导**：声音不做"D380 引导"（不提示"该去点哪"）。
9. **不分阵营**：`ownerId` 只进统计/调试，**禁进过滤**。
10. **静默回退**：缺素材负查询缓存 ＋ 一次性告警（禁刷屏）。
11. **scaled 边界**：BGM/环境/UI 走 `unscaled`；世界音效播放速率**不变**，仅 pitch 微升（§1.5）。
12. **判据同源**：可见性**必须**调公共只读服务，**禁自建第二套视口判据**（§1.7）。

### 7.2 行为级探针（P1~P9）

| # | 探针 | 判据 |
|---|---|---|
| P1 | 直调生效 | `TaskScheduler` 进入 `Working` → 对应工种音发声，**无 EventBus 订阅** |
| P2 | 三因子 priority | 同屏构造"近处采集 vs 远处战斗" → 战斗保位、采集让位 |
| P3 | 抢占用分层 | 世界音效超 12 → 抢占**最低 priority**（被抢者 0.1s fade-out，无爆音） |
| P4 | 不排队 | 超预算的新事件**被丢弃**（不延迟发声）；计数可见于调试面板 |
| P5 | 同类窗口合并 | 同帧 N 次同 key → **1 次代表音**（＋变体） |
| P6 | 防齐声 | 100 工人跨 5s 开工 → 无整块同相叠加（频谱/听感双证） |
| P7 | 倍速 pitch | 1x/2x/3x 三档下，受时间影响条目 pitch 分别 ≈ 1.00 / 1.05 / 1.10；**0.5x 不降调**；BGM 全档不变 |
| P8 | 宿主销毁清理 | 工人死亡/建筑拆除 → 对应 loop 即停（0.1s 淡出）＋池归还，**零泄漏** |
| P9 | 可见性同源 | 同一位置对"头顶冒泡"与"音效"给出**相同**可见性判定（调同一服务） |

### 7.3 配套验收

- **暂停/恢复**：暂停静 SFX；恢复后 loop **续播**（进度保留，非从头）。
- **失焦**：整体静音，恢复还原。
- **多次建局**：`WorldLifecycle.ResetState` 后零残留（冒烟必备）。
- **零世界写入**：音频开关两态下同 seed 逐字节一致。
- **zoom-to-cursor**：拖动中锚点跟手；落定后**吸附回像素网格**；地图边缘**静默失效**（不抖不绞）。

## 八、否决清单（钉死，防自由发挥）

| 档 | 否决理由 | 重启条件 |
|---|---|---|
| 走 EventBus 订阅（3.8 原案） | 现库事件面不足（18 条中 11 条无源）＋ 与美术侧双轨 | 无（已改直调） |
