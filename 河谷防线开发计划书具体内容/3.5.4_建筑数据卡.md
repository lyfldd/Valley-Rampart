# 3.5.4 建筑数据卡（每建筑一卡，集中查询）

> 日期：2026-08-06
> 前置：3.5 王国经营体系（§13.3 建筑级明细）/ 3.5.3 建筑功能审查与搬运链（任务/摧毁修复）/ 3.1.1 美术资源清单
> 说明：**每栋建筑一张数据卡**，集中功能/等级升级资源/拆除返还/产出/任务/事件，避免跨文档查找。数值占位可调。

---

## 通用规则（所有建筑适用）
- **升级**：建造/升级/修复统一走 `Constructing` + 进度条（3.3.4）。
- **拆除返还（确定规则）**：玩家主动拆除返还 = **（建造消耗 + 全部累计升级消耗）总和 × 当前HP/满HP**。即：返还的是"已投入的总资源 × 剩余血量比例"，不是单级资源。
  - 例：伐木场建造 木2/石1，升 Lv2 木12/石8，满血拆除 → 返还 木14/石9；半血拆除 → 返还一半。
- **被摧毁**：生产/民生/商业/科技/军事训练建筑 → 留废墟可修复（内部资源清空）；土木工事/战争机器 → 直接销毁（3.5.3 §七）。
- **通用任务**：建造 / 升级 / 重建 / 修复 / 搬运（3.5.3 §八）。
- **事件**：放置 = `BuildingPlacedEvent`；被摧毁/拆除 = `UnitDiedEvent`（原 BuildingDestroyedEvent 退役）；资源变化 = `ResourceChangedEvent`。

## 一、土木 / 防御

### 主城（废弃城堡 → 修复）
- **功能**：核心；君主驻留；主城等级解锁表载体（Lv0-6）；失败条件（被破=GameOver）。
- **占地**：2 格。
- **升级**：修复 木10/石6/粮6/金2 → Lv2 木30/石20/粮20/金10 → Lv3 木80/石60/粮60/金40 → Lv4 木120/石90/粮90/金70 → Lv5 木180/石140/粮140/金120。
- **产出**：无（解锁模块/建筑）。
- **任务**：修复（玩家触发，非工人）。
- **事件**：主城升级 → 模块解锁广播。

### 城墙
- **功能**：阻挡敌人，单位需绕行/走城门。
- **占地**：1 格/段。
- **升级**：Lv2 厚城墙 木12/石10（血量↑）→ Lv3 三级城墙 木30/石24。
- **被摧毁**：直接销毁。
- **任务**：建造/升级。

### 城门
- **功能**：城墙开口，可开关（玩家点击；夜晚波次自动关闭）。
- **占地**：1 格。
- **升级**：Lv2 加固 木16/石12。
- **被摧毁**：直接销毁。

### 箭塔
- **功能**：自动远程攻击。
- **占地**：1 格。
- **升级**：Lv2 强化箭塔 木16/石12（射程↑）→ Lv3 三级箭塔 木36/石30。
- **被摧毁**：直接销毁。
- **事件**：攻击产生伤害事件。

### 拒马阵
- **功能**：城墙前障碍，阻挡+减速，被摧毁一次性。
- **占地**：1 格。
- **建造**：木8。
- **被摧毁**：直接销毁。

### 弩塔
- **功能**：远射程单体高伤，造价高。
- **占地**：1 格。
- **建造**：木12/石16/金6。
- **被摧毁**：直接销毁。

### 魔法塔
- **功能**：AOE 魔法伤害。
- **占地**：1 格。
- **建造**：石20/水晶4/金10。
- **被摧毁**：直接销毁。

## 二、生产

### 伐木场
- **功能**：采集生产**木材**。
- **占地**：2 格。
- **升级**：Lv2 木12/石8（效率↑）→ Lv3 木30/石20。
- **产出**：木（需通用工人采集，不再自动产出）。
- **任务**：采集 + 搬运木。
- **事件**：采集 → `ResourceChangedEvent`。

### 采石场
- **功能**：采集生产**石材**。
- **占地**：2 格。
- **升级**：Lv2 木12/石10 → Lv3 木30/石24。
- **产出**：石（需工人采集）。
- **任务**：采集 + 搬运石。

### 矿洞
- **功能**：采集生产**矿石** + 副产水晶（Lv2）/火油（Lv3）。
- **占地**：2 格。
- **升级**：Lv2 木16/石16（矿↑+水晶副产）→ Lv3 木36/石36（矿↑↑+火油副产）。
- **产出**：矿（需工人采集）；副产 = 每 5 矿 1 水晶/火油。
- **任务**：采集 + 搬运矿/副产。

### 农田
- **功能**：种植生产**粮食**。
- **占地**：2 格。
- **升级**：Lv2 木8/粮4 → Lv3 木20/粮10。
- **产出**：粮（需工人种植 + **水井供水**，缺水停产）。
- **任务**：种植 + 搬运粮。

### 仓库
- **功能**：通用存储（任意资源）。
- **占地**：2 格。
- **升级**：Lv2 木10/石10（容量↑）→ Lv3 木24/石20。
- **容量**：每资源独立，Lv1 40/种 → Lv2 80 → Lv3 160（木/石/矿/水晶/火油 各）。
- **任务**：搬运中转。

### 训练所
- **功能**：居民 → 工人转职。
- **占地**：1 格。
- **升级**：Lv2 木8/石6（训练效率↑）。
- **任务**：训练表演（居民走过去，非工人）。

### 粮食加工坊
- **功能**：粮 → 面包（需通用工人加工）。
- **占地**：2 格。
- **建造**：木6/石4。
- **配方**：粮×2 → 面包×1。
- **任务**：加工（搬粮入/搬面包出），工人不足停工。

### 牧场
- **功能**：养殖（喂粮→成年→宰杀得肉）。
- **占地**：2 格。
- **建造**：木8/石6。
- **产出**：肉（屠宰制，无自动繁殖）。
- **任务**：喂粮/管理/宰杀（通用工人）+ 搬喂粮/搬肉。

### 高级仓储
- **功能**：大容量通用存储 + 整合。
- **占地**：3 格。
- **建造**：石12/金6。
- **容量**：400（扩展）。
- **任务**：搬运中转。

## 三、民生

### 粮仓
- **功能**：通用存储 + 进食点（NPC 来此进食）。
- **占地**：2 格。
- **升级**：Lv2 木10/石6（容量↑）→ Lv3 木24/石16。
- **容量**：每子类独立，Lv1 40/种 → Lv2 80 → Lv3 160（粮/肉/面包 各）。

### 房屋
- **功能**：人口容量（科技+1/级）。
- **占地**：1 格。
- **升级**：Lv2 木10/石6（容量 5）→ Lv3 木24/石16（容量 8）。
- **容量**：Lv1 3 / Lv2 5 / Lv3 8。

### 水井
- **功能**：农业供水（农田需水，工人从井挑水；缺水停产）。
- **占地**：1 格。
- **建造**：石6。
- **供水**：隐式水，不新增资源。
- **任务**：挑水（工人）。

### 医院
- **功能**：被动回血加成 + 幸福；主动治疗伤员（伤员去医院回血）。
- **占地**：2 格。
- **建造**：木10/石8/金6。
- **效果**：每日饱食回血额外 + `hospitalRecoveryBonus`；主动就医回血更快。

### 教堂
- **功能**：幸福加成（按数量）。
- **占地**：2 格。
- **建造**：木8/石10/金8。

## 四、军事

### 练兵场
- **功能**：训练战士/弓手（Lv1）；法师/治疗师 + 重装/盾卫/弩手/大法师/主教（Lv2 直接训练）。
- **占地**：3 格。
- **升级**：Lv2 木20/石16（解锁魔法训练）→ Lv3 木50/石40。
- **任务**：训练表演（居民走过去）。

### 投掷机厂
- **功能**：产战争机器（投掷机/弩炮）+ 弹药（普通/燃烧/魔法弹）。
- **占地**：2 格。
- **建造**：木16/石20/金10。
- **任务**：产机器/弹药（通用工人）+ 搬运。

### 卫戍营
- **功能**：训练将军（限 2）+ 骑兵。
- **占地**：3 格。
- **建造**：石20/金16。
- **任务**：训练表演。

### 投掷机 / 弩炮（战争机器）
- **功能**：AOE 溅射（投掷机）/ 超远单体（弩炮）。
- **占地**：1 格。
- **被摧毁**：直接销毁。
- **任务**：需工人操作（已实现）。

## 五、商业

### 市场
- **功能**：贸易（买/卖、额度、档位随等级）。
- **占地**：2 格。
- **升级**：Lv2 木20/石10（解锁水晶/火油）→ Lv3 木50/石30（档位全开）。
- **任务**：贸易（玩家操作，无商人 NPC）。

### 商店
- **功能**：建筑税来源（按等级抽成）。
- **占地**：1 格。
- **建造**：木6/石6/金4。

### 税务所（原金矿）
- **功能**：直接产金（收税/铸币语义）。
- **占地**：2 格。
- **建造**：石16/金10。
- **产出**：金（每日 `goldMineGoldPerDay`，直接入金计数）。

## 六、科技

### 学院 / 工坊
- **功能**：研究（金+时长）；研究等级随主城/科技模块。
- **占地**：2 格。
- **建造**：木10/石6/金6。
- **任务**：研究（建筑自动，无学者 NPC）。
