### 核心问题

3.0.1 P0 实现后，因子利用情况：

| 因子 | P0 用途 | 问题 |
|------|---------|------|
| courage | 撤退阈值 +1~-1 | 只影响"撤不撤"，不影响"撤多远""多久恢复" |
| obedience | 撤退阈值 +0.5~-0.5 | 只影响"撤不撤"，服从度高的 NPC 没有更多表现 |
| threatSensitivity | 乘到 rawFactor | 只影响威胁感知，不影响撤退行为 |
| perceptionRadius | 查询范围 | 只影响"看多远"，不影响"追多远" |

**目标**：让每个因子贯穿 威胁评定 -> 撤退决策 -> 撤退行为 -> 恢复行为 -> 追击行为 全链路。

## 一、问题分析：当前撤退逻辑的失败模式

### 1.1 场景

工匠在军队后面工作，被敌方弓箭手远程攻击到。

### 1.2 三个失败模式

**失败模式 1：距离判断 -> 无限循环**
```
工匠被箭射中 -> 撤退 -> 敌人在感知范围外 -> 判定安全 -> 回去工作 -> 又被射 -> 撤退...
```
根因：远程攻击来自感知范围之外，NPC 看不到射手就以为安全了。

**失败模式 2：位置锁定 -> 永远卡住**
```
工匠在 X 被射 -> 撤退到 Y -> 不敢越过 X -> 即使威胁已消除也永远不前进
```
根因：NPC 不知道"什么时候威胁已经消除"。

**失败模式 3：当前实现的漏洞**
```
被击 -> threat=3 -> 撤退 -> 3秒没被打 -> threat衰减到0 -> FullPower -> 回去 -> 被打 -> 再撤...
```
根因：`threatDecayTime=3s` 只是延迟了循环，没有打破它。

### 1.3 根因总结

**NPC 怎么知道"安全了可以继续"？**

- 靠敌人距离？-> 远程攻击打脸但看不到射手
- 靠受击位置？-> 不知道威胁何时消除
- 靠时间衰减？-> 衰减完就回去送死，循环

## 二、方案：受击冷却 + 渐进式恢复

### 2.1 核心思路

判断"是否安全"不靠"看没看到敌人"，而靠**"有没有持续被打"**。这避开了感知范围的盲区。

### 2.2 三阶段恢复

```
被击中 -> 撤退几步 -> 【警戒驻留】-> 持续N秒没被打 -> 【试探恢复】-> 又M秒没被打 -> 【完全恢复】
                                                              ↓ 被打
                                                           退更远，重置计时
```

| 阶段 | 触发条件 | NPC 行为 | 持续条件 |
|------|---------|---------|---------|
| 警戒驻留 | 刚被击/撤退后 | 停在原地，不前进，保持警戒 | N 秒不被打 |
| 试探恢复 | 警戒驻留期满 | 可以前进，但威胁敏感度提高 | M 秒不被打 |
| 完全恢复 | 试探恢复期满 | 正常行为 | - |

**如果试探恢复期间又被击中**：撤退更远（阶梯式），重置到警戒驻留阶段。

### 2.3 撤退距离阶梯

| 连续被击次数 | 撤退策略 |
|------------|---------|
| 第 1 次 | 后退一小段（远离受击方向 2-3 格） |
| 第 2 次 | 后退更多（4-5 格），寻找掩护 |
| 第 3 次+ | 撤退到安全点（城堡/城墙，如果设置了 RetreatDestination） |

### 2.4 撤退目标点接口

NPCBrain 预留 `RetreatDestination` 属性，供外部系统（调度中心/建造系统）设置：

- **有目标点**：`MoveTowards(RetreatDestination)` -> 到达后停止
- **无目标点**：`Move(direction)` 按方向撤一步 -> 敌人消失即停

## 四、威胁评定增强（扩展 3.0.1 第五节）

### 4.1 新增因子

| 因子类 | 输入 | 作用 | 公式 |
|--------|------|------|------|
| **敌人战斗力因子**（新） | 敌方总攻击力 / 自身防御 | 正向推高 | `enemyPowerFactor = clamp(enemyTotalAttack / (selfDefense + 1) / 2, 0, 1)` |
| **自身战斗力因子**（新） | 自身攻击力 / 敌方平均防御 | 负向抵消（自信感） | `selfPowerFactor = clamp(selfAttack / (enemyAvgDefense + 1) / 2, 0, 1)` |

### 4.2 现有因子深化

**血量因子 -> 血量恐惧（courage 参与）**：
```
hpFear = (1 - hpRatio) * (1 + (100 - courage) / 200)

// courage=100: hpFear = (1-hp) * 1.0  （满勇气，正常恐惧）
// courage=70:  hpFear = (1-hp) * 1.15 （轻微放大）
// courage=30:  hpFear = (1-hp) * 1.35 （怯懦，35%放大恐惧）
```

**距离因子 -> 距离感知（threatSensitivity 参与）**：
```
distFactor = (1 - dist / perceptionWorld) * threatSensitivity

// threatSensitivity=0.8: 要很近才感受到威胁
// threatSensitivity=1.5: 更远就感受到威胁
// 注意：clamp 到 [0, 1]
```

### 4.3 增强后的完整公式

```
rawFactor = distFactor * 0.25
          + countFactor * 0.10
          + enemyPowerFactor * 0.15
          + hpFear * 0.15
          + allyFactor * 0.20
          + selfPowerFactor * 0.10
          + timeFactor * 0.05

rawFactor = clamp(rawFactor, 0, 1)
```

权重总和 = 1.0，与 P0 一致。注意：P0 的 `rawFactor *= threatSensitivity` 改为只乘到 distFactor，避免敏感度对全公式过度放大。

## 五、撤退决策增强（扩展 3.0.1 第四节 + 第六节）

### 5.1 勇气覆盖

高勇气 NPC 在有保护时不轻易撤退：

```
if (courage >= 80 && threatLevel == Danger && hasProtection):
    spectrum = Cautious  // 别人撤退他留守
```

### 5.2 服从度覆盖

高服从度 NPC 有任务时不轻易撤退：

```
if (obedience >= 80 && hasTask && threatLevel <= Danger):
    spectrum = Cautious  // 听命令继续干
```

### 5.3 撤退阈值公式（保持不变）

```
threshold = baseThreshold
          + priorityBonus
          + (courage - 50) / 50      // -1 ~ +1
          + (obedience - 50) / 100   // -0.5 ~ +0.5
          + professionOffset
```

## 六、撤退行为增强：受击冷却 + 渐进式恢复（新增）

### 6.1 状态机

```
NormalState（正常）
  ↓ 被击中
RetreatState（撤退：按方向移动 N 格）
  ↓ 撤退完成
CautionState（警戒驻留：原地不动，持续 cautionDuration）
  ↓ cautionDuration 内未被击
ProbeState（试探恢复：可前进，敏感度提高，持续 recoveryDuration）
  ↓ recoveryDuration 内未被击
NormalState（完全恢复）
  ↓ 任意阶段被击
RetreatState（撤退：hitCount++，撤更远）
```

### 6.2 撤退距离公式（courage + threatSensitivity 参与）

```
retreatDistance = (baseRetreatCells + hitCount * stepRetreatCells)
                * (1 + (100 - courage) / 200)
                * threatSensitivity

// baseRetreatCells = 2, stepRetreatCells = 1.5
// 士兵(courage=70, sens=0.8) 第1次: (2+0) * 1.15 * 0.8 = 1.84 格
// 工人(courage=30, sens=1.5) 第1次: (2+0) * 1.35 * 1.5 = 4.05 格
// 工人(courage=30, sens=1.5) 第3次: (2+3) * 1.35 * 1.5 = 10.13 格
```

### 6.3 撤退速度公式（courage 参与）

```
retreatSpeed = walkSpeed * (1 + (100 - courage) / 100)

// courage=30: walkSpeed * 1.7（逃命速度）
// courage=70: walkSpeed * 1.3
// courage=100: walkSpeed * 1.0（镇定撤退）
```

### 6.4 警戒驻留时长（courage + hpRatio 参与）

```
cautionDuration = baseCautionTime
                * (1 + (100 - courage) / 100)
                * (1 + (1 - hpRatio) * 0.5)

// baseCautionTime = 5s
// 士兵(courage=70, 满血): 5 * 1.3 * 1.0 = 6.5s
// 工人(courage=30, 半血): 5 * 1.7 * 1.25 = 10.6s
```

### 6.5 完全恢复时长（courage + threatSensitivity 参与）

```
recoveryDuration = baseRecoveryTime
                 * (50 / courage)
                 / threatSensitivity

// baseRecoveryTime = 10s
// 士兵(courage=70, sens=0.8): 10 * 0.71 / 0.8 = 8.9s
// 工人(courage=30, sens=1.5): 10 * 1.67 / 1.5 = 11.1s
```

### 6.6 试探恢复期间的敏感度提升

```
effectiveSensitivity = threatSensitivity * 1.5  // 试探期间提高 50%
```

## 七、追击行为增强（新增）

### 7.1 追击范围公式（courage 参与）

```
chaseRange = perceptionRadius * cellSize * (courage / 50)

// courage=70: 感知范围 × 1.4（追得远）
// courage=50: 感知范围 × 1.0（正常）
// courage=30: 感知范围 × 0.6（很快放弃）
```

### 7.2 追击放弃条件

当敌人距离 > chaseRange 时，停止追击，回到待机/任务行为。
