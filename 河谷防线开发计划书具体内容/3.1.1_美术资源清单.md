## 〇、通用规则（所有资产适用）

### 0.1 建筑生命周期 8 阶段框架

每类建筑都套用此框架（无某阶段的建筑标注"无"）：

| 阶段 | 名称 | 触发 | 美术需求 |
|------|------|------|---------|
| L0 | 待建造/预览 | 玩家进入建造模式 | ghost 半透明 prefab（按模块分色）+ 区块吸附高亮 + 绿/红校验 |
| L1 | 建造中 | 放置扣资源后 | 脚手架贴图 + 进度条 UI + 完成激活特效 |
| L2 | 各等级正常态 | 建造完成/升级完成 | **每级独立外观贴图**（主城7套，普通建筑3套） |
| L3 | 升级中 | 玩家点升级扣资源 | 升级脚手架 + 进度条 |
| L4 | 正常运作 | 产能/训练/防御启用 | 运转动画/工人操作动画/产出特效 |
| L5 | 受损（3档） | HP下降 | **3档破损贴图**：>60%正常 / 30-60%轻度破损(裂缝) / <30%重度破损(塌顶) |
| L6 | 摧毁/废墟 | HP=0 | 摧毁动画 + 废墟贴图（生产/民生/商业/科技/军事训练建筑留废墟可修复）或直接消失（土木工事/战争机器） |
| L7 | 修复中 | 废墟触发修复 | 修复脚手架 + 进度条 + 完成激活特效 |

### 0.2 关键决策（2026-08-07 确认）

- **受损档数**：3档（>60%正常 / 30-60%轻度破损 / <30%重度破损）
- **升级贴图**：每级都换（主城 Lv0-6 共7套外观，普通建筑 Lv1-3 共3套外观）
- **NPC动画方向**：flipX 复用（每动作1套贴图，运行时翻转；仅弹药飞行/武器挥砍等强方向性资产做左右双套）
- **死亡动画**：P0 用 4-6 帧 alpha 淡出（满足 3.4 §6 决策15"直接消失" + 3.5 §14.1 决策5"消失动画"），P1 细化职业死亡

### 0.3 通用反馈（所有建筑/NPC共用）

- 受击闪红 0.1s（DamageFeedback，已实装，无贴图需求）
- 拆除退款资源粒子（按 HP 比例返还）
- 工人逃出动画（建筑被摧毁时，3.5.4 §8.5）
- 死亡淡出 4-6 帧 alpha（P0 最简版）

## 三、生产建筑（9类）

### 通用规则
- **等级**：Lv1-3（除特殊建筑单级）
- **占地**：2格（除训练所1格、高级仓储3格）
- **并发工人**：等级×并发（Lv1=1/Lv2=2/Lv3=3，特殊建筑=1）
- **被摧毁**：留废墟可修复（生产类规则）
- **L0-L2/L3/L5/L7**：8阶段框架通用

### 3.1 伐木场
**产出**：木 / **运转动画**：工人挥斧砍树 + 木堆累积 + 搬运工扛木走

### 3.2 采石场
**产出**：石 / **运转动画**：工人挥镐凿石 + 石堆累积 + 搬运工扛石走

### 3.3 矿洞
**产出**：矿 + 副产水晶(Lv2)/火油(Lv3)
**特有贴图**：
- Lv2：矿洞口泛紫光（水晶副产粒子）
- Lv3：矿洞口泛橙光（火油副产粒子）
**运转动画**：工人挥镐挖矿 + 进洞 + 矿脉资源点贴图

### 3.4 农田
**产出**：粮（需水井供水，缺水停产）
**特有贴图**：
- 作物生长阶段4帧（种子→幼苗→抽穗→成熟，可复用wheatPlant）
- 缺水停产：枯黄作物贴图 + 警告图标
**运转动画**：工人弯腰播种/浇水/收割

### 3.5 仓库
**容量**：Lv1=40→Lv2=80→Lv3=160（每种资源独立）
**特有贴图**：存储量可视化（按存储比例显示资源堆高度）
**特有警告**：满仓丢弃粒子 + 溢出警告图标（3.5 §13.14）

### 3.6 训练所
**等级**：Lv1-2 / **占地**：1格 / **训练槽位**：Lv1=1/Lv2=2
**功能**：居民→工人转职
**运转动画**：居民进入建筑 + 训练完成变身工人动画（职业服饰切换）+ 训练中断回退动画（建筑被摧毁时居民退回无职业，3.5.4 §8.6）

### 3.7 粮食加工坊
**等级**：Lv1单级 / **并发工人**：=1 / **配方**：粮×2→面包×1
**运转动画**：磨粉机/烤炉动画（可复用breweryOven）+ 搬粮入/搬面包出

### 3.8 牧场
**等级**：Lv1单级 / **占地**：2格 / **容量**：10动物 / **并发工人**：=1
**动物资产**（3.5 §13.10）：

| 动物 | 幼崽prefab | 成年prefab | 生长周期 | 产肉/次 |

**特有**：断粮停长状态视觉（动物静止/饥饿，不死亡）

**等级**：Lv1单级 / **占地**：3格 / **容量**：400/种 + 自动搬运整合

### 10.4 生活/生产类NPC

#### 君主（Ruler）
- **生命周期**：出生城堡旁→移动到城堡触发修复→入主驻留；阵亡=GameOver
- **基础动作**：idle/walk/run/指挥姿势（E键面板打开时）
- **工作动作**：无（不建造/不采集/不吃饭/不耗粮）
- **战斗动作**：不攻击，只指挥（无PlayerAttack入口）
- **特殊**：入主城堡动画 + E键军令面板开启姿势

#### 流浪汉（Vagrant）
- **生命周期**：营地生成→玩家点击招募（花1粮）→立即变居民→AI走回王国→抵达纳入人口
- **基础动作**：idle（营地晃悠）/walk（走回王国）
- **工作/战斗**：无
- **特殊**：招募触发动画 + 走回王国行进 + 头顶交互语句

#### 小孩（Child）
- **生命周期**：繁殖产生（两居民进房→出来+小孩）→2次天数事件累积→变居民
- **基础动作**：idle/walk + 幼年贴图（与成年居民区分）
- **工作/战斗**：无（只吃粮1/日）
- **特殊**：出生动画 + 成长变居民动画 + 对话显示成长状态

#### 居民（Resident）
- **生命周期**：流浪汉招募到达/小孩长大→居民→训练转职工人/士兵
- **基础动作**：idle/walk/run（逃跑）
- **工作/战斗**：无
- **特殊**：繁殖进房动画 + 训练菜单交互 + 转职出发动画 + 训练中断回退动画
