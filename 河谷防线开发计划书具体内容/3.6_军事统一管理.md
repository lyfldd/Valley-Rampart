## 二、解耦三原则（架构地基，最重要）

> 用户痛点："改装备不仅要军事里改，还要在生产等做装备的地方改；想加城墙等级、细分弹药，但模块等级只有三级，一改牵连太多。"

### 原则 1：等级 = 纯数据 int，不写死上限

```csharp
public class FortificationDef {
    public int defenseLevel;   // int，不设 0-3 上限。要 5 级城墙？建 5 个城墙资产
}
// 模块等级同理：ModuleDef.tiers 是数组，节点数不限（见 3.5 模块树）
```

### 原则 2：引用 = id + 运行时规则，不用等级对应表

```csharp
// "墙挡不挡弹" = 运行时比较两个 int 的规则函数，不是查表
//   pierceLevel >= defenseLevel ? 造成伤害 : 不造成伤害
// 加一档城墙 = 加一个 int 值，规则自动覆盖
```

### 原则 3：改动局部化——生产/装备/弹药/工事之间用 id 引用

改装备只改 EquipmentDef 资产；装备厂（生产建筑）只认"产 id=xxx 的装备"，生产端零改动。

| 诉求 | 解耦后（改一处） |
|------|----------------|
| 想要 1 级城墙 | 新建 `Wall_Tier1` 资产（defenseLevel=1） |
| 弓手弹 1 级 / 弩手弹 2 级 | 弓手引 `AmmoDef(Arrow,pierce=1)`、弩手引 `AmmoDef(Bolt,pierce=2)` |
| 石头穿透 4 级 > 弩炮箭 3 级 | 两个 AmmoDef 的 `pierceLevel` 各改一个 int |
| 改装备数值 | 只改 EquipmentDef 资产 |

> 核心思想：**等级只是数字，规则只是函数，引用只是 id——扩展性来自数据配置，不来自代码结构。**

## 三、介质层：弹药与效果（怎么打）

### 3.1 AmmoDef（弹射物行为模板，独立资产）

```csharp
public enum AmmoType { Arrow, Bolt, HeavyBolt, Stone, Fireball, Magic }

public class AmmoDef : ScriptableObject
{
    public AmmoType ammoType;
    public int pierceLevel;               // 穿透等级（int，不设上限）
    public float aoeRadiusCells;          // 溅射半径（0=单体）
    public float aoeFalloff;              // 溅射衰减 0-1
    public GroundEffectDef effect;        // 命中后地面效果（可空）
    public bool isParabolic;              // 是否抛物线弹道
}
```

### 3.2 弹药表（基础档位，训练校准）

| 弹药 | 穿透 | 伤害 | AOE | 命中效果 | 使用方 |
|------|------|------|-----|---------|--------|
| Arrow 箭 | Lv1 | 中 | 无 | 无 | 弓手（弓装备） |
| Bolt 弩箭 | Lv1 | 高 | 无 | 无 | 弓手（弩装备） |
| HeavyBolt 贯穿弩箭 | **Lv3** | 高 | 无 | 无 | 弩炮 |
| Stone 石头 | **Lv3** | 高 | 中（2 格） | 无 | 投掷机 |
| Fireball 火弹 | Lv1 | 低 | 大 | 灼烧区域 | 投掷机 / 法师（阉割） |
| Magic 魔弹 | Lv1 | 中 | 中 | 减速区域 | 弩炮 / 法师（阉割） |

> 注意：手持弩手（Crossbowman）的 Bolt 是 Lv1；弩炮（Ballista）的 HeavyBolt 是 Lv3——两个不同 AmmoDef 资产。

### 3.3 溅射结算（单段 AOE）

弹药命中后以**命中点**为圆心，`aoeRadiusCells` 内全部敌对单位受溅射伤害：

```csharp
// 命中结算：圆心=命中点，半径内所有敌人，距离衰减
foreach (enemy in QueryRadius(point, aoeRadiusCells)) {
    int dmg = CalculateDamage(attack, enemy.Defense);
    dmg = ApplyFalloff(dmg, dist, aoeRadiusCells, aoeFalloff);  // 0=均匀 / 1=线性衰减到边缘0
    ApplyDamage(attacker, enemy, dmg);
}
// 命中效果：groundEffect 挂到命中点（火弹灼烧场 / 魔弹减速场）
```

> 石头弹跳（两段溅射）已砍（2026-08-03 用户决策：太复杂），**弹药统一单段 AOE**——伤害管线不再需要多段命中队列。

### 3.4 GroundEffectDef / BuffDef

```csharp
public enum GroundEffectType { Burn, Slow, Heal }
public class GroundEffectDef : ScriptableObject
{
    public GroundEffectType type;
    public float radiusCells;     // 区域半径
    public float duration;        // 持续时长
    public float tickInterval;    // 结算间隔（训练调）
    public float power;           // Burn=每tick伤害 / Slow=减速系数 / Heal=每tick治疗
    public int maxTargets;        // 治疗场"有限个"：最多奶 N 个
}
// BuffDef：单体增减益（冲锋免伤/护盾/韧性变化），buffType + modifier + duration
```

## 五、规则层：伤害管线升级（怎么结算）

### 5.1 穿透 vs 防御

- 弹射物 `pierceLevel < 工事 defenseLevel` → **被挡，不造成伤害**
- `pierceLevel ≥ defenseLevel` → 造成伤害（可穿墙）
- **城墙消耗来源**：近战（等级减免）+ 高穿透攻城弹药（石头/贯穿弩箭 Lv3）。箭矢对城墙完全无效
- 近战打墙：`近战伤害 × (1 - meleeDamageReduce)`

### 5.2 免伤词条体系

```csharp
// 免伤 = Σ 各免伤因子（clamp 到上限），防御免伤是其一 + 冲锋免伤 + 未来更多
damage = rawDamage × (1 - 免伤总和)
```

### 5.3 骑兵冲锋（特殊技能，进伤害管线）

| 参数 | 值 | 备注 |
|------|-----|------|
| chargeDamage | 80 | 非常高，特殊技能 |
| chargeRange | 4 格 = 9.04 世界单位 | 中区块距离（midRegionCellCount=4 小区块编组） |
| 冲锋节奏 | 2 次/组（次间 0.3s），组间 20s | 双连击 |
| 冲锋免伤 | 70% | 冲锋过程中免伤词条 |

### 5.4 冲撞 / 被撞表现（非物理模拟）

**击飞模型（2026-08-03 定稿）**：动能定最大限度，**抛射角 θ 均匀随机（30°~75°）定路线**——同动能不同路线：

```csharp
// 1. 动能定最大限度（韧性反制在这：高韧性 → v0 小 → 整体飞得近矮）
v0    = 冲击力 × (1 - 韧性削减系数 × 韧性)
L_max = v0² / g;            // 最大水平位移（θ=45° 最远）
H_max = v0² / (2g);         // 最大高度

// 2. 抛射角 θ 每次均匀随机 30°~75°（SimRng，seed 驱动保确定性）
//    θ 大 → 高而近；θ 小 → 远而矮（"这次撞高、下次撞远"）
distFactor   = sin(2θ);     // 0-1，45°=1 最远
heightFactor = sin²θ;       // 0-1，90°=1 最高
L = L_max × distFactor;
H = H_max × heightFactor;

// 3. 飞行时间（被打断时长）
T = k × L;                  // 飞得越远滞空越久，简化线性
```

- **方向**：被左边冲撞 → 沿冲击方向（右）飞 80%、反向 20%
- **不物理模拟**：状态化位移 + 抛物线插值（复用 ProjectileManager t 插值思路），不做碰撞计算
- **击飞期间**：打断攻击（Unregister）+ 屏蔽正常移动 + 按抛物线路径插值位移
- **韧性反制**：削减 v0（不是改 θ），高韧性整体飞得近矮，语义一致
