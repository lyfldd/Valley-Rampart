## 二、建筑功能补全决策（2026-08-06）

### 2.1 粮食加工坊 —— 通用工人执行
- **机制**：通用工人自动派驻（检测王国仓库/粮仓有粮时自动受理任务），搬粮 → 加工（**有表现动画**）→ 存**面包**到仓库。
- **工人不足则停工**；工人 = 通用工人（3.5.2 一职通吃）。
- **配方**：粮 ×2 → 面包 ×1（沿用 §13.11，面包原"特殊食物"，2026-08-06 更名）。
- **加工任务 = 一个任务**：工人到加工坊执行，有表现动画（非原地消失）。

> **生产不再自动产出（2026-08-06）**：`ProducerComponent` 自动产出机制**废弃**。所有生产（采集/种植/加工/挑水/养殖）改为**需通用工人执行生产任务**（见 §八 建筑-任务清单）。以本档与 3.5.2 为准，旧 3.3.4/3.3.5 自动产出描述作废。

### 2.2 水井 —— 农业供水（重新设计）
- **定位**：水井从"饱食辅助"改为**农业供水基建**。
- **机制**：农田生产需水；工人从水井挑水供农田（**隐式"水"，不新增资源类型**，专属农业用）。
- **缺水停产**：无可用水井供水 / 工人不足 → 农田**停产**（硬前置）。
- **越高级农田耗水越多**：需更多水井 / 工人维持满产。
- 结合农业，不叠加科技（科技另有增益，二者不冲突）。

### 2.3 医院 —— 被动 + 主动
- **被动**（保留）：医院存在时每日饱食回血额外 + `hospitalRecoveryBonus`，且幸福加成。
- **主动**：伤员（血不满）自动去医院驻留回血，医院存在时回血更快。
- 士兵/工人等 NPC 受伤后可通过主动就医更快恢复。

### 2.4 金矿 → 改名"税务所"
- 原"金矿"**改名"税务所"**，保留"直接产金"机制，语义改为**收税/铸币**（非采矿），与税收体系呼应。
- 商业模块 Lv3 特殊建筑，直接产金（SO 可调 `goldMineGoldPerDay`）。

## 三、搬运链全梳理（防遗漏）

> **存储原则（2026-08-06 修订）**：**国库 = 随主城升级的仓库**（主城 Lv 对应国库仓库等级，容量随主城升级，非主仓库）。**仓库 / 粮仓 / 高级仓储 = 通用存储**，任意资源可放，不分"仓库装木石矿、粮仓装粮"；但**每个资源（含子类）各自独立容量上限**（非共用一个池）。**搬运就近到最近的仓库**，不强制搬国库。UI 显示所有仓库（含国库）加总的总量。金 = 货币不占存储。

### 3.1 搬运 = 通用工人执行
- 搬运由**通用工人**执行（3.5.2）：工人走到源建筑 → 收取 → **搬运至就近的仓库**（国库仅当最近）。有表现动画。
- 调度归中心调度（3.3.5 ScheduleCenter 思路），防重复派发、空闲工人判定、任务生命周期沿用。
- 目标仓库选择：**就近原则**（取离源建筑最近的仓库/粮仓/高级仓储/国库）。
- **搬运携带量（2026-08-06 审查补全）**：按资源类型区分，新增 `ResourceCarryDef` SO：
  | 资源 | 携带量/次 |
  |------|---------|
  | 木 / 石 / 矿 | 10 |
  | 粮 | 20 |
  | 水晶 / 火油 | 5 |
  | 面包 / 肉 | 10（同木石矿档） |
  - 工人一次搬运 ≤ 携带量；源建筑产出 > 携带量时**分批多次搬运**。
  - `WorkerTask` 加 `carryAmount` / `carryResource` 字段。

### 3.2 全环节搬运矩阵
| 环节 | 建筑 | 输入搬运 | 输出搬运（就近仓库） | 现状 |
|------|------|---------|---------|------|
| 采集 | 伐木场/采石场/矿洞/农田 | — | 木/石/矿/粮 → 就近仓库（通用装） | ⚠️ 3.3.5 已实现（入国库，需改就近仓库） |
| 副产 | 矿洞 | — | 水晶/火油 → 就近仓库 | ⚠️ 待接 |
| 加工 | 粮食加工坊 | 粮 ← 就近仓库 | 面包 → 就近仓库 | ❌ 待做 |
| 养殖 | 牧场 | 粮(喂) ← 就近仓库 | 肉 → 就近仓库 | ⚠️ 待接 |
| 供水 | 水井 | — | 隐式水 → 农田 | ❌ 待做 |
| 中转 | 仓库/粮仓/高级仓储/国库 | 各资源 | 各资源 | ✅ 存储 |
| 补给 | 前线 | 粮 → 士兵 | — | ❌ 待做 |

### 3.3 关键缺口（用户点名防遗漏）
1. **牧场产肉后搬运**：宰杀得肉后需搬运到粮仓/仓库（不能"产了肉没搬运"）。
2. **加工坊**：需工人到场加工 + 搬粮入、搬面包出，均有表现动画。
3. **水井挑水**：工人从水井挑水供农田。
4. **副产**（水晶/火油）：从矿洞副产存储搬运到仓库。
5. **前线补给**：运粮到前线士兵（§13.12 军队补给）。

### 3.4 与现有实现的对齐说明
- 当前实现 `RulerController` 持有全局资源（木/石/粮/金）+ 3.3.5 "搬运入国库"。**新方案**：国库 = 随主城升级的仓库（容量随主城 Lv），全局资源池并入国库仓库；搬运改**就近仓库**；消耗（训练/建造/进食）从就近仓库/国库读取。
- 仓库/粮仓/高级仓储**统一为通用存储**（任意资源），移除"仓库装木石矿、粮仓装粮"的分工。
- UI 资源显示 = 所有仓库（含国库）加总总量。
- 金 = 货币，保持不占存储（税务所直接产金入金计数）。

## 七、建筑摧毁与修复机制（2026-08-06）

### 7.1 摧毁分类
| 类别 | 建筑 | 被摧毁后 |
|------|------|---------|
| **留废墟可修复** | 生产（伐木/采石/矿洞/农田/仓库/加工坊/牧场/高级仓储/训练所/投掷机厂）、民生（粮仓/房屋/水井/医院/教堂）、商业（市场/商店/税务所）、科技（学院）、军事（练兵场/卫戍营） | 留废墟（占用格），需消耗资源 + 工人修复任务重建 |
| **直接销毁** | 土木工事（城墙/城门/拒马/箭塔/弩塔/魔法塔）、战争机器（投掷机/弩炮） | 直接销毁，需重新建造 |

### 7.2 内部资源处理
- 生产建筑被摧毁时，**内部已产资源（存储/副产）直接清空丢失**（激励保护产能建筑）。
- 废墟不保留资源。

### 7.3 修复机制（工人修复任务）
- 废墟生成 → 任务调度中心发**修复任务** → 空闲工人去修（耗资源 + 时间）→ 重建完成。
- 修复消耗 = 建造成本 × 50%（占位）；修复时间 = 建造同档。
- 修复任务 = 工人任务的一种（见 §八），有表现动画。

### 7.4 建筑摧毁时工人处理（2026-08-06 审查补全）
- **决策**：建筑被摧毁时，内部正在工作的工人**逃出，存活**（变无任务状态）。
- **实现**：
  - 建筑摧毁逻辑（`Building.Die`）扫描 `currentWorkers` 列表。
  - 每个工人：① 清除 WorkerTask 状态（变 Idle）② 位置 +1 格偏移逃离（避免卡在废墟格）③ 不死亡。
  - 工人逃出后可被 `ScheduleCenter` 重新派发任务。
- **训练建筑额外**：训练中居民**存活**变回无职业居民（不退款，详见 3.5.4 §8.6）。

## 八、建筑-任务清单（任务调度中心颁发）

> 每个建筑的**任务集合**如下，供调度中心生成任务。任务类型见 3.5.1 §九 NPC 任务。

### 8.3 任务优先级映射（2026-08-06 审查补全）

**TaskPriority S/A/B/C** 已在 3.5.1 §九 定义，本节明确映射任务类型 → 优先级：

| 优先级 | 任务类型 | 说明 |
|--------|---------|------|
| **S** | 修复、重建 | 产能断链/废墟必须优先修复，避免连锁崩溃 |
| **A** | 建造、升级、生产、采集、加工 | 扩产能 + 日常产出 |
| **B** | 搬运 | 有产能后再送，避免空仓/堵仓 |
| **C** | 养殖、挑水、产金（税务所） | 非关键路径，空闲工人执行 |

**调度规则**：
- `ScheduleCenterStub` 派活时按 S > A > B > C 排序，同优先级内 FIFO。
- 空闲工人不足时，高优先级任务先派，低优先级任务排队。
- TaskPriority 映射表进 SO（`TaskPriorityDef`）。

### 8.4 建筑并发上限（2026-08-06 审查补全）

**`BuildingDef.concurrentWorkers`**（int）：建筑同时可服务的通用工人数。

| 建筑类型 | concurrentWorkers |
|---------|------------------|
| 产能建筑（伐木场/采石场/矿洞/农田） | **等级 × 并发**（Lv1=1 / Lv2=2 / Lv3=3） |
| 加工坊 / 牧场 / 水井 | 始终 = 1 |
| 投掷机厂 | = 1 |
| 仓库 / 训练 / 防御 / 商业 / 科技 | = 0（无工人服务） |

**调度规则**：
- `ScheduleCenterStub` 派活时检查 `currentWorkers < concurrentWorkers`，否则排队。
- 训练建筑另有 `trainingSlots`（训练槽位，与 `concurrentWorkers` 独立，详见 3.5.4 §8.1）。
