# 3.8 音效系统与缩放混音设计

> 日期：2026-09-11
> 状态：设计定稿（用户逐点讨论收敛，待实施）

> 【设计归属】层：**表现层（非 L1/L2/L3 玩法）**｜矛盾臂：**不碰**（不参与 D403 主要矛盾赛跑）｜执行者：**世界机制**（EventBus 只读订阅，零世界写入）｜镜像：**对全阵营一视同仁**（不做"只有玩家听得见"的信息特权）｜SO 化：`AudioConfig` / `AudioEventMap` / `AudioBank`｜判官破例：**无**

---

## 〇、核心概念

```
① 缩放决定"听什么"  —— 摄像机 zoom 越大（视口越小越近）越能听见世界/NPC 细节；
                        拉远则退成 BGM + 环境底噪。
② 事件决定"发什么"  —— 世界/NPC 音效由 EventBus 可听事件驱动，在实体世界坐标发声（3D 空间音）。
③ 预算决定"同时几个" —— 视口内世界音效并发上限 12，超限按优先级抢占，同类窗口合并。
```

一句话：**近看听世界（3D 事件音效），远看听氛围（2D 音乐+环境），三层混音随缩放丝滑过渡。**

## 一、核心设计

### 1.1 定位与红线

**定位**：纯表现层系统。它**只读消费**世界状态（通过 EventBus），**绝不写入世界**——不改 KingdomState/单位/建筑，不进 `AI.Core`/sim，不参与确定性决策与胜负判定。

**红线（违反即 FAIL）**
1. **零世界写入**（表现层豁免）——验收须能证明"**关掉音频＝世界逐字节一致**"。
2. **不进 `AI.Core` / sim**，不支持任何判定逻辑（禁判官化）。
3. **不做阵营过滤**——音效对所有阵营一视同仁（禁"只对玩家发声"的约束/信息特权）。
4. **AudioSource 必须池化**，禁每事件 `new`。
5. **与 `timeScale` 完全解耦**（用 unscaled/realtime 驱动），音频不得随倍速加速或失真。
6. **不得变相引导玩家**（D380：反馈≠引导）——声音不提"该去点哪"。

### 1.2 组件（4 个，职责单一）

| 组件 | 类型 | 职责 |
|---|---|---|
| `AudioDirector` | 单例（GameScene 音频根） | 总控：订阅 zoom 变化、维护当前档位与过渡、持有各层预算、编排下列三者 |
| `AudioEventRouter` | 组件 | 订阅 **EventBus 可听事件白名单** → 过滤可见性/距离 → 产出 `AudioRequest`（类目/世界坐标/重要度/变体池） |
| `VoiceManager` | 组件 | 音效并发预算(12)/优先级抢占/同类窗口合并/变体随机/距离衰减/AudioSource 池 |
| `ZoomAudioMixer` | 组件 | zoom → 各音轨增益插值 + 三档 crossfade + Ducking |

### 1.3 缩放三档与丝滑过渡

- **三档骨架**（复用相机既有 zoom 档，如 `CameraRig.ZoomIndex`/`zoomLods`）：**近 / 中 / 远**。
- **丝滑过渡**（用户确认）：档为骨架、**插值填缝**——zoom 连续值同时计算"邻近两档的接近度"，各音轨增益用缓动插值，档切换自动 crossfade（默认 0.8s，SO 可调），**无硬切**。
- **可听门限曲线**（中档折中·并入连续模型）：每类音效配 `重要度权重 + 最大可听半径`；SFX 总增益随 zoom 连续下滑，`可听门限` 随 zoom 上抬：

| 档 | zoom（视口） | SFX 总增益 | 可听门限 | 效果 |
|---|---|---|---|---|
| 近 | 小 | 高 | 低 | 细节音效全过（伐木/战斗/建造……） |
| 中 | 中 | 中 | 中 | 仅 `重要度≥中`（战斗/立国……）越得过门限 = 折中"代表音"效果 |
| 远 | 大 | →0 | ∞ | 世界音效全关，只剩 BGM + 环境 |

> 该折中**不新增机制**：无"中档特判分支"，仅 `重要度权重 + 可听门限曲线` 两个 SO 参数。WorldBox 的硬切为离散档做法，本设计以连续门限取其张力且天然丝滑。

### 1.4 触发时机（档位 × 可见性 × 预算 三重裁决）

| | 近档（视口小） | 中档 | 远档 |
|---|---|---|---|
| BGM | 常驻 | 常驻 | 常驻（主） |
| Ambient | 弱化 | 主 | 主 |
| **世界/NPC SFX** | **活跃（full，≤12）** | 仅 `重要度≥中` 且入可见区 = 弱化代表音 | **关闭** |
| UI/播报 | 独立池 | 独立池 | 独立池 |

**可见性三区**（用户确认：视口+边缘带）：视口内 = full；**边缘带内 = 弱化**（带宽 SO 可调，默认视口外扩 10~20%）；带外 = **不播**。

**世界音效发声判据链**：`事件 ∈ 白名单 ∧ 落在视口/边缘带 ∧ priority 排得进 ≤12` → 发声；否则按 §1.5 抢占或合并。

### 1.5 声音预算与叠加模型

**① 分层配额**（各层独立预算，互不抢占）

| 层 | 空间 | 并发预算 | 优先级 |
|---|---|---|---|
| BGM | 2D | 1（常驻） | 最高，永不被抢 |
| Ambient 区域环境 | 2D | 2–4 | 中 |
| **世界/NPC SFX** | 3D | **12（出厂默认）** | 竞争层 |
| UI/播报 | 2D | 独立小池（约 4） | 不占世界预算 |

**② 超预算 = 优先级抢占**
`priority = w₁·事件重要度 + w₂·接近度(视口内/边缘带) + w₃·距离衰减(−) − w₄·最近播放惩罚`。
命中上限时：新 `priority` > 当前最低 → **抢占**（被抢者 **0.1s fade-out**，防爆音）；否则**丢弃**（实时音频宁可缺、不可迟，不排队）。

**③ 同类事件 = 窗口合并 + 变体**（防"机关枪"与相位爆音）
同一类事件在**时间窗（默认 120ms）内合并为单次代表音**，音量按计数对数微增；叠**音高 ±5% 随机 + 同类变体池轮播**，避免完全同相叠加（相位叠加是"声音互相覆盖变糊"的头号元凶）。

**④ 相互掩盖的治理**
- **响度预算**：SFX 总线挂 Limiter/Compressor，防叠加爆音；
- **素材归一化**：入库音效统一响度（建议 −16 LUFS）；
- **Ducking（开）**：`重要度≥高` 事件（战斗/立国等）触发时，BGM/Ambient 自动 **−6~−10dB** 让位，播完恢复。

**⑤ 距离 × 可见性**：3D 距离衰减 + 每类 **最大可听半径**（超出不播 = 省预算）；配合 §1.4 可见性三区。

### 1.6 倍速与暂停/失焦

- **倍速（0.5x~15x 考跑）**：音频与 `timeScale` **完全解耦**（realtime 驱动）。倍速**只通过"事件密度"间接影响音效触发次数**，由限流（§1.5）兜底；15x 下不加速、不爆音。限流窗口按"游戏日事件率"而非墙钟计。
- **暂停**：留 BGM，静 Ambient + 世界 SFX（用户确认）。
- **失焦**：整体静音（用户确认）。
- **音量分轨**（用户确认）：`BGM / SFX / Ambient / UI` 四条独立音量（扩展 2_13 设置面板 D240）。主音量沿用 `AudioListener.volume`。

## 三、数据定义（SO / 枚举）

原则：**一切可调参数走 SO**（`so-data-driven`），禁硬编码。

### 3.1 `AudioConfig`（全局）
`bgmVolume / sfxVolume / ambientVolume / uiVolume`；`maxWorldVoices=12`；`sameTypeWindowMs=120`；`edgeBandPercent`；`crossfadeSec=0.8`；`pitchJitterPercent=5`；`duckDb=−8 / duckAttackMs / duckReleaseMs`；`priorityWeights{w₁..w₄}`；`zoomBandThresholds`；`hearabilityCurve`（可听门限曲线）；`maxAudibleRadiusDefault`。

### 3.2 `AudioEventMap`（事件→音效映射，白名单）
每条：`eventKey`（EventBus 事件标识）、`category`（见 3.4）、`layer`、`spatial(2D/3D)`、`importance(0..1)`、`maxRadius`、`cooldownMs`、`clipVariants[]`（变体池）、`volumeDb`、`pitchRange`。
**未在表内的事件 = 不发声**（白名单制，防噪音灾难）。

### 3.3 `AudioBank`（音效资产集合）
音效剪辑引用、响度归一化参数（建议 −16 LUFS）、变体分组。

### 3.4 枚举
- `AudioLayer { BGM, Ambient, WorldSFX, UI }`
- `AudioCategory { Harvest, Construction, Transport, Combat, Threat, Kingdom, Ambient, BGM, UI }`
- `SpatialMode { TwoD, ThreeD }`

## 四、数据流与生命周期

### 4.1 数据流
```
EventBus(可听事件) ─► AudioEventRouter(白名单 + 可见性/距离过滤) ─► VoiceManager(预算12 / 抢占 / 合并 / 变体 / 池)
                                                                      └─► AudioSource(3D) 发声
CameraRig.zoom ────► ZoomAudioMixer(三档 crossfade + Ducking) ─────► AudioMixer 各音轨增益
SettingsPanel ─────► AudioConfig 四轨音量
```
`VoiceManager` 拾取：`AudioDirector` 于每帧派发队列批次 → `VoiceManager` 排序/抢占 → 命中 `AudioSource` 池实体 → 播放并在句末期归还池。

### 4.2 生命周期八格

| # | 环节 | 设计 |
|---|---|---|
| 1 诞生 | AudioDirector 由 `WorldLifecycle` 编排创建；订阅 EventBus 白名单事件 + zoom 事件 |
| 2 归属 | GameScene 音频根对象；AudioSource 走对象池 |
| 3 更新 | 事件驱动 + 每帧维护 active voices / Mixer 增益插值（unscaled） |
| 4 挂起/恢复 | 暂停：留 BGM、静 Ambient+SFX；失焦：整体静音；恢复时按当前档位还原增益 |
| 5 正常终结 | 世界销毁 → 退订 EventBus/zoom、归还池、Mixer 还原默认 |
| 6 异常终结 | 切场景 / 多次建局 → `ResetState`（**零残留**，守 WorldLifecycle/L-22 纪律） |
| 7 清算 | 退订全部订阅、AudioSource 归池、清 active 列表、还原音量 |
| 8 持久化 | 音频本身不持久化；音量偏好走 PlayerPrefs（沿用 D240） |

**成对闭环**：`Subscribe↔Unsubscribe`、`池借出↔归还`、`Mixer 改值↔ResetState 还原`，全部成对。

## 六、错误处理与边界情况

| 情况 | 处理 |
|---|---|
| EventBus 事件不足 | 实施前置盘点（见 §五）；补轻量表现层事件，禁改业务事件语义 |
| 反复建局/切场景 | `ResetState` 退订+归池，冒烟多次建局须零残留 |
| 时钟暂停 / 倍速切换 | unscaled 驱动，音频不受影响；限流按游戏日事件率 |
| 同帧海量同类事件 | 窗口合并（120ms）+ 变体，防爆音 |
| AudioSource 池枯竭 | 按优先级抢占最低者；仍不足则丢弃新事件 |
| 音效素材缺失 | 静默跳过 + 一次性告警，**不崩**；条目回落"待产出" |
| Mixer 未配置/加载失败 | 回落默认增益；不阻断游戏 |
| 音频关闭/静音 | 世界行为**完全不变**（零世界写入验证点） |

## 七、测试策略

**行为级探针**
1. zoom 档切换 → 各音轨增益变化 + crossfade 生效（无硬切）。
2. 世界事件 → 发声计数（`AudioEventRouter` 命中白名单）。
3. 并发超 12 → **抢占最低优先级**（被抢者 0.1s fade-out）。
4. 同类窗口合并：N 次同帧砍树 → **1 次代表音**（+ 变体）。
5. Ducking：高重要度事件触发 → BGM/Ambient 压低 → 播完恢复。
6. 暂停/失焦：暂停留 BGM 静其余；失焦整体静音；恢复还原。
7. **零世界写入证明**：音频开关两态下同 seed 世界状态**逐字节一致**。

**冒烟**：多次建局零残留（`WorldLifecycle.ResetState`）；同 seed 事件序一致。

**性能**：12 上限下 GC/CPU 无飙升；`AudioSource` 池命中率（禁运行期 new）。
