**改动**：

2. 主城等级上限 1-6（现代码注释 1-3，需确认）。

**涉及文件**：`Systems/Kingdom/KingdomManager.cs`、`KingdomConfig.cs`、`ModuleType.cs`。

**验收**：修复主城→Lv1；升主城解锁模块；存档读档保持。

## 二、人口实体化与 NPC 职业（🔶 需更新 + 🆕 新建）

### 2.1 职业枚举改名/新增（🔶）
- `Occupation.Unemployed` → 改名 `Resident`（居民）
- 新增 `Vagrant`（流浪汉）、`Child`（小孩）
- `Porter`（搬运工）删除（并入工人）
- 新增 `Worker`（已有）
- 同步 `UnitDataManager` 的 faction_occupation key 与资产映射。

### 2.2 人口从计数 → 实体（🆕 核心改造）
- `PopulationSystem` 维护**王国 NPC 实体引用列表**（居民/小孩/工人/士兵），`PopulationCount` 改为 `entities.Count` 派生。
- 实体的增删（招募/出生/长大/转职/死亡）都通过注册表，保持计数与实体一致。

### 2.3 生命周期（🆕）
- **流浪汉 → 居民**：地图流浪汉营地（3.2 生成 2-3 个）；点击招募（花 1 粮）→ 立即变居民 → AI 走回王国 → 纳入人口。
- **繁殖 → 小孩 → 居民**：两居民进房表演 → 出小孩；**2 次天数事件**后长大变居民。
- **居民 → 职业**：训练所（工人）/练兵场（士兵）/卫戍营（将军/骑兵）。

**涉及文件**：`Data/UnitData.cs`（Occupation）、`Data/UnitDataManager.cs`、`Systems/Kingdom/PopulationSystem.cs`、`Systems/Unit/UnitController.cs`（satiety/happiness/childGrowthDays）。

**验收**：开局 10 实体（1 君主+4 工人+5 居民）；招募流浪汉→居民；小孩 2 天→居民。

## 三、饱食 / 幸福（✅ 已实现，接实体化）

**现状**：`SatietySystem`/`HappinessSystem` 已按 Unit 个体结算，整体=平均。

**改动**：
1. **消耗顺序**（🆕）：先基础粮 → 面包 → 肉（自动降级）。
2. 粮/肉/面包为粮食子类，进食从仓库/粮仓取（非国库）。
3. `IsNpc` 范围含 居民/小孩/工人/士兵（流浪汉招募态单独处理）。

**涉及文件**：`SatietySystem.cs`、`HappinessSystem.cs`、`KingdomConfig.cs`（耗粮/食品数值）。

**验收**：NPC 每日耗粮，缺粮降级吃面包/肉；饱食 0 扣血、80+ 回血。

## 五、建筑功能补全（🆕 新建）

### 5.1 粮食加工坊（需工人）
- 通用工人自动派驻：检测仓库/粮仓有粮 → 搬粮 → 加工（表现动画）→ 存面包 → 工人不足停工。
- 配方：粮×2 → 面包×1。

### 5.2 水井（农业供水）
- 农田生产需水：工人从水井挑水（隐式水，不新增资源）。
- 缺水停产；越高级农田耗水越多。

### 5.3 医院（被动+主动）
- 被动（保留）：每日饱食回血 +`hospitalRecoveryBonus` + 幸福。
- 主动（🆕）：伤员（血不满）自动去医院回血更快。

### 5.4 教堂（✅ 已实现）
- 幸福加成（按数量），无需改动。

**涉及文件**：`ProducerComponent.cs`（废弃自动产出→改工人）、`Building.cs`、`BuildingPanel.cs`、`SatietySystem.cs`（医院主动）。

**验收**：加工坊有粮+有工人→加工；农田缺水→停产；伤员去医院回血。

## 六、搬运链与存储（🔶 需更新）

**现状**：`ScheduleCenterStub` 已派搬运（3.3.5）；`ProducerComponent`+`StorageComponent` 自动产出。

**改动**：
1. **自动产出废弃**：生产需工人执行（3.5.2），移除 ProducerComponent 自动产出的依赖。
2. **每资源独立存储**（🆕）：仓库/粮仓每资源/子类独立上限。
3. **就近搬运**：工人就近搬到最近仓库（国库仅当最近）。
4. 晶/火油副产搬运。

**涉及文件**：`ProducerComponent.cs`、`StorageComponent.cs`、`ScheduleCenterStub.cs`、`Building.cs`。

**验收**：木→就近仓库；粮/肉/面包各独立容量；副产搬运。

## 七、建筑摧毁与修复（🆕 新建）

- 生产/民生/商业/科技/军事训练建筑被毁 → 留废墟（内部资源清空）→ 工人修复任务重建。
- 土木工事/战争机器 → 直接销毁。
- 修复消耗 = 建造成本 × 50%；时间 = 建造同档。

**涉及文件**：`Building.cs`（Ruins 态 + Die 分支）、`BuildingFactory.cs`、`ScheduleCenterStub.cs`（修复任务）、`BuildingSaveData.cs`。

**验收**：生产建筑被攻破→废墟+资源清空；工人修复→重建。
