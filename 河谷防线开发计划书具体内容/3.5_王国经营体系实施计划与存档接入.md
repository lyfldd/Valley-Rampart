## 二、人口实体化与 NPC 职业（🔶 需更新 + 🆕 新建）

### 2.1 职业枚举改名/新增（🔶）
- `Occupation.Unemployed` → 改名 `Resident`（居民）
- 新增 `Vagrant`（流浪汉）、`Child`（小孩）
- `Porter`（搬运工）删除（并入工人）
- 新增 `Worker`（已有）
- 同步 `UnitDataManager` 的 faction_occupation key 与资产映射。

### 2.2 人口从计数 → 实体（🆕 核心改造）
- `PopulationSystem` 维护**王国 NPC 实体引用列表**（居民/小孩/工人/士兵），`PopulationCount` 改为 `entities.Count` 派生。
- 实体的增删（招募/出生/长大/转职/死亡）都通过注册表，保持计数与实体一致。

### 2.3 生命周期（🆕）
- **流浪汉 → 居民**：地图流浪汉营地（3.2 生成 2-3 个）；点击招募（花 1 粮）→ 立即变居民 → AI 走回王国 → 纳入人口。
- **繁殖 → 小孩 → 居民**：两居民进房表演 → 出小孩；**2 次天数事件**后长大变居民。
- **居民 → 职业**：训练所（工人）/练兵场（士兵）/卫戍营（将军/骑兵）。

**涉及文件**：`Data/UnitData.cs`（Occupation）、`Data/UnitDataManager.cs`、`Systems/Kingdom/PopulationSystem.cs`、`Systems/Unit/UnitController.cs`（satiety/happiness/childGrowthDays）。

**验收**：开局 10 实体（1 君主+4 工人+5 居民）；招募流浪汉→居民；小孩 2 天→居民。

## 五、建筑功能补全（🆕 新建）

### 5.1 粮食加工坊（需工人）
- 通用工人自动派驻：检测仓库/粮仓有粮 → 搬粮 → 加工（表现动画）→ 存面包 → 工人不足停工。

### 5.2 水井（农业供水）
- 农田生产需水：工人从水井挑水（隐式水，不新增资源）。

### 5.3 医院（被动+主动）

### 5.4 教堂（✅ 已实现）
- 幸福加成（按数量），无需改动。

**涉及文件**：`ProducerComponent.cs`（废弃自动产出→改工人）、`Building.cs`、`BuildingPanel.cs`、`SatietySystem.cs`（医院主动）。

**验收**：加工坊有粮+有工人→加工；农田缺水→停产；伤员去医院回血。

### 12.1 存档机制（新增）

**决策**：**每日自动 + 手动，单槽**（最近一次覆盖）。

**实现**：
- `SaveManager` 加：
  - `AutoSaveDaily()`：每日夜晚结束触发自动存档（订阅昼夜事件）。
  - `ManualSave()`：玩家手动触发（UI 按钮/快捷键）。
  - 单槽覆盖：`saveSlot = 0`，每次保存覆盖前一次。
- 存档内容沿用 §十一 边界（只存"不可重算"：建筑状态/单位状态/任务/资源/科技/时间）。
- 加载时从单槽读取，无槽位选择 UI。

**字段**：
- `SaveManager.autoSaveDayInterval` = 1（每日）
- `SaveManager.saveSlot` = 0（单槽）

### 12.2 时间加速（更新）

**决策**：**全局 Time.timeScale，仅 2 倍速**（不做 4x）。

**实现**：
- `TimeManager` 加 `timeScale`（1 或 2），UI 仅提供 1x/2x 切换。
- 加速时 `Time.timeScale = 2`，所有系统（AI/生产/搬运）同步加速。
- **战斗/夜晚强制 1x**：见 12.3。

**注意**：仅 2x 不做 4x，避免高加速时 AI 决策漏事件。

### 12.3 战斗降速触发（新增）

**决策**：**感知到敌人 = 降速**（任何我方单位感知到敌 → 1x）。

**实现**：
- `TimeManager` 订阅 `AttentionSystem.EnemyDetectedEvent`（任何我方单位感知到敌方单位）。
- 事件触发 → 强制 `timeScale = 1`，禁用 2x 切换（UI 灰显）。
- 所有我方单位感知范围内无敌方单位 → 恢复玩家选择的 timeScale。
- 夜晚波次期间 = 战斗状态，强制 1x。

**字段**：
- `TimeManager.isCombatSlowdown`（bool）
- `TimeManager.playerPreferredScale`（1 或 2，玩家选择，战斗结束后恢复）
