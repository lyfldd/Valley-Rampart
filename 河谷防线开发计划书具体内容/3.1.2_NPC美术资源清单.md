## 〇、通用规格

### 0.1 Sprite Sheet 格式

| 项目   | 规格                                                 |
| ---- | -------------------------------------------------- |
| 人物尺寸 | 32×48（普通NPC）/ 48×64（重装/骑兵/将军）/ 24×32（小孩）           |
| 动画帧率 | 12 FPS（全部动画统一：移动/战斗/生产）                            |
| 朝向   | 仅做 **右向**，代码运行时 `spriteRenderer.flipX = true` 实现左向 |
| 像素风格 | 像素硬边（关闭抗锯齿 Filter Mode = Point）                    |
| 色板   | 每职业主色 + 2 辅色 + 肤色 + 发色                             |
| 描边   | 1px 深色描边，确保在各种地形背景下可读                              |

### 0.2 动画方案：全帧序列（Sprite Sheet）

**架构决策**：采用全帧序列方案，每个动画状态是一张 Sprite Sheet（多帧横向排列），每帧是完整的角色图。**武器直接画在角色身上**，不独立拆分。

**为什么不用剪纸人偶（Cutout Puppet）**：

- Pivot 对齐成本高（头底对齐脖顶、肩缝对齐上臂内侧，之前踩过"头没接上""胳膊太长"的坑）
- 多 SpriteRenderer 层级管理复杂（Body/Head/LHand/RHand/Weapon 各一个）
- 美术产出需分部件绘制，增加沟通成本
- 与项目现有单 SpriteRenderer 架构不兼容

**帧播放方案**：

- P0 推荐：**代码驱动帧切换**（UnitVisual 组件 + Sprite\[] 数组 + 定时切帧），简单无配置依赖
- 美术到位后可迁移：Unity Animation Clip + Animator（支持 Animation Event 触发攻击判定）

### 0.3 武器方案：烘焙进图 + 代码切 Sprite Sheet

**核心原则**：武器直接画进角色 Sprite Sheet，不做独立 Sprite 拆分。每个职业根据其固定武器配置，产出对应武器版本的 Sprite Sheet。

**为什么不做独立武器 Sprite**：

- 项目中职业武器是固定的（战士=剑/长矛，弓手=弓，法师=法杖），不需要自由换装
- 独立武器 Sprite 会导致多 SpriteRenderer 层级管理 + Pivot 对齐问题
- 烘焙进图 = 一张图搞定，代码只需切 Sprite Sheet 引用

**如果未来需要武器换装**：

- 方案 A：每个武器版本一套 Sprite Sheet（`Warrior_idle_sword.png` / `Warrior_idle_axe.png`），代码切引用
- 方案 B：回退到"角色 + 武器子 Sprite"方案（仅在确实需要自由换装时）

**每个职业的 Sprite Sheet 配置示例（战士）**：

| Sprite Sheet         | 包含内容            | 帧数 |

| `Warrior_idle.png`   | 战士 + 单手剑，4帧循环   | 4  |

**代码控制方式**：UnitVisual 组件持有按状态分组的 Sprite\[] 数组，根据 UnitController 状态变化切帧：

```csharp
public class UnitVisual : MonoBehaviour
{
    public Sprite[] idleFrames;
    public Sprite[] walkFrames;
    public Sprite[] runFrames;
    public Sprite[] attackFrames;
    public Sprite[] castFrames;
    public Sprite[] workFrames;
    public Sprite[] buildFrames;
    public Sprite[] mountIdleFrames;
    public Sprite[] mountRunFrames;
    public Sprite[] mountChargeFrames;

    public void Play(UnitState state)
    {
        // 根据状态切换 Sprite Sheet
    }
}
```
