# 3.5.2 工人通用化设计

> 日期：2026-08-06
> 状态：设计定稿（逐点确认收敛，待实施）
> 前置：3.5.1_NPC实体循环与王国接入.md / 3.5 王国经营体系 / 3.3.5 资源流转搬运 / 3.0.1 AI
> 本文解决：**3.5 §13.12 把生产/生活职业分得太细（工人/农民/搬运工/厨师/牧民/教官/铁匠/工匠/学者/商人），冗余且增加维护成本。决策：收拢为一个通用「工人」职业**，用目标建筑区分行为，保留必要边界。

---

## 一、本质

**一个 `工人（Worker）` 职业通吃王国所有生产/生活执行**：采集、种植、搬运、加工、养殖、建造、维修。行为由**工人当前被指派到的目标建筑**决定，而非由多个独立职业枚举决定。

> 一句话：**工人 = 劳动力，建筑 = 分工**。职业不再按"活儿"划分，按"在哪个建筑干活"划分。

---

## 二、原分化 → 通用工人（归并表）

| 原分化（3.5 §13.12） | 归属 | 说明 |
|---------------------|------|------|
| 工人（采集） | **并入通用工人** | 采石场/矿洞采集〔伐木场已作废（2_12 D2：Tree 一次性刷新替代）——2026-08-29 Q6 C 面补注，原"伐木场"为历史语境〕 |
| 农民（种植） | **并入通用工人** | 农田种植 |
| 搬运工（Porter） | **并入通用工人** | 运粮/搬运/仓库间转运（原 `Occupation.Porter` 取消） |
| 厨师（加工） | **并入通用工人** | 粮食加工坊 |
| 牧民（养殖） | **并入通用工人** | 牧场喂粮/管理/宰杀 |
| 铁匠 / 工匠 | **并入通用工人** | 装备已并入训练，无独立铁匠/工匠 |
| 教官（训练） | **不设职业** | 训练表演 = 居民走过去变职业（见 3.5.1 §4.3） |
| 学者（研究） | **不设职业** | 研究由建筑自动实现 |
| 商人 | **不设职业** | 贸易走市场建筑面板 |

> 收拢后：生产/生活无独立工种，**通用工人一职覆盖全部**；教官/学者/商人不设职业。

> **装饰 NPC（美术）**：商人 / 学者 / 教官这些"驻守型 NPC"**不设职业、不是可交互实体**——功能全由建筑实现，NPC 图标只是**嵌入建筑图片的纯装饰**（美术把人物画进建筑精灵图），无逻辑、无行为、无交互。

## 三、通用工人的行为分发（用目标建筑区分）

> **2026-08-06**：生产**不再自动产出**（ProducerComponent 自动产出废弃），所有生产（采集/种植/加工/挑水/养殖）**需通用工人执行**。以本档与 3.5.3 为准。

### 3.1 行为 = 目标建筑，不新增职业
| 目标建筑 | 工人行为 |
|---------|---------|
| 采石场 / 矿洞 | 采集（石/矿 + 副产水晶/火油）〔伐木场已作废（2_12 D2），采集木=伐 Tree——2026-08-29 Q6 C 面补注〕 |
| 农田 | 种植 / 收获 |
| 仓库 / 粮仓 | 搬运 / 存储转移 |
| 粮食加工坊 | 加工（粮×2 → 面包） |
| 牧场 | 喂粮 / 管理动物 / 执行宰杀 |
| 建造/升级/维修 | 施工 |

### 3.2 行为调度（逻辑归 3.0 AI）
- 工人**不实时盯**：由调度中心（3.3.5）检测建筑产出/任务，自动派空闲工人到场执行。
- 一个工人同一时刻只服务一个目标建筑（一个任务），任务完成可被调度到下一个。
- 玩家只做**决策与操作点**（建/升级建筑、排训练、买动物、点宰杀），日常执行全自动。

### 3.3 覆盖组合
- 目标建筑类型：采集 / 种植 / 加工 / 养殖 / 搬运 / 建造。
- 工人状态：空闲 / 执行中 / 搬运中。
- 建筑等级：Lv1 / Lv2 / Lv3（行为一致，效率不同）。
- 多建筑竞争：空闲工人不足时按调度优先级分配。

## 四、边界（什么不并入通用工人）

| 不并入 | 原因 |
|--------|------|
| **军事职业**（战士/弓手/法师/治疗师/重装/盾卫/弩手/大法师/主教/骑兵/将军） | 战斗能力，独立于生产 |
| **君主** | 玩家控制单位 |
| **流浪汉 / 小孩 / 居民** | 生活状态，非生产执行者 |
| **机器 / 工事**（投掷机/弩炮/塔/墙/门/拒马） | 非 NPC，无行为 |

> 工人无攻击能力（生活职业，见 3.5.1 §2.1）。

---

## 五、训练与成本（装备并入后）

- **居民 → 工人**：训练所训练（耗金 + 时间），表演 = 居民走过去几秒变工人。
- **装备已并入训练**：原"去装备厂拿锤子"步骤取消（见 3.5.1 §4.3）；训练成本内含原装备成本，**适当降低，不直接相加**。
- 搬运工并入工人后，**不再单独训练搬运工**。

### 关键因子（SO）
工人训练消耗/时长、训练所等级门槛、工人数量上限（可选）、调度优先级权重。

### 验收
居民在训练所训练 → 变工人；工人可被指派到任一生产建筑执行对应行为；无需单独训练搬运工/农民/厨师/牧民。
