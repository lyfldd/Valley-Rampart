# 🔲 区块系统设计（第0阶段前置基础设施）

> 2026-07-27 阿铁拍板，主理人游承峰汇编
> 地图系统 + 战斗系统的共同前置，最先做

## 📝 设计动机

区块系统是**跨系统的基础设施**——很多系统都依赖它：

| 依赖方 | 用区块做什么 |
|--------|------------|
| 移动系统 | NPC 移动时更新所在区块；同区块内排队 |
| 攻击系统 | 攻击命中从区块取目标列表（Range + MaxHits） |
| 堆叠管理 | 防御建筑 NPC 上限低 / 敌人上限中 / 普通 NPC 无上限 |
| 地图系统（未来） | 大区块分小区块，程序化生成的基础 |
| 寻路排队（未来） | 前方区块满了，后面等 |

**不先做区块系统，上面这些系统都没法落地。** 所以区块系统是第 0 阶段前置。

---

## 一、核心概念

### 1.1 区块（GridCell）

地图按固定大小划分为网格，每个格子是一个"区块"。区块是单位堆叠的最小单元。

```
... ──┬──┬──┬──┬──┬── ...
     │  │  │  │  │
     C0 C1 C2 C3 C4
     │  │  │  │  │
... ──┴──┴──┴──┴──┴── ...
       ↑每个 C 是一个区块（cellSize 像素宽）
```

### 1.2 区块坐标（GridCoord）

1D 游戏只有 x 轴，但飞行兵有 y 层：

```csharp
public struct GridCoord
{
    public int x;  // x 网格坐标（地面层）
    public int y;  // y 层：0=地面, 1=空中
}
```

### 1.3 堆叠上限（按 NPC 类型区分）

| NPC 类型 | 堆叠上限 | 说明 |
|---------|:--:|------|
| 防御建筑 NPC（箭塔驻军等） | 3 | 上限低，避免防御过度集中 |
| 敌人 NPC（怪物/王国兵） | 5 | 上限中，允许群体进攻但不过载 |
| 普通 NPC（村民/工匠） | 0（无上限） | 经济单位不限制 |

> 上限可在 `GridConfig` SO 里配，改数值不改代码。

## 二、区块层级（未来扩展预留）

```
大区块（Region）—— 地图系统未来用
  │  程序化生成的基本单位（如一个平原区域 = 1个大区块）
  │  含多个小区块
  ▼
小区块（Cell）—— 现在做
  │  单位堆叠的最小单元
  │  cellSize 像素宽（如 32px）
  │  含堆叠上限 + 单位列表
  ▼
子层（Layer）—— y 轴分层
  │  地面层（y=0）：城墙/陷阱/地面单位
  │  空中层（y=1）：飞行兵/防空塔
```

**现在只做小区块 + 子层**。大区块等地图系统时再扩展（接口预留）。

### 3.1 GridConfig.cs（SO 配置）

**文件**：`Assets/_Game/Data/GridConfig.cs`

```csharp
using System;
using UnityEngine;

/// <summary>
/// 区块系统配置（ScriptableObject，数据驱动）。
/// 区块大小 + 堆叠上限 + 飞行层阈值，全在 Inspector 配。
/// </summary>
[CreateAssetMenu(menuName = "ValleyRampart/GridConfig", fileName = "GridConfig")]
public class GridConfig : ScriptableObject
{
    [Header("区块大小")]
    [Tooltip("一个区块多宽（世界单位/像素）")]
    public float cellSize = 32f;

    [Header("飞行层")]
    [Tooltip("y 超过此值视为空中层")]
    public float flyHeightThreshold = 5f;
    [Tooltip("空中层单位的固定 y 坐标")]
    public float flyHeight = 8f;

    [Header("堆叠上限（按 NPC 类型）")]
    public StackLimitConfig[] stackLimits = new StackLimitConfig[3];

    /// <summary>按类型获取堆叠上限（0=无上限）。</summary>
    public int GetStackLimit(UnitCategory category)
    {
        foreach (var cfg in stackLimits)
        {
            if (cfg.category == category) return cfg.maxStack;
        }
        return 0;  // 默认无上限
    }
}

/// <summary>单类 NPC 的堆叠上限配置。</summary>
[Serializable]
public struct StackLimitConfig
{
    public UnitCategory category;
    [Tooltip("堆叠上限（0=无上限）")]
    public int maxStack;
}

/// <summary>NPC 类型分类（决定堆叠上限）。</summary>
public enum UnitCategory
{
    Defense,   // 防御建筑 NPC（上限低，如 3）
    Enemy,    // 敌人 NPC（上限中，如 5）
    Civilian  // 普通 NPC（村民/工匠，无上限）
}
```

**资产实例默认值**：

| category | maxStack |
|----------|:--:|
| Defense | 3 |
| Enemy | 5 |
| Civilian | 0（无上限） |

### 3.2 GridCoord + GridCell（数据结构）

**文件**：`Assets/_Game/Systems/Grid/GridTypes.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

/// <summary>区块坐标。x=网格列，y=层（0地面/1空中）。</summary>
public struct GridCoord
{
    public int x;
    public int y;

    public GridCoord(int x, int y) { this.x = x; this.y = y; }

    public override int GetHashCode() => x * 31 + y;
    public override bool Equals(object obj) =>
        obj is GridCoord c && c.x == x && c.y == y;
}

/// <summary>
/// 单个区块。持有当前在该区块内的单位列表。
/// 堆叠上限按类型查 GridConfig（不在区块里存，因为同区块不同类型上限不同）。
/// </summary>
public class GridCell
{
    public GridCoord Coord;
    public readonly List<UnitController> Units = new List<UnitController>();

    public int Count => Units.Count;

    public int CountByCategory(UnitCategory category)
    {
        int count = 0;
        foreach (var u in Units)
        {
            if (u != null && u.GetCategory() == category) count++;
        }
        return count;
    }

    public void Add(UnitController unit) => Units.Add(unit);
    public bool Remove(UnitController unit) => Units.Remove(unit);
    public void Clear() => Units.Clear();
}
```

### 3.3 GridSystem.cs（区块管理器 Singleton）

**文件**：`Assets/_Game/Systems/Grid/GridSystem.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

/// <summary>
/// 区块系统管理器（Singleton）。
/// 职责：维护区块字典 + NPC 进出区块 + 世界坐标↔网格坐标转换 + 查询区块内单位。
/// 是地图/战斗/移动系统的共同前置基础设施。
/// </summary>
public class GridSystem : Singleton<GridSystem>
{
    [Header("配置")]
    [SerializeField] private GridConfig config;

    private readonly Dictionary<GridCoord, GridCell> _cells = new Dictionary<GridCoord, GridCell>();

    // 每个单位当前所在的区块（用于移动时快速注销旧区块）
    private readonly Dictionary<UnitController, GridCoord> _unitCells = new Dictionary<UnitController, GridCoord>();

    public GridConfig Config => config;

    protected override void Awake()
    {
        base.Awake();
        if (config == null)
            config = Resources.Load<GridConfig>("Grid/GridConfig");
        if (config == null)
            Debug.LogError("[GridSystem] 未找到 GridConfig！");
    }

    // ===== 坐标转换 =====

    /// <summary>世界坐标 → 网格坐标。</summary>
    public GridCoord WorldToCoord(Vector2 pos)
    {
        int x = Mathf.FloorToInt(pos.x / config.cellSize);
        int y = pos.y > config.flyHeightThreshold ? 1 : 0;
        return new GridCoord(x, y);
    }

    /// <summary>网格坐标 → 区块中心世界坐标。</summary>
    public Vector2 CoordToWorld(GridCoord coord)
    {
        return new Vector2(
            (coord.x + 0.5f) * config.cellSize,
            coord.y == 1 ? config.flyHeight : 0f
        );
    }

    // ===== NPC 进出区块 =====

    /// <summary>
    /// 尝试让单位进入区块。受堆叠上限约束。
    /// 返回 false = 超过上限，不能进（移动系统据此排队等待）。
    /// </summary>
    public bool TryEnter(UnitController unit, GridCoord coord)
    {
        var cell = GetOrCreateCell(coord);
        var category = unit.GetCategory();
        int limit = config.GetStackLimit(category);

        if (limit > 0 && cell.CountByCategory(category) >= limit)
        {
            return false;  // 超过堆叠上限
        }

        // 先从旧区块注销
        ExitCurrentCell(unit);

        cell.Add(unit);
        _unitCells[unit] = coord;
        return true;
    }

    /// <summary>单位离开当前区块（移动到新区块前调用）。</summary>
    public void ExitCurrentCell(UnitController unit)
    {
        if (_unitCells.TryGetValue(unit, out GridCoord oldCoord))
        {
            if (_cells.TryGetValue(oldCoord, out var oldCell))
                oldCell.Remove(unit);
            _unitCells.Remove(unit);
        }
    }

    // ===== 查询（攻击系统/移动系统用）=====

    /// <summary>获取区块内所有单位（攻击命中用）。</summary>
    public List<UnitController> GetUnitsInCell(GridCoord coord)
    {
        if (_cells.TryGetValue(coord, out var cell))
        {
            // 过滤已销毁的
            cell.Units.RemoveAll(u => u == null);
            return cell.Units;
        }
        return new List<UnitController>();
    }

    /// <summary>获取某单位当前所在区块坐标。</summary>
    public GridCoord? GetUnitCoord(UnitController unit)
    {
        if (_unitCells.TryGetValue(unit, out GridCoord coord))
            return coord;
        return null;
    }

    /// <summary>获取区块内指定类型的单位（攻击时筛选目标用）。</summary>
    public List<UnitController> GetUnitsInCellByCategory(GridCoord coord, UnitCategory category)
    {
        var result = new List<UnitController>();
        if (_cells.TryGetValue(coord, out var cell))
        {
            foreach (var u in cell.Units)
            {
                if (u != null && u.GetCategory() == category)
                    result.Add(u);
            }
        }
        return result;
    }

    // ===== 清理 =====

    /// <summary>单位死亡/销毁时调用，从区块移除。</summary>
    public void RemoveUnit(UnitController unit)
    {
        ExitCurrentCell(unit);
    }

    /// <summary>清空所有区块（场景切换时调）。</summary>
    public void ClearAll()
    {
        _cells.Clear();
        _unitCells.Clear();
    }

    // ===== 内部 =====

    private GridCell GetOrCreateCell(GridCoord coord)
    {
        if (!_cells.TryGetValue(coord, out var cell))
        {
            cell = new GridCell { Coord = coord };
            _cells[coord] = cell;
        }
        return cell;
    }

    // ===== 调试 Gizmos =====

    private void OnDrawGizmos()
    {
        if (config == null) return;
        Gizmos.color = new Color(1, 1, 0, 0.3f);
        // 画区块网格线
        Vector2 camPos = Camera.main ? Camera.main.transform.position : Vector2.zero;
        float viewWidth = Camera.main ? Camera.main.orthographicSize * 2 * Camera.main.aspect : 20f;
        int startX = Mathf.FloorToInt((camPos.x - viewWidth / 2) / config.cellSize);
        int endX = Mathf.ceilToInt((camPos.x + viewWidth / 2) / config.cellSize);
        for (int x = startX; x <= endX; x++)
        {
            Vector3 p1 = new Vector3(x * config.cellSize, -5, 0);
            Vector3 p2 = new Vector3(x * config.cellSize, 5, 0);
            Gizmos.DrawLine(p1, p2);
        }
    }
}
```

### 3.4 UnitController 扩展（获取类型）

**改动**：`UnitController` 加 `GetCategory()` 方法：

```csharp
// UnitController 里加
public UnitCategory GetCategory()
{
    if (Data == null) return UnitCategory.Civilian;
    return Data.faction switch
    {
        Faction.Human_Player => UnitCategory.Civilian,       // 玩家方=普通（村民/工匠）
        Faction.Human_Defense => UnitCategory.Defense,       // 防御建筑驻军
        _ => UnitCategory.Enemy,                             // 其他=敌人
    };
}
```

> Faction 枚举可能要加 `Human_Defense`（防御建筑驻军）。如果不想加，用 Occupation 判断也行。

## 四、和其他系统的接口

### 4.1 移动系统（移动+障碍处理）

```csharp
// NPC 每帧移动后，更新所在区块
GridCoord newCoord = GridSystem.Instance.WorldToCoord(transform.position);
GridCoord? oldCoord = GridSystem.Instance.GetUnitCoord(this);

if (!oldCoord.HasValue || oldCoord.Value.x != newCoord.x || oldCoord.Value.y != newCoord.y)
{
    // 跨区块了，尝试进入新区块
    if (!GridSystem.Instance.TryEnter(this, newCoord))
    {
        // 超过堆叠上限，不能进 → 排队等待（移动系统处理）
        StopMoving();  // 停下等前面的走
    }
}
```

### 4.2 攻击系统（防御建筑攻击命中）

```csharp
// 箭塔攻击（MaxHits=1，单体）
GridCoord targetCoord = GridSystem.Instance.WorldToCoord(targetPos);
var units = GridSystem.Instance.GetUnitsInCell(targetCoord);
if (units.Count > 0)
{
    // 按注意力选仇恨最高的
    var target = units.OrderByDescending(u => u.Attention.Score).First();
    target.TakeDamage(damage);
}

// 投石机攻击（MaxHits=5，范围）
var units = GridSystem.Instance.GetUnitsInCell(targetCoord);
int hits = Mathf.Min(units.Count, attackConfig.MaxHits);
for (int i = 0; i < hits; i++)
    units[i].TakeDamage(damage);
```

## 五、数据流

```
NPC 创建
  │
  ▼
GridSystem.TryEnter(unit, 起始Coord)
  ├─ 检查堆叠上限 → 未超 → 进入区块，加入 Units 列表
  └─ 超过上限 → 返回 false → 移动系统排队等待
  │
  ▼
NPC 每帧移动
  │
  ├─ 检测是否跨区块（WorldToCoord 对比旧 Coord）
  ├─ 跨区块 → TryEnter 新区块 → ExitCurrentCell 旧区块
  └─ 未跨区块 → 继续在当前区块
  │
  ▼
攻击系统查询
  │
  └─ GetUnitsInCell(targetCoord) → 返回区块内单位列表 → 按 MaxHits 选目标攻击
  │
  ▼
NPC 死亡
  │
  └─ GridSystem.RemoveUnit(unit) → 从区块移除
```
