### 步骤 4：撤退逃逸点算法（§5.3，2026-08-13 审计定细）

**文件**：`Systems/AI.Core/Decision/RetreatFormulas.cs`（新增逃逸点评分）、`Systems/AI/NPCBrain.cs`（BuildBaseContext 解析 EscapePoint）、`Systems/AI/RetreatToSafeAnchorBehavior.cs`（改造——安全锚点 → 逃逸点）

**迁移 RetreatFormulas（保留）**：`RetreatDistance` / `RetreatSpeed` / `CautionDuration` / `RecoveryDuration` / `FollowKeepDistance` / `SafetyUrge`——公式保留，`cellSize` 参数去除或改格单位。

**逃逸点算法（新增）**：
```
输入：单位位置 P、最近威胁方向 D（格空间归一化）、撤退距离 R_cells（RetreatFormulas）
1. 扇区：以 -D 为中心 ±60° 的撤退扇区
2. 采样：扇区内按半径 R×{0.6, 0.8, 1.0} 三圈 × 每圈 8 方向 = 24 候选点（固定顺序，确定性）
3. 过滤：候选点必须 IsWalkable 且 IsReachable(P→候选)（2_6 P1；P1 前退化为 IsWalkable）
4. 评分：score = costField(候选) + 0.2×|dist(P,候选) - R|（贴近理想撤退距离）
5. 取 score 最小的候选为 EscapePoint；全部失败 → 原地固守（L2 转防御姿态）
```

**L3 战术短撤改造**：`BehaviorCommand.Direction + Distance` 分支改 `TargetPos = EscapePoint`（2D 寻路目标，不再撞墙停语义）；Executor 走 PathFollower（2_3/2_6 接线）。

**验收**：三面围合场景撤出（§5.3 冒烟：不卡墙角/水）；撤退目标可达（IsReachable）；全部失败 → 固守防御姿态。

**文件**：`Systems/AI.Core/Formation/FormationDecisionCore.cs`（槽位形状计算入核）、`Systems/AI/Formation/FormationController.cs`（`AssignSlots` 2D 化）

**槽位 2D 生成**：
```
槽位 = 2D 形状（线/圆/楔形）带朝向（朝向敌人/前进方向，2_8 D2）
生成：以锚点+朝向做形状公式展开槽位坐标（格单位）：
  线阵：槽位沿垂直于朝向的直线展开，间距 1 格
  圆阵：将军居中，半径 r=ceil(n/2π) 环布（弓手内环/近战外环）
  楔形：朝向为轴，两翼逐排后撤 0.7 格
校验：槽位必须可走（微格 IsSubWalkable）；不可走 → 沿朝向反方向回缩 1 格重试（≤3 次）
FormationBrain 意图自决/军令强度保留
```

**验收**：圆/楔形阵在坡地/树林边生成，槽位全可走；不可走槽位回缩生效（≤3 次）。
