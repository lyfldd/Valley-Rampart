### 3.1 关系值引擎（DiplomacySystem）

#### 3.1.1 关系值模型（D351~D352）

**单一连续值 0~100**（D351）；四态=区间分界（D352）：

```
同盟 [75~100] ← 缔约+持续和平
和平 [40~74]  ← 默认初始（50）
紧张 [15~39]  ← 摩擦/威胁积累
战争 [0~14]   ← 宣战触发 / 求和回升
```

- 关系值矩阵：`Dictionary<(kingdomIdA, kingdomIdB), float>`（上三角稀疏，A<B 约定排序；同 seed 确定）
- 初始值：玩家与 AI 默认 50；AI 间按性格第五轴（D299）微调——外交高（≥0.6）= 偏 60 / 外交低（≤0.3）= 偏 40 / 中间=50
- 抽象期也跑衰减（D355：外交不受 SimMode 影响）

#### 3.1.2 关系值增减来源（D355）

| 事件 | 增减（占位，SO 可调） | 触发时机 |
|------|---------------------|---------|
| 边境摩擦（领土邻接扩张） | -2/次 | TerritoryChangedEvent（2_17 D328） |
| 贸易往来 | +3/次 | TradeSystem 交易完成 |
| 援助/送礼 | +5×(1+性格第五轴)（D364：0.0→+5 / 0.5→+7.5 / 1.0→+10；线性乘入 D311 契约） | 玩家/AI 主动操作 |
| 宣战 | -40（直接进战争态） | 宣战操作（D356） |
| 停战条约生效 | +20（回升至和平区间） | 条约生效（D357） |
| 长期和平（每 10 日无事） | +1 | 日 tick 衰减子步 |
| 攻击对方建筑/军队 | -5/次 | L3 战斗事件 |
| 撕毁条约 | -20（对对方）+ -5（对所有第三方） | 撕毁操作（D358） |

衰减规则（D355/D365）：每 5 日若无事件 → 向锚点回归 ±1：**和平/紧张态锚点=50**（避免永久仇恨或蜜月）；**同盟态锚点=75**（同盟需主动维护——送礼/贸易维持，否则缓慢滑落退出同盟）；长期和平 +1/10 日在同盟态**不叠加**（已在高位）。

#### 3.1.3 四态转换规则（D353~D354）

**单向阶梯不跳级**（D354）：

| 转换 | 条件 | 备注 |
|------|------|------|
| 和平→紧张 | 关系值跌破 40 | 自动 |
| 紧张→战争 | **宣战门槛触发（D356）**——不是跌破 15 自动开战 | 开战是决策不是状态 |
| 战争→和平 | 求和/停战条约生效 → 关系值回升至 ≥40 | 需主动操作 |
| 和平→同盟 | 缔约（互不侵犯）+ 关系值 ≥75 | 需主动操作 |
| 同盟→和平 | 关系值跌破 75 | 自动退出（不扣额外惩罚） |
| ~~和平→战争~~ | **禁止**（必须经过紧张期） | D354 不跳级 |
| ~~同盟→战争~~ | **禁止**（必须先退和平→紧张→战争） | D354 不跳级 |

> **多国同日宣战顺序**（D369）：EvaluateRelations 内 AI 宣战判定按 kingdomId 升序逐国执行。先执行者先扣关系值→0；后执行者读到 0 仍满足 <15 可宣战 → 多国围攻允许。同 seed 确定。

### 3.2 宣战门槛（D356）

复合门槛（四条件 AND）：

```
宣战触发 = 全部满足：
1. 剧本阶段 = 军事期（D320）
2. 关系值 < 15（战争态阈值）
3. 性格好战权重 × 态势分 ≥ threshold（SO 占位）
   态势分 = 威胁值（D339：邻接王国兵力和 / max(己方兵力,1)）× 利益分
   利益分 = clamp(对方木材储量 / max(己方木材储量, 1), 0, 3)（D367：0=无利可图 / 1=均势 / 3=肥肉；除零保护；SO 占位）
4. 兵力达目标 80%（D348：当前战士 ≥ 兵力目标 × 0.8——不空巢出击）
```

- **玩家宣战**跳过条件 1/3/4（人脑决策），但扣关系值 -40 并触发 ⑪出征（D324）
- **AI 对 AI 宣战**同公式无人值守（§3.5）
- **宣战后关系值直接设 0**（D368：非减法 clamp——D356 条件 2 已要求 <15，必然归 0；语义="进入战争态"）

### 3.3 条约体系（D357~D358）

**两种条约**（D357，砍自四种）：

| 条约 | 缔结条件 | 效果 | 失效 |
|------|---------|------|------|
| **互不侵犯** | 关系值 ≥40（和平态），双方同意（AI 按性格第五轴判定：外交高更愿签） | 锁宣战 30 日（占位 SO）；期间边境摩擦不扣关系值；**锁期内禁止推边界进入对方领土**（D366：AI 侧⑩可行性=0 出局；玩家侧建造系统拦截——镜像原则） | 30 日到期 / 被撕毁 |
| **停战** | 战争态，一方求和 | 锁宣战 15 日（占位）；关系值 +20 回升至和平 | 15 日到期 |

**撕毁规则**（D358）：
- 条约可随时撕毁（含 AI），撕毁方扣关系值 **-20**（对条约方）；所有第三方 **-5**（"背信弃义"名声传播）
- 撕毁播报："X 国撕毁了与 Y 国的互不侵犯条约！"（KingdomTreatyBrokenEvent → ToastManager）
- AI 撕毁条件：态势分极度有利（差距 ≥2 倍兵力）且条约剩余 <5 日——只在临界点冒背信风险，不随意撕毁

### 3.4 玩家外交交互（D359~D360）

**4 操作 + 撕毁**，走 2_13 面板入口 + 2_17 D331 指令通道（D360）：

| 操作 | 条件 | 代价 | 冷却 | 效果 |
|------|------|------|------|------|
| **宣战** | 任意时刻 | 无资源成本 | 无（即时） | 关系值→0，⑪出征（D324），播报 |
| **求和** | 战争态 | 送礼资源（木50/石30/粮50，占位 SO） | 20 日冷却 | 关系值 +20，停战条约生效（锁 15 日） |
| **送礼** | 非战争态 | 资源（木20/石10/粮20，占位 SO） | 10 日冷却 | 关系值 +5×(1+性格第五轴)（D364：外交高国收益大，+5~+10） |
| **缔约** | 和平态，关系值 ≥40 | 无资源成本 | 30 日冷却（与互不侵犯锁期同步） | 互不侵犯条约生效 |
| **撕毁** | 有条约在身 | 无资源成本 | 无 | 关系值 -20，第三方 -5，播报 |

交互入口（D360）：
- 2_13 外交面板：点选目标 AI 王国 → 显示关系值/四态/条约状态 → 操作按钮
- 操作走指令通道（D331，加 kingdomId，与 AI 同入口）

平衡意图：宣战无成本（玩家随时能打），但求和/送礼有资源成本+冷却——**鼓励先外交后军事**。

### 3.5 AI 间战争涌现（D361~D362）

**无人值守**（D361）：AI 对 AI 宣战复用 §3.2 复合门槛公式，无人工干预。

```
AI_A 对 AI_B 宣战：
  复用 D356 四条件 AND → A 经指令通道下发 ⑪ → L3 FormationBrain 出征
  → 双方关系值→0，播报"A 国向 B 国宣战！"
```

- **双方不对称**（D361）：A 宣战 ≠ B 宣战。B 可能处于和平/发育态，被打了走 ⑭防御姿态（2_17 全阶段可见高分）。B 关系值扣 -40（被动卷入），但 B 剧本阶段不变（可能还在发育期，被迫应战）。
- **多线**：A 可同时对 B 和 C 宣战，但兵力目标公式（D348）自然限制——兵力不够时 ⑪分数低，不盲目开多线。
- **抽象期战争**（D361）：抽象王国也跑宣战判定（日 tick）；军事行动是实体行为（D281 军队永远真实体）；战斗锁强制切细模拟（D333）——AI 间战争在玩家视野外也能打，走到战斗触发点时切细。

**sim 侧战争结算**（D362，阶段B 训练用）：不走完整 L3 编队战术（太重），走**抽象兵力对比**：

```
简化战争结算 = 总兵力 × 士气 × 地形系数 → 胜负判定 → 败方工人减员 → 灭国判定（D279）
```

训练学的是**外交决策**（何时打/何时和），不是战术执行（战术已有独立训练体系 2_7/2_9）。

## 四、潜在问题与对策

| 问题 | 对策 |
|------|------|
| AI 永远不开战（门槛太高） | threshold SO 可调；rubber-band 可作用于态势分（D350 第三层间接影响） |
| AI 过早开战被秒灭 | 条件 4 兵力 80% 门槛保底；不跳级规则（D354）给紧张期积累时间；防御姿态 ⑭保底（2_17） |
| 条约刷签刷撕（AI 震荡） | 缔约冷却 30 日 + 撕毁条件严格（态势差 ≥2 倍 且 剩余 <5 日）；撕毁第三方 -5 名声传播自然抑制 |
| 玩家打了就求和循环 | 求和冷却 20 日 + 资源成本；求和后关系值仅 +20（和平底线），不回高位 |
| AI 间战争刷屏（多国混战） | 宣战门槛四条件 AND 天然限制；全局战争数无硬上限但兵力目标公式自限；播报合并（多国宣战同日汇总一条，对齐 D305 惯例） |
| 关系值矩阵膨胀（8 国=28 对） | 上三角稀疏存储，28 对 float 可忽略；存档 per-pair |
| 抽象期 AI 间战争触发但玩家看不见 | 战斗锁（D333）只在领土内爆发时切细；视野外战争走抽象结算（D362）——播报仍可见（上帝视角信息层不变） |
| 灭国后关系值/条约残留 | DiplomacySystem 清理：灭亡国所有 pair 删除 + 条约作废 + 播报（2_19 触发，本篇提供清理接口） |
| 玩家与所有 AI 缔约后无敌 | 互不侵犯只锁 30 日；边境摩擦暂停但长期回归 ±1 衰减仍在跑（同盟态不衰减但有同盟→和平自动退出）；盟友也可能因 AI 间战争被灭→条约失效 |

### 5.2 逻辑层

```

  │

  │   ├─ 关系值衰减（5 日回归 ±1）
  │   ├─ 事件处理（消费 EventBus：TerritoryChanged / TradeCompleted / CombatHit / …）
  │   ├─ 四态转换检查（D353~D354，不跳级）
  │   ├─ AI 条约决策（缔结/撕毁概率，D357/D358）
  │   └─ AI 宣战判定（D356 四条件 AND，无人值守 D361）
  │
  ├─ 玩家操作 API（走指令通道 D331）：

  │   KingdomWarDeclaredEvent / KingdomPeaceMadeEvent /
```

## 六、测试策略（冒烟）

1. **初始关系值**：开局后所有 pair 关系值=50（±性格微调）；同 seed 两次一致。
2. **边境摩擦扣分**：AI 推边界邻接玩家领土 → 关系值 -2（TerritoryChangedEvent 触发）。
3. **不跳级**：和平态（关系值 50）直接注入宣战 → 拒绝（必须先到紧张态）；强行扣到 14 → 仍需 D356 门槛判定；宣战后关系值=0（D368 直接设 0 非减法）。
4. **宣战门槛**：构造 AI 军事期+关系值 <15+好战 0.9+兵力达标 → 宣战播报+⑪出征触发；缺任一条件 → 不宣战。
5. **玩家宣战**：任意时刻宣战 → 关系值→0+播报+⑪出征（跳过 AI 门槛）。
6. **求和冷却**：战争态求和 → 关系值 +20+停战条约生效；20 日内再求和 → 拒绝。
7. **送礼**：非战争态送礼 → 关系值 +5×(1+性格第五轴)（D364：外交 0.0→+5 / 1.0→+10）；10 日内再送 → 拒绝。
8. **缔约**：和平态关系值 ≥40 → 互不侵犯生效（30 日锁宣战）；期间边境摩擦不扣分；**锁期内推边界进入对方领土→拦截**（D366：AI⑩不可行、玩家建造系统拒绝）。
9. **撕毁**：撕毁条约 → 关系值 -20 + 第三方 -5 + 播报。
10. **AI 间宣战**：构造两个 AI 满足 D356 → 自动宣战+播报；B 方被动应战（⑭防御高分）。
11. **抽象期战争**：两国在视野外宣战 → 播报可见；战斗锁触发后切细模拟（D333）。
12. **灭亡清理**：注入灭亡事件 → 该国所有 pair 删除 + 条约作废 + 播报。
13. **关系值衰减**：和平态 5 日无事件 → 关系值向 50 回归 ±1。
14. **确定性**：同 seed 全程（含 AI 间战争路径）逐字节一致。
15. **同盟衰减**（D365）：同盟态 5 日无事件 → 关系值向 75 回归 -1；不送/不贸易 30 日后退出同盟（<75）。
16. **多国同日宣战**（D369）：构造 3 个 AI 同时满足 D356 对同一目标 → 按 kingdomId 升序执行，3 国均成功宣战（多国围攻允许）；同 seed 一致。
17. **DiplomacySystem 生命周期**（D370）：开局首个王国注册时初始化矩阵；注入灭亡 → pair 删除+条约作废；存档加载 → 重建矩阵（同 seed 一致）。
