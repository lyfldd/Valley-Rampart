## 一、老系统与新系统的衔接

### 1.1 现状（1D 应用层）

- 任务调度：`TaskScheduler`（S>A>B>C 优先级 + 距离排序）
- 编队：`FormationController`/`FormationBrain`（横队）
- 敌袭：1D 左右两端裂隙出怪

### 1.2 核心变化

```
1D：任务距离=轴距；编队横队；敌袭左右两端
2D：任务距离=格单位；编队 2D 形状；敌袭 360° 多方向（SpawnDef）
```

## 五、要开发的新系统（详细设计）

### 5.1 任务调度 2D（2026-08-14 补规模派工，D95）

```
任务目标 = GridCoord（微格落点；资源坑位 0.5×0.5 粒度）
TaskScheduler 沿用 S>A>B>C + 最近优先（格单位排序）
WorkerTask 移动 → PathFollower（2_3）；目标不可达 → PathFailedEvent → 换点位
建筑任务源（生产/搬运/采集/挑水）= Building.TryAdvertiseTask（**功能层归 2_12**，本篇只做任务坐标 2D 化）

**规模派工算法（D45/D95 落地）**：
  建筑发布任务时附带资源总需求（如"造自己需 500 石"）→
  理想工人数 = ceil(资源总量 / 工人单次携带量)（ResourceCarryConfig）→
  上限 SO 可配（maxWorkersPerTask）→ 调度中心按优先级 S>A>B>C + 距离 + 工人容量分配
  多工人协作：各自独立取资源→搬运→填目标仓库（协作施工归 2_12，D112）
```

### 5.2 编队 2D（槽位生成）

```
形状定义（格单位，SO FormationShapes）：
  线阵：槽位沿垂直于朝向的直线展开，间距 1 格（近战外沿）
  圆阵：将军居中，半径 r=ceil(n/2π) 环布，弓手内环/近战外环
  楔形：朝向为轴，两翼逐排后撤 0.7 格
朝向 = 敌人方向（无敌人=前进方向，D2）
槽位校验：IsSubWalkable；不可走 → 回缩（2_7 §5.4）
减员防抖重排：1s 防抖（沿用）

**阵型 + 流场分层（D89/D96，2026-08-14 补）**：
  群体移动 = 编队走流场到战略目标（高价值点/集结点，D85）+ 编队内保持阵型相对位置
  流场负责"大方向"，阵型槽位负责"小排列"；流场与槽位可走校验协同（2_6 §5.6）
  编队解散后个体走 A*；阵型移动与网上群集算法（Boid/流场）结合优化（讨论点，2_6 D89）
```

### 5.2B 守卫部署与资源点争夺（D190~D195，2026-08-14 挂起项④定稿）

> 资源点争夺战细节见 [`0.6_审查决策记录.md`](./0.6_审查决策记录.md) 十一E。守卫部署交互入口（D116）在 2_13；本篇落行为规则。

```
部署：玩家选中士兵 → 右键高价值资源点（矿洞/采石场，D190）→ 派兵驻守（D192/D116）
守卫行为：驻守士兵在资源点周围警戒 → 自动迎战入侵者（被动反击+路过开战，D83 统一价值）
争夺：无旗帜概念（D191）——谁工人多/守卫强谁占优，产出归在场工人阵营
失守：守卫被击退 → 资源点被掠夺（D193）——**玩家阵营间争夺：产出归掠夺方；怪物掠夺≠占领**：怪物携资源回传送门消失（传送门吸收），资源点产出临时归零、怪物走后恢复原归属（D254，2026-08-14 终审修订）→ 需重新派兵清场夺回
怪物抢矿：短暂掠夺 → 带箱子走（D194，对齐 2_14 §4.2）→ 击杀掉落（D142）
多据点：多资源点权衡（D195），兵力分散防守，守不住可放弃（D56 价值驱使）
```

**GuardDeploymentSystem 输出双接口（D265，2026-08-14 终审修订）**：`IsGuarded(GridCoord)->bool`（2_7 安全度消费）+ `GetGuardRegions()->IReadOnlyList<GuardRegion>`（GuardRegion 含 RectInt+faction，2_6 成本场订阅 GuardRegionChangedEvent 消费）。

### 5.3 敌袭 360°（WaveDirector，2026-08-14 价值驱使，D94/D97）

> **2026-08-14 修订（D177~D189）**：每晚波次重构为**偶发传送门灾害事件**——WaveDirector 触发器改为"灾害触发时"（非每晚），传送门/怪物设计见 [`2_14_敌怪与传送门灾害.md`](./2_14_敌怪与传送门灾害.md)。本节保留波次参数与目标选择逻辑，作为灾害波次的核心。

```
输入：MapData.threatSpawns（2_1）、WaveConfig
每夜流程（灾害触发时，2_14 §2.1）：
  1. 波次数 = baseWaves + difficulty×wavePerDifficulty（**少波次 D97：baseWaves=2/wavePerDifficulty=1 → Easy=3/Normal=4/Hard=5**）
  2. 每波选 1~2 个 SpawnDef（方向聚合 R1），strength 按表（**高强度 D97：strengthCap→60**）
  3. 组内单位错峰 2~5s 从传送门出生 → 流场 goal=**当前高价值目标**（D85/D94，价值驱使）
  4. 目标选择：怪物攻击最近/最高价值目标群（矿洞/仓库/营地/主城，价值×距离 D83/D94）；守卫区域破防判定（IsGuarded 丢失=威胁升级）
```

**波次占位数值表（WaveConfig，SO 可调，2026-08-14 审查修订 D97）**

| 字段 | 默认 | 说明 |
|------|------|------|
| baseWaves | **2**（原 3） | 基础波数 |
| wavePerDifficulty | **1**（原 2） | 每难度加波（Easy=3/Normal=4/Hard=5） |
| strengthBase | 5 | 首波规模 |
| strengthGrowthPerDay | 1.5 | 随天数增长 |
| strengthCap | **60**（原 40） | 单波上限（高强度） |
| spawnIntervalRange | (2,5)s | 组内错峰 |
| directionMergeAngle | 45° | 方向聚合夹角 |

> **WaveDirector 吸收传送门灾害波次调度（D261，2026-08-14 终审修订）**：PortalWaveScheduler 不独立成类，"灾害触发→生成传送门→分批多组召唤"为 WaveDirector 内部方法（2_14 调用）。

### 5.4 昼夜双环

```
白天：经济环（任务调度/生产/税收）在 2D 跑通
夜晚：战斗环（敌袭/守军布防/城墙作用）
切换沿用 DayCycleSettlement
```

> **2026-08-14 补充（D232~D234，0.6 二十）**：昼夜时长 1D 直迁（SO 可配，如白天 60s/夜晚 30s）；保留四季（Season，影响参数 SO 可配：冬季产量↓/怪物强度↑）；每日昼夜结算触发市场额度重置（D220）/灾害触发判定（2_14 §2.1）。

### 5.4B 巡逻/探路任务（D175，2026-08-14 迷雾联动）

> 迷雾决策见 [`0.6_审查决策记录.md`](./0.6_审查决策记录.md) 十一C。本篇落**巡逻任务**入口。

- **触发（D175）**：玩家框选士兵 → 右键未知区域 = 发布巡逻任务（自动+微操覆盖 D46）。
- **行为**：士兵沿指定方向/区域推进探路，视野并集实时揭开迷雾（D167）；遇敌进入战斗（2_5），无威胁则持续探索。
- **sim 可训**：巡逻=任务型行为，进 sim 场景训练（2_9），训练环境=真实环境（sim 全对称 D169）。
- **迷雾不阻塞寻路**：未探索区域可通行但未知（D170），巡逻本身就是"走进去才见"。
- **视野复用（D262，2026-08-14 终审修订）**：巡逻视野消费 2_7 VisionSystem 副作用（视野并集揭开迷雾，D262），本篇不新建视野系统。

### 5.5 冒烟验证
