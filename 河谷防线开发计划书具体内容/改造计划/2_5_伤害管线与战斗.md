## 一、老系统与新系统的衔接

### 1.1 现状（1D 战斗）

| 老文件 | 现状 | 2D 处置 |
|--------|------|--------|
| `DamageSystem.cs` | 伤害公式（atk×(1-def/(def+100))/攻击CD/射程判定） | 复用公式，射程线段→圆（格单位） |
| `ProjectileManager.cs` | 投射物 1D 左右飞 | 改造：360° 瞄准 |
| `CombatRules.cs` | 战斗规则 | 改造：射程圆 + 目标选择 2D |
| `GroundEffectManager.cs` | 地面效果 | 已是 2D 概念，范围改格单位圆 |
| `IDamageable.cs` | 可受伤接口 | 保留 |

### 1.2 核心变化

```
1D：射程 = 线段（左/右距离）；投射物沿 X 轴飞
2D：射程 = 圆（格单位分量归一化欧氏，doc 1 §1.6）；投射物 360° 朝向目标
```

**伤害公式完全复用**（atk×(1-def/(def+100))、CD、overkill），只改空间判定。堆叠上限数值重审（doc 1 §2.3 stackLimits 归属本篇）。

## 五、要开发的新系统（详细设计）

### 5.1 核心 API

```csharp
public class DamageSystem : Singleton<DamageSystem>
{
    public void RegisterAttack(UnitController attacker, IDamageable target);
    public bool InRange(Vector2 from, Vector2 to, float rangeCells);  // 圆判定（§5.2）
    public void ApplyDamage(IDamageable target, DamagePayload payload); // 公式复用
}

public class ProjectileManager : Singleton<ProjectileManager>
{
    public void Fire(Vector2 from, Vector2 targetWorld, ProjectileDef def, Faction faction);
    // 2D 朝向 target 飞行；池化管理
}

public static class GridMath   // 全库共用（doc 1 §1.6 的实现体）
{
    public static float DistCells(Vector2 a, Vector2 b);   // 分量归一化欧氏
    public static Vector2 DirCells(Vector2 from, Vector2 to); // 格空间归一化方向
}
```

### 5.2 射程判定（2D 圆，格单位）

```
InRange(from, to, rangeCells)
  = GridMath.DistCells(from, to) <= rangeCells
  = √((Δx/1.28)² + (Δy/0.64)²) <= rangeCells
```

### 5.3 视线判定（微格 Bresenham）

```
HasLineOfSight(from, to):
  a = WorldToSubCoord(from), b = WorldToSubCoord(to)
  Bresenham 逐微格：任一微格 !IsSubWalkable 且非 Bridge → false
  （起点/终点所在微格豁免）
```

### 5.4 目标选择（2026-08-14 价值驱使，D83）

```
通用（全员，D81）：攻击范围内候选（格单位），按「价值×距离」评分——valueWeight×目标价值 - distWeight×距离 取最高
  价值因子（D56/D83）：目标含资源（矿洞工人/满仓仓库/资源容器）、战略意义（守卫/集结点）↑；SO 权重可调
近战：价值×距离内最近敌（无视线要求）
远程：射程圆内 + HasLineOfSight，按价值×距离
箭塔：同远程（价值×距离，2_12 消费 D84）
滞回：当前目标存活且 dist ≤ range×1.15 → 不换
```

### 5.5 投射物

```
Fire → dir = GridMath.DirCells(from, target) → 直线飞
命中：dist(弹, 目标) ≤ hitRadiusCells → ApplyDamage
地面效果：范围圆（格单位半径）内候选作用（2D）
```

### 5.6 SO 配置（DamageConfig）

| 字段 | 默认 | 说明 |
|------|------|------|
| hitRadiusCells | 0.25 | 投射物命中半径（格单位） |
| stickinessFactor | 1.15 | 目标滞回保持带 |
| valueWeight | 1 | 目标选择价值权重（§5.4 D83 价值×距离评分；asset 实值 1，2026-08-29 Q6 C 面补行） |
| distWeight | 1 | 目标选择距离权重（§5.4 D83；asset 实值 1，2026-08-29 Q6 C 面补行） |
| projectilePoolSize | 128 | 投射物池上限 |
| stackLimits | 沿用 1D | 堆叠上限重审（doc 1 移交本篇） |
| losEnabled | true | 远程视线开关 |
| KnockbackArcHeight | 6 | 击飞抛物线顶点高度（世界单位，占位） |
| KnockbackForceScale | 6 | 击飞力度系数（占位） |

> KnockbackArcHeight（抛物线顶点高度，世界单位，占位 6）与 KnockbackForceScale（力度系数，占位 6）均为 DamageConfig SO 字段（D69 归本篇）（2026-08-14 终审修订，D69；实源=DamageConfig，2026-08-29 裁决修订 D414）

### 8.1 城墙/城门 HP 硬屏障接口（D263，2026-08-14 终审新增）

```csharp
public interface IHpBarrier
{
    int Hp { get; }            // 当前耐久
    int MaxHp { get; }         // 最大耐久（2_12 §5.13 数值表）
    int Defense { get; }       // 减伤（占位 0，SO 可配）
    bool BlocksProjectile { get; }  // 城墙=true 恒定；城门=关门 true/开门 false
    bool IsGateOpen { get; }   // 仅城门有意义
}
```

- 规则：**城墙=硬屏障**，阻挡单位通行与投射物（挡箭）；**城门关门=屏障**（挡人挡箭），**开门=可通行不挡投射物**；HP=0 → 城墙/城门直接销毁无废墟（D165），占格阻挡立即解除
- 敌人攻击城墙/城门：目标选择把屏障视为可攻击目标（价值权重 SO 可配，占位 0.8）
- 本篇提供接口与命中管线；HP 数值/受损/修复/升级归 2_12（§5.13）
