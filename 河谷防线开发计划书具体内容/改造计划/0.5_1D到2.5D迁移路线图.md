## 一、迁移总原则

1. **空间无关的系统直接复用**（零/少改动），只改坐标"接缝"
2. **空间强耦合的系统重写**，但对外接口语义尽量兼容
3. **微格 = 世界普朗克长度**：所有放置/寻路吸附微格（doc 1 已定）
4. **四级区块**：大区块=温度带/生成、中区块=LOD/成本场/热度、小区块=footprint/落点、微格=寻路/阻挡（doc 1 + 2_1 已定）
5. **等轴 Isometric**：逻辑方形格 + 等轴渲染（**2_10**，原 doc 4 已删）
6. **每层冒烟验证**：迁移一块验证一块，不一次性全切
7. **sim 与 Unity 全同源**：训练一次直接可用
8. **距离约定**：全库距离一律"先等轴逆变换还原格差、再求格单位欧氏"（doc 1 §1.6，2026-08-22 裁决 HH.3），cellSize=(1.28,0.64)=Tile 全尺寸、轴向步长取半尺寸(0.64/0.32)双分量禁标量化；**逻辑=格基准、世界=等轴嵌入**，`CoordToWorld`=渲染 `GridToIso` 同一条映射，旧"逻辑层正交、等轴投影只在渲染层(2_10)"废止（迁移待落）

| 阶段 | 内容 | 归属 | 验收（冒烟） | 对应 0篇 阶段（D8） |

## 四、美术到位后的落地路径（最快迁移线）

> 美术资源到位后，**最快线**是跳过纯占位，直接按此推进：

```
1. doc 1 网格 + 2_1 地图生成（美术：温度带地皮+特征物）→ 能看到整张等轴地图
2. 2_2 建筑（美术：自然+人造建筑表）→ 能放建筑/围墙
3. 2_3 移动（美术：单位 sprite 8 向）→ 单位能走
4. 2_5 伤害（美术：战斗反馈）→ 能战斗
5. 2_6~2_8 AI → 现有 AI 2D 化
6. 2_9 sim 训练 → 训练一次直接可用
```

**关键**：美术资源按 `美术资源规范_等轴立方体瓦片.md` 准备（锚点=底座中心、2:1、PPU=100（D27，2026-08-14 修订）、高度层），程序按此对接，**只换素材不换逻辑**。

## 五、各 1D 系统迁移到 2.5D 的细节对照

### 5.1 Kingdom 经营（直接复用 + 功能层归 2_12）
人口/饱食/幸福/税收/贸易/科技/畜牧/水网：**纯数值流程，无空间假设**，直接复用（D10）。仅"出生点/游荡范围/建筑坐标"引用需适配（坐标 int→Vector2Int/微格）。
> **分层说明（D10，2026-08-14 审查补）**：**经营数值规则（人口/饱食/幸福/税收公式）= 直迁零改**；**建筑功能层（产/存/训/贸/研挂到 2D 建筑实体 + 主城锚点 + 伐木场作废 + 仓库统一抽象/协作施工）= 2_12**。两者正交：数值规则被建筑功能层消费，但迁移时数值零改、功能层 2D 化。

### 5.2 建造系统（改造 → 2_2）
- 1D：`PlacementValidator` 沿 X 校验落位
- 2.5D：**footprint 矩形 + 微格吸附**（doc 1 已定）
- 新增：城门通行、资源锁格；~~围合判定~~（**D63 整体移除**，城墙=可选工事；2026-08-14 终审修订）
- 保留：BuildController/BuildingRegistry/ProducerComponent 逻辑

### 5.3 战斗系统（改造 → 2_5/2_8）
- 1D：投射物左右飞、射程是线段
- 2.5D：投射物 360° 瞄准、射程变圆（**格单位分量归一化距离**，doc 1 §1.6）、地面效果已是 2D 概念
- 保留：DamageSystem 伤害公式（atk×def 等）、ProjectileManager

### 5.4 编队系统（改造 → 2_8）
- 1D：横队（近战外/弓手内，X 车道）
- 2.5D：2D 形状（线/圆/楔形），带朝向，槽位必须可走（微格）
- 保留：FormationBrain 意图自决、军令强度、FormationController

### 5.5 AI 决策核（改造 → 2_7）
- 1D：距离类输入用轴距离（直线=真距离）
- 2.5D：欧氏距离 + 成本场（AI 看见威胁绕路）
- 保留：L1/L2/L3 三层管线、记忆组件、Vector2X 解耦

### 5.6 存档（改造 → 2_11）
- 坐标字段 int→Vector2Int/微格
- schema 版本号升级 + 迁移器；不兼容时显式清档

### 5.7 训练模拟器（改造 → 2_9）
- 1D SimWorld → 2D；槽位/热度/射程圆/成本场全同源
- 训练一次直接可用
