### 步骤 1：GridMath 全库共用距离/方向原语（doc 1 §1.6 实现体）

**文件**：新建 `Systems/Combat/GridMath.cs`（或 doc 1 已建则复用；与 2_6 GridMathCore、2_7/2_8 消费方同源）

```csharp
/// <summary>全库共用格空间距离/方向（doc 1 §1.6）。cellW=1.28 / cellH=0.64。</summary>
public static class GridMath
{
    // 格单位分量归一化欧氏距离：dist = √((Δx/1.28)² + (Δy/0.64)²)
    public static float DistCells(Vector2 a, Vector2 b)
    {
        float dx = (a.x - b.x) / 1.28f;
        float dy = (a.y - b.y) / 0.64f;
        return Mathf.Sqrt(dx * dx + dy * dy);
    }

    // 格空间归一化方向（先除分量再 normalize，保证 360° 各向同性）
    public static Vector2 DirCells(Vector2 from, Vector2 to)
    {
        Vector2 d = new Vector2((to.x - from.x) / 1.28f, (to.y - from.y) / 0.64f);
        return d.sqrMagnitude > 0.0001f ? d.normalized : Vector2.right;
    }
}
```

**验收**：编译通过；单测/调试断言横/纵/对角同距离表现一致（如 (3,0)、(0,1.5)、(2.12,2.12) 的 DistCells 均 ≈3.0 格）；全库 grep 确认无新增标量距离写法。

**新增目标评分**（D81 全员近战普攻 + D83 价值驱使，SO 权重可调）：
```csharp
public static class CombatRules
{
    // 价值×距离目标评分：score = valueWeight×目标价值 - distWeight×距离(格单位)，取最高
    public static float TargetScore(float targetValue, float distCells,
        float valueWeight, float distWeight)
        => valueWeight * targetValue - distWeight * distCells;
}
```

```
目标价值来源（D56/D83）：目标含资源（矿洞工人/满仓仓库/资源容器）、战略意义（守卫/集结点）↑；
```

### 步骤 5：视线判定（微格 Bresenham，D3）

**文件**：`Systems/Combat/CombatRules.cs`（新增 `HasLineOfSight`）

```csharp
public static bool HasLineOfSight(Vector2 from, Vector2 to)
{
    var a = GridSystem.Instance.WorldToSubCoord(from);
    var b = GridSystem.Instance.WorldToSubCoord(to);
    if (a == null || b == null) return true;      // 越界保守放行
    // 微格 Bresenham 逐点：任一微格 !IsSubWalkable 且非 Bridge → false
    foreach (var sub in SubBresenham(a.Value, b.Value))
    {
        if (sub == a.Value || sub == b.Value) continue;   // 起点/终点微格豁免
        if (!GridSystem.Instance.IsSubWalkable(sub)) return false;
    }
    return true;
}
```

**验收**：隔墙靶无视线不索敌；空地靶有视线；弧高/工事判定（弹道 §5 越墙）沿用 1D 逻辑保留在 ProjectileManager.CheckWallBlock。
