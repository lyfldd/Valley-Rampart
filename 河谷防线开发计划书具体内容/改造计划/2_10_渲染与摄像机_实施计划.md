### 步骤 2：MapRenderService 核心（格→等轴投影 / 单格更新 / 拾取）

**文件**：新建 `Systems/Rendering/MapRenderService.cs`

```csharp
public class MapRenderService : Singleton<MapRenderService>
{
    public void RenderMap(MapData map);            // features → Tilemap（一次性，2_1 MapData 驱动）
    public void UpdateCell(GridCoord cell);        // 单格增量（建造/地形变化/树刷新/废墟态）
    public Vector2 GridToIso(GridCoord cell);      // iso 嵌入投影（2026-08-22 裁决 HH.3：将反哺逻辑 CoordToWorld 同一映射，代码迁移待落；旧"仅渲染用不反哺逻辑"废止）
    public GridCoord? ScreenToGrid(Vector2 screenPos); // 鼠标拾取 → 逻辑格（经 CameraRig）
}
```

**关键**：
- `RenderMap` 遍历 `MapData.features` → `Tilemap.SetTile` 铺到对应格（等轴 2:1）；特征物（山/树/矿/水）铺 Feature 层
- `UpdateCell` 承接 2_12 生命周期：建筑受损/废墟/施工态切换时刷新该格视觉（废墟/施工态渲染，见步骤 8）
- `ScreenToGrid`：`Camera.ScreenToWorldPoint` → 逆投影 → 逻辑格（拾取误差须为 0，验收 1）

**验收**：256² 地图 `RenderMap` 铺满无缝隙；`ScreenToGrid` 点中某格返回正确 `GridCoord`（误差 0）。

### 步骤 3：CameraRig（pan/zoom/clamp/FocusOn）

**文件**：新建 `Systems/Camera/CameraRig.cs`（替换/退役旧 `CameraSetup.cs`）

旧 `CameraSetup.cs`（1D 侧滚：`followSpeed`/`cameraZ`/`backgroundSprite`/`widthRatio`，X 跟随+Y 固定，`AlignBackgroundToMap` 的 originX 对齐）→ 重写为俯视正交 pan/zoom/clamp：

public class CameraRig : Singleton<CameraRig>
