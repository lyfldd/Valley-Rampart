## 一、老系统与新系统的衔接

### 1.1 1D 波次 → 2D 传送门灾害

```
1D：每晚波次（固定时间固定强度，从裂隙出怪）
   ↓ 重构
2D：偶发灾害事件（传送门形态，非每晚；怪物掠夺者型，进 sim 训练）
```

**核心差异**：

| 维度 | 1D（每晚波次） | 2D（传送门灾害） |
|------|:------------:|:---------------:|
| 频率 | 每晚必来 | **偶发**（SO 可配，如每 3~7 晚一次） |
| 形态 | 固定裂隙刷点 | **临时传送门**（远离王国的随机点） |
| 怪物目标 | 攻击主城/君主 | **掠夺高价值建筑/资源点**（价值×距离 D83） |
| 怪物行为 | 纯进攻 | **守门+出击双目标** |
| 训练 | 规则驱动 | **进 sim 训练**（敌人 NPC，2_9 全同源） |
| 与王国关系 | 唯一威胁 | **二分法**：晚上怪物（灾害）≠ 敌方王国（后置） |

### 1.2 核心变化

1. **每晚波次 → 偶发灾害**：2_8 §5.3 WaveDirector 的"每夜流程"改为"灾害触发时流程"；正常夜晚无战斗。
2. **怪物种类**：从"波次杂兵"改为**掠夺者型**（2-3 种基础：近战/远程/精英），可抢资源（D146 箱子可抢）。
3. **怪物训练**：**怪物 AI 混合架构（D252，2026-08-14 终审）**：**普通怪走规则 AI**（MonsterAI=精简规则模式切换器，不进训练）；**精英怪走 NPCBrain 同源**（MonsterDef.isElite=true，MonsterMode（Raiding/Guarding/Retreating/Looting）注入 L1 FactorContext，L2/L3 据模式调整姿态/指令）；sim 训练时精英怪与玩家单位同核对训（入 sim 2_9，训练目标=守门+出击双目标，价值×距离/成本场/CostBias）。
4. **敌方王国分离**：后置，届时全兵种、强度不增长，独立设计。

## 二、传送门灾害事件设计

### 2.1 触发条件

- **偶发**：非每晚，由 `PortalDisasterConfig` SO 控制触发规则。
- **触发方式**（SO 可配，多选逻辑）：
  - **概率触发**：每晚 XX% 概率触发（如 30%）。
  - **天数触发**：每 N 天必定触发一次（如每 3 天）。
  - **保底触发**：连续 N 天未触发则强制触发（防长草）。
- **首次触发**：游戏第 N 天后才允许触发（如第 3 天，给玩家发展期）。
- **触发语义澄清（2026-08-14 终审）**：day < minDaysBeforeFirst(3) 不触发；day ≥ 3 开始概率判定（30%/晚）；保底 forceTriggerAfterDays=7 从 day≥3 起算（连续 7 晚未触发 → 第 10 晚必触发）。
- **多个传送门**：同一夜最多同时存在 1 个传送门；摧毁后可触发新的。

### 2.2 传送门生成

- **生成时机**：夜晚开始时（DayCycleSettlement 白天→夜晚切换事件）。
- **生成位置**：**远离所有王国**（玩家+AI 王国，后置 AI 王国也适用）的随机点。
  - **放置检测**：以传送门 footprint 为中心，半径 N 格内无任何王国建筑/据点（矿洞/采石场等）→ 视为合法。
  - 若随机点不合法，重试（最多 N 次），失败则当晚不生成（极低概率）。
- **生成数量**：每灾害事件 1 个传送门。
- **生成可视化**：传送门出现动画（2_10 渲染），玩家收到灾害预警（UI 提示）。

### 2.3 传送门属性

- **类型**：**建筑级目标**（非建筑，但走建筑目标选择逻辑）。
  - 有 HP（SO 可配，占位 500/1000/1500 随难度）。
  - 有 footprint（占位 2×2 小区块，视觉 3×3）。
  - 有阻挡（占格+阻挡，同建筑 D154）。
- **价值**：**超高价值目标**（D136 同战争机器），NPC 优先攻击。
- **无等级**：传送门不分级，属性随难度+天数缩放。

### 2.4 核心规则

| 规则 | 值 |
|------|-----|
| **可攻击时间** | **只晚上可攻击**（白天无敌/不可交互） |
| **被打反向强化** | 被攻击时额外召唤怪物（攻击频率越高/参战单位越多→召唤越快）——**弱势喘息定位（D253，2026-08-14 终审）**：未摧毁每后一晚强度 ×0.8 递减——给弱势玩家喘息窗口，拖久灾害自然消解；速攻可获得战利品与经验（保留出击收益激励） |
| **不摧毁的持续袭击** | 若传送门当夜未摧毁 → 天亮时传送门不消失（但白天无敌），**每后一晚持续召唤怪物进攻**（烈度递减，如每晚强度 -20%），直到被摧毁 |
| **摧毁后** | 传送门崩塌动画 → 清除 → 恢复正常触发周期 |
| **天亮未摧毁** | 传送门保留，白天不可交互，夜晚继续 |

> **连续变量语义（2026-08-14 终审）**：summonInterval = 30/(1+0.5×attackerCount)，attackerCount=当前攻击传送门的玩家单位数（滑动窗口 5s 内命中数折算）；封顶 5s。实施计划的 summonIntervalOnHit 二档为其简化档（P0 用二档，P1 升连续公式）。

> **白天交互补注（2026-08-14 终审）**：白天不可攻击但可选中查看 HP（只读信息，2_13 交互/2_10 渲染）。

## 三、怪物种类与属性

### 3.1 掠夺者种类（2-3 种基础）

> 怪物种类保持简洁，不搞多样化或 Boss，符合"少波次高强度"（D97）和"不加斥候等新兵种"（D126）的风格。

| 种类 | 定位 | 移速 | 特点 |
|------|------|:----:|------|
| **近战（掠夺者）** | 主力，近战肉搏，数量最多 | 100% | 基础攻击，高 HP，攻建筑 |
| **远程（投石者）** | 远程投掷，后排骚扰 | 80% | 低 HP，远程攻击，优先打守卫 |
| **精英（头目）** | 每波少量，带队突击 | 110% | 高 HP+高攻击，价值驱使下直冲高价值目标 |

> 后置扩展：未来可加"飞行单位"（无视阻挡，需 2_10 动画）或"攻城单位"（对建筑特攻），但当前不做。

### 3.2 属性数值占位

| 属性 | 近战 | 远程 | 精英 |
|------|:---:|:----:|:----:|
| HP | 100 | 50 | 300 |
| 攻击 | 10 | 15（远程，射程圆半径=6 格，D258） | 30 |
| 攻击间隔 attackInterval | 2s（占位，D258） | 2s（占位，D258） | 2s（占位，D258） |
| 移速（格/秒） | 1.0 | 0.8 | 1.1 |
| 视野半径（格） | 8 | 10 | 12 |
| 价值权重 | 1.0 | 1.2 | 3.0 |
| isElite | false | false | true |

> 所有数值 SO 可配（`MonsterDef`），且随难度+天数缩放（§3.3）。
>
> 2026-08-14 终审修订（D252/D258）：精英怪标记：MonsterDef.isElite（Raider=普通/Slinger=普通/Brute=精英——走 NPCBrain 同源，普通怪走规则 AI）；占位：每波配比含 1 成精英（D258）。

### 3.3 强度曲线（D4）

- **基础强度**：随难度档位（Easy/Normal/Hard）缩放，系数 SO 可配。
- **天数增长**：怪物属性 × `(1 + day × growthRate)`，growthRate SO 可配（占位 0.02/天）。
- **强度上限**：`strengthCap`（D97：60），防止后期数值溢出。
- **传送门自身**：HP/召唤频率/dps 同天数增长。

> **2026-08-14 难度系数（D235~D237，0.6 二十一）**：资源倍率 Easy ×1.5 / Normal ×1.0 / Hard ×0.7；波次强度系数 Easy 0.7 / Normal 1.0 / Hard 1.3（乘到本强度曲线）；灾害触发概率分档（Easy 低 / Normal 中 / Hard 高，2_14 §2.1）。

## 四、怪物行为

### 4.1 守门（传送门被打→增援）

- 传送门被攻击时 → 传送门广播"召唤增援"事件。
- 已在外出击的怪物收到信号 → 部分回援（比例 SO 可配，占位 50%）。
- 传送门额外召唤更多怪物（hit 频率/参战单位数触发，非固定间隔）。
- **行为目标**：保护传送门，攻击靠近传送门的玩家单位。

### 4.2 出击（掠夺高价值建筑/资源点）

- 怪物从传送门出生 → 走**价值×距离**选目标（D83，2_7 决策核同源）。
- **优先目标**：高价值建筑（矿洞 D113/铁匠铺/仓库/主城）+ 资源点（箱子 D146，任意阵营可抢）。
- **遇守卫（被动反击+路过开战）**：怪物不主动寻守卫，被攻击才反击；路过守卫/堵路被拦截则开战。守卫是否被优先解决由"价值×距离"自然决定（守卫价值=战斗力权重，SO 可配）。
- **建筑价值 = SO 配置价值表**：基础价值 × 高价值标志（矿洞/铁匠铺/仓库/主城标记高价值），守卫单位价值=战斗力权重，全部 SO 可配。
- **路径**：走 2_6 成本场（威胁带/安全区），避开守卫区域 → 绕路或强攻。
- **掠夺行为**：怪物到达资源点 → 短暂停留"掠夺"（动画表现）→ 携带资源返回传送门（可被击杀掉落）。
  - 若怪物被击杀 → 掉落所携资源（箱子落地 D142）。
  - 若怪物成功回传送门 → 资源消失（被传送门吸收）。（D254 定稿：怪物掠夺≠占领，资源点产出临时归零、怪物走后恢复原归属；2_8 §5.2B 已同步，2026-08-14 终审修订）

### 4.3 避让/撤退

- 怪物使用成本场决策（2_6 CostFieldBuilder），**成本权重同玩家单位**（2_7 CostBias）。
- 低血量怪物可有撤退行为（SO 可配，占位 HP<20% 尝试退回传送门）。
- 撤退中的怪物若被攻击 → 继续战斗（无逃脱）。

### 4.4 昼夜行为切换

| 时间 | 传送门 | 怪物 |
|------|--------|------|
| **夜晚** | 可攻击 | 从传送门出生，可出击/守门 |
| **白天** | 无敌（不可交互） | 白昼时已在外怪物**继续存在**（不消失），但传送门不召唤新怪物 |
| **下一个夜晚** | 仍可攻击（若未摧毁） | 继续召唤新怪物（烈度递减） |

## 五、波次构成

### 5.1 分批多组（D97 延续）

```
传送门激活后 → 每波怪物分多组从传送门方向分批散开：
1. 波次数 = baseWaves + difficulty × wavePerDifficulty（D97：baseWaves=2 / wavePerDifficulty=1）
   （D267 重锚，2026-08-14 终审：baseWaves=2/wavePerDifficulty=1 语义=单次传送门灾害的召唤批次数/随难度增长；strengthCap=60=单波强度上限）
2. 每波选 1~2 个方向聚合，strength 按强度曲线
3. 组内单位错峰 (2,5)s 出生
4. 流场 goal = 当前高价值目标（价值×距离 D83）
5. 第一波以出击为主，后续波次守门+出击混合
6. 波次怪物配比 近战:远程:精英 = 6:3:1（占位，D258，2026-08-14 终审修订）
```

### 5.2 传送门激活期间波次逻辑

- 传送门持续召唤（非一次性波次）：每波间隔 SO 可配（占位 30~60s）。
- 传送门被攻击时 → 波次间隔缩短（反向强化），召唤频率加快。
- 召唤上限：传送门同时存在的怪物数量上限（SO 可配，占位 30），防止极端堆积。

### 5.3 与白天/夜晚切换的关系

- 夜晚开始 → 检查是否需要触发灾害（§2.1）→ 是则生成传送门 → 开始召唤。
- 天亮 → 传送门停止召唤（白天无敌），已在外怪物不消失。
- 下一个夜晚 → 若传送门未摧毁 → 继续召唤（烈度递减，§2.4）。

## 六、与现有系统集成

### 6.1 2_8 WaveDirector 修改

- **原"每夜流程"**（2_8 §5.3）→ 改为"灾害触发时流程"：
  - 正常夜晚：无战斗（生产/训练/贸易照常）。
  - 灾害夜晚：触发 WaveDirector → 生成传送门 → 怪物波次。
  - 物理伤害按 2_5 管线（HP/攻击/射程/价值×距离）。
- 波次参数表（2_8 §5.3 已定）复用，仅触发器改为灾害事件。

### 6.2 2_9 sim 训练（怪物入训）

- **怪物 AI 混合架构（D252，2026-08-14 终审）**：**普通怪走规则 AI**（MonsterAI=精简规则模式切换器，不进训练）；**精英怪走 NPCBrain 同源**（MonsterDef.isElite=true，MonsterMode 注入 L1 FactorContext，L2/L3 据模式调整姿态/指令）；**sim 训练时精英怪与玩家单位同核对训**（价值×距离/成本场/CostBias）。
- **怪物种类**：近战/远程/精英 三种 Monsters 训练场景（2_9 §6.3 扩展；可训主体=精英怪走 NPCBrain，普通怪由规则 AI 扮演环境对抗方）。
- **训练目标**：
  - **守门**：传送门被攻击时回援/增援。
  - **出击**：价值×距离选目标，掠夺高价值建筑/资源点。
  - **战斗**：与玩家单位交战（2_5 伤害管线同源）。
- **训练环境**：sim 全对称（D169）——怪物也受视野限制，决策核只读视野内目标。
- **传送门**：不进训练目标（传送门=建筑，不专门训"攻打"），怪物围绕传送门的行为入训。

### 6.3 2_10 渲染

- **传送门视觉**：等轴菱形传送门特效（紫/暗色调，粒子效果），2×2 小区块 footprint，视觉 3×3。
  - 白昼：半透明/不可交互（灰暗态）。
  - 夜晚：活跃（发光+粒子）。
  - 被攻击时：闪烁/加速粒子（反向强化视觉反馈）。
  - 摧毁：崩塌动画。
- **怪物动画**：掠夺者型 8 向动画（2_10 §5.4 UnitAnimator 复用），与玩家单位同套动画系统。
- **掠夺动画**：怪物到达资源点→短暂掠夺动画（停留 2~3s）。

### 6.4 2_12 建筑（传送门=建筑级目标）

- 传送门走建筑目标选择逻辑（2_7 价值×距离），但非 `Building` 类型。
- 传送门 HP 管线接 2_5（被攻击减 HP，HP=0 摧毁）。
- 传送门占格+阻挡（同废墟 D154），摧毁后占格释放。
- 传送门**不升级/不修复**（一次性目标）。

### 6.5 2_11 存档

- **传送门存档**：若传送门未摧毁 → 存档位置/HP/已存活天数/烈度衰减系数。
- **怪物存档**：已在外怪物入 UnitSaveData（同玩家单位，2_11 §3.3）。
- **灾害状态**：距下次触发剩余天数/已连续未触发天数。

## 七、与敌方王国的关系

### 7.1 二分法（核心设计前提）

| 维度 | 晚上怪物（本篇） | 敌方王国（后置） |
|------|:---------------:|:----------------:|
| 来源 | 传送门（临时） | 地图生成的敌方基地（永久） |

## 九、验收标准

1. 传送门灾害事件按 SO 配置触发（概率/天数/保底），非每晚必来
2. 传送门在远离所有王国的随机点合法生成（放置检测正确）
3. 传送门只晚上可攻击，白天无敌/不可交互
4. 传送门被攻击时额外召唤怪物（反向强化视觉+逻辑正确）
5. 传送门未摧毁 → 每晚持续袭击（烈度递减）
6. 传送门摧毁 → 崩塌动画 → 清除 → 恢复正常触发周期
7. 怪物三种类（近战/远程/精英）属性/行为正确（守门+出击双目标）
8. 怪物走价值×距离选目标，掠夺高价值建筑/资源点
9. 怪物可抢箱子（D146），击杀掉落资源
10. sim 训练：怪物守门+出击训练场景与 Unity 对拍一致（2_9）
