## 一、老系统与新系统的衔接

### 1.1 现状（1D 移动）

老移动模型（`UnitController.cs`）：
```
Move(direction) / MoveTowards(destination)
  → Vector2.MoveTowards 直线逼近
  → newPos.y = current.y 固定 Y 轴（1D 命脉，2D 必删）
  → IsBlockedByFortification 撞墙即停（无绕行）
  → UpdateGridPosition() 每步 GridSystem.TryEnter
```

AI 侧（BehaviorExecutor/NPCBrain）只下发"目标点"，**如何到达**由 UnitController 直线走解决。1D 无寻路。

### 1.2 衔接总图

```
老链路：NPCBrain/任务 → MoveTowards(目标点) → 直线走 → 撞墙停
新链路：NPCBrain/任务 → PathRequester(2_6) → 路径点 → PathFollower → MoveTowards(下一路径点)
```

> **君主取消（2026-08-13）**：无君主实体/操控。玩家=纯上帝视角（点选/框选/指令/建造，归 2_8 应用层 + 2_2 放置交互），**不直接操控任何单位的移动**。本篇只管 NPC 移动。

**关键**：`MoveTowards` 保留，语义从"走向终点"变"走向下一路径点"；`newPos.y = current.y` 删除（2D 平面移动）。阶段 0 即接 2_6 最小微格 A\*（审计决策：A\* 提前），"绕障碍 A→B"在阶段 0 验收。

### 1.3 移动原语保留

| 原语 | 处置 |
|------|------|
| `MoveTowards(Vector2)` | 保留，语义收窄为"走向路径点" |
| `Move(Vector2)` | 保留（NPC 行为/击飞/位移类用），**不再服务君主操控** |
| `UpdateGridPosition()` | 保留，每步 TryEnter **微格**登记（D70，登记/命中/寻路同粒度） |
| ~~`IsBlockedByFortification`~~ | **移除（D68）**：正常移动全走寻路（2_6），不再位移级撞墙停；拒马减速/击飞/冲锋让位保留（数值归 2_5，D69） |

**现状（命名耦合链，4 处）**：

| 位置 | 现状 |
|------|------|
| `UnitData.cs` | 无 prefab 字段（仅 faction/occupation/属性） |
| `UnitFactory.PreloadAll()` | `Resources.LoadAll<GameObject>("UnitPrefabs")`，缓存 key = `prefab.name` |

| 成员 | 处置 |
|------|------|
| `UnitData` | 新增 `public GameObject prefab;` 字段（Inspector 拖引用，GUID 绑定） |
| `UnitFactory.PreloadAll()` | 删 `Resources.LoadAll("UnitPrefabs")` 扫描；改由 UnitDataManager 已加载的 UnitData 集合驱动（prefab 引用随 SO 自带） |

| `LoadManager.GetPrefab(string)` | 删除（无调用方）；`UnitFactory.Prewarm` 签名同步改 `UnitData` |
| 存量资产迁移 | 一次性编辑器脚本批量回写：按现有 `Resources/UnitPrefabs/{faction}_{occupation}.prefab` 命名匹配 ~30 个 UnitData 资产挂引用（仅迁移工具用命名，运行时零命名耦合）；迁移完成后 prefab 文件位置/命名不再受约束 |

## 五、要开发的新系统（详细设计）

### 5.1 核心类型与 API

**UnitController（改造后关键成员）**
```csharp
public class UnitController : MonoBehaviour, IUnitHandle, IDamageable, ISaveable
{
    public void MoveTowards(Vector2 dest, float speed);  // 2D 平面移动（删 y 固定）
    public void Move(Vector2 dir);                        // NPC 行为/击飞/位移类（不再服务君主）
    public GridCoord? CurrentSubCell { get; }            // **微格**登记（TryEnter 维护，D70/D71）（2026-08-14 终审修订，D70/D71）
    public Vector2 WorldPos { get; }                      // 精确位置
    public Facing8 Facing { get; }                        // 8 向朝向（2_10 动画消费）
    public bool IsArrived(Vector2 dest);                  // 格单位距离 ≤ arriveRadiusCells
}

public enum Facing8 { E, NE, N, NW, W, SW, S, SE }        // 与邻居顺序一致（doc 1 §5.4）
```

**PathFollower（新增，2_6 提供路径）**
```csharp
public class PathFollower : MonoBehaviour
{
    public void SetDestination(Vector2 worldPos, byte priority = 0);  // 发寻路请求
    public void SetPath(PathResult path);                              // 接收路径点
    public void Stop();
    public PathFollowerState State { get; }
    void Update();  // 状态机驱动，§5.2
}

public enum PathFollowerState
{
    Idle,        // 无目标
    Pending,     // 已发请求等路径（原地等待，超时 3s → Failed）
    Following,   // 逐路径点 MoveTowards
    Repathing,   // 下一路径点失效，冷却后重寻
    Failed,      // 连续 3 次失败 → PathFailedEvent（AI 换目标）
}
```

### 5.2 PathFollower 状态机

```
Idle --SetDestination--> Pending --SetPath--> Following
Following --到达路径点--> Following(下一点) / Idle(终点)
Following --下一点不可走--> Repathing --冷却(1s)--> Pending
Pending/Following --连续 3 次失败--> Failed --PathFailedEvent--> (2_7/2_8 换目标)
任意 --Stop--> Idle
```

### 5.3 数据流

```
NPC/任务 → PathRequester(2_6) → 路径点列表 → PathFollower.SetPath
PathFollower.Update → UnitController.MoveTowards(下一路径点) → UpdateGridPosition(**微格** TryEnter，D70/D71)（2026-08-14 终审修订，D70/D71）
BuildingChanged/GateStateChanged(2_2) → PathFollower 校验当前路径 → Repathing
```

### 5.4 SO 配置（MovementConfig，新增）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| npcSpeed | float | 沿用 | NPC 基础速度 |
| arriveRadiusCells | float | 0.3 | 到达半径（格单位，§1.6） |
| repathCooldownSeconds | float | 1.0 | 重寻冷却（与 2_6 对齐） |
| pendingTimeoutSeconds | float | 3.0 | 等路径超时 |
| maxConsecutiveFails | int | 3 | 连续失败上限 → Failed |

### 5.5 移动性能

- PathFollower 每帧纯 MoveTowards，无分配；路径点数组来自 2_6 池化 PathResult
- 落点吸附微格只在 SetDestination/到达时算，不在每帧
- LOD 休眠档：移动降频到 2Hz + 位置插值（2_4），不冻结

### 5.6 冒烟验证

1. NPC 从 A 到 B 绕开 U 型墙（接 2_6 最小 A\*）
2. 封死目标 → Failed → PathFailedEvent 触发
3. 移动中造墙 → 受影响单位 1s 内重寻

### 5.7 载具契约（战争机器）（D273，2026-08-14 终审修订新增）

```csharp
public interface IVehicle
{
    int Capacity { get; }                              // 载员上限（战争机器=2，D204）
    bool CanBoard(UnitController u);                   // 能否上车
    IReadOnlyList<UnitController> Passengers { get; }  // 当前载员
}
```

- 战争机器 = **载具单位**：操控归本篇移动层（上车/下车/载具移动），攻击归 2_5（§5.7B 战斗侧），生产/维修归 2_12（投掷机厂）
