## 〇、背景与审计结论

### 0.1 立项触发

用户对 AI 王国智能度的担忧，经三轮深化收敛（种族特调 → 生命周期思想 → 军队完整生命周期 → 全对象过筛），形成全对象生命周期覆盖矩阵：

### 0.2 关键审计实锤（2026-09-04 策划端直读代码）

1. **配兵三断点**：王国脑不产将军（15 行动无此项，TrainingSystem 将军训练仅服务玩家）→ 无编队载体；不建军事建筑（练兵场/战营/射箭场不在建造清单）→ 无兵种生产入口；⑦招战士=工人直转 Warrior 一种，无兵种概念。
2. **军事期空转悖论**：剧本推进到军事期（战士≥4+人口≥12）后，王国脑无任何真实军事行动可执行（⑪⑫⑮占位桩、⑭空 case）——AI 越努力爬到军事期，行为越与经济期无异。
3. **⑭防御姿态无实体指令**：被攻击后 AI 王国层面不调兵不守城（ExecuteFocus 空 case），全靠士兵个体反应。
4. **驻防/巡逻驱动方全为玩家交互入口**（SelectionController/BuildingPanel）——AI 永远不会下巡逻令/守军令。
5. **威胁求和偏差**：NeighborMilitary=全部非玩家王国兵力求和（UtilityScorer.cs），与 2_17 §3.1.3/D339/D348"邻接王国"文档口径偏差（D515）。
6. **将军阵亡编队自散，王国脑不知情不补任**（FormationController 自处理，无事件上浮）。

### 0.3 方案收敛过程（B/C 合流 → C′）

用户在 A（横向修补）/B（态势中枢）/C（激进涌现）之外追问"C 会不会更智能"——重估结论：**C 消除阶段锁死（真缺陷：军事期被打破产，⑬恒0 兜底失效，王国不会自动回攒粮重建）但裸 C 短视（效用输入只有自家账本）**。B 与 C′ 不是对立方案而是同一架构两深度档位：**C′ = B 的骨架 + 剧本状态机降级为纯展示标签 + 决策层完全处境驱动**，前置条件恰好是 P0/P1 交付的态势输入与底线验证——分四期落地，风险受控（镜像 2_21 D484"软涌现分阶段切"先例）。裸 C（无态势层纯效用反应器）否决：短视风险。

## 一、目标范式：C′ 处境驱动王国

```
规则（SO 硬规则 + 可训权重——人定，AI 不可改）
   ↓
内置大脑（王国脑：常设底线 → 态势快照 → 效用评分 → 焦点执行
         + 姿态层（焦点外常态行为）+ 危机打断（事件即时））
   ↓
国家行为（涌现——不写"兽人国应该先造兵营"这行代码）
```

**三原则（2_21 范式向王国层贯彻）**：
1. **阶段=标签，处境=依据**：剧本四阶段不再作决策输入（P2 退役），一切门控改处境条件；
2. **焦点=大政，姿态=常态**：每日 1 焦点管建造/招募/外交等"国策"；驻防/巡逻/边防等级是不占焦点槽的第二驱动通道；
3. **权重=双环演化，不做固定配比**：策划只拥有特征清单/动作空间/安全栏，权衡权重归训练（出厂环）+局内确定性自整定（局内环）。

## 三、P0：国家会建军（详细设计）

### 3.1 改造后的王国脑日 tick（态势层插入位）

```
每日 KingdomBrain.Tick（扩后）：
  ① 态势层重建（新）  国情快照 = 账本直读 + 邻接情报 + 事件脏标记聚合
      输出：威胁分布 / 损毁清单 / 兵种表现统计 / 边境接触面 / 军力现状
  ② 剧本推进（P0 不动；P2 退役）
  ③ 效用评分（改输入源）  NeedScore 从"读自家账本"改"读快照"
      ——军事维度缺口（缺将军/缺编队/缺兵种）首次成为可评分需求
  ④ 常设底线（不动：粮/人口/被攻击窗口）
  ⑤ 焦点执行（扩）      建造+⑥⑦照旧 + 新增：训练将军 / 建军事建筑
      ⑦"招战士"扩为"招兵"：执行时按双环权重选兵种（不再是 Warrior 直转）
  ⑥ 姿态层（新，焦点外）  三档升降 + 驻防/巡逻驱动
  危机打断（P0 先挂两类：被攻 / 军覆——事件即时不等日 tick）
```

**态势层机制**（D517）：日 tick 全量重建（纯函数聚合），事件只置脏标记不即时改快照；危机打断看事件本身不依赖快照——同 seed 确定性最强，sim 镜像最易。事件源：KingdomAttackedEvent / UnitDeath（兵种统计·局内环输入）/ BuildingDestroyed / TerritoryLost（P1 接入）。

**关键取舍**：兵种招募="⑦招兵"一个行动的执行层多兵种选择（**不是**每兵种一个行动）——行动清单只净增 2 项（⑯训练将军/⑰建军事建筑），不爆炸；权重选招在执行层消化。

### 3.2 军队诞生链（P0 交付的完整链路）

```
焦点选中建军相关 → ⑰建军事建筑（练兵场共通+四族专属[M6]，选型=种族+快照缺口）
  → ⑦招兵（双环权重：种族先验×性格×表现统计×经济 → 选招，走 TrainingSystem 同链）
  → ⑯训练将军（卫戍营，复用 generalLimit=2 限量；镜像玩家通道 D331）
  → 将军在场自动 BindGeneral → RecruitStandard 招空闲兵成军
  → 编队进入常态运转（姿态层：驻防/巡逻）
```

将军补任：将军阵亡事件上浮王国脑（新增编队解散/将军死亡事件）→ 军力现状快照更新 → 缺将军成为可评分缺口 → ⑯再次入选焦点。

### 3.3 常设军事姿态层（D518）

国家三档：**无 / 警戒 / 动员**，态势触发升降（带滞回防抖），不占国策焦点槽。

| 档 | 触发 | 行为 |
|---|---|---|
| 无 | 威胁分布≈0 | 无常态军事行为 |
| 警戒 | 邻接威胁非零/边境摩擦 | 巡逻频率升（PatrolTaskSystem AI 侧驱动接入） |
| 动员 | 被宣战/军力危机线触发 | 集结守军+停止远程派遣+召回 |

驻防复用 GuardDeploymentSystem 城墙锚点编队（AI 侧自动派驻）；分区军区 P3 后再议。

### 3.4 兵种配兵=双环演化权重（D519）

```
策划拥有（规则，AI 不可改）：
  ① 特征清单——配兵可见输入（敌情构成/我方伤亡/经济余量/种族底色/性格五轴）
  ② 动作空间——种族解锁链+建筑前置+人口上限
  ③ 安全栏——多样性下限硬规则防单兵海坍缩（不训）

王国拥有（权重，champion 真源）：
  出厂环（跨局）：champion 定期训练演化（night_run 基建）→ 回灌即换脑
    ——先验=种族底色+性格映射起步，训练自会改写；策划不保留配比解释权
  局内环（单局，确定性自整定）：
    每场战斗结算 → 兵种表现统计（存活率/交换比，确定性窗口平均）
    → wᵢ ← wᵢ × exp(η × (兵种 i 表现分 − 均值))，clamp 安全栏
    同 seed 完全复现；统计量随档存；η 可训
```

兵种招募分 = 种族出厂倾向 × 性格调制 × 表现统计 × 经济可负担性 ÷ 多样性惩罚。真·在线学习否决（同 seed 逐字节一致红线）。权重调整日志可打印归因（"这局为何狂造弓手"可追溯）。

### 3.5 威胁邻接修正（D515）

NeighborMilitary 从全部非玩家王国求和 → **邻接王国求和**（TerritorySystem 邻接查询），对齐 2_17 §3.1.3/D339/D348 文档口径。归本批顺手实施，实施时回注 2_17。

### 3.6 P0 集成点与八格快检

| 系统 | 改动 |
|---|---|
| TrainingSystem | 暴露系统级（非 UI）入口供 AI 调用——实施批核签名 |
| PatrolTaskSystem / GuardDeploymentSystem | 加 AI 侧驱动入口（现驱动方全为玩家交互） |
| DayCycleSettlement | 步骤2 不动（态势层在 Brain.Tick 内部） |
| 存档（2_11） | 兵种表现统计+姿态档位+权重现值入档 |
| sim-sync 义务 | 快照构建+权重自整定进 AI.Core 镜像区（纯 C#）+15_账本登记 |

八格：诞生=快照随日 tick 重建（无持久态）/姿态与权重随 Brain 构造+读档恢复 → 归属=全挂 KingdomBrain → 更新=日 tick+战斗事件 → 挂起=Abstract 期脑照跑（D476 分叉同款：经济执行分叉，态势/姿态照跑） → 终结=随国灭销毁 → 异常=将军阵亡→编队散→姿态自动降档 → 清算=随 Brain.Unsubscribe → 持久化=统计/档位/权重入档。八格无空。

## 四、P1：国家会打仗（详细设计）

### 4.1 2_18 实施衔接（咬合契约，主体归 2_18 实施计划）

- 宣战判定（D356 四条件）：条件1"剧本=军事期"P1 照旧（P2 随大流迁处境门控）；条件2~4 输入改读国情快照（态势分=威胁×利益公式既有）。
- ⑪出征军占位桩填充：解锁为候选 → 效用评分 → 出征意图（含目标 kingdomId）→ L3 FormationBrain 执行（2_18 D324/D395 既定链路，零新设计）。
- ⑫边境增援：姿态层联动——受威胁边境段优先获得编队派驻。
- ⑮外交：FocusController 读 DiplomacySystem 态势 → 主和/主战倾向调制评分。
- 姿态×战争联动：被宣战 → 自动升动员档（三档机硬触发器）。

### 4.2 覆灭危机响应（军队生命周期闭环）

触发（事件即时不等日 tick）：① 全部编队覆灭（将军阵亡+无存活编队）；② 军力跌破危机线（warriorCount < 军力底线阈值，SO）。
响应：危机打断 → 立即重规划（焦点强制⑦招兵+⑨城墙）；常设底线扩为四级（粮→人口→被攻窗口→**军力底线**，同构新增）；姿态锁动员档直至军力恢复线（带滞回）。全民皆兵**不做**（超规模，记录否决）。

### 4.3 损毁统计与⑬重建激活（建筑生命周期闭环）

BuildingDestroyedEvent → 快照损毁清单（类型/数量/价值加权）；⑬ RebuildGap 从恒 0 → 真实评分（损毁加权值/建筑总价值，缺口函数既有形态）；重建执行优先原位（PlacementValidator 原位合法则优先，否则螺旋重选址）。夜灾/战争打坏的建筑从此"看得见"。

### 4.4 丢土响应（领土生命周期闭环）

触发源（P1 接两个既有事件）：D306 营地被吞并 / 战争期领土变更（随 2_18 实施面）。响应：快照边境态势恶化度 → 姿态升档 + TerritoryGap 评分加权升。军事收复失地的主动战略**P1 不做**（P3 城府议题）。

### 4.5 事件打断 D340 全量实施

P0 挂两类（被攻/军覆）→ P1 扩全：**被宣战 / 主城被围 / 灾害**（2_18 定稿三源全接）——重规划=焦点立即刷新+姿态即时调整双通道。打断自带冷却窗（同型事件 N 日内只重规划一次，SO）——防多事件同日连发焦点抖动。

## 五、P2：枢轴·剧本退役（详细设计）

### 5.1 门控迁移清单（逐行动）

| 现门控（stageWeight） | 新处境门控 |
|---|---|
| ⑦⑧发育期起可见 | 需求自证（工人够→兵种/科技缺口自然出现评分），门控删除 |
| ⑤屯粮发育期起 | 常设底线已管，门控删除 |
| ⑨⑩扩张期起 | ⑨城墙：威胁分布非零即可见；⑩推边界：人口饱和度门控（工人数/容量比） |
| ⑪⑫⑮军事期起 | ⑪宣战判定四条件自门控（2_18 本有）；⑫边境接触面非零；⑮关系矩阵规模≥2 国 |
| 训练将军/建军事建筑（P0 新增） | 军力缺口+快照威胁非零（"有敌人了才需要将军"） |

剧本四阶段阈值（存活→发育→扩张→军事）**全部退役销案**——安全网职能由常设底线（粮/人口/军力四级）正式接管。

### 5.2 剧本机降级为展示派生

ScriptStageMachine 从决策输入 → 情报面板展示标签生成器：标签=最近 N 日焦点分布推导（攒粮期/扩张期/备战期/战争期四类行为画像）。玩家观感不变，决策层零依赖。

### 5.3 对照回归与回滚

`useSituationGate` 开关（对齐 2_21 useSoftFormation 先例）：false=旧剧本门控（保留期）/true=处境门控（枢轴态）。验收=同 seed 双开关对拍，行为差异逐项归因 + **王国层涌现时刻清单**：

| # | 涌现时刻 | 判据 |
|---|---|---|
| E-K1 | 军事期被打破产后自动回攒粮重建 | 阶段锁死消除的铁证（旧剧本标签不动、行为自动回退） |
| E-K2 | 威胁解除后主动降动员档 | 不再空转军费 |
| E-K3 | 弱国识相不开战 | 处境门控自然收敛，非剧本锁 |
| E-K4 | 同族两国不同行为画像 | 性格×处境分化 |

观察 ≥1 个完整局生命周期后拆除开关，剧本机文件退役归档（含 KingdomBrainConfig 阶段阈值字段销案）。

## 六、P3：国家有城府（接口级设计）

### 6.1 情报等级（快照滤镜化，D513）

王国对世界感知按等级滤，**对玩家感知对称适用**（CK 式"你不知道对方全貌"）：
- **L1 全知**（现状，P0~P2 默认）；
- **L2 邻接国可见**（快照只含接壤国情报）；
- **L3 细节需侦察**（敌军兵种构成/资源详情需侦察单位或情报建筑解锁）。

侦察单位=风行者/鹿骑（D495 现成高视野职业天然适配，P3 激活 AI 派遣逻辑）。

### 6.2 种族专属决策分支（D514）

参数化主干（全族共享：五轴基准×乘数×双环权重）P0~P2 已就位；少量结构分支**每族 ≤1 个**，入 AI.Core 镜像区，sim-sync 评估后定：
- 兽人：战争狂热焦点（连败不降反升好战度——"越挫越战"）；
- 矮人：磐石策略（军力优先守土，扩张欲望压制修正）；
- 精灵/人类：P3 设计时再定（或砍——分支宁少勿滥）。

### 6.3 军队遗产（议价项，倾向砍）

军功/番号传承=CK 味但触面大（存档+UI+编队数据结构），P3 立项时再裁，本篇只挂账不设计。

## 十、测试策略（冒烟+涌现验收）

1. **P0 冒烟**：将军可训练（AI 焦点选中→卫戍营队列→将军实体出现→BindGeneral→编队成员>0）；军事建筑可建可训（练兵场/战营落地+兵种产出）；⑦招兵按权重分布（同 seed 权重选招序列确定+多样性下限不破）；邻接威胁修正（远国兵力不计入）；姿态升降（威胁注入→警戒档巡逻频率断言）；AI 驻防（城墙锚点编队自动派驻）；读档恢复（统计/档位/权重）。
