## 一、改造背景与动机

### 1.1 现状

河谷防线当前是仿 Kingdom 的 **1D 横版卷轴**游戏：

- 世界是一条 X 轴线段，单位只有左/右两个移动方向
- 敌人从左右两端来袭，城墙是线上的两个点，防御没有纵深
- `GridSystem` 是一维格子数组；`LinearThreatFormula` 等 AI 公式建立在轴距离假设上
- 已实现系统：EventBus、时间/难度、存档（ISaveable）、UI 面板、Kingdom 经营全套（人口/饱食/幸福/税收/贸易/科技/职业）、建造与资源流转、AI 三层决策（L1 焦点→L2 姿态→L3 指令）、编队、伤害管线、训练模拟器（1D 战斗 + 经济）

### 1.2 动机

- **同质化风险**：仿 Kingdom 的 1D 玩法担心玩家不买账
- **玩法升级**：2D 开放地图带来真正防御纵深、围合建造、多方向威胁
- **资产复用**：已实现的经营/AI/数据系统大量与空间维度无关，应最大限度迁移而非推倒重来

### 1.3 本计划的唯一目标（本次重构核心）

> **一切为了 NPC AI。** 本次改造唯一的成功标准 = **让 NPC AI 在 2D 里可以被训练、训练完直接投入使用**。

这一目标派生三条硬约束，贯穿所有子文档：

1. **训练一次，直接可用**：模拟器训练出的 AI 回灌 Unity 后无需大幅重调（sim-to-real gap 最小化）
2. **Unity 端先落一个完整可用的简单模型**（占位美术），正式美术由美术同学并行推进，届时只换素材不换逻辑
3. **sim 与 Unity 全同源**：战斗 + 职业/经济全部在模拟器可训练，决策核共用一套，确定性对拍

## 二、核心决策（2026-08-12 已确认）

| 决策项 | 结论 | 备选（未采用） |
|--------|------|----------------|
| 玩法空间形态 | **全向开放 2D**：主城居中，敌人 360° 来袭，城墙围合，有防御纵深 | 带状 2D；多方向有限 2D |
| 视角形态 | **等轴菱形 Isometric**（专业术语：等轴菱形瓦片，2026-08-13 由 Oblique 修正）：菱形地块、等轴 Tilemap、斜 45° 立体 | ~~3/4 斜俯视 Oblique（方形地块）~~；纯正俯视 |
| 世界结构 | **取消多地图，单块大陆**：类文明6，玩家王国与 AI 王国随机出生；白天王国战、夜晚怪物袭 | 多岛屿多地图；先单图后恢复 |
| 地图规模 | **玩家开局可选世界大小**（128²/256²/384²，复用 MapSizeConfig 扩展） | 固定 256×256 |
| 空中层 | **暂不做，留接口**：格子预留 layer 维度，当前仅地面层 | 多高度层；彻底取消 |
| AI 决策距离语义 | **大脑→成本场→A*/流场搜索**（AI"看见"威胁绕路；可训=成本权重+目标选择） | 纯 A*；全端到端学移动 |
| 看见范围 | **活跃带细成本场 + 远处粗/纯目标搜索**（复用 LOD 遗产） | 全局细粒度；近距成本场 |
| 成本权重来源 | **先 SO 手配，训练后置**（sim 2D 化后再入训） | 一开始就入训 |

> ⚠️ 游戏大纲变更注意：世界结构使「大陆多王国」成为新大纲，影响地图生成（出生点/王国分布）、白天王国战+夜晚怪袭双威胁、存档/训练。

## 三、地基优先的建造顺序（本次重构核心）

> 原则：**先打好地基，再上 AI**；地基顺序 = 地图生成 → 建筑 → 移动 → LOD → 伤害 → AI 栈。
> 原因：训练全场最贵最慢，**不想为它重训多次**，所以 Unity 端地基做到"AI 落地即可用"再一次性训练。
> 缓解：**每层地基自带冒烟验证**（如 LOD 做完验证区块热度可见、伤害做完验证一次击杀），避免长时间"无反馈期"做错方向而不自知。

### 3.1 前置地基（5 块，每块带冒烟验证）

| 顺序 | 地基 | 冒烟验证 | 归属子文档 |
|------|------|---------|-----------|
| ① | 2D 地图生成（地形/出生点/刷点） | 空场景生成全向地图，君主可走，出生点可见 | 2_1 |
| ② | 建筑与占格（footprint/摆放/围合） | 能放建筑、占格、围城墙 | 2_2 |
| ③ | 空间与移动（2D 网格/移动/PathFollower/可视化） | 一个单位在 2D 绕障碍从 A 到 B | 2_3 |
| ④ | LOD 区块划分（区块/热度/降频） | 区块热度随战斗扩散可见，远处单位降频 | 2_4 |
| ⑤ | 伤害管线与战斗（伤害/敌对/投射物） | 一次击杀闭环，威胁/撤退有意义 | 2_5 |

### 3.2 AI 栈（4 层）

| 顺序 | 层 | 内容 | 归属子文档 |
|------|----|------|-----------|
| ⑥ | 寻路工具层 | A*/流场/成本场/PathfindingService | 2_6 |
| ⑦ | AI 决策核心层 | L1/L2/L3 2D 化、成本场决策、撤退/槽位 | 2_7 |
| ⑧ | AI 应用层 | 任务/编队/战斗/行为整合调用 | 2_8 |
| ⑨ | 模拟器与训练 | sim 2D（战斗+职业全同源）、确定性、训练-once 回灌 | 2_9 |

### 3.3 分层架构（贯穿 2_6~2_8）

```
决策大脑（可训：目标选择 + 因子→成本权重，先 SO）
   └ BehaviorCommand = {目标, 成本偏好}          ← 核心层
成本场层 CostField（纯数据，Unity/sim 同源，确定性）
   └ 威胁带↑成本 / 安全区·编队位↓成本 / 撤退逃逸点低成本
共享寻路核 Pathing.Core（纯 C#，零 Unity 依赖）
   └ A*（个体/短距）+ 流场（群体/长距）在成本场上搜索  ← 工具层
PathFollower（执行层）
   └ 逐路径点 MoveTowards，碰撞/拒马/击飞原样     ← 应用层
移动端口 IMovable（不变）
```

## 四、原有系统盘点（参考，2026-08-12 逐模块评估）

### 4.1 直接迁移（逻辑与空间无关）

| 系统 | 说明 |
|------|------|
| 事件总线 / 时间 / 难度 / 加载销毁 / 游戏状态机 | 无空间假设 |
| UI 面板（11 个） | 面板逻辑保留；小地图为新增 |
| Kingdom 经营逻辑（人口/饱食/幸福/税收/贸易/科技/职业/畜牧/水网） | 仅出生点/游荡范围等坐标引用需适配 |
| SO 数据层 / 存档架构 | 坐标/尺寸字段需扩展；schema 版本迁移 |
| AI 决策核框架（L1/L2/L3、Memory、Ports） | `Vector2X` 解耦层是最大迁移资产 |
| 注意力/感知框架 | 范围判定从"轴距离"变"欧氏距离" |

### 4.2 改造（核心保留，空间层适配）

| 系统 | 改造点 |
|------|--------|
| AI 威胁公式 / 撤退公式 | 1D 轴假设 → 2D 距离/方向/扇区 |
| NPC 执行层 / 任务调度 | 移动执行改寻路；任务目标从 X 坐标变格子 |
| 编队系统 | 阵型从横队 → 2D 形状（线/圆/楔形，带朝向） |
| 建造系统 | 1D 落位 → 2D footprint 校验；城墙围合；城门通行 |
| 战斗系统 | 投射物 360° 瞄准；射程变圆 |
| 单位基座 / 君主操控 | 移动改 8 向+寻路跟随；横移 → 8 向+碰撞 |
| 存档 schema | 坐标 int→Vector2Int；版本号+迁移器 |
| 训练模拟器 | 经济环改动小；战斗环从 1D 兵线 → 2D 战场 |

### 4.3 重写（空间强耦合）

网格系统、地图生成、摄像机、美术表现、地图可视化。

### 4.4 新增（2D 必需）

寻路系统、城墙围合判定、360° 敌袭方向、小地图、可行走/占用层、8 向动画状态机、成本场。

## 五、迁移总原则

1. **空间抽象先行**：所有改造系统先定义"位置"抽象（格子坐标 `Vector2Int` + 世界坐标 `Vector2`）
2. **逻辑层不动口**：Kingdom 经营、AI 决策框架等直迁系统，只改坐标引用的"接缝"
3. **接口语义兼容**：GridSystem 等对上游接口保持语义，内部实现换 2D
4. **每层带冒烟验证**：地基每块落地即验证，禁止一次性全切后无反馈
5. **存档版本化**：schema 升版本号，写迁移器；不兼容时宁可清档也要显式提示
6. **SO 数据驱动不变**：所有新增可调参数（寻路权重/格子尺寸/成本权重/摄像机边界）一律走 SO
7. **训练管线不断链**：模拟器与 Unity 共用 AI.Core 约定不变；寻路核/成本场纯 C#，sim 同源
8. **占位美术先行**：PlaceholderSprites 延续，正式素材由美术并行推进，阶段 4 才换

## 八、总风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| **训练-once 的 sim-to-real gap** | 训练出的 AI 回灌失效 | sim 与 Unity 决策核/成本场/伤害全同源 + 确定性对拍 + 保留 1D 对照调参 |
| **地基无反馈期做错方向** | 地基全做完才发现方向错 | 严格"每层冒烟验证"（原则 4） |
| **sim 2D 迁移成本被低估** | 阶段 3 全面卡顿 | 2_9 专门定价（SimWorld/SimGrid/槽位/热度/射程圆/成本场/职业经济） |
| 寻路性能（NPC 数量大+频繁重算） | 阶段 1 起卡顿 | 流场共享、LOD 降频、异步分帧；2_6 专门设计 |
| 城墙围合玩法复杂度 | 阶段 0 核心玩法不成立 | 凸包简化版先做，区域填充算法后补 |
| AI 决策核 2D 化后行为退化 | 已调参的 P0 行为失效 | 公式替换走 SO 可配，保留 1D 公式对照调参；sim 回归测试 |
| 存档不兼容 | 玩家旧档报废 | schema 版本迁移器；不兼容时显式清档提示 |
| 美术素材全量重做成本 | 进度不可控 | 占位方案延续；正式素材由美术并行推进 |

## 九、总验收标准（AI-first）

1. **训练一次直接可用**：sim 训练出的 NPC AI（含战斗+职业）回灌 Unity，无需大幅重调即可投入使用
2. **AI"看见"成立**：大脑经成本场感知威胁并绕路，决策与路径结合，非纯 A*
3. 新开局为全向 2D **等轴菱形**地图，君主 8 向移动、摄像机俯视操控流畅
4. 昼夜双环（白天经济/夜晚战斗）在 2D 完整闭环，与 1D 时代功能对齐
5. 城墙可围合、城门可通行、敌人 360° 多方向来袭且防御玩法成立
6. NPC 寻路无卡死、无明显绕远；同屏 200 单位帧率达标（起点 = doc 2_1 密度占位表 Medium 档）
7. 存档可读旧档（迁移）或显式清档；所有新增参数 SO 化，无硬编码魔法数值
