## 一、老系统与新系统的衔接

### 1.1 现状（1D 地图生成）

老生成链路（`WorldManager.GenerateWorld` + `MapGenRules` + 各约束 config）：

```
WorldManager.GenerateWorld(seed, worldSize, difficulty)
  → 确定大区块数 M（MapSizeConfig，1D 档位 10/15/24）
  → MapGenRules.CalcZoneCounts：5 区（左极端/左资源/中心/右资源/右极端）
  → 每大区块定地形（邻接矩阵约束 + 资源区权重）
  → ResourceGenConfig：按大区块放资源点（持续/一次性）
  → 资源保障占位（isProtectedResource：保证木/石/肥沃下限）
  → 裂隙放置（riftCellX，出怪口）
  → 主城位置（GetCastleRegionIndex，几何中心）
  → 产出 MapData（regions 列表）
```

**1D 核心假设全部失效**：5 区是线性分段；"左右出怪"是线性两端；主城=线段中心；资源保障按大区块计数。2D 后这些概念必须重新地基化。

### 1.2 衔接总图

```
老 MapData.regions[]（1D 大区块列表）──废弃──┐
                                             ├→ 新 MapData（doc 1 §5.5）：
老 MapGenRules（5区/主城/裂隙）──废弃───┤       terrain[]/plainSub[]/kingdomSpawns/资源占位[]
                                             │
老 8 个 SO config ──字段重映射/重写───→ 新 2D 生成管线（本文档 §五）
```

**衔接原则**：
1. **种子复现策略保留**：仍 `seed 复现`（WorldSaveData 存 seed，读档同 seed 重生成）——这是老存档思路，2D 沿用，只改生成算法
2. **可玩性保障框架保留，维数重定义**：老"资源保障下限（minForest/minStone/minFertile）+ 邻接约束矩阵"是成熟约束，2D 化为"全局资源保障 + 局部可走性/邻接约束"
3. **出生点概念转生**：老"主城=几何中心唯一" → 新"多个王国出生点随机分布"（玩家 1 + AI N）
4. **出怪口概念转生**：老"裂隙=左右两端" → 新"夜晚刷怪点=地图外围/裂隙/野怪巢穴"（doc 8 定时侵袭用）

### 1.3 各老系统接缝表

| 老系统 | 接缝 | 归属 |
|--------|------|------|
| `WorldManager.GenerateWorld` | 调用入口保留（ApplyConfig → GenerateWorld），内部重写；`WorldSystem.InitializeWorld` 触发链不变 | 本文档 §2.1 |
| `MapGenRules`（静态工具） | 5 区方法组废弃；`IsBuildableTerrain` 语义保留（改建到 2D 校验） | 本文档 §2.2 |
| `MapData/WorldState` | 数据契约已由 doc 1 §5.5 定义；本文档填充数据 | 依赖 doc 1 |
| `MapGenRulesConfig` | 字段重映射（5 区比→出生点分布/邻接保留） | §2.3 |
| `ResourceGenConfig` | 字段重映射（按大区块→按全局面积/出生点距离带） | §2.4 |
| `MapSizeConfig` | 2D 档位（doc 1 §2.4 已定契约） | 依赖 doc 1 |
| `MapValidator/MapPreviewer` | 校验逻辑 2D 化 | §2.5 |

## 二、老系统的改造（逐文件清单）

### 2.1 `Systems/World/WorldManager.cs`

| 成员 | 处置 | 说明 |
|------|------|------|
| `GenerateWorld(seed, size, difficulty)` | **重写** | 调新 MapGenerator2D（§5）；仍填 MapData；仍发 `MapGeneratedEvent` |
| `World/_world`（多地图） | 冻结 | 单图；`ApplyConfig` 只构一张 MapData |
| `MapGenRules.SetConfig` 注入 | 改注入新规则 | MapGenRules 废弃后改注入 MapGenerator2D 依赖 |
| ISaveable/SaveId="WorldManager" | 保留 | 存档内容变（存 seed+size+difficulty，读档重生成），schema 归 doc 9 |
| SO 加载（5 个 config） | 增新减旧 | 新增 MapGen2DConfig；废弃字段按 §2.3/2.4 |
| `ActiveMap` 属性 | 保留 | doc 1 契约 |

### 2.2 `Systems/World/MapGenRules.cs`（静态工具）

| 方法 | 处置 |
|------|------|
| `CalcZoneCounts / GetZone / GetCastleRegionIndex / GetZoneColor` 等 5 区系 | **全部删除**（纯 1D） |
| `IsBuildableTerrain(TerrainType)` | **保留语义**，迁至新 MapGenerator2D 或独立工具；2D 判断不变（Plain 可建） |
| 邻接 `CanAdjacency` | **保留算法**，迁入新生成器（2D 邻接约束仍需要） |

### 2.3 `Data/MapGenRulesConfig.cs`（字段重映射）

| 字段 | 处置 |
|------|------|
| `centerRatio / extremeRatio`（5 区） | **删除** → 新增 `spawnSpacing`（王国出生点最小间距，按地图尺寸比例）+ `kingdomCountByDifficulty` |
| `resourceInnerWeights / resourceOuterWeights` | **重映射** → `resourceNearSpawnWeights`（出生点近带，低风险）/ `resourceFarWeights`（远带，高风险）——"内外侧"从 1D 线性两侧变 2D 离出生点距离带 |
| `centerFertileChance` | 重映射 → `nearSpawnFertileChance`（出生点附近肥沃概率） |
| `adjacencyMatrix` | **保留**（邻接约束仍有效，2D 泛化到 8 邻） |
| `minForest / minStone / minFertile` | **保留语义**，成为全局资源保障下限（不再是按大区块） |

### 2.4 `Data/ResourceGenConfig.cs`（字段重映射）

| 字段 | 处置 |
|------|------|
| `baseCounts`（按大区块地形配数量） | **重映射** → 按"全局每单位面积密度 + 地形占比"计算；`GetProducerCount/GetPickupCount` 改签名按地形+面积 |
| `densityByDifficulty` | 保留（密度因子概念仍适用，改作用于全局面积） |
| `specialPointChance` | 保留 |
| `gradeProbByDifficulty / innerOffset / outerOffset` | **重映射** → `nearOffset`（近出生点：贫瘠+，富有-）/ `farOffset`（远：相反）；`GetGradeProb(difficulty, isInner)` 改 `isNear` |
| 新增 | `resourceBellCurveRadius`：资源集中带（离出生点某半径内资源更密，鼓励经营区内建设） |

### 2.5 `Systems/World/MapValidator.cs` / `MapPreviewer.cs`

- `MapValidator`：校验逻辑从"1D 区连续/保障/邻接"改 2D：① 每王国出生点可达性（用 doc 2 IsReachable）② 资源保障下限全图计数 ③ 无不可达死区（可选）④ 出生点间距 ≥ 阈值
- `MapPreviewer`：预览渲染归 doc 4（斜俯视底图）；本文件保留"生成后校验报告"功能

## 三、新系统的需求讨论

### 3.1 功能需求

| # | 需求 | 场景 |
|---|------|------|
| F1 | 2D 地形生成（高度/气候/噪声），产出 `TerrainType[]` | 地基 |
| F2 | 地形可走性映射：每种 TerrainType → WalkFlags.TerrainWalkable + 移动代价 | 寻路/移动 |
| F3 | **多王国出生点随机分布**（玩家 1 + AI N，间距约束，文明6式） | 白天王国战 |
| F4 | 出生点周边"经营区"（肥沃/资源带，鼓励建城） | 模拟经营 |
| F5 | 全局资源保障下限（木/石/粮/铁），2D 面积化 | 可玩性兜底 |
| F6 | **夜晚刷怪点**（裂隙/野怪巢穴，地图外围+随机） | 夜晚怪袭（doc 8） |
| F7 | 邻接约束（8 邻）保证地形自然过渡 | 视觉/玩法合理性 |
| F8 | 资源点占位 2D 放置（持续/一次性，等级按距离带） | 经济环 |
| F9 | 河流/水域（可选，doc 1 WalkFlags.Water 位）——D1 决策 | 地形多样性 |
| F10 | 生成确定性（同 seed 同图） | 存档复现/训练 |
| F11 | 生成性能：256² 全流程可控 | 开局加载体验 |

### 3.2 非功能需求

| # | 指标 | 目标值 |
|---|------|--------|
| N1 | 256² 生成全流程（地形+资源+出生点） | ≤ 300ms（一次加载，可接受异步 loading 界） |
| N2 | 同 seed 完全确定性 | 字节级一致（无随机源泄漏/无字典遍历序） |
| N3 | 玩家出生点至最近资源带距离 | 有保证（≤ 指定格的 90% 分位） |
| N4 | 王国出生点间距 | ≥ MapSizeConfig 比例阈值（默认 0.25×min(W,H)） |

### 3.3 待定项（附推荐值）

| # | 待定项 | 推荐 | 说明 |
|---|--------|------|------|
| D1 | 河流/水域 | **P0 不做，留接口**（WalkFlags.Water 位已预留，doc 1） | 水域带来可走/架桥/寻路复杂度，先纯陆地；P2 再加 |
| D2 | 地形生成算法 | **多层 Perlin 噪声 + 温度/湿度双因素**分类（类 RimWorld 简易版），不做高度图+侵蚀 | 复杂算法性价比低，256² 用 Perlin 足够 |
| D3 | 地形种类范围 | 保留老 7 种（Plain/Wasteland/Hills/Forest/Quarry/Snow/Coast）+ 弃用 Coast（无海岸） | Coast 是岛屿概念，单大陆删；Snow 可作地图边缘高山屏障 |
| D4 | AI 王国数量 | 沿用难度基础数（Easy 1/Normal 2/Hard 3，MapSizeConfig.enemyByDifficulty 语义转生）+ 随机浮动 | 数值重审归 doc 8 |
| D5 | 出生点分布规则 | **多方平等**：所有王国（含玩家）出生点一起随机分布，间距约束；玩家不强制居中 | 文明6式公平；老"玩家居中"概念废弃 |
| D6 | 夜晚刷怪点分布 | 地图外围环带随机 + 固定裂隙点混合 | 保证"围绕王国"的威胁感，又不至于包围死局 |

## 四、新系统可能遇到的问题

| # | 风险 | 触发 | 对策 |
|---|------|------|------|
| R1 | **出生点被地形困死**：出生在岛中/悬崖/资源死角 | 噪声随机 | 出生点后处理：强制"出生点及其 3×3 邻格为 Plain 可走"（clear 操作）；F3 出生点先定后清地形 |
| R2 | 资源保障落空：随机放资源仍不够下限 | 大图+低密度 | F5 保障机制：先算全局缺口，再按"保障占位"定点补（沿用老 isProtectedResource 思路，2D 化） |
| R3 | 邻接约束过度导致生成慢/失败 | 高约束 | 邻接约束做"软约束"（惩罚重采样而非硬失败），最多 N 次重试后容忍 |
| R4 | 王国间距失控：AI 贴脸出生 | 出生点随机 | F3 间距约束（Poisson 盘采样思想）；N4 阈值；失败则重roll整个出生点集 |
| R5 | 生成不确定（多线程/字典序） | 训练/存档 | 单线程 + 固定迭代顺序 + 自带种子 Random（不依赖 UnityEngine.Random/System environment）；N2 字节级对拍 |
| R6 | 大面积不可走（雪山包围/水）导致王国无法互攻 | 白天王国战 | map 校验（§2.5）：每个王国出生点到地图中心 IsReachable；失败重生成 |
| R7 | Snow 边缘屏障挡路影响寻路体验 | 地形多样 | Snow 代价高但可走（非阻挡），仅水域阻挡；雪山作为"慢速高山"而非"墙" |
| R8 | 存档 seed 复现但生成算法已改 → 旧 seed 地图不同 | 改造后读旧档 | doc 9 版迁移：旧档标记"算法版本"，混用则重新生成（seed 复现只对同版本有效） |

## 五、要开发的新系统（详细设计）

### 5.1 程序集与分层

```
Systems/World/MapGen2D/（新，放 WorldManager 侧）
├─ MapGenerator2D            // 主入口：编排阶段（可复入，纯 C# 核心）
├─ TerrainGen                 // 噪声→TerrType[]（Perlin 双因素）
├─ SpawnDistributor           // 出生点 Poisson 盘采样（间距约束）
├─ ResourcePlacer             // 资源带/全局保障/等级
├─ NightSpawnerPlacer         // 夜晚刷怪点（裂隙/巢穴）
├─ MapValidator2D             // 校验（可达性/保障/间距）
└─ Data/MapGen2DConfig (SO)   // 全部参数
```

> 核心 `MapGenerator2D` 纯 C# 可复入（过程性、无 MonoBehaviour），供 sim 侧生成同样地图做训练（总计划原则 7）。Unity 侧由 WorldManager 包装调用。

### 5.2 生成阶段编排

```
Generate(seed, width, height, difficulty)
  ├─ ① 噪声地形：TerrainGen → terrain[]（Perlin 温度/湿度分类）
  ├─ ② 出生点：SpawnDistributor → kingdomSpawns（玩家+AI，间距约束）
  ├─ ③ 局部清场：每个出生点 3×3 清为 Plain（R1）
  ├─ ④ 资源带：ResourcePlacer → 资源点占位（近带/远带权重）
  ├─ ⑤ 资源保障：全局缺口定点补（R2）
  ├─ ⑥ 夜晚刷怪点：NightSpawnerPlacer → 裂隙/巢穴
  ├─ ⑦ 校验：MapValidator2D → 通过则写 MapData，失败最多重生成 3 次
  └─ 产出 MapData（terrain/plainSub/kingdomSpawns/资源占位/夜刷点）
```

### 5.3 地形生成（TerrainGen）

- 多层 Perlin（2 层 octave），映射温度 T ∈ [0,1]、湿度 H ∈ [0,1]
- 分类查找表（SO 可配 `TerrainBand[]`）：
  - 高 T + 低 H → Wasteland（荒地）
  - 中 T + 高 H → Forest（林地）
  - 中 T + 中 H → Plain（平原）
  - 低 T → Snow（雪山，地图边缘/高海拔）
  - 特定带 → Hills（丘陵）/ Quarry（矿山）
- 边缘强制：地图外圈 1~2 格 → Snow/Hills（围合感，防出界，R7 慢速非阻挡）
- 子状态：Plain 格按噪声阈值 + 距出生点距离带 → Fertile（肥沃，F4）
- 邻接软约束：生成后扫描 8 邻，违规地形按权重重采样（最多 pass≤3）

### 5.4 出生点分布（SpawnDistributor）

- **Poisson 盘采样**：随机撒点，间距 ≥ `spacing = spawnSpacing × min(W,H)`（SO），保证 N4
- 数量：`1（玩家）+ GetEnemyCount(difficulty) + seed 浮动`
- 玩家出生点不强制居中（D5 多方平等）；首个点留给玩家
- 输出：`List<Vector2Int> kingdomSpawns`，索引 0=玩家，1..N=AI 王国
- 校验：每个点 3×3 清 Plain 后可走（R1）；点间可达性（R6）

### 5.5 资源带放置（ResourcePlacer）

- 离出生点距离带：`bellCurveRadius` 内为"内带"（近带权重，低风险保本），外为"外带"（远带权重，高风险高回报）
- 每带按 ResourceGenConfig 权重选地形、按面积定密度放持续/一次性资源
- 资源保障（F5）：统计全图木/石/粮计数，低于 `minForest/minStone/minFertile` 则选未有保障的地带定点补（isProtectedResource 2D 化）
- 等级：`GetGradeProb(difficulty, isNear)`（nearOffset/farOffset）

### 5.6 夜晚刷怪点（NightSpawnerPlacer）

- 固定裂隙点：地图外围环带（距边界 1~3 格）随机 N 个，供 doc 8 固定波次
- 野怪巢穴：离王国出生点一定距离外的随机点（避免贴脸死局，D6）
- 数据结构：`List<NightSpawnPoint>{ pos, type(Rift/Nest), tier }` 写入 MapData（doc 8 消费）

### 5.7 MapData 扩展（doc 1 §5.5 基础上补夜晚刷怪）

```csharp
public class MapData
{
    public int mapId;                 // 恒 0
    public int seed;
    public int width, height;
    public TerrainType[] terrain;
    public PlainSubState[] plainSub;
    public List<Vector2Int> kingdomSpawns;      // 0=玩家,1..N=AI 王国（doc 8 国界）
    public List<ResourcePlaceholder2D> resources; // 资源占位（2D，替代老 BuildingPlaceholder.localCellX）
    public List<NightSpawnPoint> nightSpawns;    // 夜晚刷怪点（doc 8）
    // 冻结：isPlayerHome / isConquered / bigTerrain（删）
}
```

`ResourcePlaceholder2D`：`{ Vector2Int cell; BuildingType type; ResourceGrade grade; bool isConsumable; }`（替代老 `BuildingPlaceholder` 的 localCellX 1D 坐标）

### 5.8 SO 配置（MapGen2DConfig + 权重重映射）

**新增 MapGen2DConfig**（`Resources/Grid/MapGen2DConfig.asset`）

| 字段 | 默认 | 说明 |
|------|------|------|
| seedSource | System Random | 内置种子 PRNG（确定性），不用 UnityEngine.Random |
| noiseOctaves / noiseScale / temperatureBias | 2 / 0.05 / 0 | TerrainGen 参数 |
| terrainBands | TerrainBand[] | T/H → TerrainType 分类表 |
| spawnSpacing | 0.25 | ×min(W,H) 出生点最小间距（N4） |
| clearRadiusAroundSpawn | 3 | 出生点清场半径（格） |
| bellCurveRadius | 0.15 | ×max(W,H) 资源内带半径 |
| edgeSnowRing | 2 | 边缘雪山环宽度 |
| nightSpawnCountByDifficulty | int[3] | 裂隙/巢穴数量 |
| adjacencyRelaxPasses | 3 | 邻接软约束重采样次数 |

**MapGenRulesConfig 重映射**：删 centerRatio/extremeRatio；新增 spawnSpacing/kingdomCountByDifficulty；resourceInner/OuterWeights → nearSpawn/farWeights；centerFertileChance → nearSpawnFertileChance；adjacencyMatrix 保留；minForest/minStone/minFertile 保留。

**ResourceGenConfig 重映射**：baseCounts → 全局密度；innerOffset/outerOffset → nearOffset/farOffset；新增 resourceBellCurveRadius。

### 5.10 实施任务拆分

**P0（阶段 1 必须）**

### 5.11 验收标准

1. 同 seed 两次生成 MapData 字段级完全一致（N2）
2. 256² 生成全流程 ≤ 300ms（N1）
3. 玩家出生点 3×3 全 Plain 可走；至最近资源带 ≤ 指定格的 90% 分位（N3）
4. 王国出生点间距 ≥ 0.25×min(W,H)（N4）
5. 全图木/石/粮 ≥ 保障下限（F5）
6. 每个王国出生点至地图中心 IsReachable（R6 校验通过）
7. 夜晚刷怪点数量 ≥ 1 且不贴玩家出生点（D6）
