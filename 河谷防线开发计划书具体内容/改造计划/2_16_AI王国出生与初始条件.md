## 三、新系统需求（生命周期六维度 × 两条出生路径）

### 3.1 第一代出生（地图生成时）

**① 进入条件**：新开局地图生成完成（2_1 管线末尾）。

**② 阶段内行为**：

```
1. 数量确定：按地图档位抽 N（D288：Small 2~3/Medium 3~4/Large 4~6）
2. 模板抽取：从模板池（8~10 个原型）不重复抽 N 个（D290）
3. 扰动：四维度数值 ±20% 随机扰动（同 seed 确定）
4. 地形匹配放置：在偏好温度带的可走大区块中按 Poisson 盘选点
   （间距 D41；匹配失败 → 回退最近匹配带 + 日志记录，D292）
5. 预置实例化：按难度错峰档（§3.4）批量生成建筑/人口/资源
6. 注册：KingdomRegistry 登记 AI 各国（玩家 id=0 已在管线前段注册，D303）→ 领土初始半径 → 染色 → 开局播报（汇总一条，D305）
7. 玩家初始领土：初始建筑外扩 1 中区块（**D343 修订口径**，2_17 声审；原"外扩 2 大区块"与 D41 出生间距冲突，详见 2_17 §3.2）
```

**③ 玩家视角**：开局汇总播报"本大陆已有 N 国并存"（D305，点击展开列国名单归 2_13）；染色一眼见各国位置。

**④ 退出条件**：预置完成即进入发展期（王国脑启动，2_17）。

**⑤ 现有系统集成点**：2_1 生成管线末尾挂载 / 2_12 建筑实例化 / ThroneAnchor / 2_10 染色 / 2_11 存档接入（KingdomRegistry 运行时态，存档表示归 2_11 统一迁移）。

**⑥ 平衡与训练**：难度错峰只调**初始预置规模**（§3.4），不改成长速率（成长速率归 2_17 的 rubber-band）；模板池是纯数据（SO），不训。

### 3.2 动态出生（孕育期 → 插旗）

**① 进入条件**（全部满足，D294/D312/D313/D314）：
- 流民营地（复用流浪汉营地）人数 ≥ 12
- 营地存续 ≥ 5 游戏日（驱散/屠杀减人不重置存续日，D313）
- 全局王国数 < 8（D280 上限，**含玩家**，D314）
- 未处于立国冷却期（全局冷却 ≥10 游戏日，冷却阻立国本身，D312）

**② 阶段内行为**：
```
插旗：营地中心生成王座锚点（ThroneAnchor，帐篷形态）+ 王旗
转型：该营地流民 → 该国工人（人口不凭空，实体还是那批人）
性格：来源国加权混合 + ±10% 扰动（D295，不抽模板池——文化延续而非新身份）
种族：=营地成员种族（**D471 修订 2026-09-02**：同族营地插旗→同族建国；混合营按野性敌意规则构造性不存在——异族无国者互攻不成营，D468；原 D433 随机池退役）
科技：不继承（从零解锁，弱势起步）
领土：以营地为中心最小初始半径
播报：KingdomEmergedEvent → "流民在 X 处建立新国家"
吞并分支（D306）：达标前营地中心格被圈入某国领土 → 营地解散，
  流民转该国工人（ConvertVagrantsToWorkers 统一管线，人口守恒），立国流程终止；**D469 异族分支（2026-09-02）**：被圈入营地若为异族 → 不解散不转化，就地转为敌对野人营（野性敌意 D468），由守军清剿或自行逃离解决
供给：地图生成预置初始流民（4~6 人，保底 3 人同点 + 余散投，D308）+ 2_19 灭亡流民入营
```

**③ 玩家视角**：前兆可见（荒野流民越聚越多）；可干预（驱散/屠杀流民延缓立国——减人不重置存续日，杀散至 <3 人才真正阻止，D313）；可旁观。

**④ 退出条件**：插旗完成即进入发展期（存活期剧本起步，弱势）。

**⑤ 现有系统集成点**：流浪汉营地（QQQ.2 需求 6+T8+T11，D481 勘正）/ ThroneAnchor / KingdomRegistry / 2_19 灭亡流民（供给侧闭环）。

**⑥ 平衡与训练**：阈值（12 人/5 日）占位可调——调高=世界更稳定，调低=更混沌；新王国不保证存活（无保护期，WorldBox 式自生自灭）；插旗判定纯规则，不训。

### 3.3 KingdomDef SO 数据定义

```
KingdomDef（ScriptableObject，每模板一份）
├─ 身份：templateName（如"雪岩国"）、namePool（国名变体池）、bannerColor（染色主色）
├─ 地理：preferredClimates（**ClimateZone[] 数组**，D298：Tropical/Subtropical/Temperate/Cold，
│        按序匹配依次回退，末位仍失败走全局回退带+日志）
│        + preferredFeature（可选：RiverAdjacent 河湾 / ForestDense 森林密度高区等特殊偏好，
│        占位枚举，匹配实现延后，D316）
├─ 性格：personality 权重向量（好战/经济/防守/扩张/**外交 五轴**，D299，0~1，
│        **各轴相互独立、不归一化**，D311：有意设计，极端值不拦截、模板自担，2_17 消费侧鲁棒；
│        2_17 王国脑消费前四轴、2_18 外交消费第五轴）
│        〔2026-08-30 修订（D426，源 2_20）：五轴语义改为**种族出厂基准×王国扰动**——RaceDef
│        提供同族出厂基准，模板五轴=基准上的 per-kingdom 扰动偏离；扰动幅度沿用既有设计〕
├─ 种族：raceId（**2026-08-30 新增维度（D416/D430，源 2_20）**：Human/Orc/Dwarf/Elf；
│        玩家选族占保底一席+AI 保底其余三族各一、余者随机（D430 修订）；已实施
│        KingdomDef.cs 无此字段，扩字段默认 Human 对既有 6 模板资产零破坏；
│        挂 RaceDef 出厂基准+专属建筑/专属兵解锁；
│        模板↔种族映射推荐：雪岩+基岩=Dwarf/密林=Elf/金穗+河湾=Human/铁蹄=Orc）
│        + preferredFeature 扩展（D429：+MineralRich 矿富=矮人/BarrenRich 贫瘠=兽人；
│        真实匹配仍按 D316 归 P2 步骤12）

**玩家出生与选族（D431 数据侧，2026-08-30 增补，源 2_20 §九 G8）**：

- 玩家开局选族=开局流程 raceId 选择 → 玩家王国挂 RaceDef（出厂基准）+玩家侧 KingdomDef（扰动按 firstGenPerturbation 同规或基准直用，实施批定）
- 保底联动：玩家种族占四族保底一席，AI 王国保底其余三族各一（D430），kingdomSpawns 分配时排除玩家族
- 动态立国（营地/流民插旗）：**D471 修订（2026-09-02）**——同族营地插旗→同族建国（国族=营地成员个体 raceId）；混合营按野性敌意规则构造性不存在（异族无国者互攻，D468），原 D433 继承/随机池口径退役
- UI 侧（选族界面）归 2_13 流程 UI（D431 双挂）
├─ 兵种科技侧重：preferredTechTags（如 cavalry/archery/mining/farming）、初始解锁兵种列表
├─ 规模基准：baseBuildings/baseWorkers/baseStockpile（被难度错峰档缩放，§3.4）
└─ 模板池注册：KingdomTemplateLibrary SO（持有 8~10 个 KingdomDef，开局抽取源）
```

## 四、潜在问题与对策

| 问题 | 对策 |
|------|------|
| 模板池不够抽（Large 6 AI vs 池 8~10） | 池 ≥ 档位最大值 +2；动态立国**不抽模板池**（来源混合，D295），池只服务第一代 |

## 五、要开发的新系统

### 5.1 数据层（SO）

| SO | 职责 |
|----|------|
| `KingdomDef` | 模板四维度数据（§3.3），`Assets/Resources/Config/Kingdoms/` |
| `KingdomTemplateLibrary` | 模板池容器（抽取源 + 不重复抽取 API） |
| `KingdomFoundingConfig` | 孕育阈值/散营阈值/扰动幅度/领土初始半径/错峰三档预置清单/立国冷却天数/初始流民数量与保底群大小（全部占位数值的 SO 落点） |

### 5.2 逻辑层

```
KingdomRegistry（Singleton&lt;T&gt;，项目惯例，对齐 TaskScheduler/TrainingSystem）
  ├─ **含玩家 kingdomId=0**（D303 统一注册）；Register/Get/GetAll/Count
  ├─ Count 含玩家（D314：全局上限检查 = Count < 8）
  ├─ kingdomId → KingdomState（运行时态：生命周期/领土/账本句柄）
  └─ KingdomFoundedEvent / KingdomEmergedEvent（EventBus，染色与播报消费）

KingdomFoundry（出生服务，两条路径共用）
  ├─ FoundFirstGeneration(mapData, difficulty)：数量→抽模板→扰动→匹配放置→预置实例化→注册
  ├─ FoundFromCamp(camp)：插旗→流民转化→性格混合→注册
  ├─ ConvertVagrantsToWorkers(camp, kingdomId)：统一转化管线（D306），
  │   插旗（FoundFromCamp 新建国）与吞并（并入既有国）两个出口共用
  └─ 预置实例化复用 BuildingFactory/UnitFactory（kingdomId 归属参数）

CampUpgrader（营地监控，并入 PopulationSystem 日 tick）
  ├─ 遍历流浪汉营地：人数/存续/全局上限/无主地/冷却五条件 → 调 KingdomFoundry.FoundFromCamp
  │   （上限含玩家 D314；冷却期内暂缓立国、营地继续生长，D312）
  └─ 吞并检查（D306）：营地中心格已有主 → 调 KingdomFoundry.ConvertVagrantsToWorkers（营地解散）

Camp（运行时数据，D301 归本篇 P1——现有流浪汉营地无存续计数，此为半新数据）
  ├─ 字段：centerCell / 成员列表 / 存续日计数（日 tick 递增；成员归零→移除营地，占位规则）
  ├─ 形成：≥3 名流浪汉共享同一聚集地锚点 → 结营（占位阈值）
  ├─ 存续日不清零（D313）：驱散/屠杀只减人数，不重置存续日计数；人数 <2 散营（D387 修订，滞回带 [2,3)）
  └─ 供给：地图生成初始流民预置（保底 3 人同点 + 余散投，D308）；2_19 灭亡流民入营；新流浪汉并入既有营（CampUpgrader 消费）
```

### 5.3 表现层接口（归 2_10/2_13 实施）

| 接口 | 消费方 |
|------|--------|
| KingdomRegistry → 染色数据（kingdomId→色/领土格集） | 2_10 Overlay 层 |
| KingdomFoundedEvent/KingdomEmergedEvent → 播报 | ToastManager（2_13 入口） |
| KingdomRegistry 运行时态 / Camp 存续计数 / 立国冷却时间戳 → 存档表示 | 2_11 统一迁移 |

## 六、测试策略（冒烟）

1. **第一代**：三档地图 × 三档难度，9 组合各生成 10 局——AI 数量符合档位、模板不重复、全部落偏好带（或回退带+日志）、资源保障过校验①、同 seed 两次生成逐字节一致。
2. **动态**：控制台注入流民 15 人于无主富地 → ≤5 日插旗播报 → 该国工人=原流民数（人口守恒）→ 王国数 +1。
3. **上限**：王国数=8（**含玩家**，D314）时注入流民 → 不插旗（日志说明原因）。
4. **干预**：插旗前屠杀流民至 <12 → 不立国（存续日不清零 D313，重新聚满继续计数）；杀散至 <2 → 散营（L187 D387 修订：滞回带 [2,3)）。
5. **统一注册**：开局后 KingdomRegistry.Count = AI 数 + 1（含玩家 id=0），染色含玩家色块（D303）。
6. **围墙环**（困难档）：生成后预置围墙呈最小矩形环 + 1 城门缺口；遇阻挡格自然断开（D304）。
7. **吞并**（D306）：既有国领土扩张圈入存续营地 → 营地解散、流民转该国工人（人口守恒），王国数不新增。
8. **冷却**（D312）：首国立国后第二营地达标 → 冷却期内不插旗；冷却到期立即立国。
9. **初始流民**（D308）：地图生成预置 4~6 名流民、其中 3 人同点 → 可结营（同 seed 可复现）。
10. **玩家领土**（D307/D343）：开局后玩家领土格集 = 开局建筑外扩 1 中区块（D343 修订口径，对齐 §3.2/§3.4/§2.1；原"外扩 2 大区块"作废），染色含玩家色块。
