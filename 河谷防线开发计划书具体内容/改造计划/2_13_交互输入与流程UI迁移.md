## 一、老系统与新系统的衔接

### 1.1 现状（1D 交互输入）

| 老文件 | 现状 | 说明 |
|--------|------|------|
| `InputManager.cs` + `GameInput` | 君主 WASD/跑/ESC + 点击交互派发 | 输入模式：Normal/Build/Dialog（3.3.1 C3；3.3.1 已归档 2026-08-30） |
| `InteractionManager.cs` | 鼠标点击射线 → IInteractable → 派发 UI/动作；点空白关面板 | 通用交互派发器 |
| `IClickInteractable`/`IInteractable` | 可交互接口 | 建筑/资源点/裂隙等实现 |
| `OverheadSpeechManager.cs` | NPC/建筑头顶气泡（对话/缺水提示） | 头顶文字 |
| `PlayerInputHandler.cs` | 君主移动输入 | **退役**（君主取消，2_3 §2.2） |
| `CharacterCreationPanel`/`NewGameConfig` | 新建游戏：输入**统治者名字** + 难度 + 地图大小 | **rulerName 君主名待删** |
| `MainMenuPanel`/`SplashPanel`/`SaveSlotPanel` | 主菜单/启动/存档槽流程 | 直迁 |
| `WorkerInventory.cs` | 工人背包（携带量按资源类型） | 搬运链文件级归属缺失 |
| `UnitDataManager`/`UnitData` | 单位数据表（SO 直读） | 直迁（空间无关） |

### 1.2 核心变化（君主取消 → 上帝视角）

```
1D：玩家 WASD 操控君主 → 点击交互（君主去点）
2D：玩家 = 上帝视角 → 点选/框选/右键指令/建造/摄像机拖拽缩放，操作整个王国
```

> **上帝视角交互范式（2026-08-13 定稿）**：
> - **左键点选**：选中单位/建筑 → 打开对应面板（沿用 1D 点击交互，射线改 2D 正交摄像机）
> - **左键框选**：拖拽框选多单位（新增，2D 必需）→ 右键指令
> - **右键点地**：指令选中单位移动到目标（走 PathFollower 寻路，2_3）
> - **右键点建筑/敌人**：指令（采集/攻击/进驻，归 2_8 任务/战斗）
> - **摄像机**：中键拖拽 / 边缘平移 + 滚轮缩放（2_10 CameraRig）
> - **建造**：进 Build 模式 → 悬停预览/点击放置（2_2）

### 1.3 衔接总图

```
老：InputManager(君主WASD) → PlayerInputHandler → RulerController → Move
新：InputManager(上帝视角) → InteractionManager(点选/框选/右键指令) → 2_8 指令 / 2_2 建造 / 2_10 摄像机
```

**关键**：`InputManager`/`InteractionManager` 保留（输入模式机制、点击派发骨架），**只改"点下去做什么"**——从"操控君主"改"上帝视角指令"。`PlayerInputHandler` 退役，交互逻辑收拢到 `InteractionManager` + `SelectionController`（新增）。

## 五、要开发的新系统（详细设计）

### 5.1 交互范式状态（SO 可配）

```csharp
public enum InteractionTool
{
    Normal,   // 点选/框选/右键指令
    Build,    // 建造模式（2_2 BuildController 接管）
    Dialog,   // 菜单/对话（禁交互）
}
```

### 5.2 SelectionController（新增，上帝视角核心）

```csharp
public class SelectionController : Singleton<SelectionController>
{
    public List<UnitController> Selected { get; }   // 框选/点选集合（己方）
    public Building SelectedBuilding { get; }        // 点选建筑（独立于单位选择）
    public void BeginDrag(Vector2 screenPos);        // 左键按下（候选框选）
    public void EndDrag(Vector2 screenPos);          // 左键抬起 → 判定点击/框选
    public void IssueRightClick(Vector2 worldPos);   // 右键指令（归 2_8）
    public void DeployGuard(GridCoord target);       // 守卫部署（D116）：选中士兵→右键高价值点
    public void PrioritizeHarvest(GridCoord resource);// 微操（D115）：框选工人→右键资源点=优先采集
}
```

- 框选：屏幕矩形 → 世界矩形 → `GridSystem.GetUnitsInRect`（doc 1 §5.2 单位层）→ 过滤 faction=己方。
- 点选：`InteractionManager` 射线 → 最近可交互物。
- 右键指令：选中集 → `TaskScheduler`/`FormationController`（2_8）消费；空选右键 = 取消选择。

### 5.3 输入映射（InputManager 扩展）

```
左键        → BeginDrag/EndDrag（点击 or 框选，阈值区分）
右键        → IssueRightClick（指令）→ 选中工人+右键资源点=优先采集（D115）；选中士兵+右键高价值点=DeployGuard（D116）
中键拖拽    → CameraRig.Pan（2_10）
滚轮        → CameraRig.Zoom（2_10）
空格        → 暂停（快捷键，沿用）；E → 语义待 2_13 实施批复核，不再承担暂停（2026-08-29 Q6 C 面裁决：统一口径，原"E/空格→暂停/菜单"双键并列口径不一）
R/滚轮(建造) → 建筑旋转（2_2，Build 模式）
ESC         → 关闭面板/取消选择/暂停（沿用策略；无面板无选择时=暂停/菜单——2026-08-29 Q6 C 面裁决：与空格双通道并存，空格=纯暂停快捷键）
```

**P1 档输入（D274，2026-08-14 终审）**：Shift+点击=加选/减选、Ctrl+数字键 1~9=编队保存、数字键=编队调用、B=建造菜单、R=训练菜单；P0 仅基础键（左/右/中键/滚轮/E/ESC）。（2026-08-14 终审修订，D2XX）
