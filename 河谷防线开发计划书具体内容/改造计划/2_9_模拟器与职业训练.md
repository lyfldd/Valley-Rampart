## 一、老系统与新系统的衔接

### 1.1 现状（1D 模拟器）

老 harness（`ai决策大脑强化训练/`）：
- `SimWorld`：**1D 数轴**（x 单位，cellSize 2.26）
- `SimGrid`：1D 格子
- `SimHeat`：1D 中区块热度
- 战斗：1D 兵线（近战/弓手）
- 经济：3.5 已加 SimTask/SimEconomy
- `Pathfinding.Core`：已规划纯 C#（2_6）

### 1.2 核心变化

```
1D SimWorld（数轴）→ 2D SimWorld（x,y 平面 + 微格）
1D 槽位/热度/射程 → 2D（形状/中区块/格单位圆）
1D 兵线战斗 → 2D 战场
+ 职业/经济全同源（工人/居民/士兵等）
```

**训练一次直接可用**：sim 与 Unity 决策核/成本场/伤害/职业全同源，确定性对拍。

### 6.2 保真度契约（同源，sim 与 Unity 逐项对齐）

| 项 | Unity 真值 | sim 复刻 | 同源载体 |
|----|-----------|---------|---------|
| 伤害公式 | DamageSystem（2_5） | 同公式 | 共享程序集/同源码 |
| 距离口径 | doc 1 §1.6 格单位 | 同 | GridMathCore |
| 射程圆 | 2D 格单位欧氏 | 同 | GridMathCore |
| 感知 | 格单位 + 视线（Bresenham） | 同 | 共享 |
| 决策核 | L1/L2/L3（2_7） | 同（共享 AI.Core） | AI.Core asmdef |
| 成本场 | CostFieldBuilder（2_6） | 同 | Pathfinding.Core |
| 编队槽位 | 2D 形状（2_8） | 同 | 共享公式 |
| 时间步 | FixedDeltaTime 0.1s（对拍模式） | tick 0.1s | 契约 |

**同源契约声明（D255）（2026-08-14 终审修订，D2XX）**：

- **Vector2X（D255）**：自定义纯 C# struct（float x, float y），定义在 GridMathCore asmdef，sim 与 Unity 共享；Unity 侧以隐式转换桥接 Vector2↔Vector2X——sim 零 UnityEngine 依赖的硬前提
- **IWarehouse（D255）**：接口统一命名（无 2D 后缀），定义在新建 Economy.Core 纯 C# asmdef，sim 与 Unity 共享（同源对拍硬要求）
- **GridCoord（D255）**：统一复用 doc1 §5.2 定义（含 layer 维度），sim 不另建 GridCoord2D
- **AI.Core 纯 C# 验证（2026-08-14 终审）**：AI.Core asmdef 必须零 UnityEngine 引用（L1/L2/L3 决策核、Vector2X、GridMathCore 全部纯计算），否则 sim 共享即破坏确定性——2_7 落地时需 asmdef 校验

### 6.5 训练产出与回灌（TuningSnapshot）

```json
// TuningSnapshot（sim → Unity 回灌格式）
{
  "version": "2d-v1",
  "championId": "champ_20260813_001",
  "costFieldWeights": { "threat": 2.3, "safety": 0.4, "formation": 0.9 },
  "retreatParams": { "baseRetreatCells": 4.5, "sampleRings": 3 },
  "formationParams": { "spacing": 1.0, "archerRing": 1 },
  "meta": { "scene": "S3_2D", "episodes": 50000, "reward": 0.87 }
}
```

- 回灌路径：TuningSnapshot 覆写 Unity 侧 SO 手配值（CostBiasConfig/RetreatConfig/FormationShapes）
- champion 策略包（若含学习策略）按 id 载入 AI.Core 策略槽
- **训练一次直接可用**：同源契约（§6.2）保证回灌无需大幅重调；回灌后跑 Unity 冒烟场景验证

### 6.6 goldenReplay 协议（确定性对拍）

```
1. 固定：seed、场景 id、输入序列（脚本化）、tick 步数
2. sim 与 Unity（FixedDeltaTime=0.1s，对拍模式）各跑一遍
3. 每 100 tick 采哈希：单位位置（量化到微格）/hp/决策状态/路径
4. 哈希序列一致 = 通过；不一致 → 二分定位漂移 tick
5. 回归基线：1000 次混合请求路径哈希一致（2_6 验收 7 同源）
```

## 七、确定性保障

1. sim 与 Unity 共用 AI.Core 决策核 + Pathfinding.Core（纯 C#）
2. 成本场合成顺序同源；邻居顺序/平局规则同 2_6
3. goldenReplay：固定种子 1000 次 → 路径/行为哈希一致
4. 禁 UnityEngine.Random / Time.deltaTime 进 sim；RNG 单源 System.Random(seed)
