## 一、背景与定位

### 1.1 从挂起项到主线

0.6 §二十六挂起项②"敌方王国（后置，独立成篇：全兵种/强度不增长/AI 王国发展/王国战）"自 2026-08-13 大纲冻结以来一直搁置。2026-08-22 需求挖掘完成，本子系列正式启动设计。

核心结论：**AI 王国不是"加强版怪物"，而是玩家王国的镜像**——同一套经营/战斗/AI 系统、同一个世界账本、不同初始条件的另一个"玩家"。参照 WorldBox 的微观涌现观感：工人自己挖矿砍树、城市自然生长、王国间自然起冲突，玩家全程看得见每个实体过程。

这与项目主线"一切为了 NPC AI"完全同向：AI 王国的君主决策脑（王国脑）正是训练体系的下一座金矿。

### 1.2 对既有决策的修订与兑现

| 既有决策 | 处理 | 说明 |
|---------|------|------|
| D177 敌方王国"强度不增长" | **修订（D276）** | AI 王国全模拟自主成长；**二分法本身保留**（晚上传送门怪物 ≠ AI 王国，2_14 不受影响） |
| D228 胜利条件"敌方王国上线后再定" | **兑现（D277）** | 胜利=征服大陆（全部 AI 王国灭亡）；通关后自由沙盒 |
| D24 kingdomSpawns"阶段4前只填玩家" | **激活（D284）** | 地图生成激活 AI 王国出生点 + KingdomDef 初始条件 |
| D249 玩家失败判定"工人全灭" | **对称扩展（D279）** | AI 王国灭亡=其工人全灭，同一条生死线 |
| D146/D269 箱子可抢 | **复用** | 灭国掉落资源箱=战利品入口 |
| D266 经济环"同源模拟但不进训练目标" | **扩展（D286）** | 抽象结算引擎与 SimEconomy 同构，econ-train 训练成果双向复用 |

### 1.3 核心定位三句话

1. **镜像**：AI 王国与玩家走同一套系统、同一本账、同一条生死线；零特例。
2. **涌现**：发展/战争/立国全部由实体行为涌现（工人真干活、流民真聚集、插旗真立国），拒绝脚本刷新与"为创建而创建"。
3. **征服**：核心玩法=征服大陆；AI 王国是最终对手，微观视角下玩家指挥 AI（或 AI 自主）打赢每一场实体战争。

## 二、生命周期状态机（全景）

### 2.1 七阶段闭环

```
【第一代】地图生成时直接立国 N 个（出生即有基础，跳过孕育期）
    ┌────────────────────────────────────────────────┐
    │                                                │
【孕育期】流民在富庶无主地聚集（营地存续，复用流浪汉体系）     │
    │ 人数 × 存续时间过阈值 → 插旗                       │
    ▼                                                │
【出生期】最小王国：帐篷 + 几个工人 + 旗                   │
    │ 王国脑启动（存活期剧本）                            │
    ▼                                                │
【发展期】王国脑内层剧本推进：存活 → 发育 → 扩张            │
    │ 剧本进入军事期 + 外交系统激活                        │
    ▼                                                │
【成熟期】军事期 + 外交往来 + 版图巅峰                      │
    │                                                │
    │ 衰落 = 处境不是状态（战争/灾害损耗，系统同套逆向跑，     │
    │       效用 AI 对受损局面自动转重建/防御姿态）           │
    ▼                                                │
【灭亡期】工人全灭（对称 D249）→ 触发灭亡处理               │
    ▼                                                │
【遗产期】建筑废墟化(箱子可捡) + 残兵/人口流民化 + 领土无主    │
    │                                                │
    └──→ 流民聚集 → 回到【孕育期】（世界自我修复闭环）◄─────┘
```

### 2.2 阶段定义与转换条件总表

| 阶段 | 进入条件 | 核心内容 | 退出条件 | 归属文档 |
|------|---------|---------|---------|---------|
| 孕育期 | 流民在无主富庶地聚集（复用 T4/T5 游离行为，往有废墟资源/食物处聚） | 营地存续、人数增长 | 插旗：人数≥阈值 且 存续≥时长（低频稀有，D280） | 2_16 |
| 出生期（第一代） | 地图生成（2_1 kingdomSpawns 激活，D284） | 按 KingdomDef 初始条件预置（四维度，难度错峰） | 建成即视为进入发展期 | 2_16 |
| 出生期（动态） | 孕育期插旗 | 最小王国：帐篷+工人+旗，性格从邻近文化微变 | 同上 | 2_16 |
| 发展期 | 出生期完成 | 王国脑剧本（存活→发育→扩张）+ 账本粒度切换 + 领土推边界 | 剧本进入军事期 | 2_17 |
| 成熟期 | 剧本军事期 | 军事调度 + 外交往来（四态+关系值）+ 版图巅峰 | 灭亡（无直接退出；衰落是处境） | 2_17 + 2_18 |
| 灭亡期 | **工人全灭**（AliveWorkerCount==0，复用 ThroneAnchor.IsKingdomLost 同款逻辑，D279） | 灭亡处理：废墟化+箱子掉落+流民化+领土静默无主 | 处理完成即入遗产期 | 2_19 |
| 遗产期 | 灭亡处理完成 | 无主地/废墟/流民；玩家或 AI 就近自然利用 | 流民聚集触发孕育期（闭环） | 2_19 |

### 2.3 两层生命周期

- **外层=王国生死大周期**（本章七阶段）：状态枚举 `KingdomLifecycleState`，驱动系统级行为（灭亡处理/立国处理/领土归属）。
- **内层=发展期剧本小阶段**（存活→发育→扩张→军事，2_17 定义）：王国脑的宏观阶段变量，驱动国策权重，不是生命周期状态。

### 2.4 各阶段玩家一览（详见子文档）

| 阶段 | 玩家看见 | 玩家能做 |
|------|---------|---------|
| 孕育 | 荒野流民越聚越多（实体可见） | 驱散/屠杀流民（阻止立国）、无视 |
| 出生 | 插旗事件播报 + 小营地 | 早期扼杀 / 观察 / 交易 |
| 发展 | 染色扩张 + 工人干活 + 事件播报 | 情报面板窥探 / 互动 / 备战 |
| 成熟 | 版图格局 + 外交态度 | 宣战/结盟/送礼/条约（2_18） |
| 灭亡 | 灭国播报 + 废墟烟尘 | 捡箱子（战利品）/ 殖民废墟 |
| 遗产 | 无主灰色地带 + 流民游荡 | 自由建造占用 / 看新王国萌芽 |

## 三、核心架构决策

### 3.1 镜像原则（D276）

AI 王国 = 玩国王国的"另一个用户"：

| 维度 | 镜像含义 |
|------|---------|
| 系统 | 同一套 TaskScheduler/PopulationSystem/TrainingSystem/建造/仓储……（per-kingdom 化，见 §3.5） |
| 生死线 | 同一条：工人全灭=灭亡（D249/D279） |
| 经济 | 同一本账：抽象结算引擎与 SimEconomy 同构（§3.3） |
| 行为 | 玩家能做的 AI 都能做（建造/采集/训练/宣战），反之亦然；唯玩家独有=上帝视角全图观察与直接指挥 |

### 3.2 L4 王国脑分层（D282）

在现有 AI 三层之上新增第四层：

```
L4 KingdomBrain 王国脑（新增）：每游戏日 tick，输出国策
    ├─ 宏观阶段剧本（保底）：存活期 → 发育期 → 扩张期 → 军事期
    ├─ 阶段内效用评分（涌现）：候选行动打分 = 需求强度 × 性格权重 × 可行性
    │   （造房/造仓/招兵/采矿/推边界/修墙/出征/外交姿态……选最高分下发）
    └─ 事件打断：被打/灾害/邻国宣战 → 重规划
L3 FormationBrain（已有）：军队意图自决
L2 任务仲裁（已有）：派工/编队
L1 NPCBrain（已有）：个体决策（挖矿/砍树/搬运现成）
```

- **剧本保下限**（每个 AI 至少像个国家，不会发展歪），**效用保个性**（同阶段不同性格走出不同国运）。
- **两阶段路线**：阶段A=规则+SO 手配（剧本阈值/效用权重/性格权重全部 SO 化，先跑通可玩）；阶段B=权重入 factor_registry，sim 多王国化后 econ-train 训练回灌（§4.3）。

### 3.3 账本统一粒度切换（D281）

玩家对"AI 智能"的感知四来源中，只有经济实体模拟是贵的；而经济活动只在视野内可见。故：

> **可见即细模拟，不可见即抽象结算，账本是同一本。**

| 对象 | 策略 |
|------|------|
| 视野/战场附近的王国 | 细模拟：工人真跑 TaskScheduler/WorkerTask，建筑真施工 |
| 视野外的王国 | 抽象结算：每日 tick，人口×生产率→资源→推进建造队列/招募（产出写同一账本） |
| 军队（所有王国） | **永远真实体**（会跨图移动、与玩家交互），但只跑编队 AI 不跑经济 AI |
| 玩家走近远处王国 | 切回细模拟：建筑数/仓储/人口全为账本真数，工人从当前账本状态续干，无缝 |

开销估算：细模拟成本 ≈ 视野内 1~2 个王国的工人 + 全部军队 ≈ 现单王国的 1.5~2 倍；其余王国每日一次结算可忽略。

### 3.4 硬领土（D283）

- 格子/区块归属硬边界；AI 只在领内建造/采集；扩张=王国脑效用决策后推边界。
- 染色可视（§4.1）；无主地=任何王国的工人先到先得（微观事实定归属，无争夺玩法）。
- 细粒度规则（边界推进节奏/与地形关系/存档表示）归 2_17 细化。

### 3.5 经营层 per-kingdom 化（D289，改造范围预警）

现状：TaskScheduler/PopulationSystem/TrainingSystem 等为全局单例，全代码库无 kingdomId 概念；sim 侧 SimEconomy 亦为单王国沙盘。

改造方向：经营系统全部带王国归属（kingdomId 参数化或 per-kingdom 实例化），AI 王国与玩家共用同一套接口。这是本子系列**最大的工程改造**，逐文件拆解归 2_17 实施计划；sim 侧多王国化归 2_17 训练节。

## 四、贯穿机制（横切所有生命周期阶段）

### 4.1 可视化三层（D287）

| 层 | 内容 | 成本 |
|----|------|------|
| 领土染色 | 世界地块归属染色/边界旗，版图消长一眼可见 | 中（Tilemap 覆盖层） |
| 事件播报 | 世界播报 Toast/日志："X 国向 Y 国宣战""流民在新大陆立国""X 国灭亡" | 低（ToastManager 扩展，2_13 入口） |
| 王国情报面板 | 点开 AI 王国看数据：人口/军力/资源/关系/剧本阶段 | 中（新面板，2_13） |

实体层（工人真干活/建筑真施工）由细模拟天然提供，不单列。情报面板的信息可见度与"战争迷雾"关系（全知 vs 探雾才知）归 2_18/2_13 细化。

### 4.2 动态平衡 rubber-band（D288）

- **落后轻加速**（AI 显著弱于玩家：生产/招募效率微增）+ **领先轻限速**（AI 显著强于玩家：扩张/军事节奏微缓），保持中后期悬念。
- 幅度可配 SO（AIKingdomBalanceConfig），上限克制（避免玩家察觉"作弊感"）。
- 叠加**难度开局错峰**（D284）：简单=AI 落后发育起步，困难=AI 成熟基地压着打。
- AI 之间自然竞争互制衡为主，rubber-band 只做微调兜底。

### 4.3 训练统筹（两阶段路线）

| 阶段 | 内容 | 产出 |
|------|------|------|
| A（先 SO 手配） | 王国脑=规则+SO：剧本阈值/效用权重/性格权重手配；外交=性格规则+态势评分；全参数 SO 化 | 可玩的镜像王国 |
| B（入训） | sim 多王国化（SimWorld 多王国账本+外交状态+战争结算）→ 场景扩展（多王国对打/econ-train 扩展）→ 王国脑权重+外交权重入 factor_registry → CMA-ES 训练 → 回灌 | 越练越强的 AI 君主 |

- 抽象结算引擎与 SimEconomy 同构 → **训练成果双向复用**：训练出的 EconomyPolicy 不只是参数，直接是 AI 王国的心脏（运行时抽象结算）。
- 外交入训（D286）：外交决策权重随多王国场景一起训。
- 训练边界延续 D1/D266：单位级决策同源已就绪；王国级=新增层，归 2_17 §训练 + 2_18 §训练。

### 4.4 性能预算

| 项 | 预算 | 依据 |
|----|------|------|
| 视野内细模拟 | ≤ 现单王国 ×2（工人总数） | 活跃带 300~400 单位口径（D268 延伸） |
| 视野外抽象结算 | 每王国每日 1 tick，N≤8 可忽略 | 账本切换 |
| 军队真实体 | 计入活跃带总额定 | 军队不跑经济 AI |
| 领土染色刷新 | 边界变化事件驱动，非逐帧 | 2_17 细化 |

## 六、总风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 经营层单例改造范围大 | 2_17 实施期长、回归风险 | 逐文件拆解+每步冒烟；先打通 1 个 AI 王国再扩 N 个 |
| AI 发展歪（不修墙/憋兵/停滞） | 观感失败 | 剧本保底（§3.2）；rubber-band 兜底（§4.2） |
| 动态立国观感突兀 | "为创建而创建" | 涌现规则：流民聚集前兆可见+低频稀有+不保证存活（D280） |
| 性能超预算 | 后期卡顿 | 账本粒度切换（§3.3）+ 性能预算表（§4.4）逐项验收 |
| 玩家平推/被碾压 | 中期定型失去悬念 | rubber-band + 难度错峰（§4.2） |
| sim 多王国化训练成本高 | 阶段B 拖期 | 抽象结算同构（训练用抽象模型，与运行时同引擎）；先 A 后 B 不阻塞玩法 |
| 外交复杂度膨胀 | 玩家学不会 | 四态+关系值克制上限；条约实效归 2_18 逐条审 |
| 与 2_14 二分法混淆 | 夜灾/王国战互相污染 | 总纲明确定界：灾害=偶发事件，王国=长期实体，互不调度 |

## 七、总验收标准

1. 一张图 ≥2 个 AI 王国从出生到灭亡**全程自主运转**（经济/扩张/军事/外交），无脚本干预。
2. 灭亡 → 遗产 → 流民聚集 → 新王国诞生**闭环可复现**（同 seed 确定性一致）。
3. 玩家通过染色+播报+情报面板能理解世界格局与 AI 意图（可读性验收）。
4. 视野外抽象结算与视野内细模拟**同账本无缝切换**（走近远处王国，数据连续无跳变）。
5. 王国脑/外交参数 sim 可训可回灌（阶段B 闭环；阶段A 验收=SO 手配下 AI 王国可从出生存活发展至成熟期——不因自身决策夭折、无 ≥10 日停滞）。
6. 全部 AI 王国灭亡触发"征服大陆"胜利（D277），通关后自由沙盒。
7. 性能预算达标（§4.4）；新增参数全部 SO 化。
