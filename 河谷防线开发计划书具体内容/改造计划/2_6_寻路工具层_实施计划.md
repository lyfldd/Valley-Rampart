## 一、实施步骤（按依赖序，每步可独立验收）

### 步骤 1：Pathfinding.Core 程序集骨架 + 核心类型

**文件**：新建 `Systems/Pathfinding/Pathfinding.Core/`（asmdef）+ 内部类型

```csharp
// PathTypes.cs（纯 C#，零 UnityEngine）
public enum PathStatus { Pending, Ready, Partial, Unreachable, Cancelled }

public sealed class PathResult
{
    public PathStatus status;
    public GridCoord[] waypoints;   // 微格序列（池化）
    public int version;             // 失效检测
    public bool reachedExactGoal;
}

public struct PathTicket { public int id; public byte priority; }
```

```
asmdef 名：Pathfinding.Core
引用：仅 Vector2X/MathfX shim（AI.Core.Shim 同源或独立复制一份纯 C# 实现）
GridCoord = doc 1 的微格坐标（Int 坐标），直接引用 Grid 命名空间契约（无 UnityEngine 依赖）
```

**验收**：asmdef 编译通过；`Pathfinding.Core` 不引用 UnityEngine（grep 无 `using UnityEngine`）；sim 可引用。

### 步骤 2：BinaryHeap + GridMathCore（确定性开放列表）

**文件**：`Pathfinding.Core/BinaryHeap.cs`、`Pathfinding.Core/GridMathCore.cs`

**迁移 doc 1 §1.6 距离约定**（与 2_5 GridMath 同源，纯 C# 版）：
```csharp
public static class GridMathCore
{
    // 格单位分量归一化欧氏（doc 1 §1.6）：√((Δx/1.28)² + (Δy/0.64)²)
    public static float DistCells(GridCoord a, GridCoord b);
    // 8 向邻居顺序固定：E/NE/N/NW/W/SW/S/SE（确定性，平局裁决依赖此序）
    public static readonly GridCoord[] NeighborOffsets8;
    public const float DiagonalCost = 1.41421356f;   // √2 走常量（浮点顺序固定）
}
```

**BinaryHeap 要点**：开放列表最小堆；**平局 f 相同 → 索引小优先**（确定性 R3）；禁字典遍历序参与结果。

**验收**：堆 push/pop 顺序确定；`DistCells` 横/纵/对角一致；单测：同 f 平局按索引稳定。

### 步骤 3：AStarSolver 微格 8 向 A*（P0a 核心）

**文件**：`Pathfinding.Core/AStarSolver.cs`

```
输入：IPathGrid、from(微格)、to(微格)、CostField(可为空=全 1.0)
邻居：NeighborOffsets8 固定顺序（E/NE/N/NW/W/SW/S/SE）
代价：g += terrainCost(GetEnterCost) × costField × (斜走 ? √2 : 1)（格单位 §1.6）
启发：Octile × 最小代价（可采纳）
防穿角：IsDiagonalMoveAllowed(from, neighbor)（doc 1 R4 禁穿角）
早停：命中目标即返回；展开数达 maxExpansionsPerRequest 截断 → Partial
不可达：封闭全部可达点仍到不了 → Unreachable + 最近可达点（g 最小者）
```

**验收**：U 型墙绕行成功（FindPathImmediate）；两墙对角夹缝不可斜穿（禁穿角）；封死 → Unreachable + 最近可达点。

### 步骤 4：GridSystem 实现 IPathGrid + 热点缓存（D12/D18 归属本篇）

**文件**：`Systems/Grid/GridSystem.cs`（doc 1 基础上补齐）

```
IPathGrid 实现：
  Width/Height = 微格数（= 小区块宽×4）
  IsWalkable(sub)  = 微格可走（doc 1 §5.4 按需推导：小区块可走 && footprint 未覆盖；Bridge 豁免）
  GetEnterCost(sub) = 地形代价（Plain=1.0/Hills=1.5... 走 TerrainCostConfig SO）
  IsDiagonalMoveAllowed(from,to) = 两正交邻微格均可走才允许斜走
热点缓存（D18）：微格可走按需推导 + LRU 热点缓存（避免每步重算 footprint 覆盖）
  缓存失效：WalkabilityChangedEvent / BuildingChanged / GateStateChanged 时按 dirtyRect 清缓存
```

**验收**：`IsSubWalkable` 缓存命中率可测；占格变化（造墙/拆墙）后缓存失效、可走性实时更新；热点缓存不破坏确定性。

> 约束（R8 强化，2026-08-14 终审修订）：缓存命中/未命中结果必须恒等（仅加速不改变输出）；sim 侧可关闭缓存以保确定性。

### 步骤 5：PathFollower 接线（P0a，支撑 2_3"绕障碍 A→B"验收）

**文件**：`Systems/Pathfinding/PathFollower.cs`（2_3 已建基础上接 A*）/ `Systems/Pathfinding/PathfindingDebugDrawer.cs`（Gizmos）

**迁移 2_3 PathFollower 五态**（不改语义，只补路径来源）：
```
Idle --SetDestination--> Pending --SetPath--> Following
Following --到达路径点--> Following(下一点) / Idle(终点)
Following --下一点不可走--> Repathing --冷却(repathCooldownSeconds 1s)--> Pending
Pending/Following --连续 3 次失败--> Failed --PathFailedEvent--> (2_7/2_8 换目标)
任意 --Stop--> Idle
```
- `SetDestination(worldPos, priority)` → `WorldToSubCoord` → `FindPathImmediate(from, to)` → `SetPath(PathResult)`
- 落点吸附微格只在 SetDestination/到达时算（D73）

**验收**：NPC 绕 U 型墙 A→B（阶段 0 冒烟通过）；封死目标 → PathFailedEvent 触发；造墙 → 受影响单位冷却后重寻。

### 步骤 6：PathfindingService 票据队列/分帧/取消/失效重寻（P0b）

### 步骤 8：CostFieldBuilder 成本场（AI 看见机制，F8/D86，P1）

**文件**：`Pathfinding.Core/CostFieldBuilder.cs`、`Systems/Pathfinding/CostFieldRegistry.cs`（Unity 侧注册表）

```
成本场 CostField：每微格一个 float cost（值 = 地形代价 × 成本场权重）
  威胁带（敌人附近微格）→ cost 提高（绕开）
  守卫区域（2_8 守卫部署输入 IsGuarded，D86/D90）→ cost 降低（吸引）
  编队位 → cost 降低
合成顺序固定（确定性）：威胁 → 守卫 → 编队 逐层叠加
LOD 联动（审计定细）：活跃带内（2_4 Active/SemiActive 中区块）= 细粒度成本场（逐微格）；
  休眠区 = 纯目标搜索（成本场不参与，等价 cost=1）；切换以中区块为单位整块生效
权重先 SO 手配（2_9 入训后由训练产出替换）
实现 clamp 公式（D250，2026-08-14 终审修订）：cost=clamp(1+2.0×T-0.5×S-0.8×F, 0.1, 10)，寻路代价=terrainCost×cost
```

API（迁移自设计 §5.4）：
| API | 说明 |
|-----|------|
| `CostFieldHandle RegisterCostField(Faction)` | 注册成本场 |
| `void UpdateCostField(handle, RectInt rect, delta)` | 增量更新（dirtyRect） |

**验收**：敌人附近微格成本高 → A* 绕开威胁带（看见机制成立）；守卫区域成本低 → 吸引；中区块整块切细/粗生效。
