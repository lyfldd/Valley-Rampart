## 一、资源第一性架构（总纲骨架）

### 1.1 五元资源

```
金 / 石 / 木 / 粮 /【劳力 = 人口】
                    ↑ 第五资源：特殊性=既生产（干活）又消费（吃粮/住房）
```

### 1.2 三端模型

| 端 | 内容 | 现状承接 |
|----|------|---------|
| **获取端** | 采集（自然源）/ 生产（建筑=资源转换器）/ 招募（人口流入）/ **复员（逆向流出，本篇新增）** | 采集生产=2_12 资源链+TaskScheduler；招募=⑥⑦ |
| **储备端** | 仓储容量 / 储备底线 / 住房容量（人口上限） | WarehouseGap/GrainGap/HouseGap 既有 |
| **分配端** | 统一国情快照（感知）→ 效用评分（决策）→ 焦点+派工活权重（执行） | 本篇核心改造 |

### 1.3 模块消费域模型

```
资源底座（本篇域）＝ 获取/储备/分配 + 建筑转换器 + 科技 + 人口结构
                              ↓ 资源流供给（底线约束+诊断信号）
模块消费域（各自细则文档）：
  军事（2_22）＝ 花资源+劳力 → 兵力        —— 在资源分配基础上运作
  外交（2_18）＝ 花资源 → 关系              —— 在资源分配基础上运作
  灭亡（2_19）/出生（2_16）/种族（2_20）＝ 生命周期与参数层，垂直正交
```

**原则**：模块文档只声明「我消费什么资源、在什么条件下消费」，资源怎么攒、怎么分、怎么诊断，归本总纲域。

### 1.4 前提链图与心跳循环（D531 销 DZ-038，嵌套循环审查产出）

```
【心跳层·维持性】        【中间层·转换】           【目标层·对外】
资源循环 ─┬─→ 国库 ─┬─→ 建筑循环（产能转换器）─┐
人口循环 ─┴─→ 劳力 ─┴─→ 科技循环（解锁放大器）─┼─→ 军事循环（征战）
    ↑___________消耗粮/住房（反哺约束）_________│
                                              ├─→ 外交循环（关系）
领土循环 ←— 军事循环的产出与前提双向咬合 ←————┘
```

**心跳循环=资源循环+人口循环**（维持性，断则全系统停摆——统一断路器见 §2.2 三通道）；建筑/科技=转换放大器；军事/外交/领土=目标性循环（建立在心跳之上）。前提链检查逐条：征战←兵力←人口+资源 ✅（常设底线兜底）；科技←金 ✅；外交←互动 ✅；守土←驻防巡逻←兵员富余（2_22 P1）；收复←主动战略（挂 P3）。

## 二、统一国情快照（感知层，D528）

### 2.1 三块合一

```
国情快照（日 tick 全量重建，纯函数聚合，事件只置脏标记——D517 同构）：
├─ 军事态势块（2_22 P0 实施）    威胁分布/边境接触/军力现状/损毁清单/兵种表现统计
├─ 经济诊断块（本篇 P0 填真值）  五元资源收支（日入/日出/净流量 per 资源）
│                                产能盘点（产能建筑×类型×产出率、farm/人口比、采集点饱和度）
│                                断链检测（MustHaveConfig 基线 vs 现有 → 缺失清单）
│                                储备水位（粮裕日/仓储占用率）
└─ 人口盘点块（本篇 P1 填真值）  人口结构（居民/工人/战士/兵种分布）
                                 兵民比（warrior÷总人口 vs 目标）
                                 劳力分配率（已派工÷可派工）
                                 饱食水位（饥饿人口比，SatietySystem 消费端信号）
```

### 2.2 资源断裂根因三通道（六病灶之首的根治，D529；D531 扩全资源）

```
任一资源断裂触发（粮=底线日告警 grainReserveDaysFloor；金/石/木=收支净流量持续为负且水位 < 基线）
  → 诊断层判根因（顺序固定 A→B→C 保确定性；多资源同时断裂按断供严重度排序 粮→金→石→木）：
  通道 A 产能不足：对应产能建筑/人口比 < 基线（SO）    → 响应=建造对应产能建筑（farm/quarry/mine…）
  通道 B 采集不足：有产能但日产出/人口低（劳力信号）    → 响应=派工偏向（对应资源采集活权重↑，即时生效）
  通道 C 仓储不足：产出正常但仓储占用率溢出损耗        → 响应=仓储扩容（Granary/Warehouse）
单通道响应不叠加（每次断裂只对最大根因下药）。
```

「屯粮」语义从此归位：⑤的执行=诊断分诊，不是无脑建粮仓；粮的三通道即全资源三通道的特例——**心跳四成员统一断路器**（D531 销 DZ-033 资源自愈单腿）。

### 2.3 派工活权重（六病灶④根治，D529）

```
TaskScheduler 排序键升级：
  原排序 = 任务类型优先级（S/A/B/C 死表）→ 距离贪心
  新排序 = 类型优先级（死表保留，S 级修复保命不动）
         × 资源偏向活权重（ResourceBiasConfig SO × 诊断层缺口信号：缺石→采石任务有效优先级↑）
         → 距离
确定性保持：同 seed 同诊断信号 → 同排序（活权重是纯函数非随机）。
```

**边界**：活权重住 TaskScheduler（Unity 侧执行层）不进 AI.Core——D525 选址打分器同型注记；结构按 D519 模式预留 champion 所有权（偏向权重出厂 1.0 占位，factor_registry 草案登记，本批不进训练）。

### 4.1 职业网状流转（新基础设施，用户拍板+策划端保护边界）

```
基础职业层（居民 Civilian / 工人 Worker+Porter / 战士 Warrior）：
  网状自由流转——任意两两可转（居民⇄工人⇄战士）
  约束=转换冷却（N 日，SO）+轻成本，防反复横跳
专属兵种层（Occ 28~37 + 将军）：
  正向（基础→兵种）：仍走训练链（战营/射箭场/卫戍营，D490~D497 训练经济=兵种平衡组成部分）
  逆向（兵种→基础）：退役自由（复员场景，即时无冷却）
玩家侧：底层 API（SetOccupation 逆向合法化）全局开放；玩家 UI 入口另议挂账（本篇只定机制+AI 消费）
```

> ✅ **边界确认（2026-09-05 用户确认，D531）**：网状自由流转=**基础层网状+兵种训练链保护**——基础职业层（居民/工人/战士）网状互转；专属兵种（28~37）正向仍走训练链（D490~D497 训练经济=兵种平衡组成部分，绕过训练链=战营/射箭场等训练建筑贬值）、逆向退役自由。全职业真·网状否决。

### 4.2 ⑲人口调控评分

NeedScore=结构缺口（兵民比偏离目标 ∪ 人口低于经济承载力 ∪ 饥饿超载）；目标兵民比 SO 占位（和平 1:4 / 战时 1:2），随 2_22 姿态档调制——**人口结构与军事态势的双向咬合点**（动员→扩军；威胁解除→复员回工人，劳力回流经济）。

**战争损耗场景条款（D531 销 DZ-034，战争→经济跨循环螺旋断路器）**：动员扩军的兵民比目标受**经济承载力硬约束**——征召后劳力水位不得低于经济维持线（SO：minLaborRatio），跨过即触发复员回调（战争持续期同样回调，安全栏优先于目标）；复员触发=威胁解除 ∪ 资源水位恢复（双条件，防刚停战就复员被下一波偷袭）。**与 2_22 P1 覆灭响应的咬合**：军覆/军力底线触发的紧急征召走同一承载力约束——「征不动」时响应升级为危机重规划的经济通道（焦点强制屯粮/断链自愈）而非硬征（防把经济心跳打死）。

## 九、测试策略（冒烟+经营涌现验收）

1. **P0 冒烟**：粮三通道正负对照（产能型饿→建 farm 而非粮仓；采集型饿→食物偏向权重生效断言；仓储型→建粮仓）；派工偏向行为级探针（缺石世界采石任务有效优先级↑+采石场边工人密度对比）；断链自愈（删 farm→数日内重建）；确定性同 seed 双跑。
2. **P1 冒烟**：⑲复员（威胁解除→战士数↓工人数↑台账断言）；职业冷却（转换后 N 日内逆向被拒）；⑱三层诊断（金盈余→城堡 Lv2 达成；模块未满→科技+1；满级态→选最低级建筑升）。
3. **P2 冒烟**：品类扩容（医院/箭塔出现在 AI 建造清单并落地）；修复触发（Ruined→S 级任务派出→Active）。
4. **经营涌现时刻清单 E-B**（对标 2_22 E-K / 2_21 E1~E8）：

| # | 涌现时刻 | 判据 |
|---|---------|------|
| E-B1 | 粮荒自救 | 断粮事件→AI 按根因对症恢复（建 farm/派工偏向）而非傻建粮仓 |
| E-B2 | 复员 | 威胁解除→战士自动复员回工人（人口结构自整定） |
| E-B3 | 成长 | 资源盈余积累→城堡/建筑升级（Lv1→Lv2 肉眼可见的王国成长） |
| E-B4 | 断链自愈 | 关键建筑被毁→数日内补链 |
| E-B5 | 派工聪明 | 缺石头时采石场边工人变多（缺啥采啥） |
| E-B6 | 产业分化 | 不同资源禀赋的王国长出不同建筑组合（石多国城墙、粮多国农田集群） |
| E-B7 | 战时经济 | 动员档→扩军+储备倾斜（与 2_22 姿态联动） |
| E-B8 | 修复 | 废墟数日内被修复（不再是永久疤痕） |

5. **确定性**：全期同 seed 逐字节一致（含活权重/三通道/职业冷却）。
