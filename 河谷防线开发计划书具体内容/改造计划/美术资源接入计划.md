## 三、加载架构：artId → SpriteRefTable（用户 2026-09-12 定案）

**方案**：新建 `SpriteRefTable`（artId → `Sprite` 的 ScriptableObject 表，**直接序列化引用**真图），把占位查询改为「**先查表 → 命中用真图 → 未命中回退占位**」。

```
调用方（BuildingVisual / MapRenderService / UnitVisual / AmmoDef ...）
        ↓
  SpriteRefTable.TryGet(artId, out Sprite s)   ← 新增（SO 表·直接引用 Assets/_Game/Art/ 下真图）
        ├─ 命中 → 返回真图
        └─ 未命中 → PlaceholderSprites.Get(artId)（占位·回退不崩）
```

**为什么选它**：
- 与既有设计**完全一致**——`Rendering/PlaceholderSprites.cs` 头注即写明「美术到位后把本表占位替换为 ArtAsset 查询（`SpriteRefTable`，2_10 步骤10），逻辑零改动」。
- 守 **D37**（artId 唯一权威源）；真图与逻辑**解耦**（换图只改表引用，零逻辑改动）。
- **缺图自动回退** ⇒ 支持"渐进可用"（个别素材缺/版式不符不致崩）。
- SO 表**直接引用** ⇒ 素材**不必**放 `Resources/`（避免构建体积与规范成本）。

**边界**：表 = 新资产（`Assets/Resources/Config/Art/SpriteRefTable.asset` 或同域）；素材落 **`Assets/_Game/Art/`**；**导入设置须先配好**（§七）再入表。

### 七.1 切帧自动化（实测可行·D689 补）

**结论：可自动化**——版式是**规则网格**，切分规则由状态决定：

| 状态 | 网格 | 帧数 | 实测尺寸族（单元格） |
|---|---|---|---|
| idle | **3×3** | **8**（末格空） | 114(38) / 120(40) / 159(53) / 96(32) |
| loot | **3×3** | 8（疑同 idle·待核） | 114(38) / 213(71) |
| walk | **4×4** | 16 | 152(38) / 128(32) / 160(40) / 284(71) |
| attack | **4×4** | 16 | 152(38) / 128(32) / 160(40) / 284(71) |
| run | **4×4** | 16 | 152(38) |
| icon | 单张（不切） | 1 | 32 / 48 |

**实现方式（走 `unity-mcp-first`·**不**写 `[MenuItem]` 让用户手点）**：用 `execute_csharp_script`（Codely 万能·Roslyn）**批量**：
1. 遍历 `Assets/_Game/Art/Units/**/*.png`（实测 **152** 张）；
2. 按 `_{state}` 后缀定 `cols/rows`（idle/loot=3×3；walk/attack/run=4×4；icon=单张）；
3. 设 `TextureImporter.spriteImportMode = Multiple` ＋ `spritesheet = SpriteMetaData[]`（每格 rect·行优先·`alignment=Custom`·**pivot=底面中心**逐帧一致防抖）＋ `spritePixelsPerUnit=100` ＋ filter/compression（§七）；
4. `AssetDatabase.ImportAsset` ＋ `SaveAndReimport`；
5. **抽检读回**：`TextureImporter.spritesheet.Length == cols*rows`（防切错）。

**须先处理的 3 个特例**：
1. **异类**：`human/archer/unit_human_archer_idle.png` = **96×102**（非正方·D662 已知）⇒ 归批5 重出；
2. **2 张异常**：`114×114` 的 **walk ×1** 与 **attack ×1**（与同状态 4×4 主流不符，疑为另一套小尺寸角色或须重出）⇒ 施工时核；
3. **帧格 ≠ 有效帧**：idle/loot 切 **9 格**但**只播 8 帧**（末格空·用户亲验）⇒ 播放器按**有效帧数**配置（非"格数"）。

**底层 API（批量切帧·调用链·`execute_csharp_script`）**：
```csharp
// Assets/_Game/Art/Units/**/*.png · 一次性全量切
var ti = UnityEditor.AssetImporter.GetAtPath(path) as UnityEditor.TextureImporter;
ti.spriteImportMode = UnityEditor.SpriteImportMode.Multiple;
ti.spritePixelsPerUnit = 100f;
ti.mipmapEnabled = false;
ti.filterMode = FilterMode.Bilinear;                 // 按 §七
ti.textureCompression = TextureImporterCompression.CompressedHQ;
int cols = (state is "idle" or "loot") ? 3 : 4;      // 状态定网格
int rows = cols;                                     // 实测行列同数
int w = tex.width / cols, h = tex.height / rows;
var metas = new List<UnityEditor.SpriteMetaData>();
for (int r = 0; r < rows; r++)
  for (int c = 0; c < cols; c++)
    metas.Add(new UnityEditor.SpriteMetaData {
      name = $"{BaseName}_{r*cols+c}",
      rect = new Rect(c*w, tex.height-(r+1)*h, w, h),        // ⚠ 原点在左下
      alignment = (int)SpriteAlignment.Custom,
      pivot = new Vector2(0.5f, pivotY)                      // ⚠ 归一化 0..1·逐帧一致
    });
ti.spritesheet = metas.ToArray();
UnityEditor.AssetDatabase.ImportAsset(path, UnityEditor.ImportAssetOptions.ForceUpdate);
// 批量提速：UnityEditor.AssetDatabase.StartAssetEditing() / StopAssetEditing() 包住循环
// 读回验证：AssetDatabase.LoadAllAssetsAtPath(path) 的 Sprite 数 == cols*rows
```
**三个坑**：① `rect` 原点在**左下**（像素坐标，非左上）；② `pivot` 是**归一化(0..1)**、且**逐帧必须一致**（否则动画抖动）；③ `spriteImportMode` 变更后须 `ImportAsset`/`SaveAndReimport`，否则 `spritesheet` 被覆盖。
> **替代路径**：也可在美术端 **pixel-forge**（`png2grid`/`grid2png`）离线拆成单帧输出，Unity 侧免切帧——但需美术流程配合，本批默认走 Unity 侧脚本切。

### 七.2 运行时动画播放（本项目**无现成系统**·须新建）

**实读**：`_Game` 全库 grep `Animator`/`AnimationClip`/`AnimatorController` **零命中** ⇒ 项目当前**无单位动画系统**（单位只挂静态 `SpriteRenderer`）⇒ 本批须**新建**。

| 路线 | 做法 | 取舍 |
|---|---|---|
| **A 自研轻量 `SpriteAnimator`（推荐）** | MonoBehaviour：持 `Sprite[]` 帧数组 + fps + 状态名；`Update` 按 `1/fps` 推进索引；`SpriteRenderer.flipX` 处理朝向 | 零 Animator 开销/状态机复杂度；与现有 `UnitController`/`NPCBrain` 直连；**对象池友好**（AGENTS.md §〇 复用复位） |
| B Animator + AnimationClip | 每状态一 clip（`AnimationUtility.SetObjectReferenceCurve(clip, EditorCurveBinding.PPtrCurve("",typeof(SpriteRenderer),"m_Sprite"), ObjectReferenceKeyframe[])` 写帧）+ `AnimatorController` 状态机 | 可视编辑；但引入 Animator 开销 + 与大脑状态机**重复**（本项目状态归 `NPCBrain`/`UnitController`） |

**建议＝A**：状态切换（idle/walk/attack/run）由现有 `UnitController`/`NPCBrain` 驱动，`SpriteAnimator` 只做"给定状态→循环播帧"；朝向两向 = `flipX`；帧源 = `SpriteRefTable` 切出的帧数组。
