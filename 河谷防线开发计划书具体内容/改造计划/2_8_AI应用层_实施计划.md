### 步骤 1：任务调度 2D——任务目标坐标 2D 化 + 距离排序格单位

**文件**：`Systems/AI/Tasks/KingdomTask.cs`（改造）、`Systems/AI/TaskScheduling/TaskScheduler.cs`（改造）、`Systems/AI/TaskScheduling/ITaskScheduler.cs`（契约复核）

**迁移旧结构（全保留，坐标 2D 化）**：
```csharp
public enum KingdomDestType { None, Treasury, NearestWarehouse, WaterNetwork, SpecificBuilding }

public class KingdomTask
{
    public KingdomTaskType type;      // 任务类型
    public ITaskSource source;        // 来源对象（建筑/资源点）
    public KingdomDestType destType;  // 终点类型
    public Vector2 destPos;           // 派发时动态解析（改 GridCoord 微格落点）
    public object args;               // 任务参数
    public float intensity;
    public Vector2 SourcePos => ...;
}

public interface ITaskSource
{
    bool IsValid { get; }
    Vector2 SourcePos { get; }
    bool TryAdvertiseTask(out KingdomTask task);
    void OnRegister(); void OnUnregister();
}
public enum TaskState { None, Assigned, MovingToSource, Working, MovingToDest, Completed, Abandoned }
```

**改造点**：
```
任务目标 = GridCoord（微格落点；资源坑位 0.5×0.5 粒度，2_1 §3.4）
TaskScheduler 沿用 S>A>B>C 优先级 + 最近优先（格单位排序）：Vector2.Distance → GridMath.DistCells
destPos/SourcePos 字段保留 Vector2 世界坐标（正交；2026-08-22 裁决 HH.3：世界统一等轴嵌入，迁移待落），微格落点仅用于寻路目标（WorldToSubCoord）
```

**迁移 TaskScheduler 配置字段**：`tickInterval=1 / taskExpiry=5 / workDuration=2 / taskTimeout=30 / waterCarryAmount=10 / gatherAmount=5`（保留，数值 2D 化复核）。

**验收**：工人从主城出发采集→搬运→入库闭环（格单位寻路，白天冒烟 #1）；任务距离排序 2D。

### 步骤 7：敌袭 360° 多方向 → 偶发传送门灾害（WaveDirector，D177~D189，2_14）

**文件**：`Systems/AI/WaveDirector.cs`（新增）、`Systems/Kingdom/DayCycleSettlement.cs`（灾害触发判定）、`Data/WaveConfig.cs`（新增 SO）

> 2026-08-14 终审修订（D261）：WaveDirector **含传送门灾害波次调度内部方法**（D261，2_14 调用：灾害触发→生成传送门→分批多组召唤），不独立建 PortalWaveScheduler 类。

**迁移 1D 裂隙出怪（无代码，1D 设计=固定裂隙）→ 2D WaveDirector**：
```
输入：MapData.threatSpawns（2_1）、WaveConfig
触发：灾害触发时（2_14 §2.1 偶发：概率/天数/保底，SO 可配），非每晚
每夜流程（灾害触发时）：
  1. 波次数 = baseWaves + difficulty×wavePerDifficulty（少波次 D97：baseWaves=2/wavePerDifficulty=1 → Easy=3/Normal=4/Hard=5）
  2. 每波选 1~2 个 SpawnDef（方向聚合 R1：direction 夹角 ≤45° 归一组，组内错峰 2~5s）
  3. 组内单位错峰 2~5s 从传送门出生 → 流场 goal=当前高价值目标（D85/D94，价值驱使）
  4. 目标选择：怪物攻击最近/最高价值目标群（矿洞/仓库/营地/主城，价值×距离 D83/D94）
  5. 守卫区域破防判定（IsGuarded 丢失=威胁升级）
传送门：超高价值目标（D182），只晚上可攻击，被打反向强化（2_14 §2.4）
```

**验收**：灾害触发 → 多方向敌潮（流场到高价值目标）→ 守卫交战（D94/D116）；2 方向敌潮同时来袭不卡（R1 方向聚合）。
