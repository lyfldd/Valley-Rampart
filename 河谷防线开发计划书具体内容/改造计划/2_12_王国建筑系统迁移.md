## 一、老系统与新系统的衔接

### 1.1 现状（1D 王国建筑功能层）

王国建筑功能层已在 1D 实现，代码位于 `Assets/_Game/Systems/Building|Kingdom/`：

| 功能 | 代码实现 | 说明 |
|------|---------|------|
| 产能（产资源） | `ProducerComponent` + `StorageComponent` + `ProductionSystem` | 每秒 tick 产资源入本地存储，工人在场才产 |
| 副产（水晶/火油） | `ProducerComponent` 副产累计器 | 矿洞 Lv2 副产水晶 / Lv3 副产火油 |
| 存储（仓库/粮仓/高级仓储） | `StorageComponent` | 本地容量 + 携带量分批搬运（`HarvestCarry`） |
| 任务源 | `Building.TryAdvertiseTask` | 生产/搬运/挑水/采集四类任务广告 |
| 训练 | `TrainingSystem` + `TrainingConfig` | 训练所/练兵场/卫戍营，槽位×等级 |
| 贸易 | `TradeSystem` | 市场买/卖/额度/档位 |
| 税收/产金 | `TaxSystem` + `ProducerComponent` 金矿分支 | 商店建筑税；税务所直接产金 |
| 科技 | `AcademyBuilding` + `ResearchProjectList` | 学院单项目队列 |
| 民生 | `PopulationSystem` / `HappinessSystem` / `SatietySystem` / `WaterNetwork` / `RanchSystem` | 人口/幸福/饱食/水网/牧场 |
| 防御工事 | `FortificationDef` + `CombatComponent`（crew 接口已落） | 塔/墙/拒马/城门 |
| 战争机器 | `SiegeProductionSystem` + `SiegeProductionConfig` | 投掷机厂产机器/弹药 |

### 1.2 本升级的两处玩法变更（2026-08-13）

1. **君主取消 → 上帝视角**：无君主实体/操控。主城从"君主驻留"改为**王座/旗帜功能锚点**——王国锚点（失败判定、王国归属）挂在主城建筑上，不再是某个 NPC。玩家=纯上帝视角（点选/框选/指令/建造，归 2_8 + 2_2）。`RulerController` 退役，但其**资源池职责**（木/石/粮/金全局资源）迁移给仓库系统（§二.4）。
2. **木材来源唯一性**：**木头 = 只有一次性树木**。树（Tree）= 采完延迟刷新的一次性资源（2_1 §3.3/§3.4），**伐木场作废**——从建筑清单/美术表/代码资产中移除，无可持续木材产能建筑。木材存量随砍随减、无自动再增长（贸易/科技等木消耗照旧）。

### 1.3 衔接总图

```
1D：Building(1D 坐标) + Producer/Storage/Training/Trade/...（功能组件）
   ↓ 2D 化
新：Building(2D footprint，2_2) + 功能组件（本篇：坐标/目标/任务 2D 化，逻辑零改）
   + 主城=王座/旗帜锚点（上帝视角）
   + 树=一次性可刷新（2_1）
```

**关键**：王国建筑**功能逻辑（产出公式/存储/训练/贸易/科技/民生规则）与空间无关，几乎零改动**。真正要改的是"接缝"：坐标字段 1D→2D、任务目标/搬运目标 2D 距离、建筑实体在 2D 的 footprint 与落点（2_2 已解决）。功能组件**不重写**，只做坐标/目标适配。

### 1.4 与 2_2 的分工（避免重复）

| 层 | 归属 | 内容 |
|----|------|------|
| **空间层** | 2_2 | footprint 矩形、微格吸附、城门通行、桥、放置交互、预览高亮（围合判定已移除 D63，2026-08-14 终审同步） |
| **功能层** | **本篇（2_12）** | 建筑有什么玩法功能：产能/存储/训练/贸易/科技/民生/防御/主城锚点；每类 2D 化 + 任务接入 + 训练前置 |

2_2 已含"桥/城门/墙"的空间设计；本篇只列它们的功能语义（防御 HP/通行），空间细节引用 2_2，不重复。

## 五、要开发的新系统（详细设计）

### 5.0 仓库统一抽象 + 协作施工（2026-08-14 玩法重构核心，D43/D44/D112）

**仓库抽象（D43/D51）**——全库资源流动统一为"仓库→仓库"操作：

```csharp
/// <summary>仓库抽象：资源不凭空位移，一切获取/消耗走仓库操作。</summary>
public interface IWarehouse
{
    ResourceAmount Query();                    // 存量查询
    bool CanTake(ResourceType type, int amt);  // 可否取
    int Take(ResourceType type, int amt);      // 减（Remove）：从本仓库拿走（金币=瞬时即取即用，无搬运）
    void Deposit(ResourceType type, int amt);  // 增（Add）：NPC 从别处拿进来（泛型"拿"Transfer）
    int Transform(ResourceType in, ResourceType out, int amt); // 改（Transform）：就地加工增值
    // 实现：王国仓库（主城/仓库建筑/粮仓/高级仓储）、资源容器（树/石堆/木堆/矿脉/矿洞）、工人背包（移动仓库）
}
```

- **增（Add）**：NPC 从一次性资源容器/另一王国仓库 → 本仓库（搬运）
- **减（Remove）**：从本仓库取用（建造/升级/训练消耗）
- **改（Transform）**：加工地加工（如粮×2→面包）
- **拿（Transfer）**：泛型资源转移；金币=无仓库瞬时（D51）
- **多仓库凑单（D51）**：建造时最近仓库不足 → 多仓库各取一点（搬运边界）
- **训练消耗（D51）**：NPC 训练耗石/木/矿 → 直接从王国随机仓库取

**建造/升级 = 仓库积满 → 协作施工（D44/D112）**：

```
1. 玩家指定目标建筑（交互入口 2_13；施工进度 UI 归本篇，D256，2026-08-14 终审修订，D2XX）
2. 建筑发布任务（资源总需求，如 500 石）→ 2_8 规模派工（D95，理想工人数=需求/携带量）
3. 工人去王国仓库取资源 → 搬运 → 填入目标建筑"仓库"
4. 仓库积满 → 触发施工期：多工人协作（上限 SO 可配）→ 施工耗时=基础耗时/协作加成
5. 完成 → 建筑激活
```

**主城 = 王座/旗帜锚点（D2/D49）**：工人=最小重建单位（自带仓库），主城被破≠绝对失败，只要残留工人可重建。

**矿洞 = 持续产出 + 竞争（D113）**：持续产出不枯竭；任意阵营工人可开采，双方工人抢矿冲突（全员可战 D59，走战斗管线 D82）；价值驱使下矿洞=高价值目标（吸引敌人/守卫，D56）。

**全资源刷新系统（D54/D61）**：TreeRespawnSystem 扩展为全资源刷新——所有一次性资源（树/石堆/木堆/矿脉）按类型记录消失位置+时间，到点重生成；周期 SO 可配（树短/石矿长）。

### 5.7 建筑生命周期（受损/废墟/修复/升级/拆除，2026-08-14 讨论定稿，D149~D165）

> 补齐本篇原只定"建造/升级=仓库积满→协作施工"（D44/D112）的状态流空白。决策编号见 [`0.6_审查决策记录.md`](./0.6_审查决策记录.md) 十一B。

**状态机**：

```
建造完成（Lv1，满血）
   │  面板点"升级"（D158）→ 广播任务 → 工人自动搬运（D46）
   ▼
Lv2+（完成满血 D159，上限绑定主城解锁 D160）
   │  被攻击（价值×距离选目标 D83/D150）
   ▼
受损（残血：HP 1%~99%）
   │  残血不影响功能（D151），但目标价值↑（D153 激励及时修）
   │  工人修 + 耗资源（D152，自动+微操覆盖）
   ▼
满血
   │  被攻击至 HP=0
   ▼
废墟（占格+阻挡 D154）
   │  修复：部分资源（D155）→ 同建造流程（仓库积满→协作施工 D156）
   │  先修复回原等级才能再升级（D157）
   ▼
原等级满血
（城墙/城门/塔等工事：被破=直接销毁 D165，无废墟）
```

**各阶段规则表**：

| 阶段 | 决策 | 规则 |
|------|------|------|
| **受损** | D150 | 敌人按价值×距离选目标，普通建筑（农田/市场/学院等）也会被拆，全建筑 HP 有意义 |

| | D156 | 修复流程 = **同建造**：仓库积满 → 协作施工 |
| | D157 | **先修复回原等级，才能再升级** |
| **升级** | D158 | 玩家面板点击触发 → 广播任务 → 工人自动搬运资源（D46） |
