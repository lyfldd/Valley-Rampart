## 一、问题定义（五池实证的根因收束）

现评分公式（sim ScoreFormulas，五轮 baseline 口径）：

```
总分 = 胜率×0.40 + 战损比归一×0.30 − 弓手被贴身率×0.20 + 槽位保持×0.10
```

> **⚠️ D588 勘正注记（训练师实施侦察发现+策划端 ObjectiveFunction.cs 直读复核）**：上式仅为五档分层体系的 **B 均势档**公式（ObjectiveFunction.Evaluate，PowerRatio∈[0.85,1.2)）——实况=**五档分层**：S/A 劣势档（ratio<0.85 且 win≤0.5；win>0.5 校准回退 B 档公式）与 C/D 优势档（ratio≥1.2）各有独立权重表；且各档均带 AnnihilationPenalty（0.15/0.20，我军全灭罚项=D560① 既有设计意图）为本稿陈述漏项；「总权 1.00」仅 B 档正向项口径（S/A 正向 0.90+翻盘奖 0.15 / C·D 正向 0.85）。落地范围拍板见 §二 补记。

**收益路径缺陷**：D 档全胜局中，「全歼式赢」（残存 10%）与「保全式赢」（残存 90%）总分相同——
- 胜率项 0.40 二值化：赢的方式不影响该项；
- 战损比归一 0.30 是「我方损失/敌方损失」**比率**：保存有生力量的**绝对值**收益无处安放；
- 槽位保持/贴身率是过程约束项，非战果保全项。

**实证链**（五池参数死亡/弱活性的共同根因）：
- T06 收兵结构：仪式性收拢（敌残存<25% 才触发，承伤已定型）——收兵触发窗口在战斗已定局尾段，新公式下仍无分可加（D572 机理注记）；
- T01/F24 风筝：保全走位的行为收益无计分承载（D560 议题① 行为结构非评分结构，但结构落地后仍需评分通路兑现演化压力）；
- F28 夜间保全：safetyNightWeight 参数面死亡=「评分面无夜间保全收益通道（存活项饱和/承伤非评分输入）」（D-017 §5）；
- T03 站槽：break* 无因果=短板在指标/结构面（D578）；
- F27/T04/T05：带内弱活性与零触发死键——参数响应被评分圆整吞掉或路径未触发。

**结论**：评分面缺一条「赢且保全 > 赢且全歼」的收益通道，导致所有保全类行为结构（收兵/风筝/夜间收缩/撤退止损）落地后训练无法给它们演化压力。

## 二、方案比对

### 方案 A：新增「战后残存率」独立边际项（推荐）

```
总分 = 胜率×0.40 + 战损比归一×0.20 − 弓手被贴身率×0.20 + 槽位保持×0.10 + 战后残存率×0.10
```

- **战后残存率** = 战后我方存活数 / 开局我方总数（0~1，场景级统计新字段 `postBattleSurvivalRate`）；
- 权重重分配：战损比归一 0.30 → 0.20，让出 0.10 给残存率——**战损比与残存率是同一「兵力交换」语义的两面**（交换效率 = 比率；绝对保存 = 残存），拆分内部重分配不触碰胜率/贴身/槽位三个独立项，总权重 1.00 不变；
- 胜率 0.40 维持第一大项：**「赢」仍是第一收益**。

**防罪2 条款（赢法单一化防线）**：
- 残存率项**仅在 winRate > 0 局计分**——败局残存再高也不加（防「逃跑保命」伪赢法；败局的保全由既有撤退行为承载，不进公式）；
- 残存率权重 0.10 远小于胜率 0.40：「不赢只保全」的进化方向被胜率项压制；
- 「收兵赢」（winRate 1 + 残存高）与「全歼式赢」（winRate 1 + 残存低）分差 = 0.10×残存差（如 0.9 vs 0.2 → 差 0.07）——足以驱动收兵时机演化（disengageRatio 可训练标量的收益通路，D567③ 处方 (h) 兑现）。

**防罪5 条款（代理指标漂移防线）**：
- 公式改动**不改行为**（同 champion 同 seed 同场景，行为字段必须全等——纯计分面改动的验证判据）；
- 改动后回放抽查义务：determinism 子集跑批 + 抽 2 场景行为级对照（前后行为字段逐字段全等=改对；行为变了=改错）；
- 残存率语义直白（存活占比），无比率函数非线性化，回放归因简单。

**落地范围（D588 拍板=丙：B/C/D 三档，S/A 劣势档维持）**：
- **B 均势档**：战损比 0.30→0.20 让位残存率 0.10（本稿原文公式）；
- **C/D 优势档**：kd 0.35→0.25 让位残存率 0.10（优势局 kd 高位饱和边际最低；win 0.25 / quick 0.15 / slot 0.10 / grappled 0.05 / annihilation 0.20 五项全部不动）；
- **S/A 劣势档**：完全不动——核心存活 0.20 已承载保全语义（对象=被保护单位，非全军残存）；win≤0.5 局残存收益通道上限 ≤0.05 近乎无效且添归因噪声；S/A 档 win>0.5 校准回退 B 档通道**自动继承**残存项（回退局实际为均势/优势局，语义自洽）；
- 范围甲否决：仪式性收兵「敌残存<25%」高发区=优势局，仅 B 档则 C/D 无收益路径；范围乙否决：S/A 与核心存活语义重叠+改面大收益低；
- annihilation（0/1 全灭重罚）与残存率（0~1 连续梯度）互补不重复。

**五池重估解锁**：公式落地后 T06 r4 候选/T01 复开/F28/T03/F27 五池统一在新公式口径下重估（D567③ (h)「评分面不足列报」的反向兑现：本稿即「评分面方案落地」事件本身）。

### 方案 B：战损比归一函数边际化（否决）

战损比归一改凹曲线（比率高位区边际递减/封顶加成），不动权重结构。**否决理由**：比率函数非线性化后回放归因困难（罪5 风险升高）；「保存兵力」的绝对值语义（少死 5 人）与比率语义（我损/敌损）混淆——比率已含相对信息，绝对保全信息比率不可分；改动面看似小实则语义最绕。

### 方案 C：评分不动+卡池自定义收益（否决）

每卡自定义收益函数。**否决理由**：碎片化=口径漂移（每卡一套收益定义，跨卡不可比）；不解决跨卡结构问题；与 D519「权重归训练、结构归策划」的分层相悖。

## 三、实施边界（训练师执行口径）

1. **仪器先于训练（罪1）**：场景级统计新字段 `postBattleSurvivalRate` 先落 report（回合末我方存活/开局数），随公式改动同批；
2. **公式改动=结构性改动**：走提案双门禁（超快验制范围）；权重为公式常量（注释声明策划域），**不入 champion tuning**（公式结构非可训练参数；D519 远期若权重入训另走受控重注册）；
3. **baseline 重建（一次成本，不可避免）**：新公式下旧 baseline 分数不可比——**建议与 T05 参数面开工合并时点**：公式落地→重建 baseline（12600 局）→参数面 7 键双探针在新公式口径下跑，一次到位（否则参数面旧公式跑完再改公式=参数面重估白跑，顺序敏感）；
4. **15_账本登记**：评分公式=训练专用评估器，Unity 侧无对应物（FormationBrain/战斗不消费此公式）=**无回灌义务**，登记事实注记即可（C-T3 口径）；
5. **行为级零变化验证**：公式落地轮（r6）@battles100 全套件——同 champion 下行为字段与 r5 全等（公式不改行为证明）+分数方向性抽查（D 档残存高场景 sub 上升/全歼式赢场景 sub 下降）。

## 四、验收判据

1. 公式落地轮行为级零变化（r6 vs r5 行为字段全等）；
2. 分数方向性符合设计（保全式赢局 sub↑ / 全歼式赢局 sub↓，抽查 ≥2 场景各一）；
3. 新 baseline 重建完成（分数快照入库，L-02 口径）；
4. 五池重估解锁声明（T06 r4/T01 复开/F28/T03/F27 在新公式口径下排队）。

## 六、修订 A（D623，2026-09-10）：**范围乙重审** —— S/A 劣势档补「全军残存」收益通道

> **修订级别 = L2**（局部机制调整，§二 方案 A 骨架与 §五 四项拍板不变）；触发=HH.165 vc 搜参轮实盘 + D622 勘正。
> **原范围乙否决的两条理由均被推翻**：
> - 理由②「win≤0.5 时残存收益通道上限 ≤0.05 **近乎无效**且添归因噪声」→ **被实盘量级证伪**：`results/vc_gate/c0/verdict.json` 退化 5 场景中 S/A 必输局（底分 ≈0.015）三场景 `W9_T-K_1`/`W9_T-R_1`/`KT-R_2_2` 的 scoreDelta 仅 **0.006~0.009** ⇒ **0.05 的上限 ≫ 实盘退化量级**，该通道足以抵消；
> - 理由①「S/A 核心存活 0.20 已承载保全语义」→ **对象不同，不成立**：S/A 现有 0.20 项对象=**被保护单位/弓手**（`ProtectedSurvivalRate` / `ArcherSurvivalRate`），**非全军残存**。

**修订内容（待训练师实施）**：

| 项 | 口径 |
|---|---|
| 新增项 | S/A 真劣势档（win≤0.5）加「**全军战后残存率 `PostBattleSurvivalRate` × `w_saSurv`**」 |
| 权重 | **`w_saSurv` ≤ 0.05（建议 0.05）**，与 B/C/D 档同量纲、同字段 |
| 权重来源 | 从 S/A 正向项**让位**（现 kdNorm 0.35 / survival 0.20 / holdTime 0.15 / winRate 0.10 / slotHold 0.10 =0.90 + 翻盘奖 0.15）：建议 **kdNorm 0.35→0.30 让出 0.05**（与 B/C/D「战损让位残存」同构，保持"兵力交换两面"语义） |
| 防罪2 硬门控 | **仅 winRate>0 局计分**（win=0 局该通道=0 → 逃跑保命不加分），与 B/C/D 全档统一 |
| 不变项 | S/A win>0.5 校准回退 B 档通道（已自动继承残存项）；其余四项不动 |

**验收**：① 同 champion 同 seed **行为字段全等**（纯计分改动，罪5 防线）；② **c0 重跑**（`T01_vcsolo_on`）**5 场景退化清零或全部 <5%**（S/A 三场景为直接靶）；③ 方向性抽查：S/A 档"保全部队"局 sub↑、"全歼式"局 sub↓（各 ≥1 场景）。

## 七、修订 B（D623）：**VC（收兵）从可训练标的退役**

> 依据：D572 机理注记 + **本稿 §一 L23「收兵触发窗口在战斗已定局尾段，新公式下仍无分可加」**（设计稿自陈未解项）+ D615 b 门把触发钉在「静态目标清空后」（更晚）。**判定=窗口不可救**——要救须重开 b 门（重引"静态误读收兵"的语义误判，D615 刚治好），代价 > 收益。

- **退役口径**：VC 保持 `vcSoloEnabled=false`（champion 现值不动）；**b 门与个体级结构保留**（已零退化、语义正确，不拆）；
- **vc 键族**：三标量保留登记（不再作为 T01 搜参目标）；**键族拆分维持不立项**（D620③ 不变）；
- **结案**：不再挂"搜参挂起"（原挂起前置=评分面落地，已由本修订兑现）→ vc 线**结案**；
- **复活条件（写明，防僵尸）**：若 b 门语义被重开、或 VC 触发窗口前移到战斗中段，本退役自动失效需重新评估。

## 八、修订 C（D623）：**baseline 重建环路破除**

- 原序（§三.3）「公式落地 → 重建 baseline 12600 局 → 参数面 7 键一次到位」；而 **D615③ 把"扩容重建"挂在"vc 收敛之后"** ⇒ **循环依赖**：vc 收敛需新 baseline、新 baseline 需 vc 收敛。
- **修订=破环**：以「**范围乙口径冻结**」（§六 落地 + 行为级零变化验证通过）为触发点，**立即执行扩容重建 baseline + F28/T03/F27 重估**，**不等 vc 收敛**（VC 已退役 §七，"vc 收敛"不再存在）。
- 重建按 D620④ 硬要求：附「**旧锚→新锚位移声明**」+ **禁跨套件比 `total`**。
- 重估序：T06 r4 / T01 复开 / F28 / T03 / F27 在新 baseline 上统一重估；**T01 的目标由「vc 键族搜参」改为「新口径下的非 vc 标量」**。
