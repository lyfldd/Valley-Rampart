## 五、要开发的新系统（详细设计）

### 5.1 渲染层结构

```
渲染层（本篇）
├─ Tilemap_Ground     // 地皮（温度带 4 色 + 河流 RuleTile 变体）
├─ Tilemap_Feature    // 特征物（山/树/矿/水，2_1 features 驱动）
├─ Prefab_Building    // 人造建筑预制体（2_2 实例化，锚点对齐格中心）
├─ Units              // 单位 sprite（UnitAnimator）
└─ Overlay            // 高亮/预览/调试标记（2_2 放置预览、Gizmos）
```

### 5.2 MapRenderService

```csharp
public class MapRenderService : Singleton<MapRenderService>
{
    public void RenderMap(MapData map);            // features → Tilemap（一次性）
    public void UpdateCell(GridCoord cell);        // 单格增量（建造/地形变化）
    public Vector2 GridToIso(GridCoord cell);      // iso 嵌入投影（2026-08-22 裁决 HH.3：将反哺逻辑 CoordToWorld 同一映射，代码迁移待落）
    public GridCoord? ScreenToGrid(Vector2 screenPos); // 鼠标拾取 → 逻辑格（经 Camera）
}
```

### 5.3 CameraRig

```csharp
public class CameraRig : Singleton<CameraRig>
{
    public void Pan(Vector2 delta);      // 边缘滚屏/中键拖拽
    public void Zoom(float step);        // 档位吸附（1×/2×/4×）
    public void FocusOn(Vector2 worldPos); // 事件跳转（破城告警等）
    // 边界 clamp：地图矩形 + margin（CameraConfig）
}
```

### 5.10 领土染色承接（视口分级国家染色，D443+D448~D452，2026-08-30 定稿/2026-08-31 修订）

> **2026-08-31 修订（D448~D452，用户逐点拍板重梳）**：原「固定 baseAlpha 0.35 全档常显」升级为**视口分级染色**——近景不遮景（用户核心诉求），拉远才显世界盒式色块。D443 的固定 baseAlpha 与 D444 的边界降 alpha 被本节取代；D445/D446/D447 沿用不变。

> 指令源：总清单 §十 N3（D414 升格）· HH.32 裁4（三写点广播）· 2_16 接缝矩阵（染色数据只出不算）· 2_19 D379（渐隐 2s 预埋）；机制框架=D328 事件驱动增量刷新+D342 真源在账本。**本篇只做渲染：领土数据归 TerritorySystem（2_17 步骤12 已落），旗色数据归 KingdomRegistry（2_16 步骤5 已落）。**

**数据源契约（三件套，均已落地）**：

| 源 | API | 用途 |
|----|-----|------|
| TerritorySystem.Ledger | `IReadOnlyDictionary<Vector2Int,int>`（cell→kingdomId，D342 真源） | 全量补染/读档重建/chunk 补色唯一真源 |
| TerritoryChangedEvent | `{KingdomId, Added[]}`（坐标序保确定性，HH.32 裁4） | 增量刷新触发器（现状仅新增格，清除语义见 D446） |
| KingdomRegistry | `KingdomState.bannerColor`（玩家 id=0 在表，D303） | 染色基色 |

**渲染结构（D443）**：`MapRender` 根新增第六层 `Tilemap_Territory`（Iso ZAsY 参数同现状）；单一菱形 tile 资产（等轴 128×64@PPU100），颜色经 `Tilemap.SetTile`+per-cell `SetColor`（tint）；Sorting=Ground 之上、Feature/建筑/单位之下（染色是地皮着色不盖任何实体）；无主地=透明不铺；玩家国 id=0 同染（D303 统一注册）。

**视口分级染色（D448/D449/D450，核心修订）**：染色强度跟随摄像机缩放档位，对齐 `CameraConfig.zoomLevels` 下标（加档扩 SO 表，下标超出取末档）：

| 档位 | 下标 | 内部格 alpha | 边界格 alpha | 观感 |
|------|------|------------|------------|------|
| 近景（默认） | 0（1×） | 0 | 0 | 全无色，地块原貌零遮挡（D449 用户拍板：近景不区分王国） |
| 中景 | 1（2×） | 0.35 | 0.50 | 半透明填色，轮廓可辨 |
| 远景 | 2（4×） | 0.55 | 0.65 | 世界盒式浓色块，一眼读国 |

- 边界恒浓（D450）：边界格 alpha 按档位表独立取值（高于同档内部格；近景 0 自洽归零）；检测仍=8 邻域异主/无主（增量重算 Added±1 圈）；~~D444 边界降 alpha~~ 废弃（方向反转）。
- 近景层隐藏（D451）：近景档 `Tilemap_Territory` 整层 SetActive(false)（零 overdraw）；跨出近景先激活再渐显，渐隐完毕再隐藏。
- 跨档过渡（D451）：档位切换时全部已染色格按新档目标 alpha 0.3s 平滑插值（fadeDurationSeconds SO 化）；**SetTile 不随缩放发生**（tile 常驻有主格，缩放只动 SetColor）。
- 配色（D447 沿用）：bannerColor 为基渲染时派生（saturation/brightness SO 化——旗色数据零污染，地形可读性由派生统一保证）。
- 灭国渐隐（D446 承接 D379）：清色时该 kingdomId 色块 2 秒 alpha→0 渐隐后清 tile——纯渲染不占数据状态（领土数据当帧已全无主）。

**刷新管线（D445 三路组合，事件驱动增量为主）**：
1. 事件增量：订阅 `TerritoryChangedEvent`→Added 格逐格 SetColor+±1 圈邻域边界重算（边界状态随新增变化）。
2. chunk 补染：MapRenderService chunk 铺设完成钩子→该 chunk 格查 Ledger 真源补色（防「事件早于 chunk 加载」竞态，D342 真源原则）。
3. 全量重染：EnterPlayingGate 后+读档完成后各一次（Ledger 全量遍历；开局 ClaimInitial 事件天然覆盖首局）。
4. 档位切换（D448 新增第四触发源）：滚轮/ZoomTo 跨档→全部已染色格按新档表重定 alpha（Ledger 内存映射直查，无重查询；与三路刷新互不冲突）。

**前向契约（D446）**：灭亡释放（2_19 八步管线未实施）需「清除语义」——现状事件仅 `Added`；2_10 只声明消费需求，事件结构扩展（Removed/clear）随 2_19 实施批落，**不预改 2_17 已落代码**；渐隐渲染侧先行就绪。

**SO 配置（TerritoryOverlayConfig，so-data-driven）**：
- `zoomLods[]`（D448）：per 档 `{interiorAlpha, boundaryAlpha}`，默认 [0]={0,0} / [1]={0.35,0.50} / [2]={0.55,0.65}（实机可调）
- fadeDurationSeconds=0.3（跨档过渡，D451）/ kingdomFadeDurationSeconds=2.0（灭国渐隐，D379 定值 D446）
- colorSaturation=1.0、colorBrightness=1.1（D447）/ enableOnStart=true（2_13 设置页可消费）

**2_13 接口（渲染层提供，UI 消费归 2_13 实施批）**：`TerritoryOverlay.SetVisible(bool)`（染色开关）/ `HighlightKingdom(int kingdomId)`（列国名单点击→**临时以中景浓度显色**（D452，无视当前档位，近景下点击亦有反馈）+CameraRig.FocusOn 跳转；关闭高亮后回当前档位状态）。
