## 三、新系统的需求讨论（已收敛决策）

| # | 决策 | 结论 |
|---|------|------|
| 投影 | 等轴菱形 2:1，Tilemap 参数沿用 2_1 §3.1（Z As Y，Cell Size 1.28/0.64/1）；**PPU=100 → 1 小区块=128×64px**（D27） |
| 坐标 | 逻辑正交 → 渲染投影单向：`isoX=(gx-gy)*halfTileW`，`isoY=(gx+gy)*halfTileH`（halfTileW=64px, halfTileH=32px，PPU100 实算 D27） |
| 摄像机 | 俯视正交，pan/zoom，边界 clamp；SO 配 |
| 排序 | **Custom Axis (0,1,0) + Sprite Sort Point=Pivot + 分层解决遮挡（D104，用户实测）**；高度纯视觉不参与逻辑 Z（D105） |
| 动画 | 8 向状态机（2_3 Facing8 输入）；占位期 4 向+镜像降级可用 |
| 替换 | artId 引用表，占位→正式只换 Sprite 引用 |
| ~~小地图~~ | **砍掉（D103，原无此设计）** |
| **Z 轴** | **无逻辑 Z，高度纯视觉（D105）**：Tilemap Z As Y 仅渲染；无飞行层 |

> **Z As Y 澄清（D275，2026-08-14 终审修订）**：勾选仅辅助 Tilemap 内部排序；建筑/单位堆叠遮挡靠 sprite 总高（地基 32px+层数×32px）+(x+y)+heightLayer 排序（美术规范 §4.3），不手动设置 Z 值；Cell Size Z=1 为 cell depth 默认值。

## 四、新系统可能遇到的问题

| # | 风险 | 对策 |
|---|------|------|
| R1 | 256²+ Tilemap 内存/渲染开销 | 分层 Tilemap + 摄像机视野外 chunk 禁用（Tilemap chunk size 256）；地皮层压缩贴图 |

## 五、要开发的新系统（详细设计）

### 5.1 渲染层结构

```
渲染层（本篇）
├─ Tilemap_Ground     // 地皮（温度带 4 色 + 河流 RuleTile 变体）
├─ Tilemap_Feature    // 特征物（山/树/矿/水，2_1 features 驱动）
├─ Prefab_Building    // 人造建筑预制体（2_2 实例化，锚点对齐格中心）
├─ Units              // 单位 sprite（UnitAnimator）
└─ Overlay            // 高亮/预览/调试标记（2_2 放置预览、Gizmos）
```

### 5.2 MapRenderService

```csharp
public class MapRenderService : Singleton<MapRenderService>
{
    public void RenderMap(MapData map);            // features → Tilemap（一次性）
    public void UpdateCell(GridCoord cell);        // 单格增量（建造/地形变化）
    public Vector2 GridToIso(GridCoord cell);      // 渲染投影（仅渲染用）
    public GridCoord? ScreenToGrid(Vector2 screenPos); // 鼠标拾取 → 逻辑格（经 Camera）
}
```

### 5.3 CameraRig

```csharp
public class CameraRig : Singleton<CameraRig>
{
    public void Pan(Vector2 delta);      // 边缘滚屏/中键拖拽
    public void Zoom(float step);        // 档位吸附（1×/2×/4×）
    public void FocusOn(Vector2 worldPos); // 事件跳转（破城告警等）
    // 边界 clamp：地图矩形 + margin（CameraConfig）
}
```

### 5.4 UnitAnimator（8 向状态机）

```
输入：Facing8（2_3）+ 状态（idle/walk/attack，沿用 1D 动画状态）
状态机：8 向 × 状态；占位期 4 向 + 水平镜像降级（镜像规则与帧数规格=美术规范 §八，D259）
锚点：底座中心（美术规范 §1.3）；排序并入 Custom Axis Sort
```

```csharp
// 序列帧驱动（D259，2026-08-14 终审修订，规格见美术规范 §八）
public void Play(AnimState state, Facing8 facing);   // idle/walk/attack × 8 向
// 内部：Sprite[] frames + float fps(=12) + int frameIndex 循环推进
// 占位期 4 向降级：E/N/W/S 独立帧 + X 轴镜像（transform.localScale.x=-1）
```

### 5.5 SO 配置

| SO/字段 | 默认 | 说明 |
|---------|------|------|
| CameraConfig.zoomLevels | {1,2,4} | 档位吸附 |
| CameraConfig.panSpeed | 占位 20 | 世界单位/秒 |
| CameraConfig.edgeScrollWidth | 16px | 边缘滚屏区 |
| CameraConfig.boundaryMarginCells | 2 | 边界外扩 |
| RenderConfig.chunkSize | 256 | Tilemap chunk |
| RenderConfig.usePlaceholder | true | 占位/正式切换总开关 |
| SpriteRefTable | artId→Sprite | 替换唯一入口 |

### 5.6 占位→正式替换流程

```
1. 正式素材按美术规范产出（锚点/PPU/高度层由 Unity 导入设置保证）
2. SpriteRefTable 逐 artId 替换引用（占位→正式）
3. 冒烟：相邻建筑无缝/遮挡正确/锚点不漂（美术规范 §五验收）
4. 逻辑零改动（footprint/锚点/高度不变）
```

### 5.8 遮挡正确性专项（2026-08-14 新增必测，D104/D106）

```
规则（用户实测 + 决策 D104）：
  Transparency Sort Mode = Custom Axis，Transparency Sort Axis = (0,1,0)
  Sprite Sort Point = Pivot（等距用）
  分层（Sorting Layer）解决"单位 vs 建筑"遮挡：
    NPC 在墙/建筑下方（y 小）→ NPC 显示在前
    NPC 在墙/建筑上方（y 大）→ 墙/建筑挡住 NPC
  游戏无逻辑 Z（D105），高度纯视觉；遮挡专项为 2_10 验收必测项
```
