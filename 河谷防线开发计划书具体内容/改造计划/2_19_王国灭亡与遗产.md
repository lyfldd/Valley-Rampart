> 玩家不入灭亡管线（D380）：同一条"数人头"规则，玩家读数=空国（数据全保留、继续玩、招募流民重建）。

### 3.1 生死=派生属性（D375 核心思想）

**王国的生死不是中央宣判的字段，而是从个体实时聚合的派生属性**（D342"领土真源在账本、State 只是视图"的同构推广——真源在个体）：

- 删 `isAlive` 布尔；任何系统问"X 国活着吗"→ `PopulationSystem.AliveWorkers(kingdomId) + InTransitWorkers(kingdomId)`；**D400 修订（2026-08-24）：验尸聚合扩为全民口径**——`TotalPopulation(kingdomId) == 0`（工人+居民+战士+在途；工人全灭≠国灭，剩余人靠饥饿链自然流失）
- **在途工人** =（a）已招募正在走回的流民（b）训练队列未完成工人单；抽象国=抽象账本工人计数+招募队列（同一套口径）
- 王国的存续=它的成员的存续：人死了王国轻一分，最后一个人（哪怕在半路）决定国运——微观承载宏观

**AI 自救窗口（免费涌现，零新增系统）**：死亡确认放在 Brain tick **之后**——濒死 AI（D400 口径下全民已近零）当晚仍跑最后一次脑 → 常设底线⑥强制招工人（D322 已有）→ 有粮+附近有流民→招成产生在途→次日验尸"有在途"→续存。**没有任何救国系统，只有一个流民走路的身影决定一个国家的命运**（高光叙事素材：播报"流民在废墟中抵达，X 国续存"——P2 润色）。

### 3.2 尘埃落定灭亡确认与八步管线（D375~D376）

```
日 tick 2.5 步（②Brain 跑完后、③领土变更前）：
对每个王国聚合查询（含玩家——同一把尺子）：
  AI：全民==0（工人+居民+战士+在途；D400 修订）→ 触发八步管线
  玩家：同条件 → 不触发（空国照玩，D380）
```

**八步管线（当帧完成，顺序权威）**：

```
1. KingdomBrain 销毁+EventBus 全退订（D337）
2. DiplomacySystem 清理：pair 删除+条约作废+播报（D370）
3. 残兵处理：战士立即解除武装→流民化（L3 编队解散，战斗即时结束——
   "国亡人散"，去武装保性命；给流民池一次脉冲供给）（D377）
4. 建筑废墟化+箱子掉落：全部建筑→废墟态；仓储类各掉 1 战利品箱
   （内容=账本剩余按容量 clamp）；产能/住宅/围墙不掉箱；
   王座废墟化=旗倒国灭视觉锚点（D378）
5. 领土释放：TerritorySystem 删该国全部中区块+TerritoryChangedEvent；
   数据当帧全无主（别国可立即推边界）；染色渐隐 2 秒=纯渲染（D379）
6. 流民化：居民转流民入营（originKingdomId 印记——D295 混合权重来源+
   D374 外溢同管线）；人口守恒（转化 1:1）
7. KingdomRegistry 注销（id 不复用 D385）→ 顺带检查：剩余 AI==0 →
   里程碑"大陆已定"（D384）
8. 灭国播报："X 国灭亡"（挂王座废墟位置）
```

**D400 修订（2026-08-24 玩家视角游戏性总审查）**：全民验尸口径下，触发管线时国内已无活人——第 3 步（残兵流民化）/第 6 步（居民流民化）**自然空转**，管线职能从"处决+清理"收敛为纯**身后清理**（Brain 销毁→外交清理→废墟+箱子→领土释放→注销→播报）；残兵/居民的实际流民化前移到存活期由世界机制执行（§3.3 全民流失机制）。

**抽象国灭亡细则（D388）**：视野外（Abstract 态）王国验尸通过 → 管线照跑但走**账本层**：建筑列表全标废墟态+资源归零+每仓储类记一条"待生成箱"；切回细模拟（或玩家走近）时按账本生成废墟实体+箱子实体——与 D335 对账同管线，零新建机制（镜像保住：视野内外灭国都掉箱）。

### 3.3 流民供给四源闭环（D371~D373）

| 源 | 定位 | 节奏 |
|----|------|------|
| ① 初始预置（D308，2_16） | 开局播种 | 一次性 4~6 人 |
| ② 营地补员降格（D371） | **持续低速线**：每日每营 +1（refill 2→1）；上限=自然生成上限（现值 3，刷出停补）；承载无上限（外部流入可超） | 和平期核心供给——无灭亡也有积累，动态立国不死锁 |
| ③ 战争溃散流民（D440，2026-08-30 补源裁决） | **战场溃散脉冲**：工人/战士战斗死亡按 warDesertionChance（SO 占位 0.15）概率转流民（战场逃亡，带当期国印记，入最近营地；UnitDeathEvent 钩子，镜像普适含玩家）；原“灭亡流民化（管线第 3/6 步）”已自然空转（D400 修订后枯竭，2026-08-29 D414）——本源承接其脉冲职能，与 2_18 P2.1 sim 战争结算「居民减员转流民」镜像同源 | 战争期主力（夜灾/AI 互打产流民；和平期回归 ②/④ 低速线） |
| ④ 王国人口外溢（D374，新增） | 涌现式供给：居民>住宅×1.2（占位）持续 3 日 → 每日溢出 1 人转流民（最近营地/富庶无主地，带 originKingdomId）；**AI 同样外溢**（镜像）——AI 人口爆炸产流民，AI 间战争多一层人口压力动因 | 人口繁荣期出现 |

**上限语义拆分（D372）**：`campMaxVagrants`=自然生成上限（≠承载上限）；散营阈值修订 <3 → **<2**（1 人不成营，与生成上限 3 拉开距离）。

**结营/散营滞回带显式化（D387）**：结营阈值 ≥3（D301 不变）+ 散营阈值 <2（D372）→ **2 人营=结营后残留态**（合法存在：3 人结营后减员至 2 不散，减至 1 才散营）；从未结营的 2 人不结营。滞回带 [2,3) 保证营地作为实体的稳定性——玩家干预需杀到 1 人才真正打散（干预成本与 D313"干预=拖延，杀散=阻止"语义对齐）。

**守恒边界（D373）**：转化守恒（流民⇄工人 1:1，D295/D306 不变）+ 自然源合法（补员/出生/灾害死亡=世界人口正常进出）——**不做全局绝对守恒**；人口账本记录进出（供情报面板与训练侧统计）。

**印记生命周期（D389）**：originKingdomId **只活在流民态**——插旗/吞并转化时用于 D295 性格混合后即清除（转成工人无印记）；工人再流民化（外溢/灭亡）重新打**当期国**印记。语义="文化在迁徙中传递，定居后融合"。

**玩家外溢可见性（D390）**：玩家国外溢时播报一条"因住房拥挤，X 名居民离开了王国"（Toast 常规，不弹窗不打断）；AI 国外溢静默（情报面板可见）。

**外溢状态注（D374 补）**：overcrowdDays 连续计数器是**状态字段需入档**（区别于 D375 灭亡确认零中间态——后者纯派生）。

**全民流失机制（D400，2026-08-24 新增——外溢机制的生存压力泛化）**：居民无粮连续 N 日（占位 3，入档计数）→ 转流民逃离（最近营地，带 originKingdomId 印记——与 D374 住房外溢同管线，动因从"住房拥挤"泛化为"活不下去"）；战士断粮（王国无粮且军队补给断）→ 解散流民化。工人全灭后的王国靠该机制自然清空，全民归零才触发八步管线（D400 验尸口径）——灭亡从"当帧爆炸"变为"数日内人一个个离开"的历史事件，**执行者是饥饿法则，不是判官**（D399 世界自决哲学）。

**战损溃散机制（D440，2026-08-30 补源裁决——源③承接原灭亡流民化脉冲职能）**：工人/战士遭战斗死亡（UnitDeathEvent，Cause=战斗致死）时按 warDesertionChance（KingdomFallConfig SO 占位 0.15）概率不阵亡而溃逃为流民——生成于死亡位置附近、带当期国 originKingdomId 印记（D389 生命周期不变）、入最近营地；镜像普适（玩家兵溃散同规则）；**执行者=世界机制**（战场逃亡，属存活期流民化，与 D400 流失机制同族——不违背八步管线瘦身，灭亡管线仍零产出）；与 D373 守恒边界相容（死亡→流民=自然源合法）；与 2_20.1 狂战士击杀钩子（D435，同挂 UnitDeathEvent）共存无冲突；sim 侧需同源建模（参数入 factor_registry 草案，sim-sync 义务，与 2_18 P2.1 战争结算难民语义镜像）。

### 3.4 遗产期（D381~D383）

- **废墟永久保留**（D381）：不消散——废墟=地图的地形记忆；占格但可被建造覆盖拆除（复用 2_12 规则）；视觉随时间换暗色 sprite 变体（纯表现层归 2_10，数据永存）

- **遗产期=世界默认态**（D383）：不是一个状态、无系统行为——无主地可推（D326）/废墟可拆/流民可聚（聚集地评估废墟资源邻近分数项天然引路，D301）；轮回闭环=流民聚集→孕育→插旗（2_16）

## 六、测试策略（冒烟）

1. **派生属性**：删 isAlive 后全代码库无引用残留；聚合查询=在册+在途实测值。
2. **尘埃落定**：全民（D400 口径：工人+居民+战士+在途）半夜死光+1 名在途回城 → 次日验尸"有在途"→ 不灭；在途者到达 → 王国续存（无任何状态变化发生过）。
3. **AI 自救**：AI 工人==0 当晚 Brain 强制⑥招工人成功 → 次日续存；招不成（无粮/无流民）→ 灭亡。
4. **玩家空国**：玩家工人全灭 → 无 UI、无管线触发、领土建筑全保留；招募流民 → 工人恢复。
5. **八步管线**：注入 AI 灭亡 → 当帧完成八步（Brain 退订/pair 清/残兵流民化/废墟+箱子/领土全无主/流民入营带印记/注销/播报）。
6. **同帧多国**：三国同帧灭亡 → kingdomId 升序执行，同 seed 一致。
7. **箱子**：仓储掉箱内容=账本剩余 clamp；玩家工人/AI 工人/掠夺者三种拾取路径各自可用；拾取即消失。
8. **领土释放**：灭亡国中区块当帧全无主；邻国次日可推边界；染色 2 秒渐隐（视觉不占数据）。
9. **外溢**：AI 住宅满×1.2 持续 3 日 → 每日 1 人转流民入最近营地（originKingdomId 印记）。
10. **补员降格**：营地每日 +1 至自然上限 3 停补；外部流入（灭国流民）可超 3。
11. **散营阈值与滞回**（D372/D387）：从未结营的 2 人 → 不结营；3 人结营后杀至 2 → 营存续（不散）；杀至 1 → 散营。
12. **里程碑**：AI 全灭 → "大陆已定"播报+记录，世界继续日 tick；首次立国 → "新芽"。
13. **确定性**：同 seed 全程（含灭亡路径+里程碑判定）逐字节一致。
14. **抽象国灭亡**（D388）：抽象国验尸通过 → 账本层处理（废墟态标记+资源归零+待生成箱）；玩家走近切细 → 废墟与箱子实体生成；同 seed 一致。
15. **印记消费**（D389）：流民带印记转化 → 工人无印记；该工人再流民化 → 印记=当期国 id。
16. **玩家外溢播报**（D390）：玩家国住宅拥挤外溢 → Toast"因住房拥挤，X 名居民离开了王国"；AI 国外溢无播报（情报面板可见）。
17. **全民验尸**（D400）：工人全灭但居民/战士存活 → 验尸不过、不触发管线；居民无粮 3 日 → 转流民离开、战士断粮解散；全民归零 → 八步管线触发（第 3/6 步空转）；流失计数器入档。
18. **战损溃散**（D440）：AI 战士战斗死亡 → 按 warDesertionChance 概率生成流民（带当期国印记、入最近营地）；概率=0 负探针 → 全部阵亡零流民；同 seed 两轮逐字节一致。
19. **王座锚点数据化**（D441）：ThroneAnchor 组件退役后全库零引用；灭亡管线 KingdomFallenEvent 王座位置=castle 派生查询正确（含主城已废墟态）；玩家 GetKingdomAnchorWorld 零回归。
20. **全民口径 API 全集**（D442）：TotalPopulation(k) 四分项逐项断言（工人/居民含 Child/战士/在途）；玩家招募在途实体打标后计入在途口径（打标前漏计对照）；训练队列未完成单计入。
