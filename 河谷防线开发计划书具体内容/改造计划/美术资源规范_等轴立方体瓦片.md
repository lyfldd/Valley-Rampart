# 美术资源规范：等轴立方体瓦片（Isometric-Cube Tilemap）

> 日期：2026-08-13
> 状态：设计定稿（用户逐点确认）
> 定位：**全项目统一美术资源规范**，不属 2_ 系列实施计划；供美术/程序对照，确保所有自然/人造建筑在等轴立方体瓦片里严丝合缝
> 前置：视角定为**等轴菱形 Isometric**（总计划 §二），瓦片 2:1（64×32）

---

## 一、全局规格（所有资源必须遵守）

| 项 | 值 | 说明 |
|----|----|------|
| 瓦片形态 | 等轴菱形（Isometric diamond） | 斜 45° 立体，非正方形 |
| 宽:高 | 2:1 | 例 64×32 |
| Pixels Per Unit | **32** | 1 世界单位 = 32 像素 |
| 锚点 Pivot | **地基菱形底面中心**（方块落脚点） | 唯一 |
| 高度基准 | **每层 = 半菱形高 = 32px** | 沿屏幕 Y 轴堆叠 |
| 排序 | **按 (x+y) + 高度** | 高层晚画遮挡低处 |
| 网格到世界 | 等轴投影输出**锚点位置**，直接给 sprite pivot | 三者一致→无缝 |

### 1.1 锚点铁律（严丝合缝的根源）

```
网格逻辑坐标 (gx, gy)
  → 等轴投影 → 世界坐标（锚点位置）
  → 直接赋给 sprite 的 pivot
```

**三者必须一致**：锚点 = 地基菱形底面中心；网格→世界输出该点；sprite pivot 设同一点。每个方块用同一规则 → 无缝隙、无错位、无重叠。

### 1.2 高度与锚点

| 对象 | 锚点 | 高度 |
|------|------|------|
| 地皮/平地（菱形地基） | 菱形中心 | 0 层 |
| 有高度物体（房/墙/山） | 地基底面中心（落脚点） | 按上标堆层 |

高度沿屏幕 Y 轴上涨：房子=2 层(64px)、围墙=1 层(32px)、山=3 层(96px)。

## 四、通用规则

### 4.1 命名
`artId` 前缀分类：`feat_`(自然) / `bld_`(人造) / `ground_`(地皮) / `mark_`(调试)

### 4.2 尺寸计算
```
sprite 总高 = 地基高(32) + 高度层数×32
sprite 总宽 = footprint宽 × 64（菱形地基每格 2:1）
pivot 位于：x = 总宽/2，y = 地基高（即地基底面中心）
```

### 4.3 排序
```csharp
// 等轴排序：先按 (x+y)，再按高度，高层后画
sortOrder = (cellX + cellY) + heightLayer
```

### 4.4 占位方针
- 占位 = 简单菱形/几何 + artId，先保证锚点/高度正确
- 正式美术替换只换贴图，锚点/高度/footprint 不变 → 逻辑零改动

---

## 五、验收标准

1. 任意两个相邻建筑/方块无缝、无错位、无重叠
2. 高层物体正确遮挡低层（排序生效）
3. 网格→世界输出锚点 = sprite pivot，一致
4. 所有资源符合 2:1 菱形 + PPU=32 + 锚点铁律

1. 是否为等轴斜 45° 立体（非正视图）
