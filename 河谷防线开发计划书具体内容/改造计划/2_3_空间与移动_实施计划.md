## 一、实施步骤（按依赖序，每步可独立验收）

### 步骤 1：UnitController 移动 2D 化（删 y 固定）

**文件**：`Systems/Unit/UnitController.cs`（改造，移动段）

**旧定义迁移**（UnitController 移动段）：
```csharp
// 旧（1D）：
public virtual void Move(Vector2 direction, bool run = false)
{
    ...
    Vector2 newPos = _rb.position + movement;
    newPos.y = _rb.position.y;  // ← 固定 Y 轴，1D 横版命脉，2D 必删
    if (IsBlockedByFortification(newPos)) return;   // ← 撞墙即停，移除（D68）
    _rb.MovePosition(newPos);
    UpdateGridPosition();
    ApplyBarricadeSlowIfNeeded();
}

// 新（2D 平面移动）：
public virtual void Move(Vector2 direction, bool run = false)
{
    if (Data == null || !IsAlive || _knockbackActive) return;
    if (ChargeState != 0) return;                     // 冲锋让位（保留，D69）
    UpdateFacing(direction);
    float speed = EffectiveSpeed(run ? RunSpeed : WalkSpeed);
    Vector2 movement = direction.normalized * speed * Time.deltaTime;  // 格空间归一化 §1.6
    _rb.MovePosition(_rb.position + movement);        // 删 newPos.y 固定
    UpdateGridPosition();
    ApplyBarricadeSlowIfNeeded();                     // 拒马减速保留
}
```

**关键迁移点**：
- `MoveTowards`：删 `newPos.y = current.y`；**语义收窄为"走向下一路径点"**（PathFollower 调用）
- **`IsBlockedByFortification` 移除（D68）**：正常移动全走寻路（2_6），不再位移级撞墙停
- 速度单位不变：**世界单位/秒 Vector2 矢量**（D67）；方向输入格空间归一化（先除 cellSize 分量再 normalize，§1.6）
- 击飞/冲锋让位保留（数值归 2_5，D69）：`Knockback`（抛物线位移，`KnockbackArcHeight=6`，世界单位，占位；2_5 KnockbackForceScale 同族参数，D69 归 2_5 统一 SO）（2026-08-14 终审修订，D69）、`ChargeState`（0=None/1=准备/2=突进①/3=停顿/4=突进②）原样保留

**验收**：单位可在 2D 平面 8 向移动；`MoveTowards` 走向任意 2D 路径点；无 `newPos.y` 固定；无 `IsBlockedByFortification` 引用。

### 步骤 2：网格登记改微格 + 到达判定（新手感系数）

**文件**：`Systems/Unit/UnitController.cs`（改造）

**旧定义迁移**（`UpdateGridPosition`）：
```csharp
// 旧（1D）：WorldToCoord → TryEnter(小区块)，_gridRegistered/_lastGridCoord 缓存
// 新（2D，D70/D71）：WorldToSubCoord → TryEnter(微格)，登记/命中/寻路同粒度（微格）
private void UpdateGridPosition()
{
    if (GridSystem.Instance == null || GridSystem.Instance.Config == null) return;
    GridCoord? sub = GridSystem.Instance.WorldToSubCoord(transform.position);
    if (sub == null) return;                          // 越界（doc 1 D2 nullable）
    if (_gridRegistered && sub.Value == _lastGridSub) return;  // 同微格零开销
    GridSystem.Instance.TryEnter(this, sub.Value);
    _lastGridSub = sub.Value;
    _gridRegistered = true;
}
```
- NPC 底座 = 1 微格（0.32×0.16，D29）；精确位置 = 世界坐标（正交）
- 微格级查询 = 直接微格 O(1)，不再用"小区块候选+世界坐标比较"双轨

**到达判定（新手感系数，D3/D73）**：
```csharp
// 旧：arrivalThreshold = 0.3f（AttentionTuningConfig 标量格数，实际用 Distance<0.01）
// 新：arriveRadiusCells = 0.3（MovementConfig，格单位 §1.6 分量归一化距离）
public bool IsArrived(Vector2 dest)
{
    float dist = GridDist(transform.position, dest);  // §1.6 分量归一化欧氏
    return dist <= arriveRadiusCells;
}
```
- **落点吸附微格只在 SetDestination/到达时算**（D73），不在每帧

**验收**：单位微格登记正确（每单位 1 条微格主表，无双表）；同微格内每步零开销；`IsArrived` 按格单位距离判定。

### 步骤 3：PathFollower 基础版（新增，接 2_6 最小 A\*）

**文件**：新建 `Systems/AI/Movement/PathFollower.cs`（新增，**阶段 0 验收**）

> 旧库无此组件（`AI/Movement/` 目录不存在）。PathFollower 是新增组件，由 2_6 提供路径，驱动 UnitController.MoveTowards。

```csharp
public class PathFollower : MonoBehaviour
{
    public void SetDestination(Vector2 worldPos, byte priority = 0);  // 发寻路请求（落点吸附微格）
    public void SetPath(PathResult path);                              // 接收路径点
    public void Stop();
    public PathFollowerState State { get; }
    void Update();  // 状态机驱动，§5.2
}

public enum PathFollowerState
{
    Idle,        // 无目标
    Pending,     // 已发请求等路径（原地等待，超时 3s → Failed）
    Following,   // 逐路径点 MoveTowards
    Repathing,   // 下一路径点失效，冷却后重寻
    Failed,      // 连续 3 次失败 → PathFailedEvent（AI 换目标）
}
```

**旧链路迁移**：
```
旧：NPCBrain/任务 → MoveTowards(目标点) → 直线走 → 撞墙停
新：NPCBrain/任务 → PathRequester(2_6) → 路径点 → PathFollower → MoveTowards(下一路径点)
```

**验收**：NPC 从 A 到 B 绕开 U 型墙（**阶段 0 内验收**，接 2_6 最小 A\*）；移动落点吸附微格，无穿角。

### 步骤 4：PathFollower 状态机完整版（五态）

**文件**：`Systems/AI/Movement/PathFollower.cs`（扩充）

**状态机迁移图（§5.2）**：
```
Idle --SetDestination--> Pending --SetPath--> Following
Following --到达路径点--> Following(下一点) / Idle(终点)
Following --下一点不可走--> Repathing --冷却(1s)--> Pending
Pending/Following --连续 3 次失败--> Failed --PathFailedEvent--> (2_7/2_8 换目标)
任意 --Stop--> Idle
```

**行为细节**：
- `Pending`：原地等待路径，超时（3s）→ `Failed`（防寻路未回时 NPC 呆立，R5）
- `Repathing`：下一路径点失效（动态阻挡）→ 冷却（1s）后重寻
- `Failed`：连续 3 次失败 → 发布 `PathFailedEvent`（2_7/2_8 换目标）
- 动态阻挡响应（R7）：订阅 `BuildingChanged/GateStateChanged`（2_2 发布）→ 校验当前路径 → Repathing

**验收**：状态机五态全覆盖；封死目标 → Failed → `PathFailedEvent` 触发；移动中造墙 → 受影响单位 1s 内重寻。

### 步骤 5：朝向输出 Facing8（供 2_10 动画）

**文件**：`Systems/Unit/UnitController.cs`（改动）+ 新增枚举

**旧定义迁移**（`UpdateFacing`）：
```csharp
// 旧（1D）：flipX 双向（direction.x < -0.01 → flipX=true）
// 新（2D，D74）：朝向 = 速度方向量化 8 向
public enum Facing8 { E, NE, N, NW, W, SW, S, SE }   // 与邻居顺序一致（doc 1 §5.4）

public Facing8 Facing { get; private set; }          // 8 向朝向（2_10 动画消费）

private void UpdateFacing(Vector2 direction)
{
    if (direction.sqrMagnitude < 0.0001f) return;    // 静止保持
    // 按 atan2 → 8 扇区量化（22.5° 边界）→ 格空间方向（先除 cellSize 分量再 normalize，§1.6）
    float angle = Mathf.Atan2(dirY, dirX) * Mathf.Rad2Deg;
    int octant = Mathf.RoundToInt(angle / 45f) & 7;  // 0=E 1=NE 2=N 3=NW 4=W 5=SW 6=S 7=SE
    Facing = (Facing8)octant;
    // flipX/动画切换归 2_10
}
```

**验收**：8 向朝向输出正确（Facing8 供 2_10 动画）；静止不跳向。
