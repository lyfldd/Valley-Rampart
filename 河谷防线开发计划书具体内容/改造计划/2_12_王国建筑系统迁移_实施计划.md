### 步骤 3：仓库统一抽象 IWarehouse（D43/D51，玩法重构核心）

**文件**：新建 `Systems/Kingdom/IWarehouse.cs` / `Systems/Kingdom/Warehouse.cs`

设计 §5.0 仓库抽象落地——全库资源流动统一为"仓库→仓库"操作：

```csharp
/// <summary>仓库抽象：资源不凭空位移，一切获取/消耗走仓库操作。</summary>
public interface IWarehouse
{
    ResourceAmount Query();                    // 存量查询
    bool CanTake(ResourceType type, int amt);  // 可否取
    int Take(ResourceType type, int amt);      // 减（Remove）：从本仓库拿走（金币=瞬时即取即用，无搬运）
    void Deposit(ResourceType type, int amt);  // 增（Add）：NPC 从别处拿进来（泛型"拿"Transfer）
    int Transform(ResourceType in, ResourceType out, int amt); // 改（Transform）：就地加工增值
    // 实现：王国仓库（主城/仓库建筑/粮仓/高级仓储）、资源容器（树/石堆/木堆/矿脉/矿洞）、工人背包（移动仓库）
}
```

**操作语义（D43/D51）**：
- **增（Add）**：NPC 从一次性资源容器/另一王国仓库 → 本仓库（搬运）
- **减（Remove）**：从本仓库取用（建造/升级/训练消耗）
- **改（Transform）**：加工地加工（如粮×2→面包、石×2→Metal D200）
- **拿（Transfer）**：泛型资源转移；金币=无仓库瞬时
- **多仓库凑单（D51）**：建造时最近仓库不足 → 多仓库各取一点（搬运边界）
- **训练消耗（D51）**：NPC 训练耗石/木/矿 → 直接从王国随机仓库取

**实现映射（老代码对接）**：
- `StorageComponent`（storedAmount/capacity/Add/TakeOut/HarvestCarry）→ 实现 `IWarehouse` 的王国仓库侧（本地容量 + 携带量分批）
- `RulerController` 全局资源池 → **迁移到仓库系统**（国库 = 随主城升级的仓库；金=货币不占存储保留）
- 工人背包（`WorkerInventory` carriedType/carriedAmount）→ 移动仓库实现

**验收**：资源流动全走 `IWarehouse`；多仓库凑单跑通；`RulerController.ModifyResource` 路径迁移到仓库系统。
