## 二、老系统的改造（经营层 per-kingdom 化，D329~D331）

改造模式（D329）：**门面单例 + 内部字典**——单例类签名不动，内部状态从"一份"变 `Dictionary<kingdomId, State>`；玩家既有调用 `PopulationSystem.Instance.X` 原样路由 id=0，**玩家侧调用点零改动**（回归风险最小化）；sim 侧 SimEconomy 同步加 kingdomId 参数镜像同构。

| 步 | 系统（实测清单） | 改造内容 | 验收口径 |
|----|------|---------|---------|
| 第一步：归属地基（P0） | UnitFactory / BuildingFactory / WarehouseRegistry / TaskScheduler / PopulationSystem / TrainingSystem | 实体带 kingdomId；仓储账本 per-kingdom 路由；任务池/训练队列按归属路由（工人只领本国任务） | 玩家侧行为同 seed 逐字节不变；两王国账本互不串 |
| 第二步：全量归属（P1） | Happiness / Satiety / Tax / Trade / Ranch / SiegeProduction / DayCycleSettlement / CastleUnlockTable / WaterNetwork | 内部态 per-kingdom；科技解锁 per-kingdom；水网按领土归属 | 同上 |
| 第三步：AI 指令通道（P1 末） | 建造/招募/科技/推边界入口 | 加 kingdomId 参数（默认 0=玩家），AI 与玩家同一入口（D331）——镜像原则代码级落地 | AI 经通道下指令与玩家手工等效 |

配套：KingdomSaveData schema 拆 `kingdoms[]`（归 2_11 统一迁移，旧档展开为单元素数组）；KingdomConfig/RanchConfig 等配置 SO **保持全局共享**（模板差异在 KingdomDef，不复制配置）。

### 3.1 L4 王国脑（KingdomBrain）

架构（D282 落地，L4 与既有三层关系见 2_15 §3.2）：

```
KingdomBrain（每 AI 王国一份，日 tick，挂 DayCycleSettlement 前段）
  ├─ 剧本状态机（保底）：存活期 → 发育期 → 扩张期 → 军事期（单向）
  ├─ 效用评分（涌现）：15 项候选行动打分 → 国策焦点
  ├─ 常设底线（触发式，不评分）
  └─ 事件打断：宣战/灾害/主城被围 → 立即重规划（不等次日）
输出：国策焦点 → 指令通道（D331，与玩家同入口）→ L2 派工 / L3 编队
```

#### 3.1.1 剧本四阶段状态机（D317~D320）

推进机制=**阈值 + 最小停留**（D317）；**单向不回退**（D318）；统一存活期起步、每日最多升一级（D319）。

| 转换 | 阈值（占位，SO 可调） | 最小停留（占位） |
|------|---------------------|----------------|
| 存活→发育 | 人均有房 + 粮储 ≥3 日消耗 + 无失业工人，连续 2 日 | 存活期 ≥2 日 |
| 发育→扩张 | 工人 ≥8 + 产能建筑 ≥3 + 连续 3 日资源净流入为正 | 发育期 ≥3 日 |
| 扩张→军事 | 战士 ≥4（守备线）+ 人口 ≥12 + **扩张占区 ≥2 中区块**（D349：初始领土外新纳 ≥2 块，与 D341 非初始占区同口径——领土规模由初始半径天然满足，本条专测"真的扩过张"） | 扩张期 ≥3 日 |

- **单向不回退**（D318）：军事期王国被打回帐篷 → 阶段标签不动，效用自动转重建/防御姿态（⑬⑭全阶段可见高分）——行为等同回退、状态机不抖动、存档简单、训练参数减半（sim 可训前提）。
- **统一起步**（D319）：第一代一律存活期起步，每日最多升一级，无难度特例——困难档要塞国凭预置规模（D300/D309 单国 160%）2~3 日自然走完存活/发育；动态立国（2_16）天然弱势起步，同一规则。
- **节奏锚**（D320）：普通难度 AI 进军事期 ≈ 开局 20~30 日（占位，按国口径 D309 下实测回填）；军事期 ≠ 开战，宣战另有 2_18 关系值/态势门槛。
- 阈值与停留全部 SO 化（KingdomBrainConfig），纯规则不训；rubber-band 通过缩放需求强度间接调节推进速度，不直接改阈值。

#### 3.1.2 效用行动系统（D321~D323）

候选行动=**扁平 15 项清单**（D321，不分层树；剧本阶段只做可见性门控，不参与打分——评分函数不用学"何时解锁"）：

| 类别 | 候选行动 | 阶段可见性 |
|------|---------|-----------|
| 经济 | ①建住宅 ②建仓库 ③建产能（preferredTechTags+地形选型）④强化采集 ⑤屯粮 | 存活期起（⑤发育期起） |
| 成长 | ⑥招工人 ⑦招战士 ⑧科技升级（挂 CastleUnlockTable） | ⑥存活期 / ⑦⑧发育期 |
| 扩张 | ⑨修工事城墙 ⑩推边界 | 扩张期 |
| 军事 | ⑪组建出征军（联动 2_18 宣战）⑫边境增援 | 军事期 |
| 恢复 | ⑬重建 ⑭防御姿态 | **全阶段可见**（D318 姿态落点） |
| 外交 | ⑮外交姿态调整 | 军事期（内容 2_18 接管，本篇留槽） |

评分公式（D323）：`score = 需求强度 × 性格权重 × 可行性 × 阶段权重`

- 四因子全部 SO 化；性格五轴独立 0~1 **线性乘入**（D311 契约，无联合归一化）
- **可行性=二值门控（D346）**：不可行（资源不足/无合法选址/前置未解锁/冷却中/达上限）→ 分数 0 直接出局，否则 ×1——资源紧张的信息由需求强度（缺口函数）天然承载，可行性不做连续化；参数最少、语义清晰
- 需求强度=缺口函数（例：住房缺口=无房人口/总人口；兵力缺口=(目标-现役)/目标；缺口越大分差越大，单调不抖）
- 阶段A 手配 / 阶段B 入 factor_registry（econ-train 多王国扩展，§3.4）

> **P0 行动子集=①~⑥+⑬⑭（8 项）**（D345）：必含 ⑥招工人（人口增长唯一途径，防卡死存活期）与 ⑬重建/⑭防御（防夜灾打死）——指令通道最小集（建造+招募）随 P0 落地；⑦⑧随通道扩展；⑨⑩⑫ 归 P1；⑪⑮ 依赖 2_18 接口，P1 为占位可执行子集。

输出模型（D322）：每日 1 个**国策焦点**（无固定时长，被替换才结束——呈现"这几年攒粮、那几年扩军"的国运曲线）：

```
日 tick 顺序：
1. 常设底线（触发式，不评分，优先级最高）：粮储 <2 日消耗 → 强制屯粮/采集；
   本土被攻击 → 强制防御姿态
2. 效用评分：可见候选打分（阶段门控过滤）
3. 焦点切换：最高分 ≠ 当前焦点 且 当前焦点已持续 ≥3 日（防抖占位）→ 切换；否则维持
4. 事件打断（不等次日）：宣战/灾害/主城被围 → 立即重规划
```

#### 3.1.3 王国级军事调度（D324）

- **兵力目标常设**（D348 占位公式）：`目标 = clamp(2 + ⌈威胁值×3⌉ + 阶段系数, 2, 2+工人数)`；阶段系数：存活/发育 0、扩张 +1、军事 +2；软帽 2+工人数=军力受经济人口约束。**威胁值 = 邻接王国兵力之和 / max(己方兵力, 1)**（D339 分母零保护，弱化处理），从 TerritorySystem 领土表 + KingdomRegistry 兵力实时拉取；缺口越大 ⑦招战士 需求强度越高——军事建设自然并入效用体系，零新增独立机制。
- 出征/增援/多线 = 候选行动⑪⑫；执行全归 L3 FormationBrain（复用 3.6/3.7 编队、Sally、守城），L4 不碰战术。
- 训练：兵力目标系数入训（阶段B）；战术层已由 L3 训练体系覆盖（2_7/2_9）。

#### 3.1.4 日 tick 五步权威顺序（D347；步骤 2/2.5 含子系列扩展）

DayCycleSettlement 日 tick 内按固定顺序执行（同 seed 确定；决定同日交互——如"当日推边界圈营地"——的生效时点）：

```
1. SimMode 判定（SimModeManager：活跃带覆盖/迟滞/战斗锁 → 各国 Fine/Abstract 定档）
2. 外交子步（2_18 D395：EvaluateRelations 单次执行——衰减/事件/四态/AI 条约/AI 求和/AI 宣战判定，
   kingdomId 升序；⑮与后续脑评分读到当日新鲜关系值）
   → 王国脑 / 抽象结算（Fine 国跑 KingdomBrain.Tick；Abstract 国跑 AbstractEconomySettler）
2.5 灭亡确认（2_19 D375：尘埃落定验尸——~~活工人+在途工人==0 的 AI 触发八步灭亡管线~~
   **D400 修订（2026-08-24）：全民==0（工人+居民+战士+在途）才触发八步管线，居民/战士靠饥饿链自然流失（2_19 §3.3）**；
   Brain 在前=无工人国当晚仍可⑥招工人自救）
3. 领土变更（⑩推边界 + 玩家建造纳土）→ 发 TerritoryChangedEvent
4. CampUpgrader 吞并检查（消费第 3 步事件，同日生效——D306 当日圈入当日吞并）
5. 其余日结算（幸福/饱食/税收/人口等既有 DayCycleSettlement 流程）
```

> 步骤 2 的外交子步与 2.5 灭亡确认由子系列文档扩展登记（2_18 D395 / 2_19 D375），本表为权威汇总处。

### 3.2 领土系统（TerritorySystem，D283 细化）

- **账本单位=中区块**（D325，4×4 格）：与 LOD/热度/编队槽位同粒度（D77/D80 基建复用）；`Dictionary<中区块坐标, kingdomId>` 稀疏存储（D80 惯例）。**初始领土口径（D343 修订 D307）：第一代/玩家=初始建筑外扩 1 中区块（实际直径约 3~5 中区块）；动态=营地所在中区块+1 圈**——原"外扩 2 大区块"（半径 32 格）与 D41 出生间距（Small=24 格）冲突且使扩张机制形同虚设；改后邻国间仍留 ≥2 中区块空隙，扩张 1~2 块/次才有意义（2_16 已同步回写）。
- **AI 推进**（D326）：⑩推边界被选中 → 一次纳入 1~2 个**邻接**无主中区块（4 邻接连通、可走率 ≥50%）；冷却 5 日（占位）；同日多国争同一区块按 kingdomId 顺序结算，先到先得（同 seed 确定）。
- **上限挂钩人口**（D327/D341）：**扩张额度 = clamp(4 + 工人数 − 当前非初始占区, 0, territoryHardCap)**——初始领土（D343）不占额度，避免玩家开局即顶满（D341 决策）；territoryHardCap=96 中区块（SO 占位）；扩张必须先有人口增长，天然自平衡，替代"扩张耗资源"设计。
- **玩家建造纳土**（D327，镜像微不对称）：在邻接无主地放建筑落成 → 自动纳该中区块；从 D307 初始边界邻接起算；双方都能扩、互不重叠、无争夺玩法（D283）。
- **染色与事件**（D328）：TerritoryChangedEvent 事件驱动增量刷新（非逐帧，2_15 §4.4 预算）；消费方=2_10 染色 overlay / 2_16 CampUpgrader 吞并检查（D306 数据源）/ 2_11 存档 / 情报面板。
- **账本唯一真源=TerritorySystem**（D342）：`Dictionary<中区块坐标, kingdomId>` 是领土归属**唯一真源**；KingdomState.领土句柄仅为只读引用/视图，不缓存数据（防双源漂移）。运行时写入点只在 TerritorySystem。
- 存档表示归 2_11 统一迁移。

### 3.3 模拟粒度切换（SimModeManager，D281 落地细则）

- **切换单位=王国整体**（D332）：SimMode{Fine 细模拟 / Abstract 抽象}；账本 per-kingdom 同一本账，杜绝同王国双写路径；大王国半入视野 → 整国细模拟（成本受 2_15 §4.4 预算约束）。
- **判定**（D333/D344）：

```
"视野"定义 = LOD 活跃带（D344，对齐 D77）：Fine 集合 = 活跃带（玩家视角焦点 +
全部战斗热点，固定半径区块集）覆盖到领土的王国——与 LOD 同一信号源；摄像机缩放
全图活跃带不变，2_15 §4.4 性能预算不击穿；染色/情报面板照常全图可见（上帝视角不受影响）
切细：活跃带覆盖到王国领土 → 立即切 Fine（响应优先）
切抽象：连续 2 日未被活跃带覆盖 → 切 Abstract（迟滞防边界抖动）
战斗锁：领土内出现战斗热点 → 强制 Fine（军队打到家门口，工人逃跑/救火必须真跑）
存档记录 SimMode
```

- **实体策略=常驻+休眠**（D334）：不销毁重建；休眠态 NPCBrain 停 Think、停寻路；渲染天然剔除（视野外不渲染）；切回细模拟工人**原地续干**（位置/任务/建筑进度全保留）——D281"走近无跳变"的实现载体；内存成本 ≤8 国 × 30~80 单位 ≈ 数百单位数据量，可接受。
- **对账规则**（D335）：
  - 人口：抽象期只维护**计数**（增长/饿殍按同构公式）；切回按差值补/删单位（unit id 序确定性生成，新兵刷住宅、无住宅刷王座——帐篷级国 fallback）——同 seed 逐字节一致
  - 建造/招募：抽象期按每日资源投入推进队列进度；切回续接真实施工
  - 军队：永远真实体（D281），不受 SimMode 影响
  - **抽象态全民流失（D400 追写，2026-08-24 补审）**：AbstractEconomySettler 公式补流失项——居民计数无粮连续 N 日 → 计数 -1 且最近营地把民计数 +1（同一世界账，两侧同 seed 一致）；战士断粮（王国无粮）→ 解散转流民计数；流失后全民==0 → 抽象国灭亡走 D388 账本层管线。细模拟侧流失（实体转流民）与抽象侧流失（计数迁移）公式同构（D336 同一纪律）
- **抽象结算引擎**（D336）：运行时 `AbstractEconomySettler`（每抽象王国日 tick）——纯 C#、零 Unity 引用、公式与 sim 侧 SimEconomy **同构**（D286）；训练出的 EconomyPolicy 不只是参数，直接是 AI 王国的心脏（运行时抽象结算）；sim 侧 SimWorld 多王国化归阶段 B（§3.4）。


## 六、测试策略（冒烟）

1. **剧本推进**：控制台注入资源/人口满足阈值 → 按最小停留推进；单日满足多级条件 → 每日最多升一级（D319）。
2. **单向不回退**：军事期王国被打残至帐篷级 → 阶段标签不变（仍军事期），焦点自动转⑬重建/⑭防御（D318）。
3. **性格分化**：同 seed 同局面，好战 0.95 vs 0.05 两个模板 → 30 日焦点统计：好战国 ⑦招战士+⑪出征 占比 ≥ 经济国 ×2（D323 线性乘入有效；可测判据）。
4. **常设底线**：粮储清零 → 次日 tick 强制屯粮，无视评分排序（D322）。
5. **兵力目标**：注入威胁（邻国军队逼近边境）→ 兵力目标上调 → ⑦招战士分数上升（D324）。
6. **领土推进**：⑩被选中 → 纳入 1~2 个邻接无主中区块（可走率 ≥50%）；5 日冷却期内不再推进；扩张额度耗尽（D341 clamp 公式含 territoryHardCap）拒绝推进并降分（D326/D327/D341）。
7. **玩家建造纳土**：在邻接无主地建仓库 → 落成即纳该中区块 + 染色刷新 + TerritoryChangedEvent（D327/D328）。
8. **吞并联动**：AI 推边界圈入存续营地中心格 → CampUpgrader 触发 D306 吞并（流民转工人，人口守恒）。
9. **SimMode 切换**：王国出视野 2 日 → 抽象（NPC 停 Think）；入视野 → 细（原地续干）；反复切 10 次 → 账本无差、建筑进度连续（D332~D335）。
10. **战斗锁**：抽象王国领土内爆发战斗 → 立即切细模拟（D333）。
11. **per-kingdom 回归**：改造前后同 seed 玩家侧行为逐字节一致（D329 门面验证）。
12. **确定性**：同 seed 全程（含抽象结算路径）逐字节一致。
13. **玩家无剧本**（D338）：玩家 kingdomId=0 不建 KingdomBrain，KingdomState.剧本阶段=null，情报面板不展示玩家剧本阶段。
14. **王国脑生命周期**（D337/D340）：灭国后王国脑销毁、EventBus 订阅全部退订（无收到已死王国的打断回调）；宣战/灾害侵入后当日即重规划（不等次日）。
15. **领土真源**（D342）：修改领土归属后 KingdomState.句柄读到的值与 TerritorySystem 一致（句柄不缓存、真源唯一）；上限公式按 D341 扣除初始领土验证。
16. **初始领土口径**（D343）：开局各国领土=初始建筑外扩 1 中区块；Small 图（24 格间距）下任意两国领土不相交（邻接空隙 ≥2 中区块）。
17. **活跃带视野**（D344）：摄像机缩放至全图 → Fine 集合不变（无王国因缩放被切细）；玩家焦点移到远处王国 → 该国当日切细。
18. **日 tick 顺序**（D347）：构造"当日推边界圈入营地"→ 同日 tick 内完成吞并（CampUpgrader 在领土变更后执行）；同 seed 复现一致。
19. **P0 行动子集**（D345）：P0 阶段 AI 可执行 ①~⑥+⑬⑭ 且存活期不卡死（⑥招工人可执行）；⑨~⑫⑮ 在 P1 前不可见不可执行。
