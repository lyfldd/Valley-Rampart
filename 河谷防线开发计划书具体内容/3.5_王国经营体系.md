## 一、核心循环（用户决策）

```
【废墟开局】废弃城堡在地图中央，开局资源只够修复（木100/石60/粮60/金30）
  ↓ 修复主城（Lv1 激活）→ 解锁基础建造（土木 Lv1）
【生存起步】工人采集（木/石）→ 伐木场/采石场 → 资源自循环（搬运已就绪）
  ↓ 农田产粮 → 粮养人口 → 饱食度系统
【经济发展】人口↑（房屋）→ 税收（人头+建筑税）→ 市场贸易（金）
  ↓ 主城 Lv2 → 模块 Lv2 解锁
【防御成型】城墙/箭塔/城门 → 拒马/弩塔 → 夜晚/波次防守
  ↓ 主城 Lv3 → 模块 Lv3 解锁
【军事扩张】练兵场/装备厂（装备驱动职业）→ 卫戍营（将军限量2）→ 编队（AI 已就绪）
【王国完整】主城满级 + 全模块满级 + 军力成型 + 抵御波次
【失败条件】主城或君主死亡 = GameOver（胜利暂不设）
```

- **昼夜循环**：1 天 = 3 分钟（白天经营 / 黄昏预警 / 夜晚防守），TimeManager 已有
- 饱食/幸福/税收/贸易/装备/科技全部挂昼夜结算

## 二、模块体系总览（架构核心）

### 2.1 主城等级约束

> **主城 N 级 → 所有模块等级 ≤ N 级**。主城升级是王国成长的唯一瓶颈。

### 2.2 六个模块与归属模型（责任一刀切）

| 模块 | 领域职责 | 基础建筑（可升级，≤模块级） | 特殊建筑（每级解锁，仅一级） |
|------|---------|---------------------------|---------------------------|
| **土木** | 防御工事 + 建筑等级上限 | 城墙 / 城门 / 箭塔 / 主城 | Lv2 拒马阵、弩塔；Lv3 魔法塔 |
| **生产** | 资源产出 + 加工 + 存储（全链条） | 伐木场 / 采石场 / 矿洞 / 农田 / 仓库 | Lv2 粮食加工（特殊食物）；Lv3 高级仓储 |
| **民生** | 人口容量 + 饱食 + 幸福（消耗侧） | 粮仓 / 房屋 | Lv2 水井（饱食辅助）；Lv3 医院 / 教堂 |
| **军事** | 兵种 + 装备 + 将军（全链条） | 练兵场（战士/弓手）+ 装备厂 | Lv2 投掷机厂（全局唯一）；Lv3 卫戍营（将军） |
| **商业** | 金来源（税 + 贸易 + 金矿） | 市场（贸易） | Lv2 商店（建筑税）；Lv3 金矿 |
| **科技** | 跨模块全面小增益 | 研究设施（学院/工坊） | 每级解锁研究方向（全面增益） |

**归属原则**：产出类建筑归生产，消耗/生活类归民生，工事归土木，兵种装备归军事，金归商业，增益归科技。**装备厂从土木移入军事、农田从民生移入生产、粮食加工归生产 Lv2**（用户确认）。

## 三、各模块 Lv1-3 内容

### 3.1 土木建筑
| 等级 | 基础建筑（升级） | 特殊建筑（新解锁） |
|------|----------------|------------------|
| Lv1 | 城墙 / 城门 / 箭塔（基础防御） | — |
| Lv2 | 城墙→厚城墙 / 箭塔→强化箭塔 | **拒马阵**（城墙前障碍，阻挡+减速，被摧毁一次性）+ **弩塔**（射程更远、单体高伤，造价高） |
| Lv3 | 三级城墙 / 三级箭塔 | **魔法塔**（AOE 防御）+ 特殊防御工事 |

### 3.2 生产模块
| 等级 | 基础建筑（升级） | 特殊建筑（新解锁） |
|------|----------------|------------------|
| Lv1 | 伐木场 / 采石场 / 矿洞 / 农田 / 仓库（基础产能） | — |
| Lv2 | 二级产能建筑（效率↑） | **粮食加工坊**（粮→特殊食物，饱食恢复更多） |
| Lv3 | 三级产能建筑（效率↑↑） | **高级仓储**（容量↑ + 自动搬运直连国库） |

### 3.3 民生模块
| 等级 | 基础建筑（升级） | 特殊建筑（新解锁） |
|------|----------------|------------------|
| Lv1 | 粮仓 / 房屋（基础，一房容 N 人） | — |
| Lv2 | 二级粮仓 / 二级房屋 | **水井/喷泉**（饱食恢复辅助） |
| Lv3 | 三级粮仓 / 三级房屋 | **医院**（恢复 + 幸福）+ **教堂**（幸福） |

### 3.4 军事模块
| 等级 | 基础建筑（升级） | 特殊建筑（新解锁） |
|------|----------------|------------------|
| Lv1 | **练兵场**（训练战士/弓手）+ **装备厂**（产装备） | — |
| Lv2 | 二级练兵场 / 二级装备厂 | **投掷机厂**（全局唯一，绑定唯一投掷机，定向供弹药） |
| Lv3 | 三级练兵场 / 三级装备厂 | **卫戍营**（训练将军，限量 2 可配置；重装战士/弩手由装备驱动，不单独训练） |

### 3.5 商业模块
| 等级 | 基础建筑（升级） | 特殊建筑（新解锁） |
|------|----------------|------------------|
| Lv1 | 市场（粮↔金贸易） | — |
| Lv2 | 二级市场 | **商店**（商业建筑税来源） |
| Lv3 | 三级市场 | **金矿**（直接产金）+ 矿↔金贸易 |

### 3.6 科技模块（全面小增益）
| 等级 | 研究方向（每级全领域小幅提升，不单点强化） |
|------|------------------------------------------|
| Lv1 | 城墙 +5% / 弓手误差 -5% / 装备防御 +1 / 产能 +5% / 房屋容量 +1（各加一点） |
| Lv2 | 再叠 +5%（城墙 +10% 累计 / 误差 -10% / 装备 +2 / 产能 +10% / 房屋 +2） |
| Lv3 | 再叠 +5%（满级全面增益） |

> 用户原则：**科技不单点强化，整体增加、每个都加一点**。

## 四、饱食度系统

- 每个 NPC 个体有**饱食度**（0-100）
- **饿了就吃**：饱食度低 → NPC 到民生食堂/粮仓进食（消耗粮食）
- **搬运新工种**：搬运工运粮给军队（前线/防守单位补给）
- 规则：
  - 饱食度 0 → 持续扣血
  - 饱食度 80+ → 缓慢回血
  - 长期不满足 → 个体幸福度降低
- 工人/军人日耗粮不同（占位：工人 1/日、士兵 2/日、将军 3/日）

## 五、幸福度系统

- **平均分配**：幸福度计算到每个 NPC 个体，整体幸福 = 全体平均
- **多因素**：饱食满足 / 有房住 / 教堂 / 医院 / 税负（税高幸福低）
- **三层惩罚**（整体幸福低时）：
  1. 税收减少（幸福系数 × 税率）
  2. 人口增长减少
  3. 士气低（个体撤退阈值降低）

## 六、税收系统（金来源①）

- **人头税**：每人口每日 N 金
- **建筑税**：商业建筑（市场/商店/磨坊）按交易额或等级抽成（10%）
- **幸福系数**：整体幸福 × 税率（幸福 100% 全额收，幸福 0 收 0.5 倍）

## 七、贸易系统（金来源②）

- **商人**：市场建筑 NPC（市场 Lv 决定可交易资源档位）
- **资源等级**：1 粮食 / 2 石头 / 3 矿石 / 4 金币
- **不对称兑换损失**：20 粮 → 1 金；1 金 → 15 粮
- **梯度额度 + 长周期防刷**（用户决策，防"无限堆人口→税→换资源"）：

| 资源 | 每次额度 | 刷新周期 |
|------|---------|---------|
| 粮食 | 100 | 3 天 |
| 石头 | 50 | 4 天 |
| 矿石 | 20 | 5 天 |
| 金币 | 20 | 6 天 |

> 越高级资源额度越少、更新周期越长。额度用完等待刷新。

## 八、装备系统

- **装备驱动职业**：装备厂产装备（重甲/弩/武器），NPC 穿上 = 职业转变（战士+重甲=重装战士、弓手+弩=弩手），**不单独训练职业**
- **装备产业链**：兵种职业转变需要对应装备（军事模块内自洽，装备厂→练兵场）
- **编队不受影响**：编队按职能（Occupation）划分，装备是附加属性，换装备不改变职能、不退出编队
- 装备属性：防御加成 / 攻击加成（科技可强化）

## 九、科技系统

- **研究设施**：学院/工坊（科技模块基础建筑）
- **消耗**：金 + 研究时长（进度条）
- **研究等级 ≤ 主城等级**（主城 Lv1 只能研究 Lv1 科技）
- **效果**：全面小增益（§3.6 逐级）

## 十一、SO 解耦原则（用户硬性要求）

> **任何能影响游戏的数据都要解耦，用 SO 配置，减少硬编码。推广到所有设计。**

- 所有王国数值（税率/额度/周期/耗粮/饱食阈值/幸福系数/科技增益）→ SO 配置
- 模块等级表 / 建筑解锁表 / 装备条目 / 研究方向 → SO 资产
- 现有先例：AttentionTuningConfig / GridConfig / BuildingDef / FormationTable
- 专项 skill 固化此规范（后续单独做）
