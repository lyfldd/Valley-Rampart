## 一、核心循环（用户决策）

```
【废墟开局】废弃城堡在地图中央，开局资源只够修复（木100/石60/粮60/金30）
  ↓ 修复主城（Lv1 激活）→ 解锁基础建造（土木 Lv1）
【生存起步】工人采集（木/石）→ 伐木场/采石场 → 资源自循环（搬运已就绪）
  ↓ 农田产粮 → 粮养人口 → 饱食度系统
【经济发展】人口↑（房屋）→ 税收（人头+建筑税）→ 市场贸易（金）
  ↓ 主城 Lv2 → 模块 Lv2 解锁
【防御成型】城墙/箭塔/城门 → 拒马/弩塔 → 夜晚/波次防守
  ↓ 主城 Lv3 → 模块 Lv3 解锁
【军事扩张】练兵场/装备厂（装备驱动职业）→ 卫戍营（将军限量2）→ 编队（AI 已就绪）
【王国完整】主城满级 + 全模块满级 + 军力成型 + 抵御波次
【失败条件】主城或君主死亡 = GameOver（胜利暂不设）
```

- **昼夜循环**：1 天 = 3 分钟（白天经营 / 黄昏预警 / 夜晚防守），TimeManager 已有
- 饱食/幸福/税收/贸易/装备/科技全部挂昼夜结算

## 二、模块体系总览（架构核心）

### 2.1 模块树模型（2026-08-03 解耦改造：等级不限数量）

> **结构：主城（树根）→ 模块（6 棵独立树）→ 模块等级节点（不限数量）→ 建筑解锁。**
> 主城等级 = 模块节点的解锁门槛（每节点独立门槛，可跨级解锁）；模块等级 = 树节点数，**不写死三级**——"一级土木"可以有二级三级四级，随时加节点，不牵连其他模块/文档。资源存储下放建筑（仓库/粮仓/高级仓储），主城不内置国库。
> 解锁数据全进 SO（ModuleDef 资产，见 §十一 与 3.6_军事统一管理 解耦三原则）。

```csharp
// ModuleDef：模块定义（土木/生产/民生/军事/商业/科技）
public class ModuleDef : ScriptableObject {
    public string moduleId;                 // 模块标识
    public ModuleTierDef[] tiers;           // 等级节点树，不限数量（初始 3 节点，可扩展）
}

// ModuleTierDef：模块等级节点
public class ModuleTierDef {
    public int tier;                        // 等级（1/2/3/...）
    public int requiredCastleLevel;         // 主城解锁门槛（每节点独立，可跨级）
    public string[] upgradeBuildings;       // 该级可升级到的基础建筑（建筑等级 ≤ 节点级）
    public string[] unlockBuildings;        // 该级新解锁的特殊建筑
    public ModuleEffectDef effect;          // 该级效果（产能效率/防御等级/研究方向，全 SO）
}
```

**初始模块树（6 模块 × 3 节点示例，节点数可自由扩展）**：

| 主城等级 | 解锁内容 | 跨级解锁 |
|---------|---------|---------|
| Lv1（修复） | 土木Lv1（城墙/城门/箭塔）· 生产Lv1（伐木场/采石场/矿洞/农田/仓库/**训练所**）· 民生Lv1（粮仓/房屋）· 军事Lv1（练兵场/装备厂）· 商业Lv1（市场） | — |
| Lv2 | 生产Lv2（**粮食加工坊**/牧场/矿洞Lv2 水晶副产）· 民生Lv2（水井） | **科技Lv1**（学院/工坊） |
| Lv3 | 土木Lv2（拒马阵/弩塔）· 军事Lv2（魔法训练/新装备/投掷机厂）· 商业Lv2（商店） | — |
| Lv4 | 生产Lv3（**高级仓储**/矿洞Lv3 火油副产）· 民生Lv3（医院/教堂） | **科技Lv2** |
| Lv5 | 土木Lv3（魔法塔/三级城墙/三级箭塔）· 军事Lv3（卫戍营）· 商业Lv3（金矿） | — |

> 模块节奏差异化示例：生产 1/2/4 级、土木 1/3/5 级、科技 2/4/6 级（跨级）。"生产 Lv2 不等于主城 Lv2"由解锁表驱动。

**建筑解锁两条规则（2026-08-03 澄清）**：
- **可升级建筑**（基础建筑：伐木场/采石场/矿洞/农田/仓库/训练所/粮仓/房屋/城墙/箭塔/练兵场/装备厂/市场…）：升级 Lv2/Lv3 = 所属模块等级达标（建筑 ≤ 模块级）；升级自 Lv1 起自然链（Lv1 即前置，无需额外前置建筑）
- **特殊建筑**（仅一级：粮食加工坊/牧场/水井/医院/教堂/拒马阵/弩塔/魔法塔/投掷机厂/卫戍营/商店/金矿/高级仓储/学院…）：所属模块等级解锁**即可建造**，独立放空地，**无前置建筑**
- **无叠建**：建筑独立占 footprint，不建在矿洞/农田等已有建筑上，矿洞照常采矿
- **资源点 ≠ 地基**：地图资源点（矿脉/树）是采集物；建筑建在空地，仅校验地形（allowedTerrain），不占用资源点

### 2.2 六个模块与归属模型（责任一刀切）

| 模块 | 领域职责 | 基础建筑（可升级，≤模块级） | 特殊建筑（每级解锁，仅一级） |
|------|---------|---------------------------|---------------------------|
| **土木** | 防御工事 + 建筑等级上限 | 城墙 / 城门 / 箭塔 / 主城 | Lv2 拒马阵、弩塔；Lv3 魔法塔 |
| **生产** | 资源产出 + 加工 + 存储（全链条） | 伐木场 / 采石场 / 矿洞 / 农田 / 仓库 | Lv2 粮食加工（面包）；Lv3 高级仓储 |
| **民生** | 人口容量 + 饱食 + 幸福（消耗侧） | 粮仓 / 房屋 | Lv2 水井（农业供水）；Lv3 医院 / 教堂 |
| **军事** | 兵种 + 职业训练 + 将军（全链条） | 练兵场（战士/弓手） | Lv2 投掷机厂（全局唯一）；Lv3 卫戍营（将军） |
| **商业** | 金来源（税 + 贸易 + 税务所） | 市场（贸易） | Lv2 商店（建筑税）；Lv3 税务所 |
| **科技** | 跨模块全面小增益 | 研究设施（学院/工坊） | 每级解锁研究方向（全面增益） |

**归属原则**：产出类建筑归生产，消耗/生活类归民生，工事归土木，兵种装备归军事，金归商业，增益归科技。**装备厂从土木移入军事、农田从民生移入生产、粮食加工归生产 Lv2、训练所归生产 Lv1、牧场归生产 Lv2**（用户确认）。

## 四、饱食度系统

> 本节为**系统规则**；饱食作为 NPC **实体属性**的挂载/边界见 3.5.1 §五。

- 每个 NPC 个体有**饱食度**（0-100）
- **饿了就吃**：饱食度低 → NPC 到民生食堂/粮仓进食（消耗粮食）
- **搬运新工种**：搬运工运粮给军队（前线/防守单位补给）
- 规则：
  - 饱食度 0 → 持续扣血
  - 饱食度 80+ → 缓慢回血
  - 长期不满足 → 个体幸福度降低
- 工人/军人日耗粮不同（占位：工人 1/日、士兵 2/日、将军 3/日）
- **消耗顺序（2026-08-06）**：**自动降级**——先吃基础粮，基础粮耗尽 → 吃面包，再耗尽 → 吃肉（高档食物靠"产出多撑久"自然消耗，无需手动喂）。
- **粮食 UI（2026-08-06）**：资源栏**折叠成"粮食"大类**（含粮/肉/面包总量），点击/悬停展开三个子类（UI 大工程，实现时完成）。
- **食品等级**（2026-08-03 投入产出比重调）：
  - **粮**：饱食 +5（基础管饱，被削弱）
  - **面包**（粮食加工坊加工）：饱食 +8 + 幸福 +1（素食快加工）
  - **肉**：饱食 +20 + 幸福 +3（牧场，荤食高档食品，被增强）

## 五、幸福度系统

- **平均分配**：幸福度计算到每个 NPC 个体，整体幸福 = 全体平均
- **多因素**：饱食满足 / 有房住 / 教堂 / 医院 / 税负（税高幸福低）/ 食品品质（吃面包/肉 = 幸福加成）
- **三层惩罚**（整体幸福低时）：
  1. 税收减少（幸福系数 × 税率）
  2. 人口增长减少
  3. 士气低（个体撤退阈值降低）

## 六、税收系统（金来源①）

- **人头税**：每人口每日 N 金
- **建筑税**：商业建筑（市场/商店/磨坊）按交易额或等级抽成（10%）
- **幸福系数**：整体幸福 × 税率（幸福 100% 全额收，幸福 0 收 0.5 倍）

## 七、贸易系统（金来源②）

- **商人**：市场建筑 NPC（市场 Lv 决定可交易资源档位）
- **资源等级**：1 粮食 / 2 木材 / 3 石头 / 4 矿石 / 5 金币 / 6 水晶 / 7 火油（2026-08-03 扩展，木补入）
- **不对称兑换损失**：4 粮 → 1 金；1 金 → 3 粮（÷5 降数量级）
- **梯度额度 + 长周期防刷**（用户决策，防"无限堆人口→税→换资源"）：

| 资源 | 每次额度 | 刷新周期 |
|------|---------|---------|
| 粮食 | 20 | 3 天 |
| 木材 | 12 | 3 天 |
| 面包 | 6 | 4 天 |
| 石头 | 10 | 4 天 |
| 矿石 | 4 | 5 天 |
| 金币 | 4 | 6 天 |
| 水晶 | 2 | 6 天 |
| 火油 | 2 | 7 天 |

> 越高级资源额度越少、更新周期越长。额度用完等待刷新。

## 八、职业训练（装备已并入训练，2026-08-06 修订）

> **装备系统已全量移除**（详见 3.5.1_NPC实体循环与王国接入.md §一 决策 9/10）。原「装备驱动职业」改为**训练直接出职业**：训练成本内含原装备成本（适当降低，不直接相加），训练完成即完整职业能力。不再有装备厂 / 装备 / 装备面板 / 装备存档字段。

- **训练直接出职业**（不设装备）：
  - 练兵场：**战士 / 弓手**（Lv1）；**法师 / 治疗师**（Lv2）
  - 练兵场 **Lv2 直接训练** 原装备组合职业：**重装战士 / 盾卫 / 弩手 / 大法师 / 主教**
  - 卫戍营：**将军**（限量 2）+ **骑兵**
- **编队不受影响**：编队按职能（Occupation）划分，职业即能力，换装概念已取消。
- 原装备强化效果（防御/攻击）改为由**科技**全面增益覆盖（§3.6）。

## 九、科技系统

- **研究设施**：学院/工坊（科技模块基础建筑）
- **消耗**：金 + 研究时长（进度条）
- **研究等级 ≤ 主城等级**（主城 Lv1 只能研究 Lv1 科技）

```
金(税/贸易/金矿Lv3) ──→ 训练/装备/研究/贸易
```

### 13.5 人口系统（新增）

- **开局人口 10**：1 君主 + 4 工人（伐木场/采石场/农田/矿洞 各 1 自带）+ 5 无职业废人
- 人口增长 = **生育事件**：满足条件（整体幸福>60 且 平均饱食>50）时，每 2 人每 5 天 +1（无性别配对，人口/2=对数）
- 新生儿默认职业 = **无职业**（废人）：吃粮（1/日，同工人）但不干活，必须训练转职
- 转职链：无职业 →（训练所）工人/搬运工；（练兵场）战士/弓手；（练兵场 Lv2）法师/治疗师
- 生育压力 = 经营压力：人口涨→废人吃粮→必须训练或增产，形成"建房屋→有粮→人口涨→税多"循环的代价

### 13.10 养殖业（新增，第二条粮食来源）

> 定位：农田=基础产粮（管饱，粮+5），牧场=高级产粮（肉+20，屠宰制）。**肉属于粮食大类**。动物模型来自美术包 `Assets/_Game/Art/Medieval Kingdom`：chick/chicken、piggy/pig、calf/cow、rabbit（幼崽+成年双 prefab，支持生长阶段可视化）。

**全流程（屠宰制，一次性产出）**：
```
买幼崽（商人：兔4/鸡5/猪10/牛20金）
  ↓
牧场（生产 Lv2）投放动物（牧民 NPC 管理，玩家不实时盯）
  ↓
每日自动喂粮（牧民执行，每动物 1 粮）
  ↓
生长（兔2/鸡3/猪5/牛8天）→ 成年
  ↓
玩家点"宰杀"（牧民执行）
  ↓
一次性得肉（兔1/鸡2/猪3/牛5）
  ↓
肉 → 饱食+20 / 幸福+3 / 贸易（额度4/4天）
```

**动物表（美术资源确认）**：

| 动物 | 美术 prefab | 幼崽价 | 生长 | 产肉/次 | 投入产出比 |
|------|------------|-------|------|--------|-----------|
| 兔 | rabbit | 1 金 | 2 天 | 1 肉 | 2粮→1肉（快周转） |
| 鸡 | chick/chicken | 1 金 | 3 天 | 2 肉 | 3粮→2肉 |
| 猪 | piggy/pig | 2 金 | 5 天 | 3 肉 | 5粮→3肉 |

**规则细节**：
- **屠宰制**：动物成年后玩家选择"宰杀"得肉（一次性），宰杀后回收动物，需再买幼崽。无每日产肉、无自动繁殖
- 断粮：当日无粮 → 动物停止生长（成年期顺延），不死亡
- 牧场容量：动物总数上限 10（Lv1），升级扩容
- 玩家职责：买幼崽、选动物、点宰杀；牧民 NPC 负责喂养/管理/执行宰杀（逻辑归 3.0）
- 肉/特殊食物/粮饱食与幸福：粮+5 / 特殊食物+8·幸福+1 / 肉+20·幸福+3（2026-08-03 投入产出比重调）
- 牧场占位 2 格，isObstacle=false（§13.9）

### 13.14 数值平衡设计（2026-08-03 定稿，占位可调）

| 主城 | 消耗 | 目标天数 |
|------|------|---------|
| Lv1 修复 | 10/6/6/2 | 第 1 天 |
