## 二、拍板决策汇总（2026-08-03 用户确认）

| 决策点 | 结论 |
|---|---|
| 近战透墙 | 近战被墙/拒马挡，守城近战必须破墙或出城 |
| 拒马机制 | 城外我方阵地：我方自由进出 / 敌方减速 50% / 可摧毁（HP 100） |
| 出城/回撤 | 编队 AutoIntent + 决策因子加权（墙血量/敌距进核，权重训练） |
| 工事等级 | 四维完整：防御等级+HP+近战减免+塔攻，训练可调 |
| 混编定义 | **所有编队都能加新兵种**；混编=人数更多的编队 |
| 编队招募 | 自适应招募（场景可用士兵尽量编入） |
| 阵型选择 | 合法阵型列表 + AI 自选（权重训练） |
| 安全策略 | 保护者/被保护者矩阵参数化 + 训练 |
| 选阵容主体 | 将军 AI 自选 + 玩家可覆盖（E 面板） |
| 自主编队 | 无战斗时自主组队（热度低+无受击） |
| 编队重编 | 串联条件链（AND）：安全 ∧ 新兵种可用 ∧ 兵种平衡变化（防抖） |
| 城门 | 决策动态开门（Sally 开、回撤关） |
| 协同指标 | 骑兵撞飞数/重装承伤/盾卫保护率/远程输出占比进 SimMetrics |
| 冲锋落点 | 先 Unity 基础功能 → 再训练师训练 |
| 弹药占位 | **复用弓箭手箭矢美术资源**（arrow_21x11.png + arrow.prefab） |
| 单区块上限 | **是 bug**：士兵算居民 → 上限从未对我方生效；修复=UnitCategory 加 Soldier 类别 |
| 执行顺序 | 本蓝图审阅 → 按优先级实施 |

## 四、核心新设计摘要

### 4.1 编队构成与安全策略（G12/G13）
```
编队构成决策（训练目标）
输入：场景可用士兵（全兵种）+ 战术意图 + 敌方构成 + 保护关系矩阵
输出：① 招谁（构成比例）② 谁站哪（槽位）③ 选哪个阵型
```
- 兵种角色族：抗线（战士/重装/盾卫）/ 输出（弓手/弩手/法师）/ 辅助（治疗）/ 机动（骑兵）
- 保护矩阵 `protectMatrix[A][B]`（可训练权重）：盾卫→远程、重装→抗线、骑兵→冲阵
- 合法阵型列表（LookupAll）+ 阵型偏好权重，训练器选最优
- 玩家可覆盖（E 面板手动指定）

### 4.2 自主编队/补员（G11）
- 触发：编队不满员 + 附近热度低 + 无受击 10s（周期扫描 + 防抖）
- 战斗状态停止自主组队；重编=串联条件链（安全 ∧ 新兵种 ∧ 平衡变化）

### 4.3 出城迎战（G3，决策因子加权）
- FormationDecisionCore 加 `wallHpRatio` / `enemyClosestDist` 输入 + `Sally` 意图 + 回撤门限
- 可训练参数：sallyWallHpWeight / sallyEnemyDistWeight / sallyRetreatSurvivalGate / sallyRetreatDistGate
- 城门决策动态开关（Sally 开、回撤关）

### 4.4 单区块上限修复（G22）
- UnitCategory 加 `Soldier`（军事单位：士兵/骑兵/将军/机器）类别，配堆叠上限
- 农民/工人保持 Civilian（无上限）；敌方 Enemy 上限保留
- GetCategory() 改为按兵种/职业映射（不再纯阵营）

### 4.5 弹药占位（G14）
- 复用 `arrow_21x11.png` + `arrow.prefab` 作为弹药 Sprite 占位（箭/弩/石/火/魔各用色变）
