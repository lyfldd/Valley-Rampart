> 2026-07-27 阿铁拍板，主理人游承峰汇编
> 战斗系统太大，拆成 7 个子模块独立设计 + 独立实施

## 📝 设计决策确认（阿铁 2026-07-27 20:36 拍板）

| # | 决策 | 方案 |
|---|------|------|
| 1 | 敌人类型 | **双敌人系统**：怪物（晚上塔防）+ 王国军队（白天策略） |
| 2 | 外交系统 | **要**：四段好感（死敌/中立/友好/同盟）+ 3 动作（进贡/通商/协同清剿）+ 衰减 |
| 3 | 攻打王国 | **反向塔防**：你进攻敌方守，复用塔防建筑在敌方地盘建临时防线 |
| 4 | 王国军队 AI | **高复杂度**：多兵种战术配合（绕路/集火/兵种协同） |

---

## 一、双敌人系统（核心设定）

| 敌人 | 出没时间 | 性质 | 玩法 | 外交 |
|------|:--:|------|------|:--:|
| **裂隙怪物** | 晚上 | 无脑野兽/亡灵，从裂隙涌出 | 塔防（守城） | 无（不可交流） |
| **敌方王国军队** | 白天/特定事件 | 有 AI 的人类军队，多兵种战术 | 策略（攻城/远征） | 有（外交博弈） |

**为什么这么拆**：
- 晚上出怪合理（怪物夜行），是塔防核心循环（白天经营→晚上守城）
- 人类王国白天打仗合理（不会大半夜行军）
- 两套敌人不冲突，反而丰富玩法：白天防王国偷袭+经营，晚上防怪物围城
- 你之前的"裂隙刷怪"设定保留，"王国斗争"是上层玩法

## 二、战斗系统 7 个子模块

### 底层（其他模块依赖）

| # | 模块 | 负责 | 核心内容 |
|---|------|------|---------|
| 1 | **寻路系统** | 敌人/村民怎么走 | A* 或 Unity NavMesh2D；敌人从裂隙→主城的路径；壕沟/城墙绕路 |
| 2 | **伤害管线** | 统一伤害接口 | IDamageable 接口 + Projectile（箭矢/石头）+ 范围伤害（投石机）+ 伤害类型（物理/火焰） |

### 核心战斗

| # | 模块 | 负责 | 核心内容 |
|---|------|------|---------|
| 3 | **防御建筑** | 自动攻击逻辑 | 箭塔（单体+瞄准）/ 投石机（范围）/ 陷阱（触发式）/ 伏兵（隐藏）；BuildingData SO 驱动 |
| 4 | **敌人 AI** | 怪物 + 王国兵 | 怪物：无脑寻路冲主城；王国兵：多兵种战术（步兵/弓手/骑兵，绕路/集火/协同） |
| 5 | **波次系统** | 刷怪/入侵事件 | WaveData SO 配置；怪物波次（晚上裂隙刷）+ 王国入侵事件（白天，外交降到死敌触发） |

### 玩法层

| # | 模块 | 负责 | 核心内容 |
|---|------|------|---------|
| 6 | **外交系统** | 王国间博弈 | 四段好感 + 3 动作 + 衰减；好感影响王国入侵频率/援军；独立于战斗但联动波次 |
| 7 | **攻城玩法** | 远征反向塔防 | 造船→抵达敌方岛屿→建临时防线→击退反扑→推进主城→占领；复用 1-5 模块 |

**依赖关系**：
- **区块系统(0a)** 和 **注意力系统(0b)** 是最底层前置，跨系统通用（地图+战斗+经济都用）
- 移动+障碍处理(1) 依赖 区块系统(0a)——排队/堆叠
- 伤害管线(2) 独立（自带 Range + MaxHits 参数，命中数和范围解耦）
- 防御建筑(3) 依赖 伤害管线(2) + 区块系统(0a)——攻击命中从区块取目标
- 敌人 AI(4) 依赖 移动(1) + 伤害管线(2) + 注意力系统(0b)
- 波次系统(5) 依赖 敌人 AI(4)
- 外交系统(6) 独立，但和 波次系统(5) 的王国入侵事件联动
- 攻城玩法(7) 复用 0-5 全部模块
- **地图系统（未来）** 依赖 区块系统(0a)——大区块分小区块

## 四、实施顺序（拆分计划）

按依赖关系，从底层往上做。**不跳级**，每一层为上一层提供材料。

```
第0阶段：前置基础设施（最先做，跨系统通用）
  └─ 0a. 区块系统     ← 地图+战斗共同前置（堆叠/命中/排队）
  └─ 0b. 注意力系统   ← 跨模块决策中枢（仇恨/任务/威胁）

第1阶段：战斗底层（依赖第0阶段）
  └─ 1. 移动+障碍处理 ← 用区块（排队）；1D移动不用NavMesh
  └─ 2. 伤害管线      ← 自带 Range+MaxHits（范围和命中数解耦）

第2阶段：核心战斗（依赖第1阶段）
  └─ 3. 防御建筑      ← 用伤害管线+区块（攻击命中）
  └─ 4. 敌人 AI       ← 用移动+伤害+注意力
  └─ 5. 波次系统      ← 用敌人AI

第3阶段：玩法层（依赖第2阶段）
  └─ 6. 外交系统      ← 独立，但联动波次
  └─ 7. 攻城玩法      ← 复用全部
```

**实施节奏建议**：每个子模块 = 1 个独立文档 + 1 轮开发。不要一次性全做，做完一个验证一个再下一个。

> ⚠️ **当前进度**：第 0 阶段——区块系统设计已完成（`3.2_区块系统设计.md`）；注意力系统设计已完成（`3.0.1注意力机制与刺激源.md`），代码待实现。下一步进入第 1 阶段（移动+障碍 / 伤害管线）。

## 六、和现有系统的衔接

| 现有系统 | 和战斗的关系 |
|---------|-------------|
| **WorldSystem** | 难度系数（DifficultyManager）影响敌人血量/数量 |
| **TimeManager** | 季节变化影响难度；昼夜切换触发波次（晚上刷怪） |
| **RulerController** | 君主资源（金/石/木/粮）用于建造防御建筑；君主带队远征 |
| **UnitController** | 敌人/村民/王国兵都复用 Unit 底层（已有），挂不同 AI 脑子 |
| **SaveManager** | 波次进度/外交好感/建筑状态都要存档（ISaveable） |
| **EventBus** | BuildingPlacedEvent / BuildingDestroyedEvent / WaveCompletedEvent / FactionRelationChangedEvent 等 |
