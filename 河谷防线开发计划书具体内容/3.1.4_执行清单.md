## 实施修订（P0 落地时发现，已回写设计文档）

1. **工具目录 `tools/pixel-forge/` → 根级 `pixel-forge/`**：`.gitignore` L59 `Tools/` 在 Windows（core.ignorecase=true）下大小写不敏感匹配会吞掉 `tools/`，workspace 将无法 git 跟踪（违反 §3.1 持久化格子）
2. **编辑器↔工作区通信：File System Access API → serve.mjs 本地 API**：彻底消除浏览器兼容差异（§5.6 全浏览器全功能）、发布无需二次目录授权、AI 调用经服务端代理零 CORS 配置
3. **脚本依赖 pngjs → 零依赖纯 node**：PNG 编解码用 node 内建 zlib 手写（IHDR/IDAT/滤镜/Paeth/CRC32），兑现"零构建零依赖"承诺
4. **调色板 hex 扩展 8 位**：`#rrggbb`（不透明）/`#rrggbbaa`（半透明），AI 生图边缘可能有半透明像素，协议必须保真往返
