## 二、探针结论

### P1 ＝ 路径①在数据上无效

| 指标 | 读数 |
|---|---|
| 单扇区 tick | 787,941（52.4%） |
| 多扇区 tick（≥2） | 716,147（47.6%） |
| r1 影子选中 ≠ 全局最强（偏离） | 261,602（17.4%） |
| └ 偏离中·**单扇区** | **0（0.00%）** |
| └ 偏离中·多扇区 | 261,602（100.0%） |

⇒ 偏离（＝r1 改变选中源的时刻）**100% 在多扇区 tick**；路径①的作用面（单扇区回退）**本就不产生偏离** ⇒ **零覆盖**。附加：`r(多扇区%, 退化%) = 0.280`（弱正相关）⇒ 退化不可用"多向/单向"解释。

### P2 ＝ 「排序替代」结构性伤目标选择（D687 假说①证伪、假说②坐实）

| 象限 | 计数 | 占比（/偏离总数） |
|---|---|---|
| `nearWeak`（选中更近更弱） | 963 | 0.37% |
| `nearStrong`（更近更强） | 237 | 0.09% |
| `farWeak`（更远更弱·无理由劣化） | **260,395** | **99.53%** |
| `farStrong`（更远更强） | 7 | 0.003% |
| 合计 | 261,602 | 100% |

⇒ 偏离 **99.5% 是 `farWeak`**（系统偏向远弱源），平均**远 1.26~4.41 世界单位、弱 7.6~19.2 强度**，21 场景同向无例外。机理＝**扇区聚合分把「同向多源」合成为大数** ⇒ 某扇区只要源多（哪怕逐个更远更弱），聚合分即压过「单个最强近源」⇒ **「方向聚合作为威胁层排序替代」结构性改变任务选择、且单向劣化·非参数可救**。
