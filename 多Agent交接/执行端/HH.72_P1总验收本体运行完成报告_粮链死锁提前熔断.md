## 五、判定证据链（粮链死锁·不可自愈）

1. **粮产出恒零**：CSV 逐日粮账 D2~D10（40→4，每日 -6 耗，零入账）、D11 起 0 恒 18 日（D29 终）。
2. **金链对照存活**：金 +3/日恒定（D2=3→D29=67）——资源系统非全面死，独粮断。
3. **建造停摆不救粮**：D21 后建造焦点封顶 30 条、工人不再被工地占用，但粮仍 0——排除「建造占用劳动力」解释，实证**采集→国库粮流断裂是断链本体**（若链通，停建即回补）。
4. **⑥招工确定性死锁**：镜像 26 日招工零落地（招粮费 2 粮/人，粮 0 不可支付）→工恒 6/6/5。
5. **扩张门死锁**：developToExpand_workersMin=8（KingdomBrainConfig SO），工 6<8 永不满足→扩张期/军事期双门不可达；阶段机数据佐证（D3 后零升级）。
6. **不可自愈性**：粮 0 的唯一解锁=粮源恢复；AI 可用粮源仅 ⑥招工（需粮）/生产（断链）/贸易（镜像零贸易行为证据）——三路全断，死锁自封。
