## 一 · ⭐⭐ 判据 4（本批正解 ＝ 逐帧三项守恒 · `D834` §C-②）

### 实现（⛔ 不用产水速率、⛔ 不用水位净差）
逐帧（**非每秒** · 避免"同帧装载＋卸货"采样错位）记账：
```
Δ = Δ井仓水量 + Δ靶例农场仓水 + Δ(Σ背包中 carriedType==Water 的量)      ⇒ 应恒 ≥ 0
```
⭐ 鉴别力：产水只增；合法 `WaterHaul` 只让水在「井仓 → 背包 → 农场仓」间**转移** ⇒ 三项合计不变；**`Δ<0` ⇒ 水不在三者中 ⇒ 疑被写死国库的动作取走**。

### 读数（`·farm]` 逐帧列 ＋ summary）
```
⭐⭐守恒Δ负值帧=94（最负=-44）      ⇒ 表观「判红」
（诊断·非判据）井仓水量最低=20 ｜井仓 Δ<0 总帧=14（其中无承载=8）
```

### ⛔ 本端裁定：**该读数不可采信 ⇒ 判据 4 未达（仪表缺项 · 第二次同族错误）**

⚠️ **反证（硬）**：逐样本对拍「负值帧数 ↕ 井仓下降帧」——

| 样本 | 井仓下降帧 | 其中无承载 | 守恒负值帧 | 最负 |
|---|---|---|---|---|
| ① t≈1.28s | **0** | 0 | **2** | −12 |
| ② t≈2.35s | **0** | 0 | **5** | −28 |
| ③ t≈… | **1** | 0 | **9** | −44 |

⇒ ⭐ **负值帧数 2→5→9 增长时，`井仓下降帧` 恒为 0** ⇒ **负值并非来自井仓被取走** ⇒ 只能来自 **Δ农场仓／Δ背包**。
⭐ **缺项定性**：水**合法**流入的部位**不止靶例农场仓** —— `WaterHaul` 卸货目标是 `NearestWarehouse`（**任何收水仓/箱皆可**，⛔ 不必是本档 `farm`）⇒ 「背包减少而井/农不变」被本式记成**凭空减少** ⇒ ⭐ **假阳性**。
⛔ ⇒ **本端不把 94 帧当作"疑被旁路取走"证据**（否则即重复 `D833` §三 同族的**代理口径错**）。
⭐ **正解（下一批）**：守恒式改为**全库水账** ＝ `Σ(FindObjectsOfType<StorageComponent> 全量水) + Σ(全部 WorkerInventory 背包水) + 国库水位`，右侧加「**农场产粮耗水（2/次）**」项 ⇒ 即 `Δ全库水 = 产 − 耗` ⇒ 方可判绿/判红（本批**未落**）。
