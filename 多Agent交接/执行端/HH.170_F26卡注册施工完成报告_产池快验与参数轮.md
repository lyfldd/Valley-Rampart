## §六 参数轮（TD-001 ⑥：候选＝`perceptionUpdateInterval` 为主）

**方法**：`probe-k all 100 --card F26 --patch patches/F26_r{1,3}_perception_*.json`（champion 键值 0.20 为基线；patch 只覆写该键，**champion 零改动**）。

| 场景 | base (0.20) 切换/churn/响应率/背刺率 | **r1 (0.10)** | r2 (0.05) | r3 (0.40) |
|---|---|---|---|---|
| `_2_0` | 4296 / 1597 / 9.6% / 26.2% | **4051 / 1321 / 10.7% / 21.5%** | ≡ r1 | 4649 / 1913 / 10.3% / 25.5% |
| `_2_1` | 3774 / 1224 / 18.1% / 19.0% | **4574 / 1452 / 16.7% / 15.6%** | ≡ r1 | 3767 / 1256 / 17.3% / 22.7% |
| `_2_2` | 5310 / 3020 / 15.4% / 26.4% | **4992 / 2538 / 17.3% / 23.8%** | ≡ r1 | 5495 / 3212 / 15.7% / 27.5% |
| **聚合** | 13380 / 5841 / 14.3% / 23.9% | **13617(+1.8%) / 5311(−9.1%) / 15.2% / 20.3%(−15.0%)** | ≡ r1 | 13911(+4.0%) / 6381(+9.2%) / 14.3% / 25.2%(+5.7%) |

- **粒度量化发现**：**r2(0.05) ≡ r1(0.10) 逐字段全等** —— `SimWorld` tick `dt = damageTickInterval = 0.1s`（`harness/Sim/SimConfig.cs:28`）+ `SimBrain.UpdatePerception` 累加-比较-清零（`harness/Sim/SimBrain.cs:362-366`）⇒ **`interval ≤ 0.1` 一律每 tick 刷新（饱和）**。该键**有效域 = 感知周期 tick 数** {1,2,3,4,…}，属**粒度量化**（**非**「参数死」）。
- **条件 B 判定（TD-001 硬条件 B / 17手册 病5 三层诊断）**：触发式＝「**切换↑ 伴随 churn↑、响应率不升**」。**聚合面 r1 vs base** = 切换 **+1.8%（近平）** / churn **−9.1%（降）** / 响应率 **+0.9pp（升）** / 背刺率 **−15.0%（降）** ⇒ **触发式不成立 ⇒ 条件 B 未触发**（感知键**对冲成立**：核心指标同向改善且 churn 未膨胀），**不登记结构议题**、**不自行调参硬凑**。
- **如实列报（局部反向）**：`KF26_2_1` 单场景 r1 出现 **切换↑(+21%) + churn↑(+19%) + 响应率↓(−1.4pp)** 的负向组合（同场 win 0.26→0.69、背刺率 ↓3.4pp）⇒ 属**单场景行为重构**，未见「威胁按方向聚合缺失」的系统性证据 ⇒ **不构成结构议题**。
- **结论（参数轮收口）**：`perceptionUpdateInterval` = **F26 训练面上活性成立但弱**（有效域仅 1 档实调：0.20→0.10；更敏捷方向使 F26 核心指标同向改善：背刺率 −15.0% / churn −9.1% / 响应率 +0.9pp），**但跨套件门否决**（§七.5：总分 +0.001↑ 且 holdout 不退，却触发 **8 场景退化 >5%**，其中 `W9_T09_1`/`W9_T11_1` **−54.4%**、`KF28_2_0` −35.2% ⇒ 该键为**T09/T11/F28/F27 面**的敏感键，改动属跨卡交易）⇒ **候选 rejected、参数轮收口：本笔不改 champion**（champion 现值 0.20 维持；若后续要动该键，须按 T09/T11/F28 面另立评估，**不在 F26 卡内**）。
