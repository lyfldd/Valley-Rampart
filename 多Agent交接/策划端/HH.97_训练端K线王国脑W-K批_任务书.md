## 三、决策点 1 细化：王国就绪态构造器（阶段直落核心交付物）

### 3.1 KingdomStatePreset JSON schema

```json
{
  "kingdomId": 1,
  "raceId": 2,
  "name": "Frostpeak",
  "stage": "develop",                      // 直摆剧本阶段：settle|develop|expand|military（对齐 Unity ScriptStageMachine D318）
  "buildings": [                            // 建筑预置（defId+count+level；对齐 Unity BuildingDef id 逐字）
    {"defId": "Castle", "level": 2},
    {"defId": "Farm", "count": 3, "level": 1},
    {"defId": "Well", "count": 1}
  ],
  "resources": {"gold": 500, "stone": 200, "wood": 300, "food": 400},  // 国库账本
  "waterBucket": 100,                       // 水桶（决策点①轻量建模；井在场时供端自动维护）
  "population": {                           // 人口构成（决策点②三段链：Child 为一等实体）
    "worker": 12, "warrior": 4, "general": 1, "child": 2, "porter": 1, "resident": 2
  },
  "territory": {"radius": 5},               // 领土粗粒度（决策点2⑤）：以主城为心 r 格集合；或 "cells":[[x,y],...]
  "military": {                             // 军力预置（K8~K13 消费）
    "formations": [{"type": "Archer", "size": 6, "hasGeneral": true}]
  },
  "diplomacy": {"relations": {"2": -30, "3": 10}},  // pair 关系值（含跨族 D470 减成后的初值）
  "warmup": {"happiness": 80, "satiety": 80, "housing": 12},  // 底数 warm-up（L-08 硬条款：默认≥KingdomConfig 阈值）
  "crisis": null                            // 显式危机标记（K14）：{"type":"food_cut|well_destroyed|worker_loss|siege", ...}
}
```

### 3.2 一键落位 API 口径

- `SimKingdomFixture.Apply(world, preset)`：**唯一落位通道**（gen-kingdom 也产 preset 走此 API，禁绕过构造器直摆王国——单源纪律 L-06）。
- 确定性：落位固定序（建筑→资源→人口→领土→军力→外交→底数）；同 preset+seed 逐字节一致。
- **底数 warm-up 硬条款（L-08）**：`warmup` 字段缺省时自动按 KingdomConfig 阈值回填（幸福/饱食/房容≥阈值），防被训行为被门槛遮蔽误判「AI 不会判断」；`crisis` 非空时显式覆盖（危机注入=明面标记，不是靠删资源隐式制造——排雷 M11）。
- **资源注入三源断言（L-07）**：落位后断言「国库账本（resources）+仓储账本（建筑 storage）+水桶（waterBucket）」三源与 preset 声明一致，任一分叉=FAIL 落位（sim 侧对应 Unity KingdomState/Warehouse/WaterNetwork 三源建模时对齐）。
- **第一代人格（15_账本 #5）**：preset 未指定人格时按 MergeFirstGenPersonality 同公式生成（RaceDef 基准+模板偏离×0.5+±0.2 扰动，第一代不 clamp D474）——届时对拍 Unity 输出。

### 3.3 gen-kingdom 随机王国场景生成器

- 产 **KingdomStatePreset JSON**（多王国数组+地图+邻接拓扑+族别），再走 3.2 落位——**生成器只产 schema，落位归构造器**。
- 约束：族别四族覆盖（K15 随机族）；资源/人口/领土按档位分布（开局/中期/军事期三档，对齐 Unity PlaceMatureKingdom 同语义）；邻接拓扑随机（0~3 邻国）；同 seed 逐字节一致。
- 产物直写 `harness/Kings/king_scenarios/`（新目录，v9-K 分代见 §七）。

## 六、决策点 5 细化：K15 复合分公式（定死，勿自改）

```
CompositeScore = 0.25×MilitaryReached + 0.25×Survived + 0.25×EconomicHealth + 0.25×ExpansionScore

MilitaryReached = 1 若剧本阶段达军事（对齐 Unity「→军事」判定语义）否则 0
Survived        = 1 若局终王国存活（worker+warrior>0）否则 0
EconomicHealth  = clamp(1 − DroughtDays/TotalDays, 0, 1)   // DroughtDays=任一资源连续断供日数累计
ExpansionScore  = clamp(TerritoryGain/TargetTerritory, 0, 1)  // TargetTerritory=档位期望值（gen-kingdom 声明）
```
