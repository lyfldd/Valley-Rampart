## 一、任务缘起（用户指定典型案例——本审查的问题原型）

2026-09-02 发现：D415「种族=国家属性」（2_20）在国家层定义种族，未覆盖**个体层**；而 2_16 D433 动态建国（流民插旗定国族）、2_19 D389 印记生命周期均在个体层消费该概念 →「四族混合营地怎么建国」无口径 → 用户三轮拍板 D467~D472（种族=人口属性+野性敌意+同族锁定，0.6 §四十七）修复。

**缺陷类抽象：概念定义域 ≠ 引用域**——概念在语境 A 定义（如国家层），被语境 B 引用（如个体层/跨系统/跨时间点），定义未覆盖 B 时产生设计缺口，下游实施后即成 bug。

同缺陷类**已兑现代码实锤**（审查灵敏度标定样本，不重开只作对照）：
1. **IPathGrid 坐标域错位**：接口契约=微格坐标，隐式实现按宏格查表——微格域 1024² 超宏格域 256²，sub≥256 全越界 → A* 全图不可达（divisor=4 长期潜伏，HH.47 寻路1 修复）。
2. **撤退半径跨层语义**：sim retreatRadiusStrategic=5 vs 运行时 baseRetreatCells=6——数值相近语义存疑、跨层误改风险（缺陷台账 R3 已挂账，只更新不重开）。

## 三、方法与种子概念清单

方法：**定义域 × 引用域矩阵**——对每个核心概念：
1. 定义位置（权威文档 §节 + 定义覆盖的语境边界）
2. 引用位置（哪些文档/机制消费，触及已落代码的标注「触及已落代码：是/否」）
3. 引用语境是否落在定义域内 → 缺口归类（**域缺口 / 语义漂移 / 生命周期断层 / 跨层语义错位** 四型）
4. 影响面（哪些机制可能出 bug / 已出）+ 级别（🔴概念冲突已致语义矛盾 / 🟡引用域超定义域未定口径 / 🟢定义完备仅表述含糊）+ 修订建议方向

## 四、纪律（违者退回）

1. **只审查不修订不裁断**：报告=缺陷清单；改不改、怎么改归策划端裁决（三级修订制 L1/L2/L3 分流）；触及已落代码的发现**只标注不生成工作单**（分流归策划端，vr-triage-flow §七）。
2. **锚点**：2026-09-02 磁盘态（D467~D472 修订已落档未提交——审查以磁盘为准，报告头部声明锚点+核查时间点）。
3. **并发文件纪律**（agent-handoff §六 全端红线）：只写报告新文件 + 两处登记行；禁整文件覆盖任何共享文档；改前必重读。
4. **搜索工具陷阱**：gitignore 路径（训练仓 `ai决策大脑强化训练/`、CODELY.md 等）搜索**静默零命中**——凡「未登记/不存在」结论涉及被 ignore 路径，必须 read_file 直读复核后才可定论。
5. 成文前查 `河谷防线开发计划书具体内容/缺陷台账.md` 去重：已登记缺陷（如 R3 撤退半径）只更新不重开。
6. 判断类发现不与执行端交付报告混流：本审查与执行端（TraeCode）会话并行时，互不等待、互不改对方产物。
