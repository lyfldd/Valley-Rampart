## §四 坑位级施工详规（3 处最易翻车点）

1. **构造器落位断言链（T5）**：落位序=建筑→资源→水桶→人口→领土→军力→外交→底数 warm-up→crisis 覆盖（末位，覆盖后重断言）；每步断言失败=整体 FAIL 不落半态（防「半落位王国」污染场景）；三源断言=国库 resources+建筑 storage+waterBucket 对 preset 声明逐字段相等。
2. **BattleEvaluator 边界（T13）**：seed 派生=王国层 seed XOR 战役序号（确定性+多评估不重局）；armyA/armyB 转战斗 sim 单位时**走 professions.json 单源注册**（L-06：禁散写直构职业）；王国层因素（援军到达/国内生产）由外层结算后二次注入，不进首局战斗 sim。
3. **K 卡 README 骨架模板（T10/T15/T18）**：六节=目标（一句话）/就绪态（preset JSON 要点）/训练什么（关键因子域+registry 草案引用）/指标（含时间成本项+L-10 收益路径行）/配套场景（≥3+生成命令）/验收（达标线+回放抽查条款）；落 cards/K{N}/README.md，decisions/ 台账照 AGENTS 0.7。
