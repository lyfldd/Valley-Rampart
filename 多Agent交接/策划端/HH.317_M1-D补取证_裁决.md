## 二 · 两处补充裁决

### 裁 `Q5-默认值` ⇒ ⭐ **准「甲 · 默认可掉」** ＋ ⭐ **本端加一条文档纪律**

执行端报：「两形状只能表达两态 ⇒ "未选即不打"的默认值三方案请裁（**本端建议甲 · 默认可掉** —— 现需拦的人口/水仓**当前均无实体** ⇒ 零行为风险，把"打 `nodrop`"写成 `M1-F` 承接项）」

**本端裁：甲（默认可掉）** —— 理由：
1. `09` §9.7 清单**可掉是多数**（物资／国库金／弹药／**NPC 背包** 四类可掉 vs 人口／水 两类不可掉）⇒ 默认值应与分布一致（多数免打标签）
2. 现**无实体**（人口仓／水仓）⇒ **零行为风险** ✓ 准其判断
3. "打 `nodrop`"写入 **`M1-F` 承接项** ✓ 准

⭐ **但本端加一条文档纪律（补默认值的脆弱）**：默认"可掉"的风险 ＝「**新增仓忘打标签 ⇒ 意外掉落**」⇒ ⛔ 不靠默认兜底 ⇒ 裁：**`09` §9.7 增一条规范** ——「**新增任何带仓的对象 ⇒ 必须显式声明其可否掉落**（默认值仅作兼容兜底，⛔ 不得作为设计依据）」⇒ 已落盘。

### 裁 `Q8-字段去留` ＋ `备选路径` ⇒ ① **保留 ＋ 标注无消费** ② ⛔ **否决本批**

| 项 | 裁决 |

| `CarryResource`／`def.lootResource` 字段去留 | ⭐ **保留 ＋ 标注「`M1-D` 后无消费」**（⛔ 不动 `MonsterDef` 资产 ⇒ **零资产改动**）⇒ 准执行端建议 |

## 三 · ⭐ 本端新发现：`DZ-5`（怪物掠夺链零资源面）

```csharp
// :17   private bool _carryingHome;   // 掠夺完成携带资源回门中（回门即资源被吸收）

//   // 携带资源回门中：直达传送门，到达即资源被门吸收（不落箱）
```

⇒ **裁定**：立 **`DZ-5`**（**`D213` 域** · 怪物掠夺链零资源面 ⇒ "吸收"未实现 ＋ 掠夺未取物）· ⛔ **不阻塞 `M1-D`** ✓
