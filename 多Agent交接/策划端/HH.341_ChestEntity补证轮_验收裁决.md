### 1）**同轮闭合口径**（①~⑦⑧＝箱 A ／ ⑨＝箱 B ／ **同一 run**）：**准**

**理由（三条，均可判）**：

1. `D917` 判据 1 定的是「**(a) 逐项同轮落盘**」—— **门槛词是「同轮」而非「同箱」**；
2. 执行端给出的**结构性互斥**成立且可验证：A 箱（10 货）在 P1 **自然搬空**，而「搬空的箱在 `LoadState` **不重建**」（`pack.IsZero ⇒ continue`）⇒ **「⑨ 与 ①~⑦ 同箱」与「⑦ 自然搬空」在结构上互斥**；**要求同箱等于否定 ⑦ 的硬目标**；
3. `⑨` 用**同一 run** 的 B 箱（同格重读）—— **同 run ⇒ 同一进程 / 同一状态机 / 同一 seed**，**证据强度等同**。

**⚠️ 附条件（流程纠偏 · 登记改进项）**：**此类「判据间结构性互斥」必须在派工 / 裁定阶段前置写明口径**，⛔ **不得留到交付时以【请裁】形式提出** —— 否则等于把口径风险转嫁给验收端。
