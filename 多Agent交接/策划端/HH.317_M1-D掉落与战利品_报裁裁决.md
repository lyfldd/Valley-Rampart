## 四 · 对执行端表述的勘正（`Q3`）—— 「毁」**有**实际发生面

**执行端报**：「`§9.6` 说『毁（`Die`）掉箱』，实盘普通建筑被打爆走 `EnterRuined`（不销毁、仓留存）—— 按契约字面施工则**"毁掉箱"永不发生**」

⚠️ **本端实读推翻**（`Building.cs:1180-1191`）：
```csharp
public void TakeDamage(int amount)
{
    if (state != BuildingState.Active) return;
    hp = Mathf.Max(0, hp - amount);
    if (hp <= 0)
    {
        if (IsFortification) Die(DeathCause.Killed);   // ⭐ 工事被破直接销毁（D165，无废墟）
        else                 EnterRuined();             // 策略建筑/主城被破 → 废墟可修（D154/D163）
    }
}
```
＋ `IsFortification`（`:1171-1173`）＝ `Wall`／`isGate`／`isBridge`／`Defense 且非 CastleCore`

⇒ ⭐ **"毁"的实际发生面 ＝ 工事**（城墙／城门／桥／防御塔）⇒ ⛔ **不是"永不发生"**。
⇒ 准确表述：**非工事**建筑被打爆走 `EnterRuined`（不销毁 ⇒ 仓留存**是设计合理的**，废墟可修）；**工事**走 `Die`。

⇒ ⭐ 本端据此裁 `#49` 的处置面（见 `Q3` 裁决）—— 这条勘正**直接决定了 `#49` 的边界**。

## 五 · `Q1`~`Q9` 裁决

### `Q1` `Killer` 链是否入本批 ⇒ ⭐ **入本批**（⛔ 不打通则 `#58` 改了个寂寞）· 形态优先**甲**

**致死判定语义**（报告问的）⇒ ⭐ 裁 **「致死一击的施加者」**：
- 依据：用户原话「就是**被兽人结束生命周期**的」⇒ 语义 ＝ "谁结束的" ＝ **最后一次成功伤害的 `source`**
- ⛔ 备选"最后攻击者／主攻"需额外记账 ⇒ **本批不做**（YAGNI）
- ⛔ `Demolished`（玩家拆除）**不参与**（⇒ `Killer=null` ⇒ 战利品不触发）

**施工方案两案**：

| 案 | 形态 | 正确性 | 代价 | 副作用 |
|---|---|---|---|---|
| ⭐ **甲**（优先） | `IDamageable.TakeDamage(int, IDamageable source = null)` ⇒ `Die()` 携带 ⇒ 事件填真值 | ⭐ **最高**（一次到位 · `Killer` 从"误导字段"变"真值" · 战利品＋`D490` 同批复活） | ⚠️ `IDamageable` 实现者 ＋ `TakeDamage` 全库调用点 ⇒ **须报调用面** | ⚠️ 额外落点：`DamageSystem:406 shield.TakeDamage(…)` 须传**原 `source`**（⛔ 不是 `victim`） |
| 丁（备选） | `DamageSystem` 维护 `_lastKiller` 表（`:412` 后记录 ⇒ `OnUnitDied` 查表） | 中（不动签名） | 小 | ⚠️ `UnitDiedEvent.Killer` **永久为空** ⇒ 须同时裁字段去留（否则留误导字段） |

⇒ ⭐ **本端裁：阈值判据 ＝ `TakeDamage` 全库调用点 ≤ 20 ⇒ 走甲；> 20 ⇒ 走丁**（先报调用面再定）。
⇒ ⛔ **否决**任何"双事件"或"静态回填"形态（丑 ＋ 易错）。
⇒ ⚠️ **含是否同修 `D490`**：⭐ **同批**（`BerserkerFrenzy` 读同一字段 ⇒ 甲案下一并复活 · 零额外成本）。
