### 3.4 「删」（`03` §七）

| 结论 | 指针 |
|---|---|
| ⭐ **删不是增的镜像，是逆序**（栈式：**谁后加的先拆**） | `03` §7.1 |
| 本层删的**不是"那个东西"，是"本层赋予它的那几样"**（位置/占格/登记/锚点/重生资格） | `03` §7.2 |
| **入口**：`Remove(什么, 在哪/哪个 id)` —— **唯一、不区分死因**；七步：存在性 → 锚点返还 → 清表 → 释放占格 → 注销 → 出重生池 → 广播 | `03` §7.3 |
| **校验对偶**：增＝位置**空闲**；删＝**它确实在**（不通过 ⇒ **幂等跳过**） | `03` §7.4 |
| **本层不判"能不能删"**（业务归高级层／数据栏） | `03` §7.5 |
| **高级层自订广播**收尾（回池/摘编队/清任务/结算/死因统计/拆除产物） | `03` §7.6 |
| **特例落法**：**加栏**（静态）＋**钩子**（动态），**主干不绕开** | `03` §7.7 |
