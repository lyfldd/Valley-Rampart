## 〇、一句话

> **下层给材料，上层自己拼。下层不认识"玩法"，它只认识"事实"。**

⚠️ **先看这个数**：当前 **62 个文件、331 处**直接引用地图层（`GridSystem`／`MapData`／`ActiveMap`）。
⇒ **契约一动，62 个文件受影响** ⇒ 所以**接口先写清，再动手**。

## 一、边界：下层管什么、不管什么

| | **下层（地图层）** | **上层（系统层）** |
|---|---|---|
| 管 | **"这里有什么"的存在** | 实体、功能、引用、AI、编队、结算 |
| 存 | 气候 · 地表 · 资源点 · 建筑占格 · 单位标记 · 可走 · 归属 | 建筑属性（HP/等级/生产/工人）· 单位属性（HP/AI/背包）· 国库 · 时间 |

⇒ 一句话判据：**「位置」是不是这个东西的身份？** 是 ⇒ 下层；不是 ⇒ 上层。

## 二、你能拿到什么（读 · 五个件）

| # | 件 | 你能问什么 | 返回 |
|---|---|---|---|
| ① | **格子属性** | 这格**是什么**（地表／气候／可走／归属／坑位） | 复合结构 |
| ② | **格子上的存在** | 这格上**有什么**（建筑／单位／资源点） | 复合结构 |
| ③ | ⭐ **区域枚举** | 这**一片**里有哪些（带条件，可只要一个） | 按格 ／ 按实体 |
| ④ | **换算** | 世界 ↔ 格 ↔ 小格子 | 纯值 |
| ⑤ | **变更订阅** | 这里**变了**通知我 | 事件 |

### ③ 的三个旋钮

```
区域枚举 ＝ { 范围 ＋ 条件 ＋ 数量（全部／一个／N） }
范围：矩形（窗口·扫描片）｜半径（视野·爆炸）
```

**条件 ＝ 选择器**（只有下层知道的事实能当条件）：

| 类 | 能勾的 | 限定参数 |
|---|---|---|
| 地表 | 平地／树／山／雪山／河／海／海岸／矿 | 具体类型 |
| 气候 | 温度带 | 热／亚热／温／寒 |
| 可走 | 能／不能 | — |
| 建筑 | 有／无 | 类型 · 阵营 · 归属 |
| 单位 | 有／无 | **阵营** · 分类 |
| 资源点 | 有／无 | 类型 · 等级 · 可否重生 |
| 归属 | 属于谁 | 王国 id（无主 ＝ -1） |
| 坑位 | 还剩几个空坑 | 数值比较 |
| ⭐ 邻接 | 周围有没有 X | 目标事实 |
| ⭐ 距离 | 离某点多远／最近的是谁 | 参照点 |
| ⭐ 计数 | 这片里有几个 X（只要数） | 目标事实 |

⚠️ **后三类是"算出来的"（派生量）**，只可查，**不在格表里**。

⛔ **禁止**把上层词塞进条件（"敌人／威胁／值钱"）。**上层自己翻译**：敌人 ＝ **有单位 ∧ 阵营 ≠ 我**。

## 三、你能改什么（写 · 四个门）

| 门 | 做什么 | 说明 |
|---|---|---|
| **Place** | 加东西（资源点／建筑／单位） | 门内七步完整：校验→锚点→写表→占格→登记→实体→重生池 |
| **Remove** | 抹掉 | **唯一入口·不区分死因**（拆／打烂／采走一视同仁） |
| **Replace** | 换一个（A → B） | 封装的"先删后增"，**对外只发一条 `Replaced`** |
| **Set** | 字段覆写 | ⚠️ **只有两个字段可改**：**归属** · **地表** |

---

## 四、你能订什么（广播）

| 广播 | 何时 | 你要做什么 |
|---|---|---|
| `Added` | 有东西进来 | 建实体／登记业务索引 |
| `Removed` | 东西没了 | 回池／摘编队／清任务／清仓库／结算 |
| `Replaced` | 换了一个 | ⭐ **自己决定"换皮（保留实体）"还是"重建"** —— 不是拆一建一 |
| 状态变化 | 格子属性变了 | 需要的话刷新自己的缓存 |

⇒ **下层只宣布"发生了什么"，不替你做决定。**

## 五、常见拼法（照抄就行）

| 上层想要 | 用哪些件拼 |
|---|---|
| 寻路 · 能不能走 | **①**（读"可走"） |
| 寻路 · **窗口内敌人** | **③** 范围＝视野，条件＝有单位 ∧ 阵营≠我 |
| 找建造点 | **③** 条件＝空格 ∧ 可建 ＋ **①** 属性 |
| 找资源点 | **③** 条件＝有资源点 ∧ 类型 |
| 范围伤害 | **③** 条件＝有单位（半径） |
| 渲染刷新 | **③** 范围＝视口 |
| 领土推进 | **①** 归属 ＋ **Set** |
| 工人派工 | **③** 找目标 ＋ **⑤** 订变更 |
| 存档 | ？ （见 §八 待议） |
| ⭐ **升级 / 换属性** | **不用下层** —— 对象自己的事（本层零操作） |

## 六、纪律（五条「不许」）

| # | 不许 |
|---|---|
| 1 | ⛔ **直接摸底层数组**（`map.features[]` 等）—— 必须走件 |
| 2 | ⛔ **自己算可走** —— 可走是**派生缓存**，读 ① 即可 |
| 3 | ⛔ **把上层概念当条件**（敌人／威胁／价值）—— 自己翻译成事实组合 |
| 4 | ⛔ **要求下层加"某某系统专用接口"** —— 用现有件拼；拼不出来 ⇒ 说明**该补"件"**，不是补"需求接口" |
| 5 | ⛔ **属性变化／升级走下层** —— 归对象自己 |

## 八、你想加东西时怎么办

| 你想加 | 正确做法 |
|---|---|
| 一个新**条件**（下层认得的新事实，如"有火"） | ⇒ **在下层加"菜单项"**（不动老查询） |
| 一个新**玩法**（如"找最近的仓库"） | ⇒ **用现有件拼**（③ ＋ 条件）—— 下层**一个字不改** |
| 一个新**上层系统** | ⇒ 先读本文，再读 `03`（照件写，不加接口） |

⭐ **这是一套解耦的工具箱** ⇒ **随时可增补缺失的底层工具**，增补**不破坏已有用法**。

## 九、配合好了怎么验（判据）

1. **无裸读**：全库 grep ⇒ 除下层自身，**无任何文件直接读**地图底层数组
2. ⭐ **不涨接口**：任取一条上层新需求 ⇒ **能用五个件拼出来**（拼不出 ⇒ 补"件"）
3. **条件干净**：所有查询条件**只用事实菜单里的项**
4. **只读安全**：上层**拿不到可写引用**
5. **拾取同源**：点最靠前的建筑 ⇒ 命中**渲染上最靠前的那个**（y 序一致）
6. **替换是一次**：一次替换 ⇒ 只收到**一条** `Replaced`
