## 一、边界：L4 管什么、不管什么

| | **L4（系统层）** | **上层** |
|---|---|---|
| **管** | ⭐ **王国的状态**（人口・幸福・饱食・资源・领土・关系・等级）＋ ⭐ **日界的时机** | **决策**（AI · 训练轨）／**呈现**（渲染・UI） |
| **存** | 王国实体状态（`KingdomState`）／账本（`09`）／领土账本（`16`）／关系值（`14`） | 想怎么打、怎么发展（AI）／画面（表现） |
| **⛔ 不管** | 基础设施（单位／时间／难度／存档／加载 ⇒ ⭐ **见 `_索引` §2.7**）／⛔ 表现／⛔ **AI 决策大脑本体**（归训练轨 `ai决策大脑强化训练/`） | — |

⇒ ⭐ **交界一句话**：**L4 是"王国处于什么状态"，上层是"拿这个状态做什么"。**

| 你想知道 | 读谁（接口） | 归属 |

| **人民过得好吗** | `GetKingdomHappiness(kid)`／`GetAverageSatiety(kid)`／`GetTaxCoefficient(kid)`／`GetPopulationGrowthFactor(kid)` | `11` §3.2 |
| **有多少资源** | ⭐ **`09` 账本**（**按前缀子树汇总**查王国总量）／`KingdomState.resources`（**AI 台账**）／`TreasureVault`（玩家国库仓） | `09` |
| **我的地盘多大** | `TerritorySystem`：`GetKingdomTerritory(id)`／`IsTerritory(mid,kid)`／`KingdomCellCount(id)`／`NonInitialTerritoryCount(id)` | `16` |
| **四周有谁** | `GetAdjacentKingdoms(id)`／`AreKingdomsAdjacent(a,b)` ＋ ⭐ **`GetIntruders(id)`（待新增）** | `16` §3.7 |
| **跟邻国关系如何** | 关系值（四分量＋六态）—— ⛔ **未实施**（代码 0%） | `14` |
| **建筑能建了吗** | `CastleUnlockTable.GetModuleLevel(module, castleLevel)`／`KingdomManager.IsBuildingUnlocked(def)`／`CanUpgradeBuilding(b)` | `15`／`10` |
| **这栋建筑有什么功能** | ⭐ **`10` 的 29 栋登记表**（能力 ＋ 参数）—— 任一建筑**能列出能力清单** | `10` §十 |
| **资源怎么流转／仓怎么算** | `09` §五（仓库＝标签＋容量）／§六（账本）／§七（CRUD＋转移） | `09` |
| **现在第几天／什么季** | `TimeManager`（`CurrentDay`／`CurrentSeason`／…） | ⭐ 基础设施（`_索引` §2.7） |

## 三、你能做什么（**动作**）

| 你想做 | 走谁 | 归属 |
|---|---|---|
| **派活给 NPC** | `06` 委托（⭐ L4 的委托清单见 `06` §2.1） | `06` |
| **建／拆／升级／修复** | ⭐ **四个动作全走仓**（投料 ⇒ 等时间 ⇒ 完成）—— `09` §十六 ＋ `08` | `09`／`08` |
| **收税／贸易／日结** | ⛔ **这不是"做什么"，是"何时跑"** —— 由 `12` 定时驱动（⛔ 上层**不手动调**） | `12` |
| **打仗／宣战／送礼** | `14`（⛔ 未实施） | `14` |
| **扩张领土** | `TerritorySystem.ExpandTick`（**AI 日 tick 自动跑**）；玩家建造纳土 `ClaimFootprintChunk` | `16` |
| **立国／灭亡** | ⛔ **不是上层动作** —— 立国由营地插旗（`CampUpgrader` 五条件）、灭亡由**验尸**（`15`）自动触发 | `15` |

⚠️ **通例**：⭐ **上层只能"通过动作影响状态"，⛔ 不能直接写 L4 的字段**（见 §五 纪律 3）。

## 五、纪律（**五条「不许」**）

| # | 不许 |
|---|---|
| **1** | ⛔ **不自己重算系统层的数** —— 幸福／饱食／人口／领土**都有读口** ⇒ 禁自建副本（防双真源漂移） |
| **2** | ⛔ **不绕过 `09` 账本直接改资源** —— 读写口**全走 CRUD**（`09` 定「**扣费统一一个 API**」） |
| **3** | ⛔ **不直接写 L4 的状态** —— 上层只能**通过动作影响**（如"派搬运"⇒ 资源变），⛔ 不能写字段 |
| **4** | ⛔ **不依赖隐式订阅顺序**（`12` 规则 A′） |
| **5** | ⛔ **不把玩法逻辑塞进表现层** —— 表现**只读**（`_索引` §2.7「表现」行） |
