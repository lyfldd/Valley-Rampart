## 〇、本契约是什么 / 不是什么

**是什么**：L4 系统层规则中，**凡其消费者是玩家侧**（玩家可见的读数呈现、UI、手动操作入口）的部分 —— 在此登记**适配条目**（来源｜源行号｜消费者｜适配内容）。

**不是什么**：
- ⛔ **不搬运系统层正文**（幸福／饱食／人口…的规则留在 `11`~`16`）；
- ⛔ 不是表现／音频契约（归 `03_玩家分支/表现与音频契约.md`）；
- ⛔ 不是美术资源与表现契约（归 `03_玩家分支/表现与资源接入/美术资源与表现契约.md`）；
- ⛔ 不改代码、不接线、不订数值。

## 二、逐条适配

### 2.1 `B1` 生育读数 → UI 呈现【PLAYER】

- **来源**：`11 §3.2` L320 —— `birthRateMax`／`birthRateMin`（**新** · 实时上下界读数）消费方 ＝ **UI 显示** ＋ 未来 AI 决策。
- **适配内容**：玩家侧须提供该对读数的**实时呈现**（源 §1.3.1 说明其采用**惰性重算（脏标记）** ⇒ **谁读谁触发重算** ⇒ UI 一读即为最新；⛔ 不需每帧算）。
- **对偶**：AI 侧同一读数见 `04_王国AI分支/王国系统适配契约.md §2.3`（**同源不同消费**）。

### 2.2 `B2` 幸福读数 → 玩家可见面【PLAYER】

- **来源**：`11 §3.2` L313 —— `GetKingdomHappiness(kid)`（＝ `OverallHappiness`）消费方含 **UI**（另含 `12` 税收系数、L3 决策）。
- **适配内容**：玩家侧呈现王国幸福读数（及其影响：税率系数）；⛔ **规则**（怎么算）在 `11 §1.1.1`。
- **备注**：⭐ **唯一对外出口**（源 L41）⇒ UI 应读**同一出口**，⛔ 不自算第二套。

### 2.3 `B3` 士气读数 → 情报面板【PLAYER】

- **来源**：`11 §3.2` L316 —— `GetRetreatThresholdModifier(kid)` 现状消费方 ＝ **仅探针 ＋ UI**（`KingdomIntelPanel`）。
- **适配内容**：玩家侧情报面板呈现士气／撤退阈值读数。
- ⚠️ **【取证】现状**：该出口**从未接入玩法**（`11#18`）；**AI 消费面**见 AI 契约 §2.4。⛔ 本契约只登记**玩家可见面**。

## 二之二、逐条适配（批次 B9-B · 源 `12_日结算与经济编排.md`）

> ⛔ 只登记**玩家侧消费面**；⛔ **不复制 `12` 正文**。

### 1. `B4` 贸易的玩家手动面（`12 §0.2.2` 功能 4）

- `12` 实读：`TradeSystem` **只有 `SellToGold`／`BuyWithGold`（玩家手动）**；规则（档位随市场等级／不对称兑换／梯度额度防刷）**留 `12`**。
- **玩家侧适配** ＝ 贸易**手动操作入口**（买卖交互）＋ 额度可见性。
- ⚠️ 另注：**AI↔AI 贸易已裁「不做」**（`12`）；⛔ 本条不涉 AI。

### 2. `B5` 日结算 UI 订阅者（`12 §0.3 规则 A′`）

- `12` 实读：`TimeDayChangedEvent` 有 **6 个订阅者**，其中 **3 个是 UI**（`ResourceHUD`／`PopulationPanel`／`TopLeftHUD`）。
- **玩家侧适配** ＝ 日界刷新**玩家可见读数**；⚠️ 三者与 `DayCycleSettlement` 的**相对顺序无契约**（`12` 规则 A′ 要求**显式定序**）⇒ 玩家契约登记其**存在与依赖**，⛔ 不定序（定序归 `12`）。

### 3. `B6` 渲染侧降级（`12 §0.3 规则 C`）

- `12` 原话（用户）：「**我只需要在不活跃的地带做渲染的性能优化就行了**」⇒ ⭐ **优先在渲染侧省**：只在**不活跃地带**做 **LOD／视距／特效降级**。
- **玩家侧适配** ＝ 表现层性能策略（⛔ 与逻辑无关，⛔ 不动决策侧）。
- ⚠️ 与 `03_玩家分支/表现与音频契约.md` 的**表现规则**相邻；本契约只登记**系统层授权的降级面**。

### 4. `B7` `DaySettledEvent` 的 UI 消费（`12 §五`）

- `12 §五`「订」栏：`DaySettledEvent` ＝「今日结算全部完成」；消费方 ＝ `SaveManager`（存档）＋ **UI**。
- **玩家侧适配** ＝ UI 在结算完成后刷新（与 `B5` 的三个 UI 订阅者互为印证）。
