## 一、定位与红线（**【定案】**）

**定位**：**纯表现层**系统 —— 只**只读消费**世界状态，**绝不写入世界**；不改 `KingdomState`／单位／建筑；不进 `AI.Core`／sim；不参与确定性决策与胜负判定。

**红线（源 `3.8:34-41` · 违反即 FAIL）**

1. **零世界写入**（表现层豁免）—— 验收须能证明「**关掉音频 ⇒ 世界逐字节一致**」。
2. **不进 `AI.Core` / sim**，不支持任何判定逻辑（**禁判官化**）。
3. **不做阵营过滤** —— 音效对**所有阵营一视同仁**（⛔ 禁「只对玩家发声」的约束／信息特权）。
4. **`AudioSource` 必须池化**，⛔ 禁每事件 `new`。
5. **与 `timeScale` 完全解耦**（用 `unscaled`/realtime 驱动），音频不得随倍速加速或失真。
6. ⛔ **不得变相引导玩家**（`D380`：反馈 ≠ 引导）—— 声音不提「该去点哪」。

> ⚠️ **本契约的「玩家分支」定位说明**：本契约归 `03_玩家分支`（体感／表现归属），但**红线③明令其不具玩家特权** —— 即「归属玩家分支」≠「只服务玩家」。此点须保持，⛔ 不得在后续分支化中被改写成阵营过滤。

## 二、缩放三档混音（**【定案】**）

### 2.1 三档骨架与丝滑过渡

- **三档**：**近 / 中 / 远** —— 复用相机既有 zoom 档（`CameraRig.ZoomIndex` / `zoomLods`），⛔ 不自建。
- **丝滑过渡**：档为**骨架**、**插值填缝** —— zoom 连续值同时计算「邻近两档的接近度」，各音轨增益用**缓动插值**，档切换自动 **crossfade（默认 `0.8s` · SO 可调）**，⛔ **无硬切**。

### 2.2 可听门限曲线（中档折中 · 并入连续模型）

| 档 | zoom（视口） | SFX 总增益 | 可听门限 | 效果 |
|---|---|---|---|---|
| 近 | 小 | 高 | 低 | 细节音效全过（伐木／战斗／建造……） |
| 中 | 中 | 中 | 中 | 仅 `重要度≥中`（战斗／立国……）越得过门限 ⇒ 折中「代表音」 |
| 远 | 大 | →0 | ∞ | 世界音效全关，只剩 BGM ＋ 环境 |

- ⭐ **不新增机制**：无「中档特判分支」，仅 **`重要度权重` ＋ `可听门限曲线`** 两个 SO 参数（源 `3.8:65`）。
- 世界上限：视口内世界音效**并发上限 12**，超限按优先级**抢占**，同类窗口**合并**（见 §四）。

### 2.3 焦点模型 ＝ **三因子**（**【定案】** · `3.8.1` 扩）

| 因子 | 作用 | 类型 |
|---|---|---|
| **视口矩形** | 决定「**能不能播**」 | **硬闸门** |
| **镜头中心距离** | 决定「**多重要**」 | 软权重（进 priority） |
| **玩家注意力锚点**（鼠标投影世界点） | 玩家正看的地方更响 | 额外加权 |

> ⭐ **白赚收益**：注意力锚点与 **zoom-to-cursor 的缩放锚点「是同一个点」** ⇒ 实现一次，音效加权与相机缩放**共用同一份输入**（源 `3.8.1:48`）。

### 2.4 触发时机（档位 × 可见性 × 预算 三重裁决）

| | 近档（视口小） | 中档 | 远档 |
|---|---|---|---|
| BGM | 常驻 | 常驻 | 常驻（主） |
| Ambient | 弱化 | 主 | 主 |
| **世界/NPC SFX** | **活跃（full，≤12）** | 仅 `重要度≥中` 且入可见区 ＝ 弱化代表音 | **关闭** |
| UI/播报 | 独立池 | 独立池 | 独立池 |

**可见性三区**（视口 ＋ 边缘带）：视口内 ＝ `full`；**边缘带内 ＝ 弱化**（带宽 SO 可调，默认视口外扩 **10~20%**）；带外 ＝ ⛔ **不播**。

**世界音效发声判据链**：`key ∈ 白名单 ∧ 落在视口/边缘带 ∧ priority 排得进 ≤12` → 发声；否则按 §四 抢占或合并。

> ⚠️ **判据链的输入来源已改**：⛔ 不再经 `EventBus` 订阅，改由**状态源直调**（`3.8.1` §1.1）；**判据链本身不变**（源 `3.8:80`）。

## 四、声音预算与叠加（**【定案】**）

### 4.1 分层配额（各层独立预算，互不抢占）

| 层 | 空间 | 并发预算 | 优先级 |
|---|---|---|---|
| BGM | 2D | 1（常驻） | 最高，永不被抢 |
| Ambient 区域环境 | 2D | 2–4 | 中 |
| **世界/NPC SFX** | 3D | **12（出厂默认）** | 竞争层 |
| UI/播报 | 2D | 独立小池（约 4） | 不占世界预算 |

⭐ **池容量 ＝ 24**（＝ 世界 12 ＋ 环境 4 ＋ UI 4 ＋ BGM 1 ＋ **抢占余量 3**）（用户裁定值 · 源 `3.8.1:200`）。

### 4.2 超预算 ＝ 优先级抢占（⛔ **不排队**）

- `priority = w₁·事件重要度 + w₂·接近度(视口内/边缘带) + w₃·距离衰减(−) − w₄·最近播放惩罚 + w₅·注意力锚点加成`。
- 命中上限时：新 `priority` > 当前最低 ⇒ **抢占**（被抢者 **0.1s fade-out**，防爆音）；否则 ⇒ **丢弃**。
- ⭐ **为何不排队**：**声音延迟 >200ms 即音画不同步** ⇒ 实时音频**宁可缺、不可迟**。⛔ **禁照抄 `OverheadSpeechManager` 的「超限入轮转队列」**（对**文字**成立，对**声音**不成立）。
- ⭐ **排序按行为类型分层**（`3.8.1` 改判）：**战斗/威胁 > 建造 > 采集** —— ⛔ **是按行为类型、非按阵营** ⇒ 红线③（不分阵营）**仍成立、未开口子**。动机：同屏 AI 单位远多于玩家，纯拼 priority 会让 AI 的伐木音吃满 12 条预算。

### 4.3 同类事件 ＝ 窗口合并 ＋ 变体（防「机关枪」与相位爆音）

- 同一类事件在**时间窗（默认 `120ms`）内合并为单次代表音**，音量按计数**对数微增**。
- 叠 **`pitch ±10~15%` 随机 ＋ 同音效变体池轮播**，避免完全同相叠加（⚠️ 源 `3.8` 原写 ±5% ⇒ **`3.8.1` 判定「±5 不足」**，以 **±10~15%** 为准）。

### 4.4 相互掩盖的治理

- **响度预算**：SFX 总线挂 **Limiter/Compressor**，防叠加爆音；
- **素材归一化**：入库音效统一响度（建议 **−16 LUFS**）；
- **Ducking（开）**：`重要度≥高` 事件（战斗/立国等）触发时，BGM/Ambient 自动 **−6~−10dB** 让位，播完恢复。

### 4.5 距离 × 可见性

3D 距离衰减 ＋ 每类**最大可听半径**（超出不播 ＝ 省预算）；配合 §2.4 可见性三区。

### 5.2 pitch 曲线（**【定案】**）

- **BGM 不加速**（氛围层，加速变调且破坏情绪）。
- **音效**：`pitch = 1 + k × max(0, timeScale − 1)`，`k` 与封顶**走 SO**（⛔ 禁硬编码），**只上行** —— `0.5x` 档**不降 pitch**（降八度会低沉怪异）。
- 出厂建议 `k=0.05`／封顶 `1.12` ⇒ `0.5x→1.00  1x→1.00  2x→1.05  3x→1.10`。

**哪些变速**（判据 ＝ 该音效的「**语义时长**」是否挂钩游戏世界时间）：

| 变速 ✅ | 不变 ❌ |
|---|---|
| A1／A2／A3 劳作 · A3b 农作 · A5 施工 · A8 近战命中 · A9 远程命中 · A10 野怪 | A5b 完工升级 · A6 拆除倒塌 · A11 立国/灭国 · B1~B4 环境 · C BGM · D UI 点击 |

- **loop 改按次 one-shot**：伐木/施工由「长 loop」改为「**敲一下响一声**」的密集 one-shot ⇒ ①密度自动跟倍速、不变调、节拍天然咬合；②**顺带解决防齐声**（长 loop 无法随机化相位，一旦错开即永久错开）。

### 5.3 时间基（**【定案】**）

- **BGM／环境／UI**：`unscaled`（不受倍速）。
- **世界音效**：随倍速的只是 **pitch 微升**（§5.2），**播放速率本身不变调** ⇒ ⛔ **不使用 `scaled`**（避免高倍速下整体变调失真）。与美术侧 `Time.deltaTime`（scaled）的分工：动画随倍速加速，音效靠「按次触发密度 ＋ pitch 微升」咬合。

### 5.4 暂停／失焦／音量分轨（**【定案】**）

- **暂停**：**留 BGM**，静 Ambient ＋ 世界 SFX（用户确认）。
- **失焦**：**整体静音**（用户确认）。
- **音量分轨**：`BGM / SFX / Ambient / UI` **四条独立音量**（扩展 `2_13` 设置面板 `D240`）；主音量沿用 `AudioListener.volume`。

## 六、播放器规格（**【定案】**）

### 6.1 架构与数据流

```text
状态源（唯一）：NPCBrain / TaskScheduler / DamageSystem / ProjectileManager
    │ PlayWorld(key, worldPos, host, ownerId) / StopWorld(handle) / PlayUI(key) / PlayBgm(slot)
    ▼
AudioDirector（单例 · GameScene 音频根 · 直调入口）
    ├─ 可见性门限（公共只读服务）→ 距离/最大可听半径 → priority 计算
    └─ 产出 AudioRequest（类目/坐标/重要度/变体池/宿主句柄）
    ▼
VoiceManager（播放器核心 · 与 SpriteAnimatorSystem 同构）
    ├─ VoiceRecord[] 平铺结构体数组 ＋ AudioSource 池（PlayOneShot 复用）
    └─ 遍历：过期回收 / 窗口合并 / 分层抢占 / 脏写
    ▼
AudioSource（2D/3D 点音源）
CameraRig.zoom ──► ZoomAudioMixer（三档 crossfade ＋ Ducking）──► AudioMixer 各音轨增益
SettingsPanel ──► AudioConfig 四轨音量
```

### 6.2 三组件职责（⭐ **4 → 3**）

| 组件 | 职责 | ⛔ 不做 |
|---|---|---|
| `AudioDirector` | 总控：直调入口、可见性门限、priority 计算、分层预算、生命周期编排（含 `ResetState`） | 不管播放句柄、不碰 Mixer 增益 |
| `VoiceManager` | 播放器本体：池／按次触发／窗口合并／变体随机／pitch 曲线／宿主销毁清理／回调 | 不做决策、不反向驱动逻辑（红线） |
| `ZoomAudioMixer` | zoom → 各音轨增益插值、三档 crossfade、Ducking | 不决定「听什么」（只决定「多响」） |

> ⚠️ 原 `AudioEventRouter`（职责＝订阅 `EventBus`）**在直调范式下不存在** ⇒ 其「过滤可见性/距离 → 产出请求」职责并入 `AudioDirector`（源 `3.8:47`／`3.8.1:32`／`:154`）。

### 6.3 数据结构（建议草案 · 执行端可按实现微调字段组织，⛔ **但不得违反 §6.5 纪律与功能口径**）

```csharp
public enum AudioLayer    { BGM, Ambient, WorldSFX, UI }
public enum AudioCategory { Harvest, Construction, Combat, Threat, Kingdom, Ambient, BGM, UI }
public enum SpatialMode   { TwoD, ThreeD }
public enum PlayKind      { Once, Burst }              // 一次性 / 按次密集（原 loop）

struct VoiceRecord { int handleId; Transform host; AudioKey key;
    AudioLayer layer; AudioCategory category; float startAt; float expireAt;
    float priority; int ownerId; int sourceIndex; bool active; }

struct AudioRequest { AudioKey key; Vector2 worldPos; Transform host;
    float importance; int ownerId; float timeScaleAtCall; }   // ownerId 只用于统计/调试，禁用于过滤
```

> ⚠️ 与源 `3.8` §3.4 的差异：`AudioCategory` **去掉 `Transport`**（因 A7 搬运不做）⇒ 9 值 → **8 值**（以 `3.8.1` 为准）。

**表面 API**：`PlayWorld(k, worldPos, host, ownerId) → handleId`（`-1` ＝ 被丢弃）｜`StopWorld(handleId)`／`StopAllOfHost(host)`｜`PlayUI(key)`／`PlayBgm(slot)`／`StopBgm()`｜`ResetState()`｜预留 `OnVoiceEnd(handleId)`（⭐ **只预留不接逻辑**）。

**SO 配置 `AudioConfig`（出厂建议）**：`maxWorldVoices=12`｜`poolCapacity=24`｜`ambientVoices=4`｜`uiVoices=4`｜`sameTypeWindowMs=120`｜`pitchJitterPercent=±10~15`｜`volumeJitterDb=±3`｜`speedPitchK=0.05`｜`speedPitchCap=1.12`｜`crossfadeSec=0.8`｜`duckDb=−8 / duckAttackMs / duckReleaseMs`｜`zoomBandThresholds`（三档）｜`edgeBandPercent=10~20`（⭐ **由公共只读服务持有**）｜`priorityWeights{w₁..w₄}`｜`maxAudibleRadiusDefault`。

### 6.5 实现纪律（**硬** · 12 条）

1. **零世界写入** —— 音频开关两态下同 seed 世界状态**逐字节一致**。
2. **直调单向** —— ⛔ 禁反向驱动逻辑。
3. **不排队** —— 超预算即丢弃。
4. **零 GC** —— 遍历路径零分配（⛔ 无 LINQ／闭包／字符串拼接）；变体池注册表一次构建。
5. **枚举键** —— `AudioKey` 用 int 枚举，⛔ 禁每帧字符串比较。
6. **禁每声 `new`** —— `AudioSource` 一律池化 ＋ `PlayOneShot` 复用。
7. **池成对** —— 借出↔归还、`Subscribe↔Unsubscribe`（若未来有）、Mixer 改值↔`ResetState` 还原，**全部成对**。
8. **不引导** —— ⛔ 不做 `D380` 引导。
9. **不分阵营** —— `ownerId` 只进统计/调试，⛔ **禁进过滤**。
10. **静默回退** —— 缺素材负查询缓存 ＋ 一次性告警。
11. **`scaled` 边界** —— BGM/环境/UI 走 `unscaled`；世界音效播放速率**不变**，仅 pitch 微升。
12. **判据同源** —— 可见性**必须**调公共只读服务，⛔ **禁自建第二套视口判据**。

### 6.6 否决清单（钉死，防自由发挥）

| 档 | 否决理由 | 重启条件 |
|---|---|---|
| 走 `EventBus` 订阅（源 `3.8` 原案） | 现库事件面不足（18 条中 11 条无源）＋ 与美术侧双轨 | ⛔ **无**（已改直调） |
| 音频整体随 `timeScale` 变速（`scaled`） | 高倍速下变调失真 | ⛔ 无 |
| 长 loop ＋ 变相位防齐声 | 相位一旦错开即永久错开，无法随机化 | ⛔ 无 |
| 超预算排队延迟播放 | 声音延迟 >200ms 即音画不同步 | ⛔ 无 |
| 命中音材质分层（金属/血肉/木石） | 本轮裁定不做 | 有明确「听感分不出材质」实盘反馈时 |
| 挥击起手／格挡音 | 格挡**无机制**；挥击起手非用户所需 | 格挡机制立项时 |
| 按阵营过滤（「只给玩家发声」） | 破镜像红线 | ⛔ **永不解禁** |
| 自建第二套可见性判据 | 双轨断链温床（`2_24` §二） | ⛔ 无 |
| 运行时 `Resources.Load` 每个音效 | 卡顿＋GC | ⛔ 无（走 `AudioBank` 预载） |
| 混响／空间化编辑／DSP 创作 | 帧精灵 ＋ 点音源用不到 | ⛔ 无 |

### 8.4 LOD：双轴分治（**【定案】**）

| 轴 | 权威 | 理由 |
|---|---|---|
| **能不能听到** | **视口（玩家视角）** | 相机拉远时，哪怕区块 AI 热度爆表，玩家也看不见 ⇒ 不该全播 |

## 九、性能预算与验收（**【定案】**）

### 9.1 性能预算

| 项 | 预算 | 判法 |
|---|---|---|
| 播放器 `Update` 推进 | **<0.05ms/帧**（24 池上限下） | Profiler 截图 |
| `AudioSource` 运行期 `new` | **0 次**（稳态） | 池命中率计数 |
| GC alloc | **0 B/帧**（稳态） | Profiler GC Alloc 列 |
| DSP 占用 | 活动 source **≤ 24** | Audio Profiler |

### 9.2 行为级探针（**P1~P9**）

| # | 探针 | 判据 |
|---|---|---|
| P1 | 直调生效 | `TaskScheduler` 进入 `Working` → 对应工种音发声，**无 `EventBus` 订阅** |
| P2 | 三因子 priority | 同屏构造「近处采集 vs 远处战斗」→ 战斗保位、采集让位 |
| P3 | 抢占用分层 | 世界音效超 12 → 抢占**最低 priority**（被抢者 0.1s fade-out，无爆音） |
| P4 | 不排队 | 超预算的新事件**被丢弃**（不延迟发声）；计数可见于调试面板 |
| P5 | 同类窗口合并 | 同帧 N 次同 key → **1 次代表音**（＋变体） |
| P6 | 防齐声 | 100 工人跨 5s 开工 → 无整块同相叠加（频谱/听感双证） |
| P7 | 倍速 pitch | 1x/2x/3x 三档下受时间影响条目 pitch 分别 ≈ 1.00／1.05／1.10；**0.5x 不降调**；**BGM 全档不变** |
| P8 | 宿主销毁清理 | 工人死亡/建筑拆除 → 对应 loop 即停（0.1s 淡出）＋ 池归还，**零泄漏** |
| P9 | 可见性同源 | 同一位置对「头顶冒泡」与「音效」给出**相同**可见性判定（调同一服务） |

### 9.3 配套验收

- **暂停/恢复**：暂停静 SFX；恢复后 loop **续播**（进度保留，非从头）。
- **失焦**：整体静音，恢复还原。
- **多次建局**：`WorldLifecycle.ResetState` 后零残留（冒烟必备）。
- **零世界写入**：音频开关两态下同 seed **逐字节一致**。
- **zoom-to-cursor**：拖动中锚点跟手；落定后**吸附回像素网格**；地图边缘**静默失效**（不抖不绞）。

### 9.4 行为级探针（源 `3.8` §七 另有 7 条 · 与上表同源，此处不重复）

zoom 档切换增益变化 ＋ crossfade 生效（无硬切）／世界事件 → 发声计数／并发超 12 → 抢占／同类窗口合并／Ducking 压低与恢复／暂停失焦三态／**零世界写入证明**（音频开关两态同 seed 世界状态逐字节一致）。
**冒烟**：多次建局零残留（`WorldLifecycle.ResetState`）；同 seed 事件序一致。**性能**：12 上限下 GC/CPU 无飙升；池命中率（⛔ 禁运行期 `new`）。
