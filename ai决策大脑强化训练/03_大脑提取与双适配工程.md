# 03 大脑提取与双适配工程（M1 施工单）

> 目标：决策核脱离 UnityEngine，同一份 .cs 同时编进 Unity 与控制台模拟器。
> 好消息（实测结论）：**核已半纯**——L1/L2/L3/RetreatFormulas/ThreatAssessment/HysteresisQuantizer/FactorContext/DecisionStructs/AttentionSystem 只用了 Mathf+Vector2，时间全部 dt 参数注入，零协程、零物理、RNG 全目录仅 1 处。真正的接缝只有 5 类。

## 一、5 类接缝与解法（全部实测定位）

## 二、接口设计（草案，照抄可用）

```csharp
// 核内抽象（放 AI.Core/Ports/）
public interface IUnitHandle {
    Vector2X Position { get; }
    Faction Faction { get; }
    bool IsAlive { get; }                       // 替代伪 null 检测
    int CurrentHp { get; } int MaxHp { get; }
    int Attack { get; } int Defense { get; }
    float WalkSpeed { get; }
    ProfessionSnapshot Profession { get; }      // 替代 NpcProfessionDef
}
public interface IClock { float Now { get; } }                 // Unity: Time.time；Sim: tick×0.1
public interface IRngPort { float Range(float min, float max); } // Unity: UnityEngine.Random；Sim: 种子 System.Random
public interface IWorldQuery {
    float CellSize { get; }
    float GetHeatAt(Vector2X pos);
    bool TryGetHotspot(Vector2X pos, float maxAge, out Vector2X hotspot);
    void QueryUnitsInCell(int cx, int cy, List<IUnitHandle> results);
}
public interface IMovable {                                    // BehaviorExecutor 的移动出口
    void MoveTowards(Vector2X dest, float speed, float dt);
    void Stop();
}
```

- Unity 适配器：UnitController 实现 IUnitHandle/IMovable；GridSystem/LODSystem 包一层实现 IWorldQuery
- 模拟器适配器：SimUnit / SimWorld 实现全部接口

## 三、配置快照方案（接缝 4 的落地）

```
TuningSnapshot（POCO，~60 字段，与 AttentionTuningConfig 一一对应）
ProfessionSnapshot（POCO，NpcProfessionDef 字段拷贝）
```

- Unity 侧：`AttentionTuningConfig.ToSnapshot()` / `NpcProfessionDef.ToSnapshot()`（各 ~30 行机械拷贝，一次性写）
- 核内全部改吃快照（FactorContext.Config 类型换掉，机械替换）
- harness 侧：System.Text.Json 从 `tuning.base.json + patch.json` 反序列化出快照
- **这是一致性的关键**：Unity 的 SO 值与 harness 的 JSON 值从同一默认值表生成，改一处同步

## 四、Vector2/Mathf 处理：最小 shim（~80 行）

```csharp
// AI.Core/Shim/Vector2X.cs：struct{x,y} + Distance/ normalized/Lerp/MoveTowards
// AI.Core/Shim/MathfX.cs：Clamp/Clamp01/Max/Min/Lerp/RoundToInt/CeilToInt/Exp/Sin/Abs
```

核内 `Vector2→Vector2X`、`Mathf→MathfX` 机械替换。**不自造轮子引第三方数学库**——需求只有二维加减乘除，80 行 shim 最稳。
