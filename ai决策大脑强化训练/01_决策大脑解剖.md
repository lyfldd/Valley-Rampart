## 一、双层架构总览

```
军队级（秒级，1Hz）                    个体级（10Hz think 分片 + 每帧 Execute）
FormationManager（注册表）
  └─ FormationController（挂将军）      NPCBrain（MonoBehaviour 壳）
       └─ FormationBrain 意图自决  →  军令 → FollowStimulus ──→ 三层管线
          输入：LOD热度/热点/存活率/任务价值                       L1 焦点 → L2 谱系 → L3 指令
          输出：SetIntent/SetAdvanceTarget                        → BehaviorExecutor 六模块执行
```

- 军队定"去哪、什么战术、值不值得拼"（位置+意图+任务价值），个体定"打谁、撤不撤"
- 协作靠 LOD 热点涌现，不写编队间 if-else（3.0.1_5 §4.1）
- 军令强度：正常 4.5（`formationOrderIntensity`），切阵型瞬时 6.0 保底 1s（`_boostUntil`），君主令期内带 `IsRoyalCommand`（FormationController.cs:43-52,374,389,406；值住 AttentionTuningConfig）

## 三、军队级管线（FormationBrain）

- 节奏：`decisionInterval=1s`（FormationBrain.cs:58-65）
- 输入：本地热度 `LODSystem.GetHeatAt(anchor)`、跨中区块热点 `TryGetNearestCombatHotspot(anchor, 5s, 30)`、存活率 `MemberCount/6`、任务价值 `EvaluateTaskValue`（:74-79）
- 决策 5 分支（:82-108）：① 残编(<0.4)+被压(heat≥0.3) → Retreat；② 远热点+本地无激战 → 支援 Charge；③ heat>0.6 且 value>0.6 → Charge；④ heat>0.3 → Defense；⑤ 低热维持
- 意图枚举：`TacticIntent{Defense,Charge,Retreat}`（FormationEnums.cs:14-19）
- 任务价值（config 可调）：守 0.5 / 攻 0.8 / 巡 0.2 + 修正（taskValueGarrison/Attack/Patrol，FormationBrain.cs:118-131）
- 传导链：任务价值 → 维持意图 → 军令强度 → 编队抵抗 → 个体撤退阈值（3.0.1_5 §4.2）

## 五、五综合因子详解（3.0.1_8 核心资产）

| 因子 | 公式 | 计算处 | 主要消费者 |
|------|------|--------|-----------|
| ThreatFactor 0-1 | = 上帧 rawFactor 透传（6 小因子加权：dist0.35/count0.15/hp0.2/ally0.2/time0.1/heat0.5 + 职业敏感度 + 贴脸保底0.5） | ThreatAssessment.cs:61 → NPCBrain.cs:507 | L2 有效威胁、破阵博弈 |
| FormationFactor 0-1 | = FollowStimulus.Intensity / 4.5（切阵型瞬时可达 1.33→clamp） | NPCBrain.cs:508-510 | L2 编队抵抗、坚持任务收益 |
| SafetyFactor 0-1 | = 离家×0.4 + 夜晚×0.35 + 受伤×0.45 | ComputeSafetyFactor NPCBrain.cs:520 | L2 撤退 AND 门控（>0.3） |
| AbandonTaskFactor 0-1 | = clamp01(成本4项 − 收益5项)；收益：可击杀0.6/军令0.4×FF/装备0.3/敌弱防0.2/移速0.3；成本：受伤0.4/孤军0.3/超时0.4(6s)/距离拉大0.3；君主令恒 0 | ComputeAbandonTaskFactor NPCBrain.cs:551 | L2 放弃追击→归位（>0.5） |
| WorkFactor 0-1 | = 任务焦点时 priorityWeight/4（S1/A0.75/B0.5/C0.25），非任务焦点=0 | ComputeWorkFactor NPCBrain.cs:537 | L2 工作抵抗 |

**L2 连续仲裁核心式**（L2PostureDecider.cs:58-95）：
```
撤退阈值 threshold = max(0.2, (2 + (courage−50)/50 + (obedience−50)/100 + retreatThresholdOffset)/3)
编队抵抗 = FormationFactor × (0.5 + obedience/100) × 0.4     ← 0.4 硬编码
工作抵抗 = WorkFactor × workResistScale(0.5)                    ← config
有效威胁 = ThreatFactor × (1 − 编队抵抗 − 工作抵抗)             ← 总抗性封顶 0.95
有效威胁 > threshold 且（非编队 或 SafetyFactor > 0.3）→ FullRetreat
ThreatFactor < 0.3 → FullPower（硬编码低威胁线）
```

## 七、撤退判定链（无 IRetreatRule，收敛于 L2）

`L2PostureDecider.DecideRetreatSubtype`（:105-133）三规则顺序：
1. `HitCount >= maxHitCount`（工人3/士兵99）→ 战略撤退回 HomePoint
2. 焦点是活跃 ThreatStimulus 且有 Enemy → 战术短撤（方向=自身−敌人，距离走 RetreatFormulas.RetreatDistance）
3. 无威胁焦点但威胁超阈 → 战略撤退回 HomePoint
前置闸门：`有效威胁 > threshold` 且（非编队 或 SafetyFactor>0.3）。
