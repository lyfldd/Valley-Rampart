# 04 Headless 模拟器规格（M2 施工单）

> 目标：1D 点单位世界，秒级跑完一场战斗，产出与 Unity 同构的行为与结果。
> 阿铁定案的简化：**弓箭手=直线命中打得远、士兵=点**。本文把简化 formalize 成"保真度契约"。

---

## 一、世界模型

```
SimWorld（1D 数轴，x 单位=世界坐标，cellSize=2.26 与 Unity 一致）
├ SimUnit[]：x / hp / attack / defense / range / cd / walkSpeed / faction / profession快照
│            / 决策核实例（L1/L2/L3+记忆组件）/ 编队槽位
├ SimGrid：格子字典（复刻 GridSystem 的 TryEnter/GetUnitsInCell，1D 只需 x 向）
├ SimHeat：中区块热度表（复刻 LOD 热度累积/衰减/扩散——FormationBrain 的输入）
├ SimDamage：伤害时间轮（§三复刻要点）
└ SimClock：tick=0.1s 步进；IClock.Now = tick×0.1
```

**无 y 层**：Unity 的 y=0/1 双层（地面/空中）在模拟器全部压平为地面层（战斗单位不飞）。

## 二、tick 循环（每 0.1s 固定顺序——判定顺序是保真的命脉）

```
1. clock 步进
2. 感知刷新（每 2 tick=0.2s）：线性扫 SimGrid，阵营过滤+距离精判（复刻 PerceptionSystem）
3. think（每 tick；v0 不分片，差异见 §四）：BuildBaseContext → 记忆Tick → L1 → 因子补算 → L2 → rawFactor → L3
4. 攻击注册/注销（复刻 UpdateCombatRegistration 的射程判定）
5. 伤害时间轮：CD 到点者结算（近战即时 / 远程 hitscan 延迟 1 tick）
6. 移动积分：executor.Execute(dt=0.1) → x += speed×dt（锁 1D）+ 抵达判定 0.3×cellSize
7. 死亡结算：hp≤0 → 移除 + overkill 表清理 + 编队减员通知
8. 事件落盘：JSONL append
```

## 四、已知差异清单（诚实声明，差异≠缺陷）

| 差异 | Unity | 模拟器 v0 | 影响评估 |
|------|-------|----------|---------|
| 弓箭命中 | 抛物线飞行+落点最近者命中 | **直线 hitscan + 固定 1 tick 延迟** | 阿铁定案简化；弹速差异抹平（Undead_Archer 弹速25 vs 人类15 失效），可接受 |
| 弹道误差圆 | projectileErrorRadius=0 | 无 | 现配置本来就是 0，无差异 |
| think 分片 | 5 片错帧 | 不分片全量每 tick | 同帧决策顺序略变，对结果影响微小；v1 可复刻 |
| LOD 降频 | 活跃10Hz/半2Hz/休眠0.5Hz | 全活跃 10Hz | sim 场景规模小无需降频；行为差异：远方单位不会"变傻"——**这正是我们想要的**（测的是脑子不是调度） |
| 对象池/视觉 | 有 | 无 | 与行为无关 |
| RNG | 漫游+弹道误差 2 处 | 同 2 处，种子注入 | 确定性基础 |

## 五、FormationBrain 在模拟器中的处理

- **v0**：军队意图用**剧本脚本**驱动（场景 JSON 里写时间线：`t=5s SetIntent(Charge)`）——先测个体脑+编队机制
- **v1**：FormationBrain 决策逻辑已在核内（03 迁移步 5），接 SimHeat 即可自动意图——再测军队级大脑
- 这样 v0 就能回答"白嫖/破阵/撤退"手感问题，v1 才回答"将军蠢不蠢"

## 七、确定性（同卷考试的前提）

1. 所有 RNG 走 IRngPort（种子=场景 seed）——全代码仅漫游+弹道误差 2 处
2. 固定判定顺序（§二 8 步）+ 单位数组按 spawn 顺序遍历（不用字典序）
3. float 运算禁并行化乱序（v0 单线程；并行按"每局一个进程/任务"粒度，局内单线程）
4. **M3 验收：同配置同 seed 跑两次，JSONL 逐字节一致**


### 指标（打分态，harness 聚合）
- 结果类：胜率 / 战损比 / 平均时长 / 全灭率
- 行为类：弓手被贴身总时长（白嫖指标）/ 破阵次数 / 撤退时机分布 / 槽位偏差均值 / 放弃追击次数
- 目标函数 v0：`score = 胜率×0.4 + 战损比归一×0.3 − 弓手被贴身率×0.2 + 槽位保持×0.1`（权重本身也是 T1 参数，champion 机制管理）

## 九、性能目标

单局（30 单位 × 60s 模拟）< 10ms → 单核 100 局/s；200 局评估一套参数 < 3s。
瓶颈预判：感知线性扫描（30 单位无所谓）；**到 200+ 单位再考虑格子优化**。
